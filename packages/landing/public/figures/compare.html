一、图 1（SkillAdam 容器内自进化机制）— 6 版候选对比

版本 SA-V1：对称双大框（左浅蓝 Task Rollout vs. 右浅紫 SkillAdam Revision） 当前默认挂载 · 与图 2 的左蓝右紫双大框 100% 呼应

构图特点：左边浅蓝框 Task Rollout (1 Shared Container) 展示 SKILL.md → 3+2 训练题池 → Online Judge；右边浅紫框 SkillAdam Revision 将 Issue Tracker (EIT) 与 Edit Budget (▼→●○○○ / ▲→●●●●) 合并为 Bounded Patch，再经 Mean Gate 分出采纳回流与拒绝记账。

版本 SA-V2：左中右三阶段色块（1. Task Rollout → 2. Adam Controller → 3. Mean Gate） 浅蓝 + 浅紫 + 浅绿三段式

构图特点：把流程拆成左（实测判分）、中（一阶 EIT 账本 + 二阶方差预算 → 受限补丁）、右（均值门控采纳/回退）三个独立色块面板，层次分明。

版本 SA-V3：上下顺时针双轨闭环（上排从左到右 Rollout → 下排从右到左 Revision → 右侧导出 Evolved Agent） 顺时针闭环 · 无外部长回流线

构图特点：在同一个 1 Shared Container 内，上轨从左向右执行 Agent + SKILL.md → 3+2 训练题池 → Online Judge，下轨从右向左完成 EIT & Budget → Bounded Patch → Mean Gate，左侧直接向上闭环更新 SKILL.md，右侧导出绿色的 Evolved Agent (+ SKILL.md)。

版本 SA-V4：纯水平中轴分叉-汇合树（1 → 2 → 1 → 2 对称树，零外部回流线） 复刻图 2 版本 1 的水平中轴对称分叉树

构图特点：完全采用图 2 版本 1 的“水平中轴分叉-汇合”结构——左边 Base Agent 🔄 3+2 训练题池 → Online Judge，进入右边浅紫框后水平一分二为 Issue Tracker (EIT) 和 Edit Budget，二合一进入 Bounded Patch → Mean Gate，最后水平一分二输出 ✔ Accept 与 ⊗ Reject，全图没有任何绕外圈的回流线。

版本 SA-V5：左全景 + 右放大（左边直接复用图 2 的训练容器框，右边放大展开中间的循环符号 🔄） 左宏观 + 右微观 Zoom-In

构图特点：左边浅蓝框与图 2 的左半部分完全一致（Base Agent 🔄 3+2 训练题池 → Evolved Agent），右边浅紫框专门把中间的 🔄 放大展开为 Online Judge → [EIT + Edit Budget] → Bounded Patch → Mean Gate。

版本 SA-V6：上主干四步直线流 + 下通栏持久状态底座（Persistent SkillAdam State） 极简上下分栏

构图特点：上方 4 张等高卡片从左到右直线排列（5 Train Tasks → Online Judge → Bounded Patch → Mean Gate）；下方一条通栏紫色底座并列放置 Issue Tracker (EIT) 与 Volatility Edit Budget，仅用两根垂直短箭头与上方主干交互。
