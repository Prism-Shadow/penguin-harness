> Written for PenguinHarness 0.2.16. Later releases may differ in some details.

Context slope is per-request context growth. Anthropic frames LLM context as a finite, depletable resource.[^1] Long inputs trigger context rot and accuracy drops even within advertised windows, and compaction adds latency, cost, cache misses, and detail loss.[^1][^2][^3] The Self-Manager paper, LangWatch, and TraceLab measure this per-request growth under other names.[^4][^5][^6] We found no prior use of "context slope" and offer it as a unifying design lens.[^7] Managing context slope is the harness's core job, with concrete rules for Skills, tool output, CLI, and MCP.

## Intercept and slope, the two numbers
We split per-request context cost into two parts. A fixed intercept (system prompt, tool definitions) rides every request. Per-request slope is what each step adds: tool output, loaded instructions, replies.

OpenAI reports inference cost grows quadratically with sent JSON without prompt caching; caching pulls growth near linear.[^8][^9]

Cutting the intercept lowers every request's baseline cost. Flattening slope delays or removes the need for compaction, our backstop. Compaction fires at the threshold, replaces context with a lossy summary; in simulation the new context's first request reads nothing from cache.[^1][^10][^11]

We measured per-request context growth with and without the shipped output cap, using a synthetic fixture of identical 64k build-log reads. Sizes are character-based estimates, not provider counts; no live provider was hit. Uncapped runs hit the threshold in 12 requests.[^10][^12][^13]

The first lever is cutting this intercept.

## Progressive loading cuts the fixed intercept

Skill design is the clearest intercept control example.

The industry standard for Skills is progressive disclosure: send only a name and short description per Skill up front, load full instructions on demand.[^14][^15][^16]

In PenguinHarness 0.2.16, the system prompt lists one line per installed Skill; the model reads bodies on demand with `read_file` or shell calls.[^17][^18][^19]

Two exceptions break this index-first rule: `AGENTS.md` is injected whole and uncapped, and every MCP tool definition rides every request.[^17][^18][^20]

Loaded Skill bodies stay in the current context until compaction replaces history with a summary, so progressive loading cuts fixed intercept rather than eliminating slope entirely.[^21]

Intercept cuts are insufficient on their own; most per-turn slope comes from tool output.

## Disk-backed caps flatten per-turn growth

In our synthetic fixture runs, unconstrained tool output drives steep per-turn growth, with uncapped logs quickly nearing compaction.[^12]

PenguinHarness defaults to a 16,000-character cap per tool result, keeping head and tail to preserve exit codes and errors.[^22][^23] Over-cap output is saved to a session scratchpad recovery file (up to 8 MiB per call), with its path appended inline.[^22][^24][^25] The model reads slices via existing file tools.[^24][^25]

Above the cap, per-turn growth holds steady regardless of raw output size.[^12] Claude Code and Cursor also persist oversized output to disk.[^26][^27][^28] We think lower inline overhead, like Claude Code's path-plus-preview, would flatten slope further, but PenguinHarness does not ship it today.

This inline-slice plus on-disk rule applies to CLI and MCP interfaces as well.

## CLI and MCP follow the same slope rule

The shipped browser-automation plugin adds no tool schemas to the intercept.[^29][^30] Its `penguin browser` command runs via `exec_command`: `scan` caps at 35,000 characters, `exec` prints at most 8,000, and `--save` writes full results to disk.[^31][^32][^33]

`penguin run --json` returns only the child's assistant text, so CLI-delegated tool traffic stays out of the context.[^34]

Simon Willison notes models know `--help`, so CLIs need little upfront description.[^35] Zechner's 120-run benchmark found well-designed MCP and CLI are a wash.[^36]

As of 0.2.16, PenguinHarness loads all discovered MCP schemas on every request, with no deferred loading.[^20][^22][^25] Anthropic reports Tool Search cut one example from about 77K to about 8.7K tokens.[^37] Cloudflare: Code Mode cuts MCP cost from 1.17 million to 1,000 tokens.[^38]
