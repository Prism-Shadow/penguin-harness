PenguinHarness 0.2.20 是基于 0.2.19 的修复版本。**桌面应用里的工作台恢复正常加载，加载失败的工作台现在提供「用 AI 修复」**。未能生成完整摘要的压缩或模型切换会在对话里展示交接说明；插件市场恢复列出已发布的索引，并写明来源失败的原因。

## 修复加载失败的工作台

**Web App 显示工作台文件加载失败的各处，现在在「重新加载」旁提供「用 AI 修复」与「[报告问题]」**。它们出现在应用中心窗口、应用中心的「查看错误」对话框，以及「Agent 设置」中该工作台那一行的「更多」菜单里。

![类型检查失败的工作台在应用中心窗口里：错误、「重新加载」「用 AI 修复」与「报告问题」](/blog-assets/penguinharness-0-2-20-workbench-fix-zh.png)

「用 AI 修复」会先请你确认，再由默认 Agent 在临时 Workspace 里开一个新对话，修复请求预填在输入框里，不代为发送。请求写明工作台、所属 Agent 与所在机器、目录和原样的加载错误，并说明加载的过程：在宿主固定的选项下对 `index.ts` 做类型检查，保存文件即重新加载，结果记在 `.build/status.json`。Agent 在改动之前会先说明打算。错误出自平台本身时（例如缺少 Node 或 TypeScript 的声明），Agent 会直接说明、不做改动，并建议报告问题。

![「用 AI 修复」在开新对话之前先请你确认](/blog-assets/penguinharness-0-2-20-workbench-confirm-zh.png)

「[报告问题]」打开共用的问题报告，附上工作台和打码后的加载错误。

## 没有摘要时，也能看到交接内容

**压缩未能生成完整摘要时，对话现在会展示新上下文改以什么开头**：就地的交接说明，或会话内切换模型时的 Trace 交接说明。它放在所接续的压缩行里，该行定格为「压缩完毕」，由状态图标说明没有摘要的原因。

![glm-5.3-flash 真实回答一轮后，从一个已不在配置中的模型切换出去：「压缩完毕」一行展开到「交接说明」，下方是「模型已切换」分隔线](/blog-assets/penguinharness-0-2-20-handover-zh.png)

这一行默认折叠。其中的「交接说明」一节依次给出原因、交接说明点名的 Trace 文件和交接说明原文。长路径在节内折行，每一行都可以选中复制。从一个已无法访问的模型切换出去时，不会向它发出任何请求，这一行会写明「原模型不可用，没有请求摘要」。在此之前，经 Trace 交接的切换只显示一条分隔线和悬停提示。

## 弄明白插件来源为何失败

**已发布的插件索引恢复列出，插件市场会写明来源读取失败的原因**。索引为十九行条目加上了不带 `url` 的 `npm` 渠道，而服务端读到第一行这样的条目就拒绝了整份文档，于是市场把一个其实已经访问到的来源报成了无法访问。现在只有安装时下载用的 `github` 渠道必须带 `url`。

![插件市场的提示展开后：一个文档被拒的来源和一个主机无法解析的来源，各附服务端给出的原因](/blog-assets/penguinharness-0-2-20-market-sources-zh.png)

插件市场提示后面的「详情」逐个列出读取失败的来源地址和服务端给出的原因，原因可以选中复制，后接「[报告问题]」。文档被拒时写明出错的条目和字段；获取失败时写明 `fetch failed` 底下的网络错误，尝试过的每个地址都会列出。

## 这一版还有

- **桌面应用**：桌面应用里的工作台恢复正常加载。0.2.19 的安装包缺少 `@types/node` 的声明文件，所有工作台都以 `TS2688` 加载失败。
- **远程机器**：机器的服务端仍在启动时，连接机器不再在「同步配置」一步失败；「机器」任务最多等它一分钟，机器拒绝时写明服务端给出的原因。
- **插件**：插件安装失败时显示 npm 自己的错误，而不是 npm 先打印的警告（例如 `npm warn Unknown user config "always-auth"`）。
- **Agent**：默认系统提示词新增六处优化，涉及交付物校验、低成本定位失败，以及长命令与常驻服务的运行（内核版本 `2026-11-26`）。
- **界面**：提示气泡里的长路径在面板内折行，不再溢出边缘。

## 升级须知

- **已有 Agent**：在「智能体」页面运行「更新内核」，让提示词仍为内置默认值的 Agent 采用优化后的默认系统提示词。
- **远程机器**：远程机器必须和服务器是同一版本。升级服务器后，请在「机器管理」页面逐台更新。
- **打开中的对话里的交接说明**：没有切换模型、压缩退回到交接说明时，「交接说明」一节要在重新加载后才出现；切换模型的交接说明即时出现。
