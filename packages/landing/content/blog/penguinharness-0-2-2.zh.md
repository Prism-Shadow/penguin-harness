PenguinHarness 0.2.2 发布了。前几版把 Agent 的手脚补齐——文件工具、子代理、技能、定时任务——这一版补的是记性：会话结束后，Agent 终于能把学到的东西留给下一次。配套的还有 MCP Server 支持、可开关的提示词注入，以及给配置本身加的版本机制。

## 记忆

每个 Agent 在 `agent_state/memory/` 下维护自己的长期笔记，分两个作用域：用户作用域每个会话都读，工作区作用域跟着目录走——同一个 Agent 在不同项目里各记各的，临时工作区则只拿用户作用域，因为不会有下一个会话回来读它。

进入上下文的只有各作用域的 `MEMORY.md` 索引（每个作用域至多 200 行、25,000 字符，超出部分注明截断），正文文件由模型在需要时用普通文件工具打开。写入、去重、合并同样全靠文件工具完成：Harness 决定记忆放在哪里、把写入圈在里面，其余是模型自己的事，没有为此新增任何工具。

设置页新增记忆标签页：按作用域分组列出全部记忆，可查看、删除（索引行同步清掉）、或经由一段预填的对话让 Agent 自己改写；两段记忆提示词也在这页直接编辑。记忆机制此前的 Agent 不受影响——模板里没有 `{{MEMORY}}` 占位符就什么都不注入，标签页会指出这一点，并提供一键插入。

## MCP Server 支持

Model Context Protocol 落在官方 TypeScript SDK v2 上，stdio、Streamable HTTP、legacy SSE 三种传输都支持。服务器工具以 `mcp__<服务器>__<工具>` 的名字进入既有的执行与审批契约，`readOnlyHint` 映射为只读权限；密钥保险柜的值不会进入任何 MCP 服务器进程;连不上的服务器跳过并告警，不拖垮会话创建——连接过程以步骤行的形式流进对话，而不是让「新建会话」卡住等它。

管理界面是表单式的：Agent 设置页新增 MCP Server 一节,可增删改配置并当场做连通性测试。工具清单从 `session_meta.tools` 移到了新的 `tool_list_ready` 事件——这是本版唯一的破坏性变更：拆分之前写下的轨迹文件不再显示其内嵌的工具记录。

## 提示词注入：占位符、开关、可编辑文本

记忆的注入模式被推广到了其余三个子系统。系统提示词模板里现在只放 `{{VAULT}}`、`{{SKILLS}}`、`{{SCHEDULES}}` 占位符，各自展开成一段随 Agent 保存、可在对应标签页下方直接编辑的提示词，页顶一个开关决定注入与否。关掉开关只影响模型看到什么——保险柜的值仍以环境变量注入子进程，已排期的任务、已装的技能也都照常工作，只是模型的系统提示词里不再出现那一段。

定时任务的默认提示词是新写的，它教模型用文件工具直接管理 `agent_state/schedule/` 下的 TOML——字段规则、五分钟的周期下限、服务端约三十秒内自动生效，都写在里面，当前任务清单也随提示词注入。也就是说，「每天早上九点跑一遍测试」这类要求，现在可以直接在对话里提，模型自己落文件。

存量 Agent 的模板在创建时就物化了旧段落，这些模板原样可用；旧默认文字没被改过的，标签页提供一键迁移到占位符写法，改过的不动。

## 配置内核版本

`system_config.yaml` 在 Agent 创建时定格，从不自动升级——好处是行为可预期，代价是新默认值只属于新 Agent。0.2.2 给配置加了内核版本：一个日期，记录这份配置基于哪一代内置默认值，创建与还原时盖章，日常编辑不动它。

日期的升级由一条守卫测试强制执行：它把全部默认值的哈希钉在版本历史表的最新条目上，改了默认值而不登记新条目，CI 直接变红。概览页在「还原为默认配置」旁边多了「更新内核」：逐字段比对历代默认值做合并——没改过的字段跟进新默认，改过的保留并按可读名称列出，认不出来历的一律保守保留。想全量刷新，旁边的还原按钮仍是兜底。

## 核心运行时

`max_turns` 默认值改为 -1（不限轮次），请求上限与压缩阈值改由模型的上下文窗口推导，小窗口的 vLLM 类部署不再需要手工调参。LLM 重试阶梯放缓到 2 秒起步，除凭证被拒外的失败全部纳入重试。

轨迹文件的写入串行化了，每条记录一次 `write(2)` 落盘，恢复会话时自动修复崩溃留下的残尾。此前偶发的轨迹损坏，来源正是大记录在 512 KiB 边界被劈开的那道缝，这一版把它补上了。

## 桌面端与 Web 应用

桌面端补上了各平台的品牌图标、任务完成的系统通知、显式的单用户模式，并随包携带 `penguin` CLI。管理员多了一个代理选项对话框：应用本身与 Agent 环境两个开关共用一个代理地址，留空跟随系统代理，回环地址始终豁免。

Web 应用这一个月的积累不少，拣要紧的说。对话头部的统计并入详情卡，会话 id 点击即复制，后台进程列表带可用的停止按钮；输入未发的文字存为侧栏草稿。设置侧：初始密码横幅可以永久关闭，锁定模型的提示精简为「输入 /model 切换模型」，详情页标签定序为概览、系统提示词、运行参数、工具、技能、记忆、密钥保险柜、定时任务（列表统计图标同序），概览页改为横线分节、State 路径可复制，共享滑动开关也修掉了点击后残留的灰色光环。离开运行中的对话不再引发全应用闪烁。

## 其余改进

模型目录：Thinking Machines Lab 的 Inkling 上架 OpenRouter 与 Fireworks AI，Fireworks 新增 DeepSeek V4 Flash 0731，GLM-5.1 的网关条目下架（Z.AI 直连保留），OpenRouter 价格按官方 API 刷新。技能库新增 `humanizer`——中英等多语言通用的去 AI 味改写技能，手动安装；这篇发布文就是按它的方法写的。依赖侧以 workspace override 强制 `@hono/node-server` ≥ 2.0.5（Windows 下 serve-static 的路径穿越通告，旧副本来自 MCP SDK 的传递依赖）与 `nanoid` ≥ 3.3.17，`pnpm audit` 归零。发布工作流拒绝版本号与仓库不一致的 tag。完整清单见 [changelog/0.2.2](https://github.com/Prism-Shadow/penguin-harness/tree/main/changelog/0.2.2)。

## 安装或升级

桌面端：前往 [penguin.ooo/download](https://penguin.ooo/download) 下载对应平台安装包。

CLI / 服务端：

```sh
curl -fsSL https://penguin.ooo/install.sh | sh
penguin web
```

Windows（PowerShell）：`irm https://penguin.ooo/install.ps1 | iex`；或在 Node >= 24 下 `npm install -g @prismshadow/penguin-cli`。已有安装直接 `penguin update`。
