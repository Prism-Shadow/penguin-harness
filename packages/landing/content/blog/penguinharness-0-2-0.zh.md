PenguinHarness 0.2.0 发布了。这一版围绕"长时间运行的工作"：对话可以导航而不是一路滚动、工具输出不会被截断上限吞掉、分发管道能到达 GitHub 不可达的机器。逐项说明：

## 长对话导航

对话页一次落地三件导航能力。

**↑ 命令行式回填历史输入。** 输入框为空时按 ↑，从最新一条开始逐条回填本会话输入过的内容；↓ 反向走回并恢复原来的草稿。编辑过的回填立即把方向键还给光标，多行条目先逐行移动光标，输入法候选导航不受影响。

**运行标题栏分层吸顶。**「Reasoning & Tools」组头钉在消息流顶部，你正滚动阅读的思考 / 工具行紧贴其下再钉一层——内容正上方的横条永远是它所属的段落，不跨层级。二十屏长的工具输出滚到任何位置都能一键收起所在段或整组，收起后视图落回该段本身。

**整场对话的迷你地图。** 一列零宽度的刻度线覆在消息流左侧留白上，每轮问答一条、当前所读加长加深；悬停弹出预览卡（问题加粗 + 截断的回答），点击直达该轮。手机上或侧面板挤占留白时，同一份索引移到右上角工具栏下拉菜单——任何布局下导航都可达。

## 截断的工具输出可找回

Agent 会话中超过单次上限的工具输出会写入会话 scratchpad，找回路径附在模型与两个前端看到的同一条截断结果末尾；需要时模型按路径读取其余部分——没有新工具、协议不变、可见上限不变。同批改动里，core 组装的所有模型可见路径在 Windows 上统一为正斜杠拼写。

## 插话与会话列表的规模化

运行中的插话现在刷新后仍在、内容可见、恰好送达一次——文件附件也能随插话送出，与图片同规。工具卡副标题不再随参数流式渲染而抖动。侧栏会话列表默认由数据库直出（CLI 会话变为可选开关），分组内列表与分组本身都分页，大量 Agent 与 Workspace 的 Project 依然快而可扫。

## 每平台一个安装包，且有镜像

每个 Release 每个平台只附一个文件：一个扁平安装包，内封原生安装器、程序负载与校验和。同一个文件同时服务在线与离线安装，两层校验无条件执行。管道新增：完全相同的字节镜像到阿里云 OSS，安装器优先走镜像、自动回退同版本 GitHub（`PENGUIN_DOWNLOAD_SOURCE=auto|oss|github`）。原地升级也能在钉住占用目录的文件系统上完成，Windows 包移除了会被执行策略拦下的 `penguin.ps1` 启动器——直接敲 `penguin` 不受影响。

## 跟上时代的模型目录

qianwenai 分组换到当前阵容——qwen3.8-max 与 deepseek-v4-flash-0731 上架，退役的 preview 下架——OpenRouter 新增 deepseek/deepseek-v4-flash-0731 与 openai/gpt-5.6-luna，各网关行价格按模型 API 重新读取，新 Project 默认 deepseek-v4-flash。已有 Project 保持原有模型与默认值不变。

## 其余改进

`read_file` / `edit_file` 对缺失路径给出诊断（最深存在的祖先、第一个缺失段、邻近同名项）而不是一句 "File not found"。手动检查更新汇报每种结果——检查中、已最新、发现新版、失败。评估中心的 Case 详情把目标 Agent 的任务材料与评审侧评分标准分开。文件摘要移到任务边界，每个完成的任务一张卡。完整清单逐条见 [changelog/0.2.0](https://github.com/Prism-Shadow/penguin-harness/tree/main/changelog/0.2.0)。

## 安装或升级

```sh
curl -fsSL https://penguin.ooo/install.sh | sh
penguin web
```

Windows（PowerShell）：`irm https://penguin.ooo/install.ps1 | iex`；或在 Node >= 24 下 `npm install -g @prismshadow/penguin-cli`。升级即重跑安装器，0.1.3+ 也可直接 `penguin update`。
