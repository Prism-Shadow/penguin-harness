PenguinHarness 与 TokenDance 联合推出 Agent 开发冲榜赛。活动时间为 **2026 年 10 月 13 日 00:00 至 10 月 23 日 23:59**，期间通过 PenguinHarness 调用 TokenDance 产生的有效 Token 消耗计入排行榜。总奖池为 **15,000 元 Token 额度**，共 **400 个获奖名额**，最高奖励 **500 元 Token 额度**。

## 怎么参加

1. 在 [TokenDance](https://tokendance.space/) 注册并登录账号。
2. 打开 PenguinHarness 模型库，在 TokenDance 分组点击「连接」并完成授权。选择该分组下的模型运行 Agent（原文以 DeepSeek V4.1 Flash 为例）。
3. 填写[活动报名表](https://prismshadow.feishu.cn/share/base/form/shrcnpbknCKDNkOY7UAaKoYMDbd)，正常开发或运行 Agent 项目。

TokenDance 是观猹推出的大模型 API 聚合平台，支持 DeepSeek、Kimi、Qwen、MiniMax 等模型，并兼容 OpenAI、Claude、Gemini 等 API 协议。PenguinHarness 已提供 TokenDance 连接入口。

## 奖励与结算

| 排名 | 每人 Token 额度 |
| --- | --- |
| 第 1–5 名 | 500 元 |
| 第 6–20 名 | 200 元 |
| 第 21–50 名 | 100 元 |
| 第 51–150 名 | 30 元 |
| 第 151–250 名 | 20 元 |
| 第 251–400 名 | 10 元 |

活动期间，PenguinHarness 官方微信群每隔 **48 小时**更新排名。活动结束后统一结算并发放奖励。

报名、模型配置或领奖问题，可联系 PenguinHarness 运营小助手，微信号 `zhang1220yy_`。完整规则见[活动原文](https://mp.weixin.qq.com/s/0LG41-i3iIPTYY2eX762MA)。
