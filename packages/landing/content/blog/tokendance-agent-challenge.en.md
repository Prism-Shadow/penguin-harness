PenguinHarness and TokenDance are running an Agent development challenge from **October 13, 2026 at 00:00 to October 23 at 23:59**. Eligible token usage through TokenDance in PenguinHarness counts toward the leaderboard. The prize pool is **¥15,000 in token credits**, with **400 prize places** and a top reward of **¥500 in token credits**.

## How to join

1. Register and sign in at [TokenDance](https://tokendance.space/).
2. Open the PenguinHarness model library, choose **Connect** in the TokenDance group and complete authorization. Run an Agent with a model from that group. The announcement uses DeepSeek V4.1 Flash as its example.
3. Complete the [registration form](https://prismshadow.feishu.cn/share/base/form/shrcnpbknCKDNkOY7UAaKoYMDbd) and develop or run your Agent projects as usual.

TokenDance is a model API aggregation platform from Guancha. It offers models including DeepSeek, Kimi, Qwen and MiniMax, and supports OpenAI, Claude and Gemini API protocols. PenguinHarness includes a TokenDance connection flow.
