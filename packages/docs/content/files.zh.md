**文件浏览**面板是对话页的侧边面板之一，展示当前对话的 Workspace：左侧是目录树，右侧是所选文件的预览。Project 的所有成员都可以在这里浏览、预览、编辑、上传、重命名和删除文件。

- 第一次使用，见[打开文件面板](#打开文件面板)。
- 查找文件，见[搜索 Workspace](#搜索-workspace)。
- 修改文件，见[编辑文本文件](#编辑文本文件)和[使用右键菜单](#使用右键菜单)。
- 添加文件，见[上传文件](#上传文件)。

## 打开文件面板

可以从以下任一位置打开面板：

- 对话工具栏右上角：选择**右侧栏**或**下侧栏**，再选择**文件浏览**。如果侧栏里已经有别的面板，就用它的**添加面板**菜单。
- 对话区右缘的**快捷方式**悬浮球。
- 消息里的文件小卡片或文件卡片：点击后打开面板并定位到该文件。回复里指向 Workspace 内文件的链接也在这里打开，而不是让浏览器跳转；点击前不检查文件是否存在，文件不在时由面板给出提示。

对话开始后才能使用这个面板，见[使用侧边面板](/chat#使用侧边面板)。

## 浏览文件树

目录第一次展开时才列出其中的内容。文件行在名称后显示文件大小，鼠标指向某一行可以看到它的路径、大小和修改时间。

目录树的顶栏里有搜索框、**刷新**和**上传**。

预览上方的路径行显示当前打开的文件。空间不够时，前面的目录先折叠成一个 `…`，文件名最后才省略。没有打开文件时，路径行显示当前目录。根目录写作 `.`，Workspace 的绝对路径在 Session 详情卡片里查看。

每轮对话结束时，目录树和打开的预览会重新读取；面板重新回到视野中时，目录树也会重新读取。

### 用键盘操作

- 上、下方向键移动选中行。
- 右方向键展开目录，或进入目录。
- 左方向键收起目录，或回到上一级。
- Home 和 End 跳到第一行或最后一行。
- Enter 和空格键相当于点击。

### 隐藏目录树或调整宽度

在面板顶栏最左侧选择**隐藏文件树**，目录树会从面板左缘滑出，搜索框、**刷新**和**上传**也一起隐藏。选择**显示文件树**即可恢复。目录树默认显示，这个选择会记在浏览器里。

拖动两栏之间的分隔条可以调整目录树的宽度；分隔条获得焦点时，也可以用方向键微调。宽度同样会被记住。

面板窄于 480px 时改为单栏显示：先显示目录树，选中文件后换成预览，预览里有**返回列表**按钮。

## 搜索 Workspace

搜索框在服务器上搜索整个 Workspace，而不只是你展开过的目录。

1. 在目录树顶栏点击**搜索文件**框。
2. 输入文件名或目录名的一部分。

停止输入片刻后，结果以平铺列表显示，每项都是完整路径，层级浅的排在前面；搜索期间显示「搜索中…」。搜索只匹配条目名称，不区分大小写。

匹配数达到 200 个，或遍历了 20,000 个条目时，搜索会停下并提示「匹配项过多，仅显示最靠前的 N 条」。没有匹配时显示「Workspace 中没有匹配项」。

在结果中选择一个目录，会清除搜索并在目录树中打开该目录。按 Esc 或点击清除按钮可以清空搜索框。

## 预览文件

在目录树中选择文件即可预览。不同类型的文件显示方式不同：

| 文件类型 | 显示方式 |
| --- | --- |
| Markdown 和 HTML | 渲染后显示，可用**预览 / 源码**切换 |
| 文本 | 语法高亮，带行号 |
| 图片 | 直接显示，点击可放大 |
| PDF | 内嵌显示 |
| 其他类型 | 提供下载，见[下载文件](#下载文件) |

扩展名看不出类型的文件（例如 `Makefile`、`LICENSE`），如果内容看起来是文本，就按文本处理。

超过 64KB 的 Markdown 文件默认以源码视图打开，仍可切换到渲染视图。渲染后的 Markdown 里，相对链接会在面板内打开对应的 Workspace 文件，相对路径的图片也能正常显示。

HTML 文件还可以在浏览器新标签页中打开：在预览中选择**新页面打开**。

> [!NOTE]
> 如果当前访问地址没有独立的预览源，新标签页会以沙箱模式打开，localStorage、Cookie 和第三方嵌入内容都无法使用。要避开沙箱，请通过 127.0.0.1 或 localhost 访问应用，或设置 `PENGUIN_PREVIEW_ORIGIN`。

文本预览最多读取 1MB。更大的文件会截断显示，提示「内容过大，预览已截断，请下载查看完整文件」，并且不能在这里编辑。**下载**按钮在预览顶栏。

文件视图右上角浮着三个按钮：**复制代码**、**自动换行**和**编辑**。**自动换行**让过长的行折行显示，默认开启；源码视图和编辑器共用这一个设置，并会记住你的选择。

## 编辑文本文件

1. 在预览中打开文件，选择文件视图右上角的**编辑**。预览变成编辑器：依然是带高亮和行号的文本，只是可以修改了。这里没有富文本编辑器。
2. 修改内容。
3. 选择**保存**（对勾图标），或按 Ctrl+S / Cmd+S。
4. 在**保存文件**对话框中选择**保存**，写回文件。

选择**取消**（×）会放弃编辑，回到预览。

未保存的修改有可能丢失时，面板会先询问，例如切换到其他文件、关闭面板标签页或离开页面。

> [!TIP]
> 收起或隐藏侧栏不会丢失任何内容。面板保持原样，预览、目录树和草稿都在，再次展开时直接恢复，不会询问。

切换到其他 Session 后草稿依然保留：再次打开同一个文件，编辑器会带着草稿重新打开，并提示「已恢复 … 的未保存修改」。

保存的内容超过 14MB 写入上限时，保存会被拒绝并给出提示。

## 处理磁盘上已变更的文件

Agent 也在写同一个 Workspace，所以你编辑的文件可能在此期间被改动。每轮对话结束时面板都会检查一次。你输入的文本不会被替换，但只要文件变了，编辑器顶栏就会标出**磁盘上已变更**。

如果保存会覆盖一个已变更的文件，面板会在写入前拒绝，并弹出**文件在磁盘上已变更**对话框，让你选择**仍然覆盖**，或者继续编辑。无论选哪一项，你输入的文本都会保留。

## 使用右键菜单

在目录树的某一行或文件视图上点击右键，即可打开右键菜单。触屏设备上长按，键盘上按 Shift+F10 或菜单键。

> [!NOTE]
> HTML 或 PDF 预览内部以及编辑器里不会弹出这个菜单，在编辑器里要靠浏览器自带的右键菜单粘贴文本。

| 菜单项 | 作用 | 适用于 |
| --- | --- | --- |
| **复制相对路径** | 复制从 Workspace 根目录开始的路径。 | 文件和目录 |
| **添加到对话** | 把文件或目录的引用作为小卡片放进输入框，目录的路径以 `/` 结尾。发送消息前不会发出任何内容。 | 文件和目录 |
| **将选中内容添加到对话** | 发送时，选中的文本以代码块形式随消息发出，代码块开头标明文件和行号范围，例如 `@src/app.ts:12-18`。 | 文件，需在文件视图中选中文本 |
| **上传到此文件夹** | 把文件上传到该目录，见[上传文件](#上传文件)。 | 目录 |
| **下载** | 下载该文件，见[下载文件](#下载文件)。 | 文件 |
| **重命名 / 移动** | 输入相对于 Workspace 根目录的**新的路径**，再选择**移动**。路径中不存在的目录会自动创建；目标已存在时拒绝操作。 | 文件 |
| **删除** | 确认后删除文件。文件不会进入回收站。 | 文件 |

> [!NOTE]
> 重命名、移动和删除都会先读取文件的当前版本。如果对话框打开期间 Agent 改写了该文件，这些操作不会做任何改动。

## 上传文件

### 用按钮上传

1. 在目录树中打开要上传到的目录。
2. 在目录树顶栏选择**上传**。
3. 选择一个或多个文件。

文件会上传到当前目录，一次可以选多个。每个文件最大 14MB，超限的文件会在读取前被点名跳过。目标目录中已有同名文件时，**覆盖同名文件**对话框会列出这些文件，选择**上传**即覆盖。上传完成后自动打开第一个上传的文件；如果编辑器里有未保存的修改，则不打开。

### 拖放上传

把文件从电脑拖到面板上，虚线框会标出文件将放入的目录（「松开即上传到 …」）。

- 拖到目录行上松开，上传到该目录；拖动经过时该行高亮。
- 拖到文件行上松开，上传到该文件所在的目录。
- 拖入的文件夹会被跳过，并给出提示。

> [!NOTE]
> 把文件拖到对话区或输入框上，文件会作为附件加到消息里，不会上传到 Workspace。见[对话](/chat#把文件拖到对话区)。

## 下载文件

1. 在目录树中选择文件，在预览中打开。
2. 在预览顶栏选择**下载**。

在桌面应用自己的窗口里，**下载**旁边还有**在文件夹中显示**按钮，点击后会在系统文件管理器中打开文件所在的目录：Finder 和资源管理器会选中该文件，Linux 桌面则打开该目录。

> [!NOTE]
> **在文件夹中显示**只出现在桌面应用自己的窗口里。用浏览器登录同一台服务器时没有这个按钮，即使浏览器就在同一台机器上也一样，因为服务器无法把它与远程浏览器区分开。

## 限制

| 项目 | 限制 |
| --- | --- |
| 文本预览 | 最多 1MB；更大的文件截断显示，不能在这里编辑 |
| Markdown 渲染 | 最多 64KB；更大的文件以源码视图打开 |
| 上传大小 | 每个文件 14MB |
| 保存大小 | 每个文件 14MB |
| 搜索 | 达到 200 个匹配或遍历 20,000 个条目后停止 |
| 面板宽度 | 窄于 480px 时改为单栏显示 |
