---
title: 定时任务
description: 让 Agent 按设定的时间在对话中执行 Prompt，并在对话的定时任务面板里管理这些任务。
---

定时任务在设定的时间向 Agent 发送一条 Prompt，可以只执行一次，也可以按周期重复。绑定到对话的任务把 Prompt 发进这段对话，Agent 因此能接着对话里已有的内容工作。这类任务在对话的**定时任务**面板中创建和管理。

> [!NOTE] 每次新建会话的任务
> 定时任务也可以设成每次运行都新开一个 Session。这类任务在 Agent 的设置页创建；设置页会列出该 Agent 的全部定时任务，也包括绑定到对话的任务。见[智能体](/agents)。

- 查看一段对话的任务，见[打开定时任务面板](#打开定时任务面板)。
- 添加任务，见[用 AI 创建任务](#用-ai-创建任务)或[手动创建任务](#手动创建任务)。
- 暂停、修改或移除任务，见[开启或关闭任务](#开启或关闭任务)和[编辑或删除任务](#编辑或删除任务)。

## 打开定时任务面板

定时任务面板是对话页的侧边面板之一，对话开始后才能使用：还在草稿状态时，面板会提示先发送第一条消息。

1. 打开对话。
2. 在对话工具栏右上角选择**右侧栏**或**下侧栏**。也可以点对话区右缘的**快捷方式**悬浮球。
3. 选择**定时任务**。如果侧栏里已经有别的面板，先选择**添加面板**。

面板列出绑定到这段对话的任务。搜索框同时匹配任务名称和 Prompt。筛选项有**全部**、**生效中**、**已暂停**和**已完成**，其中**已完成**包括已执行完、已过期和已错过的任务。每行显示状态图标、任务名称和一句话描述的执行时间，例如：

- 「每天 08:00 · 下次 明天 08:00」
- 「每 30 分钟」
- 「每周一 09:00」
- 「一次性 · 9月3日 10:00」

任务到点时如果对话还在运行，Prompt 会先等着，对话空闲后再发送，等待期间该行带有**排队中**标记。一个任务最多排队一次，等待期间再到的触发时间不会累加。

任务文件无法使用时（例如绑定的对话已被删除），任务只出现在**全部**下，该行显示**无效**，鼠标指向红色图标可以看到原因。

## 用 AI 创建任务

Project 的所有成员都可以用这种方式创建任务。创建由这段对话的 Agent 完成，它会回复确认设定的时间。

1. 在面板标题下方选择**用 AI 创建**。
2. 描述要安排的事情和时间。
3. 选择**在本对话中编辑**，提示词会填入这段对话的输入框。
4. 检查提示词，确认无误后发送。

按下发送之前什么都不会发出，发送时和手动输入的消息走同一条路径。提示词之所以填进当前对话而不是新对话，是因为在对话里创建的任务默认绑定到这段对话。

### 从建议开始

列表下方的**建议**提供四个现成的请求：**每日简报**、**每周回顾**、**跟进提醒**和**监控更新**。选择其中一个，会打开已经填好请求的 AI 对话框，接着从第 2 步继续。搜索框里有文字时，建议会隐藏。

## 手动创建任务

**开始之前**：只有 Project owner 可以手动创建任务。

1. 在面板标题下方选择**手动创建**。
2. 填写表单。表单与 Agent 设置页上的相同，**目标**固定为**本对话**：
   - **名称**（必填）：任务的文件名，创建后不能修改。
   - **周期**：如 `30m`、`12h`、`7d`。一次性任务留空。
   - **开始时间**（必填），以及可选的**结束时间**。
   - **Prompt**（必填）：发给 Agent 的内容。
   - **启用**：任务是否开启。
3. 选择**创建**。

## 开启或关闭任务

**开始之前**：只有 Project owner 可以开启或关闭任务。

在面板中拨动任务所在行的开关即可，改动立即生效：定时任务按调度器的时钟触发，与任何对话的上下文无关。

## 编辑或删除任务

**开始之前**：只有 Project owner 可以编辑或删除任务。

1. 在面板中打开任务所在行的**更多操作**菜单。
2. 选择**编辑**；或者选择**删除**，再确认。

## 闹钟标记

侧边栏的对话列表里，只要某段对话绑定的任务还有下一次触发时间，这段对话就会显示一个闹钟图标。不论对话属于哪个 Agent、列表怎样分组，都会显示这个标记，但标记不带数量。

任务已关闭、已过结束时间，或是已经执行过的一次性任务，都没有下一次触发时间。

## 列表的刷新时机

面板里的列表在以下时机刷新：

- 面板切换到前台时。
- 窗口重新获得焦点时。
- 有任务触发或进入排队时。
- 对话的一轮结束时。
- 面板可见期间，每 30 秒一次。
- 每次改动之后。

闹钟标记读的是同一份列表，跟着同一次刷新更新，因此标记和面板不会互相矛盾。

## 限制

- 周期性任务最快每 5 分钟运行一次，即最短周期为 5 分钟。周期短于 5 分钟的任务会被判为无效。
- 定时任务只在 PenguinHarness 服务运行期间执行。
- 错过的运行不会补跑。服务停止期间错过的触发时间，周期性任务直接跳过，一次性任务标记为已错过。

## 工作原理

每个任务是 Agent 的 `agent_state/schedule/` 目录下的一个 TOML 文件，文件格式见[配置参考](/configuration#定时任务)。调度器每 30 秒检查一次这些文件，因此手动编辑的文件会在下一次检查时生效。
