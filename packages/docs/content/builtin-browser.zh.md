**浏览器**面板是桌面应用侧边栏里内置的网页浏览器。你可以像使用任何浏览器一样在其中浏览；Agent 则在自己的 shell 里用 `penguin browser` 驱动同一组标签页：读取页面、点击和输入，并提取亚马逊订单这样的数据，登录用的是你自己的账号。内置浏览器有自己的登录状态和历史记录，与系统浏览器互不相通，两者都可以从 Chrome、Edge、Brave、Arc、Vivaldi、Opera、Chromium 或 Firefox 导入。

- 第一次使用，见[打开浏览器面板](#打开浏览器面板)。
- 想让 Agent 使用你的账号，见[登录](#登录)和[从你的浏览器导入](#从你的浏览器导入)。
- 想自己写自动化，或了解 Agent 在做什么，见[在命令行中驱动](#在命令行中驱动)。

## 开始之前

内置浏览器是 macOS、Windows 和 Linux 桌面应用的一部分。用浏览器登录服务器（`penguin web`）、在 Docker 中或在远程机器上都没有它：Web App 在这些场合隐藏这个面板，`penguin browser` 则返回 `browser_unavailable`。需要浏览器的 Agent 必须运行在桌面应用自己的服务器上；在应用里发起的对话默认就是这样。

## 打开浏览器面板

在对话工具栏右上角选择**右侧栏**或**下侧栏**，再选择**浏览器**。如果侧栏里已经有别的面板，就用它的**添加面板**菜单。见[使用侧边面板](/chat#使用侧边面板)。

整个应用只有一组浏览器标签页。每个对话的侧栏显示的都是同一组标签页，所以 Agent 在一个对话里打开的页面，切换到另一个对话后依然在。

Agent 在你正在查看的对话里打开页面时，侧栏会自动切换到浏览器面板，方便你旁观。

## 浏览

- 标签栏显示每个标签页的图标和标题。选择 **+** 新开标签页，选择 **×** 关闭标签页。
- 工具栏上有**后退**、**前进**、**刷新**（页面加载时变为**停止**）和地址栏。输入 URL 即可打开；只写域名（如 `amazon.com`）时以 `https://` 打开；其他内容则用 Bing 搜索。输入时会列出浏览器历史记录中的页面，可用方向键和回车选择。
- 工具栏的菜单里有**从浏览器导入…**、**清除浏览数据…**、**在系统浏览器中打开**和**开发者工具**。
- 会打开新窗口的链接和页面弹窗，都以新标签页打开。一个页面每五秒最多打开三个标签页，超出的会被忽略。
- 下载文件时会询问保存位置，与系统浏览器一样。

面板跟随应用的浅色或深色主题；页面本身保持各自的配色。

## Agent 使用浏览器时

Agent 在某个标签页里工作时，页面四周会有一圈缓慢脉动的光环，工具栏上也会出现一个图标提示。Agent 的命令通过浏览器的开发者工具作用于页面，而不是借用你的鼠标和键盘，所以你旁观时屏幕上的指针不会乱动。Agent 工作期间请不要在页面里点击：你的点击会在 Agent 不知情的情况下改变页面。

Agent 操作期间页面弹出的对话框会被自动应答，页面不必等你处理：提示框一律接受；确认框和离开页面对话框默认拒绝，除非 Agent 要求接受。你自己浏览时弹出的对话框照常显示。

屏幕上的页面按面板的尺寸排版，面板较窄时，网站可能显示它的移动版布局。你没有在看的页面（位于其他标签页，或侧栏已关闭）仍保持加载，尺寸沿用最后一次显示时的大小，从未显示过的则为 1280×800，Agent 可以继续在其中工作。

## 登录

在面板里登录网站，与在任何浏览器里一样。登录状态和网站数据保存在内置浏览器自己的配置里，重启后依然有效：在这里登录不会让系统浏览器也登录，反之亦然。

Agent 从不输入你的密码。Agent 需要的页面要求登录时，`browser-automation` Skill 会让它停下来，请你在面板里自己登录，或者从你平常使用的浏览器导入登录状态。

## 从你的浏览器导入

导入会把本机某个浏览器中一个个人资料的 Cookie（其中保存着你的登录状态）和历史记录复制到内置浏览器。

1. 在工具栏的菜单中选择**从浏览器导入…**。没有打开任何标签页时，面板上也有同样的按钮。
2. 选择一个个人资料。个人资料按浏览器分组，名称与浏览器中显示的一致。
3. 选择 **Cookie 与登录状态**、**历史记录**，或两者都选。
4. 可以填写只导入哪些网站的 Cookie，用逗号分隔，例如 `amazon.com, github.com`。网站包括它的子域名。留空则导入所有网站的 Cookie。
5. 开始导入。对话框会显示找到和导入的 Cookie 与历史记录条数，以及警告信息。

| 浏览器 | macOS | Windows | Linux |
| --- | --- | --- | --- |
| Chrome、Edge、Brave、Vivaldi、Opera、Chromium | 支持 | 支持 | 支持 |
| Arc | 支持 | — | — |
| Firefox | 支持 | 支持 | 支持 |

各平台的注意事项：

- **macOS**：基于 Chromium 的浏览器用保存在钥匙串里的密钥加密 Cookie，因此 macOS 会询问是否允许 PenguinHarness 使用以浏览器命名的钥匙串项目，例如「Chrome Safe Storage」。请选择允许；拒绝的话，加密的 Cookie 会被跳过，导入结果中会说明。
- **Windows**：Chrome 127 及以后的版本用应用绑定加密保护大部分 Cookie，只有 Chrome 自己能读取。这些 Cookie 会被跳过并给出警告，请改为在面板里登录。正在运行的浏览器也可能占用它的 Cookie 文件，关闭浏览器后再导入即可。
- **Linux**：较新的 Cookie 用保存在桌面密钥环里的密码加密，通过 `secret-tool` 读取（Debian 和 Ubuntu 上由 `libsecret-tools` 软件包提供）。没有它时，这些 Cookie 会被跳过并给出警告。
- **Firefox** 的 Cookie 不加密。容器专用的 Cookie 和按其他网站分区的 Cookie 不会导入。

导入只读取数据：每个文件都先复制到临时目录，在那里读取后删除，不会向另一个浏览器写入任何内容。导入的历史记录与内置浏览器自己的历史记录合在一起保存，最多保留最近的 5,000 个页面。只有管理员可以导入。

在 shell 里，`penguin browser import --list` 列出个人资料，`penguin browser import --from chrome --cookies --domain amazon.com` 导入一个网站的登录状态，见 [penguin browser](/cli#penguin-browser)。

## 清除浏览数据

在工具栏的菜单中选择**清除浏览数据…**，再选择要清除的内容：Cookie 与登录状态、缓存文件、网站存储或浏览历史记录。这只影响内置浏览器。

## 在命令行中驱动

`penguin browser` 在 shell 中驱动这些标签页，Agent 也正是这样使用浏览器的。预装的 `browser-automation` 插件教给 Agent 一个循环：打开页面、读取页面、用 JavaScript 操作，再检查页面发生了什么变化。

```bash
penguin browser open https://www.amazon.com/your-orders/orders
penguin browser scan --text
penguin browser exec <<'EOF'
return [...document.querySelectorAll('.order-card')].length;
EOF
```

- `scan` 以简化后的 HTML 输出页面，加 `--text` 时输出纯文本：隐藏、浮动和被遮挡的元素会被去掉，长列表只保留三项，并附上一条提示，给出其余条目的选择器。
- `exec` 在页面中运行 JavaScript，报告返回值、有多少元素发生变化、出现后又消失的提示，以及新打开的标签页。
- `click` 和 `type` 发送真实的鼠标和键盘输入，页面无法把它们与真人操作区分开。
- 其余由 `screenshot`、`cdp`（一条原始的 Chrome DevTools Protocol 命令）和 `history` 完成。

每条命令及其输出格式见 [CLI 参考](/cli#penguin-browser)。

## 工作原理

- 每个标签页都是桌面应用承载的一个 Chromium 页面，使用内置浏览器自己的持久化配置。在页面看来，这就是一个普通的 Chrome 浏览器。
- 服务器通过 Chrome DevTools Protocol 驱动页面，由桌面应用转发。读取页面、运行脚本、点击和输入都在这条链路的服务器一侧完成，因此会随服务器更新而改进。
- 读取页面与追踪变化所用的脚本改编自 [GenericAgent](https://github.com/lsdefine/genericagent)（MIT 协议），包括它的 DOM 简化以及 `web_scan` / `web_execute_js` 的设计。
- 历史记录是数据根目录下的一个文件：`builtin-browser/history.json`。Cookie 和网站存储保存在桌面应用自己的配置目录里。
- 一切操作都经过服务器的 `/api/builtin-browser` 路由，只有管理员可以调用，见[服务器 API](/server-api)。

## 限制

| 项目 | 限制 |
| --- | --- |
| 可用范围 | 仅桌面应用 |
| 标签页 | 最多 30 个；超出时新建标签页会被拒绝（`too_many_tabs`） |
| `scan` 正文 | 默认 35,000 个字符（`--max-chars`）；加 `--text` 时取其三分之一 |
| `exec` 显示的返回值 | 8,000 个字符；`--save` 把全部内容写入文件 |
| `exec` 脚本时限 | 默认 15 秒（`--timeout`） |
| 页面加载等待 | `open` 最多等 15 秒 |
| 历史记录 | 最近的 5,000 个页面，含导入的部分 |
| Windows 上导入 Cookie | Chrome 的应用绑定 Cookie（Chrome 127 及以后）无法导入 |
