成本中心展示各个 Agent 用了多少 Token、这些请求花了多少钱，以及哪些请求失败了。在侧边栏选择**成本中心**即可打开，页面标题为**成本与统计**，地址是 `/usage`。

- 想缩小页面的统计范围，见[按 Agent、模型和时间范围筛选](#按-agent模型和时间范围筛选)。
- 想看汇总数字，见[查看汇总卡片](#查看汇总卡片)。
- 想看随时间的变化，见[查看图表](#查看图表)和[图表中的空档](#图表中的空档)。
- 想排查失败的请求，见[查看并清空服务器异常](#查看并清空服务器异常)。

## 按 Agent、模型和时间范围筛选

在页面顶部选择 Agent（默认**全部 Agent**）、模型（默认**全部模型**）和日期范围：**最近一小时**、**最近一天**、**近 7 天**（默认）、**近 30 天**、**近 90 天**或**自定义**。选择**自定义**后会多出起始和结束两个日期。

日期范围同时决定图表的精度，因此没有单独的精度设置：

| 日期范围 | 图表精度 |
| --- | --- |
| 最近一小时 | 按分钟 |
| 最近一天 | 按小时 |
| 近 7、30 或 90 天 | 按天 |
| 自定义 | 92 天以内按天，190 天以内按周，更长按月 |

异常面板列出哪些记录、**清空**删除哪些记录，也由同一组日期范围和 Agent 筛选决定。

## 查看汇总卡片

三张卡片分别汇总**今日**、**近 7 天**和**累计**的数据，其中**累计**统计的是所选日期范围。三张卡片都受 Agent 和模型筛选影响，每张列出 Token 用量、请求数和成本。

价格按你在[设置 › 通用](/settings#通用)中选择的币种显示。只有配置了价格的模型才计入成本；部分记录没有价格时，**成本**旁会出现星号，页面底部也有一行说明。

## 查看图表

四张图表以时间序列展示所选范围：

| 图表 | 画的是什么 |
| --- | --- |
| **各 Agent 请求与成功率** | 每个时间桶的请求数画成一根堆叠柱，每个 Agent 一段，对应左轴。每个 Agent 的成功率各是一条虚线，对应右侧 0–100% 的轴，画在柱子上方。 |
| **各模型请求与成功率** | 同上，按模型拆分。 |
| **Token 变化** | 分三段的堆叠柱，前面叠一条缓存命中率虚线。 |
| **成本变化** | 带数据点的折线，下方填充面积。 |

两张请求图只为请求最多的四个 Agent 或模型单独命名，其余的合并成一条中性色序列，标签写明合并了几个，例如「其他 3 项」；如果只剩一个，则保留它自己的名字。

每张图表的悬停方式都一样：

- 悬停在某一列上，气泡里显示这个时间桶的数字。
- 悬停在某段柱子上，单独突出这一段。
- 悬停在某条线上，单独突出这条线。
- 在请求图的图例里悬停某个 Agent 或模型，同时突出它的柱段和折线。

## 图表中的空档

悬停表格里的短横线表示这个时间桶没有比率：没有发出请求、请求全部中止，或者没有缓存流量。什么都没记录的时间桶不会出现在任何图表里，跳过的位置用断轴标记标出。

## 查看并清空服务器异常

页面底部的**异常**面板展示服务器记录的异常：

- 汇总数字：**总数**、**未预期**、**预期内**和**最常见**的错误码。
- 异常明细表：时间、**来源 · 错误码**、**类型**和**消息**。点击消息可展开全文。每页 10 条，用**较新**和**更早**翻页，不滚动。

模型筛选对这个面板不起作用。

最近 7 天内记录到未预期异常时，侧边栏的**成本中心**旁会出现一个圆点，页面标题下方也会提示异常条数。选择**标记为已读**，圆点和提示一起消失，直到有更新的异常出现。

### 清空异常记录

**开始之前**：只有 Project owner 可以清空异常。

1. 设置日期范围和 Agent 筛选，让面板列出要删除的记录。
2. 在**异常**面板中选择**清空**。只有面板列出了异常时才有这个按钮；自定义范围还要填好起止两个日期。
3. 核对确认框。预设范围按选择器里的叫法写出，例如「近 7 天内」；自定义范围写出起止日期。
4. 确认删除。此操作不可恢复。

管理员清空时，还会一并删除只有管理员能看到的未归属异常记录。
