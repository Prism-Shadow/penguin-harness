对话页是你和 Agent 一起工作的地方：在这里开始对话，看 Agent 的工作过程流式呈现，并在 Task 运行时随时插话。对话旁边的侧边面板还能查看它的文件、Trace、定时任务等。

- 刚开始用，先看[开始对话](#开始对话)和[发送消息](#发送消息)。
- Agent 工作期间能做什么，见 [Task 运行期间](#task-运行期间)。
- 想改变对话的运行方式，见[切换思考等级](#切换思考等级)、[切换模型](#切换模型)、[交接给其他 Agent](#交接给其他-agent) 和[分叉对话](#分叉对话)。
- 想随时掌握 Agent 的状态，见[查看 Agent 的工作过程](#查看-agent-的工作过程)、[查看 Session 统计](#查看-session-统计)和[管理上下文](#管理上下文)。
- 熟悉界面布局，见[使用侧边面板](#使用侧边面板)和[整理对话列表](#整理对话列表)。
- 速查，见[快捷键](#快捷键)和[限制](#限制)。

## 开始对话

新对话从草稿开始，发送第一条消息时才创建 Session。

1. 在侧边栏选择**新建对话**。草稿默认使用 Project **新对话默认值**里的那个 Agent，前提是它还在这个 Project 里；否则用 `default_agent`，再没有就用第一个 Agent。
2. 在输入框上方选择 **Agent**、**Workspace**（服务器上的一个目录，在目录浏览器中选取）、**审批模式**、**Model** 和**思考等级**。
3. 输入消息，按 Enter 发送。

Session 创建后，Workspace 就锁定了；模型仍然可以换，见[切换模型](#切换模型)。

几点说明：

- Project 的**新对话默认值**（在 **Project 设置**中，见 [Web App](/web-app#project-与成员)）会预填新草稿的 Agent、Workspace 和审批模式，模型则默认为 Project 的默认模型。思考等级优先显示 Agent 自己的等级，没有时用 Project 的默认值，再没有就是 medium（中）。
- 在草稿里切换思考等级或模型，切换后的值就成为新的默认值：思考等级立即写回所选 Agent 的 `model.thinking_level`，模型则沿用到你的下一个对话。
- 草稿按用户和 Project 保存所选项、正文和选中的 Skill。草稿里有已输入的文字时再点**新建对话**，这份草稿会移到侧边栏的**草稿**分组。

审批模式共四种，见[工具与审批](/tools)。

| 选择器中的名称 | 模式 | 工具调用 |
| --- | --- | --- |
| **全部放行** | `allow-all` | 全部直接执行，不询问 |
| **全部拒绝** | `deny-all` | 全部拒绝 |
| **放行只读** | `read-only` | 只读工具直接执行，其余调用等你审批 |
| **总是询问** | `always-ask` | 每次调用都等你审批 |

### 从示例 Prompt 开始

草稿页在输入框下方把示例 Prompt 分放在几个折叠夹里，同一时间只展开一个。点击某一行，这条 Prompt 会填入输入框，但不会发送，你可以先读一读、改一改再发。内置示例还会顺带选中它需要的 Skill。

### 保存自己的快捷指令

最后一个折叠夹**我的快捷指令**用来存放你自己的 Prompt，最多 3 条。

1. 在输入框里写好 Prompt。
2. 在**我的快捷指令**中选择**新建快捷指令**。编辑框会带上输入框里的内容，并把第一行建议为**名称**。
3. 保存。

一条快捷指令由名称（最多 40 个字符）和 Prompt（最多 4000 个字符）组成，不绑定 Skill。快捷指令按用户保存在服务器上，换浏览器、换机器都还在。每行都有编辑和删除操作，删除前会确认。折叠夹标题会显示用量，例如 `2/3`；存满 3 条后，**新建快捷指令**这一行不再出现。设这个上限，是为了让它和内置折叠夹一样高。

## 发送消息

按 Enter 发送，Shift+Enter 换行。输入框为空时，按上、下方向键可以调出你在本 Session 里输入过的消息。

### 附加图片和文件

- 直接把图片粘贴到输入框。粘贴只接受图片。
- 在 + 菜单（**更多输入方式**）中选择**上传图片**或**上传文件**。

附件不限类型。选中的文件按选择顺序以小卡片的形式显示在正文上方，可以逐个移除；只有附件、没有文字的消息也能发送。

大小和数量限制分两个时刻检查：

- 选择或拖入文件时：超过单个文件大小上限（默认 100MB）的文件，或超过 20MB 的图片，会在读取之前被拒绝，提示中写明当前生效的上限。
- 发送时：一条消息默认最多 20 个文件、合计 120MB，超出时发送失败，提示「一条消息附加的文件过多。」或「请求体过大。」

管理员可以在[系统设置 › 上传限制](/settings#上传限制)中修改这两个大小。嵌入对话的图片另有 20MB 上限，不随它们变化：这类图片会进入对话和 Trace，此后每次翻阅历史、每次恢复 Session，都要再付出一次它的体积。

发送时，附件写入 Session 的 scratchpad，随 Session 一起删除。对话中显示一条「附加文件」提示；文件内容本身不进入对话，模型用文件工具按路径逐个读取。如果模型不支持图片输入，图片也会这样存进 scratchpad、以文件路径传给模型，输入框上方会给出提示。

### 把文件拖到对话区

在对话页或草稿页，都可以把文件拖到对话内容或输入框上。

- 拖动经过这个区域时，会出现覆盖整个区域的「松开以添加附件」浮层。拖动文字等非文件内容时不触发。
- 松开即把整批文件加入附件。图片按粘贴图片的方式处理，其余文件成为附件，校验和报错与 + 菜单一致。
- Task 运行期间也可以拖入，这时附件按[运行中发送方式](#插话或排队)发送。
- 目标模式下，拖入的图片照常添加，文件会被拒绝并给出提示。

只有对话区会接收附件。把文件拖到侧边栏、顶栏、其他面板或没有输入框的页面上，什么都不会发生，浏览器也不会跳转去打开这个文件。另一个拖放目标是文件浏览面板，它会把文件上传到 Workspace，见[文件面板](/files)。文件浏览面板还能把文件、目录或选中的一段内容作为小卡片加进你的消息。

### 使用斜杠命令

输入 `/` 打开斜杠菜单，按 Enter 或 Tab 执行高亮的条目。Task 运行或压缩期间，菜单不会弹出。

| 命令 | 作用 |
| --- | --- |
| `/compact` | 压缩上下文 |
| `/agent` | 把对话交接给另一个 Agent，见[交接给其他 Agent](#交接给其他-agent) |
| `/model` | 用另一个模型开一个新对话，见[切换模型](#切换模型) |
| `/goal` | 开启目标模式，见[设定目标](#设定目标) |
| Skill 名称 | 选中或取消一个已安装的 Skill；选中的 Skill 随消息一起发送 |

`/compact`、`/agent` 和 `/model` 只在已经开始的对话里出现：草稿没有可压缩的上下文，Agent 和模型也在一开始就选定了。

### 设定目标

**目标模式**（在 + 菜单中，或输入 `/goal`）把你的消息变成一个目标。之后 harness 会一轮接一轮地运行 Task，直到目标完成、受阻或用完 **Token 预算**；预算可以在目标小卡片上设置。

- Agent 需要安装 `goal` 插件。
- 目标必须是文字。图片可以一起带上，文件附件会被拒绝。
- Task 运行期间不能开启目标模式。

见[目标模式](/goal-mode)。

## Task 运行期间

Task 运行时，输入框仍可使用，工具栏上只保留一个操作按钮。输入框为空时它是**停止**，点击结束 Task；正在进行的压缩也能用它停止。

### 插话或排队

Task 运行时输入了内容，发送按钮的行为取决于 + 菜单底部的**运行中发送方式**，这个选择记在当前浏览器里。

- **插话**（默认）：按钮显示为**发送给运行中的 Agent**。文字、图片和文件随 Agent 的下一轮送达，消息显示为**用户插话**。
- **排队**：按钮显示为**排队为下一条消息**。消息先存在服务端，本轮运行结束后作为一条普通的新消息自动发出。在此之前，输入框上方逐条列出排队中的消息（「跟进消息已排队，本轮结束后自动发送：…」）。刷新页面后队列仍在。

有几种草稿不能插话：

- 只选了 Skill，没有文字、图片或文件时，改为排队。
- 已暂存 `/agent` 的选择时，发送会立即打开新对话。
- 已暂存 `/model` 的选择时，发送要等本轮结束：按钮保持为**停止**，输入框上方有一行说明。

### 撤回消息

还没送达 Agent 的插话（「插话已排队，将随下一轮送达：…」）和每条排队中的跟进消息，行尾都有一个**撤回**按钮（弯回的箭头）。点击后，消息连同附件回到输入框，排在你已输入的文字前面，可以修改后重新发送。

- 已经送达 Agent 的插话不能撤回，已经开始发送的跟进消息也不能。
- 如果插话送达之前运行就结束了（常见的情形是工具还在运行时你按了**停止**），这条消息会连同附件自动回到输入框。

### 审批工具调用

工具调用需要你审批时，对话里会出现允许和拒绝按钮，它所在的步骤组也会展开。子 Agent 有待审批的调用时，它那一行会显示琥珀色圆点。Session 进行中可以随时更改审批模式，见[工具与审批](/tools)。

### 把工具调用转入后台

`exec_command` 或 `run_subagent` 调用运行满 10 秒后，这一行会出现**转入后台执行**。点击后调用立即返回一个任务句柄，不会中止任何工作，本轮也不再等它，直接往下进行。结果之后以后台任务通知的形式送达。这一行随后标为 **[后台任务]**，转入后台的命令会出现在[会话进程](#会话进程)中。

### 重试或放弃

模型请求失败、harness 要等待 2 秒及以上再重试时，重试提示行会倒计时到下一次尝试。选择**立即重试**跳过剩余等待，选择**放弃**结束 Task。

模型供应商拒绝的请求（例如 API key 无效）会以一行错误结束本次运行（「[错误]：模型请求错误：…」）。解决问题后重新发送即可，比如到[模型库](/models)页更新 key。

## 切换思考等级

输入框的思考等级选择器提供 low（低）、medium（中）、high（高）、xhigh（极高）和 max（最高）几档。

在已经开始的对话里，选择器显示 Agent 配置的等级（Agent 没有设置时显示「—」），并一直跟随它，直到你自己选一档。在此之前发送消息不带等级，所以对 Agent 设置的修改会持续生效。你选定的等级保存在 Session 上：

- 刷新页面后不变。
- 这段对话之后的每次运行都用它，之后再改 Agent 设置也不影响。
- 不会写回 Agent 设置。

对话中途切换等级会降低提示词缓存命中率、增加成本，所以会先弹出确认框：

- **压缩后切换**（推荐）：先像 `/compact` 一样压缩上下文，压缩结束后再应用新等级。压缩失败、被中断或无法启动时，等级照样切换，并以提示或报错说明。
- **仍要切换**：立即应用。
- **取消**：保持当前等级。

压缩只能在对话空闲时启动，所以 Task 运行期间第一项不可用，旁边有说明，另外两项照常可用。对话还没有消息、重选当前显示的等级，或者刚成功压缩完，切换时都不弹确认框。

## 切换模型

换模型有两种方式，作用不同。

### 在本对话内

点击输入框工具栏上的模型名称，选另一个模型。Task 运行期间和压缩期间选择器不可用，选当前模型没有反应。会先弹出确认框，因为切换要先用当前模型压缩上下文：

- **压缩并切换**：先用当前模型压缩上下文（总是生成摘要，即使 Agent 配置为清空），然后本对话在新模型上继续。压缩失败或被中断时，对话保持在当前模型上。
- **取消**：保持当前模型。

刚压缩完时没有可压缩的内容，确认框会说明本对话将带着现有摘要在新模型上继续，按钮只写**切换**；还没有消息的对话直接切换。

切换在对话中显示为一条压缩行，后面跟一行「模型已切换 · A → B」标记（刚压缩完时只有标记）。压缩失败只显示失败的压缩行，没有标记。切换完成后，模型徽标、上下文窗口和费用估算都跟随新模型。

### 开新会话

`/model` 新开一个 Session 在另一个模型上延续对话，本对话保持不变。

1. 在输入框输入 `/model`，选择一个模型。它以小卡片的形式出现在正文上方，此时还不会发送。
2. 可以接着输入要说的话。输入框为空时，会发送「换用新模型继续这段对话」。
3. 按 Enter。

新 Session 沿用原来的 Agent、Workspace 和审批模式，开头有一条「换模型新开的会话（原模型 …），延续原会话」横幅，可以点回原对话；模型需要早先的历史时，会自己读取原对话的 Trace 文件。

- 交接要等 Session 空闲，因为新 Session 要从原 Session 的 Trace 接续，而运行中的一轮或压缩还在写这个文件。等待期间，输入框上方有一行说明。
- 要取消，点小卡片上的 ×，或在正文开头按 Backspace。
- 小卡片随草稿一起保存，刷新页面或去别的对话再回来都还在。

## 交接给其他 Agent

1. 在输入框输入 `/agent`，选择一个 Agent。它以小卡片的形式出现在正文上方，此时还不会发送。
2. 输入要一并带过去的消息。
3. 按 Enter。

系统会为这个 Agent 打开一个新对话，带上你的文字，并注明是从哪段对话交接来的。输入框为空时，只发送交接本身。和 `/model` 一样，× 或 Backspace 可以取消，小卡片也随草稿保存。

## 分叉对话

每条完成的回复下方有一行统计：输入和输出 Token、TPS、用时和成本，然后是回复时间、复制和**分叉**。宽屏上，鼠标指向回复时才显示这一行；手机上一直显示，但不显示 TPS。只有含文字的回复才提供分叉。

1. 选择**分叉**（**从这里分叉对话**）。
2. 确认。截至这条回复的对话会复制成一个新对话，原对话保持不变。

分叉得到的是一个新 Session，沿用相同的 Agent、模型、Workspace 和审批模式。它的 Trace 和 scratchpad 都是独立的副本，所以即使删除了原对话，图片和文件仍能正常显示。同一对话的多个分叉依次命名为 `原标题 (1)`、`原标题 (2)` 等，不随界面语言变化，编号也不会复用。

## 查看 Agent 的工作过程

- **文字**随生成逐步显示，思考块可以折叠。
- **步骤**，即思考和工具调用，归在一个标着**运行中**或**运行完毕**的分组下，显示步数和用时。分组运行时展开、结束后收起，组内有调用需要审批时会再次展开。
- **工具卡片**可以展开查看参数和输出，运行时有实时计时。卡片标题是模型写的说明，或缩短后的文件路径。内置工具用短名显示（`read_file` 显示为「读取」，完整名称在悬停提示里），可以在[系统设置 › 外观](/settings#外观)中关闭**工具短名**。其他工具（含 MCP 工具）始终显示原名。
- **压缩**会留下一行，标题就是状态：进行中为**压缩中**，结束后为**压缩完毕**（清空上下文时为**清空中**、**清空完毕**），并带用时。进行期间，这一行在请求的思考内容到达后出现思考部分，摘要开始生成时出现结果部分，两部分默认折叠，各有自己的用时。压缩结束后这一行收回成一行。压缩失败时，标题保持为**压缩**（或**清空**），下面一行写明原因。
- **MCP 连接**，即首次连接 MCP 服务器，会留下一行，显示发现的工具数，并列出不可用的服务器。展开后每个服务器一组，显示状态、工具数和连接用时；再展开可以看到工具列表或失败原因。
- **子 Agent** 各自留下一行，显示头像、名称、短 Session id，运行中带转圈动画，有工具调用待审批时带琥珀色圆点。点击这一行会打开**智能体面板**：上方是该 Task 的调用图，每个节点显示运行时长；下方是所选子 Agent 的实时对话。嵌套的工具卡片和审批与主对话完全一致，子 Agent 还有自己的输入框，**跳转到该会话**可以把它作为完整对话打开。当前 Task 派生子 Agent 时，智能体面板会自动打开，每个 Task 只自动打开一次。

### 更早的消息

打开对话时只加载最近 50 轮。滚动到顶部附近会再加载 50 轮，阅读位置保持不动；加载失败时，点击「更早的对话加载失败，点击重试」。没有更早的内容时，顶部显示「已是对话开头」。轮次编号和顶部统计都从对话开头算起，与一次加载全部的结果一致。

要回到最新消息，选择**回到最新消息**。对话较长时，左侧留白处有一列刻度，每个刻度对应一轮问答：指向刻度可以预览，点击即跳转。留白放不下时（例如在手机上），工具栏会出现**对话索引**按钮，列出同样的内容。

## 使用侧边面板

对话页有两个放面板的侧栏：右侧栏和下侧栏，用对话工具栏右上角的**右侧栏**和**下侧栏**按钮显示或隐藏。空的侧栏会列出可以打开的面板；用**添加面板**可以再加一个，面板也可以移到另一侧。对话开始后才能使用这些面板。

| 面板 | 内容 |
| --- | --- |
| **智能体面板** | 本 Task 的子 Agent：调用图和每个子 Agent 的实时对话 |
| **文件浏览** | Workspace 中的文件，可预览、编辑和上传，见[文件面板](/files) |
| **记忆** | Agent 的记忆 |
| **轨迹观测** | 对话的 Trace 文件：汇总、每轮统计、执行时间线和逐条事件，可以**导出** |
| **远程控制** | 把对话绑定到聊天软件，见[远程控制](/remote-control) |
| **定时任务** | 按计划向这段对话发送 Prompt 的任务，见[定时任务](/schedules) |
| 终端 | 一个 Shell，见[使用终端](#使用终端) |

每段对话会在当前浏览器里记住自己的面板布局，切换对话时恢复。隐藏侧栏不会改变其中的面板，未保存的编辑也会保留。子 Agent 等待审批时，放着智能体面板的那个侧栏按钮上会出现琥珀色圆点；智能体面板没有打开时，圆点在**右侧栏**按钮上。

### 用快捷方式悬浮球打开面板

桌面宽度下右侧栏关闭时，或窄屏下没有打开任何面板时，对话区右缘内侧 32px 处会浮着一个圆形的**快捷方式**按钮。草稿页不显示它；对话历史正在加载或加载失败时也不显示。

1. 点击按钮，或聚焦后按 Enter 或空格键。按钮左侧会展开一圈圆形入口：**智能体面板**、**文件浏览**、**记忆**、**轨迹观测**、**远程控制**、**定时任务**和**终端**，最后是**隐藏悬浮球**。
2. 指向或聚焦某个入口，按钮下方会显示它的名称。
3. 选择入口。桌面宽度下面板在右侧栏打开，窄屏下在底部弹层中打开，按钮随即消失。

几点说明：

- 入口只有图标，没有悬停提示，名称显示在按钮下方。指向或聚焦按钮本身时，下方文字说明点击后的效果：**打开**或**关闭**。
- 上、下方向键在按钮和各入口之间移动，Home 和 End 跳到两端。按 Esc、点击别处、滚动或用 Tab 移走焦点，都会收起这圈入口。
- 靠近对话区顶部或底部时，这圈入口会缩短，只显示放得下的部分。
- 按钮可以沿右缘上下拖动，短按仍是点击。松手后按钮贴回边缘，不会停在工具栏或输入框上；它的位置记在当前浏览器里，所有对话共用。
- 右侧栏关闭时，如果有子 Agent 在等待审批，按钮和其中的智能体面板入口上都会出现琥珀色圆点。
- **隐藏悬浮球**会让按钮不再出现，同时提示在哪里重新打开：[系统设置 › 外观](/settings#外观)中的**快捷方式悬浮球**开关。

### 使用终端

终端以标签页的形式出现在侧栏里，也可以在独立的 `/terminal` 页面中打开。

- Ctrl+` 显示或隐藏终端标签页。没有打开的终端时，会接管一个没有被任何对话占用、仍在运行的 Shell，或者新建一个。
- 终端获得焦点时按 Ctrl+W，确认后关闭这个终端，与点击标签页上的 × 效果相同。这个按键不会传给 Shell。浏览器把 Ctrl+W 留给关闭浏览器标签页，可能会先响应；桌面应用会把它交给终端。

## 查看 Session 统计

对话工具栏右侧显示 Session 的累计数据：Token、成本和用时。对话还有后台任务时，旁边会多一个图标，并显示任务数量。窄屏上，这些统计合并为一个 **Session 信息**图标。Task 运行期间，标题旁显示沙漏和**运行中**。

点击这组统计会打开详情卡片：

- **Agent**、**Model**、Session id（旁边有复制按钮）、**Workspace** 路径，以及 Session 的**创建时间**。
- **总 Token**，含缓存命中率和子 Agent 的用量。
- **成本**，只在模型配置了价格时显示；带星号表示部分用量没有价格。
- **用时**，括号里有两项，形如 `用时 10.3s（API 5s，工具 5.3s）`。API 是花在模型请求里的时间，已扣除等待你审批的时间；工具是各次工具执行覆盖的实际时间，并行的工具只算一次。两项是各自独立的测量，并不是对总用时的拆分：后台工具会和模型解码同时进行，审批等待和 harness 开销又不属于任何一项，所以两项之和可能大于、也可能小于总用时。

应用里的复制按钮都在按钮本身给出反馈：图标短暂变成对勾。对话行菜单中的**复制 Session ID** 则改为弹出「已复制」提示。

### 会话进程

详情卡片的**会话进程**列出对话启动的后台进程：超过等待时间仍在运行的命令、用 `run_in_background` 启动的命令，以及通过**转入后台执行**转入后台的命令。每行显示命令、启动时间和 pid。检测到进程所服务的地址时，运行中的行会附上链接（取其输出中最后打印的本机 URL，否则取其进程组监听的端口）。

- **停止**会结束整个进程组，并把这一行从列表移除。对话会得知这个进程是被停止的，而不是运行失败，模型因此知道服务已经关掉，不会把它当作崩溃去重启。
- 已退出的行标注「已退出」，带**移除**按钮，可以把这一条从列表中删除。

> [!WARNING]
> 移除进程立即生效，且不可撤销。它捕获的输出会一并删除，之后无法再让模型读取这些输出。输出还有用的话，请先保留这一行。

## 管理上下文

工具栏右侧的上下文圆环显示上下文的占用程度，标尺是压缩触发的位置：Agent 的 `compaction.max_context_length`，但不超过模型窗口允许的大小。占用超过 80% 时变成琥珀色，超过 95% 时变成红色。刚压缩完时圆环是空的，要等下一次请求回报用量。

点击圆环打开上下文面板：

- 已用量与阈值。
- 一条与模型完整窗口等长的横条（下方标着「最大上下文 N」），按**系统提示词**、**工具定义**、**用户消息**、**模型消息**、**工具请求**和**工具结果**分段。点击某一段或某个图例行会保持高亮，再点一次取消。
- **工具用量 Top 5** 或**文件用量 Top 5**，用**工具**和**文件**按钮切换。文件只列文件名，悬停可以看到完整路径。

横条上的虚线标记就是压缩阈值。虚线右侧的斜纹部分是模型还有、但 Session 暂时用不到的空间，因为压缩会先触发。

### 修改压缩阈值

1. 拖动虚线标记，或者聚焦后按左、右方向键：每按一次移动 1,000 Token，按住 Shift 时移动 10,000。
2. 松开鼠标或按 Enter，弹出**修改压缩阈值**对话框，数值仍可修改。按 Esc 取消。
3. 确认。新阈值写入 Agent，并立即对这段对话生效，运行中也不例外。

填入超过模型窗口的值也会被接受，同时提示实际生效的是窗口大小。如果模型窗口本来就小于 Agent 的阈值，输入框上方会出现提示，并提供**打开 Agent 设置**和**忽略**两个按钮。

## 整理对话列表

侧边栏列出当前 Project 的对话。**搜索会话**按标题筛选已经加载的对话。

在**列表选项**（列表顶部的滑块图标）中：

- **分组方式**：**按工作区分组**（默认）、**按智能体分组**或**按时间分组**（分为**近一天**、**近一月**和**更早**）。
- **排序方式**：**最近更新**或**手动排序**（拖动行来排序）。手动排序只在使用鼠标或触控板时提供。

旁边的按钮随分组方式变化：**新建工作区**、**创建 Agent** 或**新建对话**。分组可以置顶，也可以拖动调整顺序；分组上的 + 按钮用来在该分组里新建对话。

按工作区分组时，系统自己创建的目录会并入同一个**临时工作区**分组：一种是没有选择 Workspace 时对话自动得到的目录，另一种是评估为每道题目、每次运行创建的测试 Workspace。两者都直接位于 Agent 的 `workspaces/` 目录下，这个目录下的所有目录都归入该分组。

### 行操作

- 鼠标指向某一行时，行尾的最近活跃时间换成两个按钮：**归档**和**更多**（…）。用 Tab 移到这两个按钮上时也会显示。
- 右键点击这一行、在触屏上长按、按 Shift+F10，或者选择**更多**，都能打开行菜单：**置顶**、**重命名对话**、**远程控制**（见[远程控制](/remote-control)）、**归档**、**复制 Session ID** 和**删除对话**。按 Esc、点击别处或滚动列表会关闭菜单。
- **删除对话**需要确认，删除后对话的消息和 Trace 会被永久移除。

只有在对话行和文件浏览面板里，右键菜单才会替代浏览器自带的菜单。置顶的对话排在所属分组的最前面。置顶只在活跃列表中提供，置顶状态按 Project 记在浏览器里。

### 行标记

| 标记 | 含义 |
| --- | --- |
| 翻转的沙漏 | Session 正在运行 |
| 向中线合拢的横条 | Session 正在压缩 |
| 绿点 | 有一次运行已经结束，你还没有查看 |
| 绿色小活动波形 | Session 仍有后台任务：超过等待时间仍在运行的命令，或正在跑一轮的后台子 Agent。悬停提示会显示数量，例如「2 个后台任务」 |
| 琥珀色数字 | 有工具调用等待审批 |
| 置顶标记 | 对话已置顶 |
| 远程控制图标 | 这段对话已启用消息软件连接 |
| 闹钟 | 绑定到这段对话的定时任务还会触发，见[定时任务](/schedules) |

后台任务标记与其他标记互不影响：对话已经空闲、但 dev server 还开着时，标记仍在；最后一个后台任务结束的那一刻标记就会消失，无需刷新。

### 折叠夹

每个分组的活跃对话下方是它的折叠夹：**子智能体**、**定时任务**、**评估任务**和**已归档**，各自在展开时才加载其中的对话。按时间分组时，整个 Project 共用一组折叠夹，**加载更多会话**用来加载更早的对话。

- **评估任务**收纳在[评估中心](/evaluation-center)点击**使用**打开的对话，以及评估为每道题目、每次运行启动的测试 Session，这样它们就不会挤满被测 Agent 的列表。
- 打开子 Agent、定时任务或评估的对话时，它所在的折叠夹会自动展开。
- 只有折叠夹、没有活跃对话的分组（例如只跑过评估的 Agent）默认折叠，排在其他分组之后（置顶的分组除外），分组标题变浅，并显示折叠的对话数。展开过一次后，在这个 Project 中会一直保持展开。

分组里的活跃对话和每个展开的折叠夹，一次都显示 10 条。**展开其余 N 个对话**每次再显示 10 条：先显示已经加载的，不够时才向服务器取。显示超过 10 条后，**收起**可以折回前 10 条。分组超过 10 个时，列表每页显示 10 个分组，下方有翻页控件。

## 工作原理

你在对话中的一些操作会以结构化文本的形式写进对话，查看 Trace 时可能会注意到：

- `/model` 开的新 Session，第一条消息以 `[model_switch_from]` 块开头，写明原 Session、它的标题、Trace 文件、Workspace，以及原来的供应商和模型，后面跟着你的消息。新对话把这个块显示为「换模型新开的会话」横幅。在本对话内切换模型不写这个块：它记录为一次普通压缩，新上下文的 `session_meta` 记录新模型。
- 插话以 `[user_steering]` 用户消息的形式，随 Agent 的下一轮送达。
- 选中的 Skill 放在 `[use_skills]` 块里随消息发送。
- 每个附件会在消息里加一行 `[attached file: <path>]`。
