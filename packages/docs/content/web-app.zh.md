PenguinHarness 自带一个 Web App：多用户登录、流式对话、Agent 配置、模型与用量管理，都在浏览器里完成。桌面应用在自己的窗口中显示的也是同一套界面。本页是总览，各个部分另有专门的指南。安装与首次启动见[快速开始](/quickstart)。

- 第一次登录，见[打开 Web App 并登录](#打开-web-app-并登录)。
- 熟悉界面，见[应用布局](#应用布局)。
- 设置 Project 或管理成员，见 [Project 与成员](#project-与成员)。
- 让 Agent 替你填写表单，见[用 AI 创建或手动创建](#用-ai-创建或手动创建)。
- 为团队部署，见[生产环境部署](#生产环境部署)。

## 打开 Web App 并登录

在终端中启动服务：

```bash
penguin web
# opens http://localhost:7364
```

`penguin web` 会启动服务，等它就绪后打印地址并打开浏览器；加上 `--no-open` 则不打开浏览器。`penguin server` 启动的是同一个服务，但不打开浏览器。见 [penguin server / penguin web](/cli#penguin-server-penguin-web)。

> [!NOTE]
> 服务只监听本机地址时，应用的地址是 `localhost`。`127.0.0.1` 留给 Agent 写出的文件做预览用，访问它会被转到 `localhost`。

### 首次登录

初始账号是 `admin`，一开始没有自己的密码。在设置密码之前，服务每次启动都会以带边框的提示打印一条首次登录链接，打开这条链接即可在浏览器中登录。

1. 用 `penguin web` 启动服务。
2. 在服务的输出里找到带边框的提示，其中有首次登录链接。
3. 在浏览器中打开链接，即以 `admin` 身份登录。
4. 设置密码：点击随后出现的横幅上的**去修改**，或进入**设置** › **账户**。这次登录后设置密码，不需要输入当前密码。

> [!NOTE]
> 链接可以重复打开，有效期 30 天，设置密码后即失效。重启服务会打印新链接，旧链接随之作废。打开已失效的链接会跳到登录页，并显示说明。

桌面应用不会打印这条提示；用 `PENGUIN_SEED_ADMIN_PASSWORD` 固定的密码仍然有效时，服务也不打印。这些机制如何保证安全，见[安全模型](/security)。

### 账号

登录页要求填写**用户名**和**密码**，页面一角有语言和主题的切换。

系统不开放自助注册：账号由管理员在设置的**用户管理**页创建。每个新用户都会自动获得一个独立的初始 Project，名为 `<userId>-default_project`。

仍在使用初始密码时，页面顶部会显示横幅，提醒尽快修改，并附有**去修改**链接。关闭横幅后，它就不再出现。

连续登录失败 5 次后，服务会要求等待：等待时间从 1 秒开始，每次翻倍，最长 1 分钟。

### 密码

用户忘记密码时，由管理员在**用户管理**页通过**重置密码**重置。

**admin** 忘记密码时，需要离线重置：

**开始之前**

- 服务已停止。

1. 运行 `penguin server reset-admin-password`。
2. 重新启动服务。
3. 打开带边框提示中的首次登录链接，设置新密码。

这条命令会给 admin 账号换上一个没人见过的随机密码，并结束 admin 的所有登录会话。下次启动时，服务会重新打印首次登录链接。

### 登录会话

登录状态保持 30 天，滑动续期：只要在使用，有效期就重新算满 30 天。

管理员重置某个用户的密码后，该用户的所有登录会话立即失效；自己修改密码则不影响当前会话。

**登出**在账户菜单中，点击后会先确认。登出只结束这个浏览器里的会话，正在运行的对话会在服务端继续。

> [!NOTE]
> 桌面应用会以 admin 身份自动登录自己的窗口，不需要密码。这个窗口里没有**登出**、没有初始密码横幅，也没有**账户**页和用户管理。

## 应用布局

左侧的侧边栏放着对话之外的所有入口，窗口的其余部分显示当前打开的页面。各个部分都有自己的指南。

### 侧边栏

侧边栏从上到下依次是：

- **开发** / **公司**切换，只在公司模式可用时出现：管理员已为服务器启用公司模式，而你没有为自己关闭它。切换到公司模式后，下面的页面入口换成组织的页面，对话列表换成频道。见[公司模式](/company-mode)。
- Project 切换器，旁边是**收起侧栏**按钮。见 [Project 与成员](#project-与成员)。
- **新建对话**，打开一份新的对话草稿。见[对话](/chat)。
- 页面入口。最后一项下方的箭头可以把这组入口折叠起来：

| 入口 | 用途 | 指南 |
| --- | --- | --- |
| **智能体** | 创建 Agent，编辑它们的提示词、记忆、运行参数、工具、Skill、钩子、密钥保险柜和定时任务 | [Agent](/agents) |
| **插件市场** | 浏览插件，把插件中的 Skill 和钩子包安装到 Agent 上，为 Project 添加服务端插件 | [Skill](/skills) |
| **模型库** | 配置 Project 的模型、供应商和凭证 | [模型](/models) |
| **成本中心** | 按 Agent、模型和时间范围查看 Token 用量、成本和服务器异常 | [成本中心](/usage) |
| **评估中心** | Benchmark：评估 Agent，并以 Benchmark 为标准优化 Agent | [评估中心](/evaluation-center) |

- 对话列表，可以搜索，可以按 Workspace、Agent 或时间分组。见[对话](/chat)。
- 底部是你的用户行，点击打开账户菜单：
  - **设置**，见[设置](/settings)。
  - 更新行，显示更新进行到哪一步，点击打开更新对话框，见[更新 PenguinHarness](/updates)。
  - **登出**。

### 提醒圆点

页面入口上出现圆点，说明那里有事情等你处理：

| 入口 | 圆点的含义 |
| --- | --- |
| **智能体** | 有 Agent 的内核版本过旧 |
| **插件市场** | 有插件可以更新 |
| **模型库** | 有预置模型可以同步（仅 owner 可见） |
| **成本中心** | 有未预期的错误 |

头像上的圆点表示有软件更新。鼠标指向入口，可以看到具体在等什么。

### 收起的侧栏与窄窗口

**收起侧栏**把侧边栏收成一列图标，从上到下是：**展开侧栏**、公司模式切换（可用时）、**最近一次对话**、**新建对话**、各页面入口，以及你的头像，点击头像打开的也是同一个账户菜单。鼠标指向或键盘聚焦某个图标时会显示它的名称。收起状态记在浏览器里。

窗口较窄时，侧边栏收进顶栏的菜单按钮里，点击后以抽屉形式展开。

### 轨迹观测与机器

应用里有两个部分没有侧边栏入口。

**轨迹观测**是对话页的一个侧边面板，而不是独立页面。它展示当前对话的 Trace 文件，包括汇总、每轮统计、执行时间线和逐条事件，点击**导出**可以下载文件。见[对话](/chat)。

**机器**页通过 ssh 把当前版本的 PenguinHarness 安装到其他主机上，主机从服务器账户的 `~/.ssh/config` 中选择。这个版本的侧边栏还没有它的入口，管理员可以直接访问 `/machines`。

### 语言与主题

界面语言（English / 中文 / 跟随系统）和主题（浅色 / 深色 / 跟随系统）随时可以在[设置](/settings)中切换，登录页上也能切换。两者都按浏览器保存。

## Project 与成员

一个 Project 包含它的 Agent、模型、Benchmark 和对话。侧边栏顶部的 Project 切换器列出你拥有或参与的所有 Project，并标出你在其中的角色（`owner` 或 `member`），点击即可切换。同一个菜单里还有**新建 Project** 和 **Project 设置**。

### 创建 Project

任何已登录的用户都可以创建 Project，并成为它的 owner。

1. 打开侧边栏顶部的 Project 切换器。
2. 选择**新建 Project**。
3. 在**显示名**中填写显示名，可以不填，不填时显示 id。
4. 在 **Project id** 中填写 id，也可以点输入框旁边的**用 AI 生成**，从显示名生成一个。提议由当前 Project 的默认模型写出，因为 Project 本身不在任何 Project 之内。
5. 选择**创建**。你就是这个 Project 的 owner 了。

id 长 2–64 个字符，以小写字母开头，只能包含小写字母、数字和下划线。admin 以外的用户创建的 id 以「用户名-」开头，输入框里只需填写这个前缀后面的部分。

> [!NOTE]
> Project id 创建后不能修改。

### Project 设置

**Project 设置**包含四个页面：

| 页面 | 内容 |
| --- | --- |
| **通用** | 显示名、**Project ID**，以及**删除 Project**（递归删除 Project 目录，不可恢复） |
| **成员** | Project 有哪些成员、各是什么角色。owner 可以按用户名添加已有用户（**添加成员**），也可以移除成员（**移除**）。桌面应用中没有这一页。 |
| **默认值** | **新对话默认值**：每个新对话默认使用的 Agent、工作目录、审批模式、思考等级和默认模型 |
| **安全策略** | 命令策略规则：命中任何一条已启用规则的命令都会被拒绝，与审批模式无关。见[命令策略](/configuration#命令策略) |

### 角色

成员角色分为 `owner` 和 `member` 两种。每个 Project 只有一个 owner，即它的创建者；角色不能更改，所有权也不能转移。管理员身份不会让你获得访问其他用户 Project 的权限。

只有 owner 可以：

- 重命名或删除 Project、管理成员，以及修改**默认值**和**安全策略**（member 只能查看这些页面）。
- 修改模型、密钥保险柜和定时任务。
- 创建和删除 Benchmark、删除 Agent、清空成本中心的异常记录、设置远程控制。
- 导入 Agent 快照、记忆和 Trace。

member 仍然可以创建 Agent 和对话，也可以删除对话、Skill、钩子包和记忆文件。

> [!NOTE]
> `default_project` 与 CLI 共用，不能在 Web App 中删除；一个账号的最后一个 Project 也不能删除。

## 用 AI 创建或手动创建

Web App 中很多通过表单创建的东西，也可以改为向 Agent 描述，让它来创建。这些位置并排放着两个按钮：带魔法棒的**用 AI 创建**，和带手形的**手动创建**。

| 可以创建的内容 | 位置 |
| --- | --- |
| Agent | 智能体页 |
| 模型分组 | 模型库页 |
| Benchmark | 评估中心 |
| 密钥保险柜中的密钥 | Agent 的「密钥保险柜」标签页 |
| 定时任务 | Agent 的「定时任务」标签页，或对话的「定时任务」面板 |

其中有些只对 Project owner 开放：

- 模型库页和「密钥保险柜」标签页：两个按钮都只有 owner 可用。
- 定时任务：**手动创建**只有 owner 可用。

提示词输入框附带可点击的示例，点一下就会填入草稿。如果页面会在你输入的内容后面附加固定说明，下方会有一个折叠的**完整提示词**预览展示这些说明，并提供**复制提示词**。

出口只有一个：**在新对话中编辑**。它用 Project 的 `default_agent`（没有时用第一个 Agent）打开一个新对话，并把提示词预填进输入框，发不发送由你决定。

- 刷新这个新对话页面，提示词仍在。
- 既不编辑也不发送就离开页面，提示词会被丢弃，不会在之后的对话里再次出现。
- 一旦在其中输入，它就成为普通草稿，和你写的其他内容一样保留。

「定时任务」面板是例外：它的出口是**在本对话中编辑**，提示词会填进当前对话的输入框。见[定时任务](/schedules)。

## 生产环境部署

服务端自己托管构建好的 SPA（同源、支持 SPA fallback），生产环境只需运行一个 `penguin web` 或 `penguin server` 进程。

npm 安装包已经内置前端构建产物。如果要使用自定义的静态目录，用 `PENGUIN_WEB_DIST` 覆盖即可，见[配置参考](/configuration)。

服务默认监听 `127.0.0.1`，只能从本机访问。如果要通过 `HOST` 让它在网络上可访问，应当放在负责 TLS 终结的反向代理之后，见[安全模型](/security)。
