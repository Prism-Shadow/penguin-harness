**系统设置**把不属于 Project 也不属于 Agent 的设置集中在一个对话框里：你的个人资料、界面偏好和密码；管理员还能在这里管理服务器的用户、代理、上传和公司模式。

- 个人设置：[个人资料](#个人资料)、[通用](#通用)、[外观](#外观)和[账户](#账户)。
- 服务器设置，仅管理员：[用户管理](#用户管理)、[代理选项](#代理选项)、[上传](#上传)和[公司模式](#公司模式)。

## 打开系统设置

1. 在侧边栏底部点击你的用户行；侧边栏收起时，点击你的头像。账户菜单随即打开。
2. 选择**系统设置**。

## 对话框的结构

对话框左侧是一列页面导航，每个页面由若干行设置项组成，标题在左，控件在右。窄屏上，这列导航会变成页面上方的一条横向滚动栏。

导航分为**个人**和**服务器**两组：

| 页面 | 分组 | 谁能看到 |
| --- | --- | --- |
| [个人资料](#个人资料) | 个人 | 所有人 |
| [通用](#通用) | 个人 | 所有人 |
| [外观](#外观) | 个人 | 所有人 |
| [账户](#账户) | 个人 | 仅在有密码可改时出现 |
| [用户管理](#用户管理) | 服务器 | 仅管理员，桌面应用中没有 |
| [代理选项](#代理选项) | 服务器 | 仅管理员 |
| [上传](#上传) | 服务器 | 仅管理员 |
| [公司模式](#公司模式) | 服务器 | 仅管理员 |

个人偏好改动即生效，没有保存按钮，关掉对话框也不会丢失什么。唯一的例外是个人资料页的昵称：输入的文字需要显式提交，它的**保存**按钮就在输入框旁边，不在页面底部。

个人偏好的存储位置：

- 保存在当前浏览器：语言、币种、任务完成通知、主题、终端主题、字号、主题色、快捷方式悬浮球和工具短名。
- 随账户保存在服务器：个人资料，以及你个人的公司模式开关。

服务器组的页面仅管理员可见，作用于整台服务器。非管理员既看不到这些条目，也无从得知它们存在：他们只能看到个人组的几页，导航也不再显示分组标题。

桌面应用里没有**用户管理**页，因为这时服务器是单用户的。桌面应用自己的窗口也没有**账户**页：它通过 shell 的 token 登录，没有密码可改；用密码登录同一台服务器的浏览器仍有这一页。

设置项标题旁的「?」可以查看这一项的说明，页面标题旁的「?」则说明整个页面。

检查更新不在这个对话框里，见[更新 PenguinHarness](/updates)。

## 个人资料

**个人资料**页包含你的**头像**和**昵称**。它属于个人设置，在任何登录方式下都有，包括桌面应用自己的窗口，因为这两项都不需要密码就能修改。

这一页没有底栏：每个控件在使用时立即写入，负责写入的按钮就在对应的值旁边。

两项一开始都未设置。设置之前，侧边栏底部的用户行、收起后侧栏上的头像，以及从这两处打开的账户菜单顶部，都显示你的用户名和首字母头像。

设置之后，这三处都换成你的头像和昵称；账户菜单顶部仍会在昵称下方显示用户名。昵称还会显示在**用户管理**列表中用户名的下方。

### 更换头像

**开始之前**

- 一张 PNG、JPEG 或 WebP 格式的图片。

1. 在**个人资料**页选择**更换头像**。
2. 选择一张 PNG、JPEG 或 WebP 图片。

头像立即生效。图片会按中心裁成正方形，重新编码为 128×128。

要换回首字母头像，选择**更换头像**旁边的**恢复默认**。

### 修改昵称

1. 在**个人资料**页的**昵称**里输入 1–32 个字符的昵称。
2. 选择**保存**。

长度按字符计算，因此中文昵称也可以写满 32 个字。保存空白昵称即清除昵称。

**保存**旁边的**恢复默认**把昵称恢复为默认值，即你的用户名。两个按钮都是点击即写入；要写入的值与已保存的值相同时，按钮不可用。

## 通用

**通用**页是个人设置。

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| **语言** | English / 中文 / 跟随系统 | 「跟随系统」表示跟随浏览器。 |
| **币种** | 美元 $ / 人民币 ¥ | 价格显示所用的币种。数据始终以美元存储，换算只发生在显示层。 |
| **任务完成通知** | 开 / 关（默认关闭） | 窗口隐藏或失去焦点时 Task 结束，会弹出系统通知，点击即回到该 Session。 |
| **公司模式** | 开 / 关（默认开启） | 只在管理员为服务器开启公司模式后出现。关闭只隐藏你自己的**开发** / **公司**切换，别的都不影响，组织照常运转。见[公司模式](/company-mode)。 |
| **导入 Trace** | — | 把 Trace 文件导入为一段对话。只有你拥有至少一个 Project 时才会出现这一行。见[导入 Trace](#导入-trace)。 |

> [!NOTE]
> 打开**任务完成通知**时会当场向系统申请通知权限。系统只问一次：被拒绝后开关保持关闭并显示提示，只能到系统的通知设置里改回来。浏览器不支持系统通知时，开关不可用。

### 导入 Trace

**导入 Trace** 把 `.jsonl` 格式的 Trace 文件导入为某个 Agent 的一段对话。

**开始之前**

- 一个从其他部署导出的 `.jsonl` Trace 文件，不超过 14MB。
- 你是目标 Project 的 owner。

目标 Project 和目标 Agent 都要自己选：Agent 要选，是因为 Trace 文件本身无法指明本机的哪个 Agent；Project 要选，是因为这个对话框里看不出当前打开的是哪个 Project，这也意味着 Trace 可以导入到当前打开的 Project 之外。下拉框只列出你自己拥有的 Project，因为导入是 owner 的操作；一个都没有时，这一行不出现。

1. 在**通用**页的**导入 Trace** 一行选择目标 Project：你拥有当前打开的 Project 时默认选它，否则默认选你拥有的第一个 Project。
2. 选择目标 Agent，默认是该 Project 的 `default_agent`。
3. 点击**选择文件**，选中 `.jsonl` 文件，导入随即开始。

Trace 会成为该 Agent 的一段新对话。如果该 Agent 下已有相同 id 的 Session，导入会被拒绝。

导出是反方向的操作，入口和要下载的文件在一起，位于对话的轨迹观测面板中。

## 外观

**外观**页是个人设置。

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| **主题** | 浅色 / 深色 / 跟随系统 | 界面主题。 |
| **终端主题** | 跟随主题 / 浅色 / 深色 | 终端面板有自己的明暗配色，默认跟随应用主题。固定为浅色或深色即与应用主题脱钩，适合只针对一种底色调校过的命令行提示符和 TUI。 |
| **字号** | 小 / 中 / 大 | 界面字号。 |
| **主题色** | 灰白、蓝、绿、紫、红、橙 | 界面的主题色。 |
| **快捷方式悬浮球** | 开 / 关 | 浮在对话区右缘的圆形按钮，展开后是通往工作台各面板和终端的快捷方式。关掉它与点击展开项里的**隐藏悬浮球**效果相同。 |
| **工具短名** | 开 / 关 | 对话里的工具卡片用短名称呼内置工具（`read_file` 显示为「读取」）。其余工具（含 MCP 工具）和轨迹观测始终显示工具原名，悬停短名也能看到原名。 |
| **托盘图标** | 开 / 关（默认开启） | 仅桌面应用。见下文。 |

关于**托盘图标**：桌面应用运行期间，会在系统托盘（Windows 的通知区域、macOS 的菜单栏、Linux 的托盘）里常驻一个图标。点击图标回到窗口，右键可以开新会话或退出。

关掉后图标立即消失，无需重启。此后关闭窗口不再收进托盘：macOS 上应用留在 Dock 中，Windows 和 Linux 上则直接退出。

## 账户

**账户**页提供**修改密码**操作。

只有存在可修改的密码时才有这一页。桌面应用自己的窗口用 shell 的一次性 token 登录，从来没有密码，所以没有**账户**页；用密码登录同一台服务器的浏览器仍有这一页。

> [!NOTE]
> 通过首次登录链接登录时，设置密码不需要输入当前密码，因为这个账户此前的密码从来没有人见过。

### 修改密码

1. 在**账户**页选择**修改密码**。
2. 在**当前密码**里输入当前密码。通过首次登录链接登录后，这个字段不会显示。
3. 在**新密码**里输入新密码（至少 8 个字符）。
4. 在**确认新密码**里再输入一遍。
5. 选择**保存**。

## 用户管理

**用户管理**页列出服务器上的所有用户。仅管理员可见；桌面应用里的服务器是单用户的，没有这一页。

在这里可以新增用户、重置密码和删除用户。

### 新增用户

1. 在**用户管理**页选择**新增用户**。
2. 输入**用户名**（2–32 个字符：以小写字母开头，后面只能用小写字母、数字和下划线）和**初始密码**（至少 8 个字符）。
3. 选择**创建**。

新用户会得到一个名为 `<userId>-default_project` 的默认 Project。仍在使用初始密码的用户会带有「初始密码」徽标。

### 重置用户密码

1. 在**用户管理**页找到用户，选择**重置密码**。
2. 输入新的**初始密码**，选择**保存**。

重置密码会让该用户的所有登录会话失效，之后须用新密码重新登录。

### 删除用户

> [!WARNING]
> 删除用户会一并删除其名下的全部 Project，包括数据目录，且不可恢复。

1. 在**用户管理**页找到用户，选择**删除**。
2. 在对话框中选择**删除**，再选择**确认**。

管理员角色的用户没有删除按钮，服务器也会拒绝删除内置的 admin。

## 代理选项

**代理选项**页仅管理员可见，作用于整台服务器，决定哪些出站流量走代理。

| 设置 | 默认值 | 覆盖范围 |
| --- | --- | --- |
| **应用程序使用代理** | 开 | 服务器自身的出站流量：LLM 请求、更新检查、图片抓取。 |
| **Agent 环境使用代理** | 开 | Agent 命令子进程的环境。 |
| **代理地址** | 空 | 可选，两个开关共用。留空表示跟随代理环境变量。 |

**代理地址**接受 undici dispatcher 支持的任何代理 URL：`http://`、`https://`、`socks5://` 或 `socks://`，可以带凭据。裸的 `host[:port]` 也可以，存储时会规范化为 `http://…`。其他输入一律拒绝，原因显示在输入框下方。

点击**保存**之前不会写入任何内容。保存时整个表单通过一次 PUT 提交，所以地址被拒时其余各项也不会写入。保存后出站 dispatcher 随即重建，对新建立的连接生效，无需重启。回环地址始终直连。

### 设置并测试代理

**开始之前**

- 你的代理地址，使用上文支持的任意一种格式。

1. 在**代理选项**页的**代理地址**中填入代理地址；留空则跟随代理环境变量。
2. 打开**应用程序使用代理**，让服务器自身的出站流量走代理。默认已开启。
3. 打开 **Agent 环境使用代理**，让 Agent 命令子进程的环境也使用代理。默认已开启。
4. 选择**保存**。地址无效时不会写入任何内容，原因显示在输入框下方。
5. 在**保存**下方选择**测速**，运行**连通性测速**。

连通性测速测量的是本服务器出站到各模型供应商这一跳。运行前页面会先列出目标：OpenAI、Anthropic、Gemini、DeepSeek、Z.ai 和 BigModel 的模型列表地址。点击**测速**后，向每个目标各发一次不带凭据的 GET 请求，结果先到先显示，每个目标最多等待 5 秒。

- 只要收到 HTTP 响应就算**已连通**，401、403 也算，因为凭据被拒恰好说明域名解析、TCP 连接和 TLS 握手都已走通。已连通的目标会显示耗时。
- 失败会给出具体原因：连接超时、域名解析失败、连接被拒绝、TLS 握手失败或无法连接。

> [!NOTE]
> 测速用的是已保存的设置，因为只有保存才会重建出站 dispatcher。如果你改过地址，请先保存再测速。

## 上传

**上传**页仅管理员可见，作用于整台服务器，用于设置自动图片压缩：

| 字段 | 默认值 | 允许范围 |
| --- | --- | --- |
| **压缩大图** | 开 | — |
| **超过此大小的图片将被压缩（MB）** | 4MB | 1–64MB |

这里没有体积上限可设。附件写入 Session scratchpad，由模型按路径打开，下游没有任何环节随文件体积增长。内嵌图片则相反——它进入对话与 Trace，此后每次翻阅历史、每次恢复 Session 都要再付出一次它的体积——因此它被压小，而不是被拒绝：超过阈值的图片会在浏览器里缩放到 2048px 的框内、以原格式重新编码，然后再上传。

小于阈值的图片按原样发送，动图与矢量图同样如此——经过 canvas 往返，它们会变成第一帧或一张位图，那是另一张图，而不是更小的同一张。若重新编码后并不更小，则仍发送原图。超出范围的值会被拒绝，原因显示在输入框下方，例如想设「100GB」而在 MB 字段里填了 102400。校验先于写入：一次 PUT 里只要有一个字段不合法，其他字段也都不会写入。

### 修改图片压缩

1. 在**上传**页打开或关闭「压缩大图」。
2. 在「超过此大小的图片将被压缩（MB）」里输入 1 到 64 之间的整数。开关关闭时该字段仍可编辑，因此两项可以一次设好。
3. 选择**保存**。

保存立即生效，无需重启：输入框会在下一次 `/api/me` 时读到该策略。

## 公司模式

**公司模式**页仅管理员可见，作用于整台服务器。页面上只有**启用公司模式**这一个总开关，默认关闭，需由管理员在这里打开。

开关一拨即生效，没有保存按钮。

关闭后，组织调度器和全部组织路由随之停用，所有人的模式切换也会隐藏。磁盘上的组织不受影响；重新打开后，错过的触发不会补发。

> [!NOTE]
> 公司模式是内测功能。见[公司模式](/company-mode)。
