# Chinese (zh)

Default-AI markers:

- 「不是……而是……」及其亲属（「不需要 X，只需要 Y」「这不仅是……更是……」）翻案句。
- 首尾升华：宏大开场（在……的今天）与拔高结尾（未来已来；……的故事仍在继续）。
- 三连排比与四字格堆叠（一种态度、一种选择、一种生活方式；源远流长、波澜壮阔）。
- 显性路标（首先/其次/最后、总而言之、值得注意的是）与设问自答开头。
- 「这意味着/这标志着」自我注解句：先陈述，再补一句解释其意义。
- 象征膨胀动词：见证了、承载着、彰显了、是……的缩影。
- 机构腔与黑话：赋能、打造、助力、闭环、抓手、擦亮名片；公文动词 进行/加以。
- 破折号与冒号定义腔的移植（「手冲的本质：一场与时间的对话」）。
- 万能安全垫结尾（具体效果因人而异，建议根据自身情况调整）。
- 伪 hedge（某种意义上、一定程度上、或许正是）与幽灵人群（比多数人预想的快——谁预想？）。
- 欧化搭配与翻译腔：作为……的身份就此终结、死档案、密集的簇；欧化长定语。
- 信息复读：换句话说/也就是说 引出的同义重述。

Scrubbed-text markers (over-correction):

- 冒号、破折号、引语、史料味全部清零，逗号串承担一切（七个分句一逗到底）。
- 口语点缀按段配给（每段恰好一个"接地气"词），温度像用滴管加的。
- 段段短句收尾的"留白"节拍器（人写的段落有时就平平地结束）。
- 判断句系列：连续段落都用「……的是X」承重（把流程定下来的是创始团队。真正把成本压下来的是第二代产线。），同一句型当引擎。
- 电报体编年：连续分句各带一个年份（1997年……。1998年……；2000年……，2001年……），叙事被压成 changelog；改用相对时间（三年后、世纪末）并让重要事件独占一句。
- 分号串联叙事事件：中文散文里分号几乎只属于正式的并列列举，拿来串故事就是压缩痕迹。
- 无主语压缩：「初代销量不错」——谁的初代？首次提及必须带全称，指代不能靠上一段撑着。
- 等重短句链：四个同构主谓短句一口气连排，虽无重复虚词，读感仍是排比；把其中一件事降为从句，节拍就破了。
- 紧缩四字支点：「接口一变」「需求一改」式的四字条件枢纽，后面挂「就得/都得跟着……」的尾巴；展开成「一旦……」或直接拆句。
- 「就」字链：就/就得/都得/一……就…… 承担全篇的因果衔接，单个地道、高频机械；每段数一数「就」，用拆句、从句或自带结果的动词分担。

Native, not a tell: 四字格 in titles and set phrases at natural density; topic-comment comma chains of moderate length; 顿号 enumerations of real items.

Print norms: mainland print typically sets Arabic numerals tight (「公元605年」); spacing ASCII from CJK (「605 年」) is a tech-blog convention — follow the venue.
