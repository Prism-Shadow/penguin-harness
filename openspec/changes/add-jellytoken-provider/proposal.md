# JellyToken 供应商接入提案

开发分支：`feat/add-jellytoken-provider`；合并目标：`main`。本提案描述待实现的功能。

## 接入原因

目前，用户要在 PenguinHarness 使用 JellyToken，需要自行添加模型、填写地址并选择协议。JellyToken 提供兼容 Chat Completions 的接口，因此可以像使用 SiliconFlow 一样：在模型库找到供应商，填写一次分组密钥，再从对话中选择模型。不需要额外开发登录页或客户端。

## 本次变更

- 新增内置分组 `jellytoken`，显示名称为 `JellyToken`。默认使用 `openai-chat` 和 `https://aiservice.jellytoken.com/v1`，也允许手动添加账号已开通的模型。
- 分组设置的「前往密钥管理」「前往模型列表」，以及模型配置中的「前往密钥管理」「获取模型 id」，都打开 `https://www.jellytoken.com/models?utm_source=penguin-harness`。这是浏览器跳转，不是推理地址，也不会自动导入模型。
- 按下列顺序预置并默认展示九个模型，保留原始请求标识：

  1. `deepseek-v4.1-flash-1017`
  2. `qwen4-max`
  3. `glm-5.3`
  4. `glm-5.3-flash`
  5. `qwen3.8-flash`
  6. `glm-5.3-flashx`
  7. `doubao-seed-2.1-lite`
  8. `doubao-seed-2-1-pro`
  9. `kimi-k3`

- 九个预设的上下文窗口统一配置为 **1M（1,000,000 个词元）**。首版不列视觉能力，不展示「视觉」标签。账号能否调用相应模型仍需单独核验。
- 价格以需求方提供的人民币价目表为依据。九个预设的模型卡片按价目表逐项展示「6折起」「9.5折起」等折扣标签，保留“起”字。标签仅用于展示，不把它作为固定 `discount` 写入成本统计。
- 新项目获得上述预设；已有项目通过「同步新增模型」补充缺失项，不自动改写现有密钥、连接或默认模型。

## 能力范围

新增能力：`jellytoken-provider`，覆盖供应商展示、连接设置、密钥继承、模型选择、推理请求和预设同步。没有需要替换的既有 OpenSpec 能力规格。不做钱包、授权登录、余额、推广横幅、默认置顶或官方推荐。

## 影响范围

主要改动在服务端模型目录；模型库、模型选择器和命令行继续使用同一份配置。实施时验证用户实际看到的顺序，而不只检查目录数组。复用现有设置弹窗和请求客户端；没有可再分发的品牌图标时使用现有首字母图标。同步更新相关测试、中英文产品文档和变更记录。验证使用的真实密钥不进入仓库、截图或方案。
