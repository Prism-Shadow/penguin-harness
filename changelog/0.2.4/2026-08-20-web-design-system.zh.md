# Web App：一套状态色、按需披露的说明、一族图标

- **Date:** 2026-08-20
- **Type:** refactor
- **Scope:** `web`, `tooling`
- **PR:** [#378](https://github.com/Prism-Shadow/penguin-harness/pull/378)

[English](2026-08-20-web-design-system.md)

Web App 此前隐含遵循的三条约定改为写下来并加以约束：状态色按含义从同一个模块取用；说明文字除非用户边输入边要看，否则改为按需披露；线性图标出自同一个渲染器、同一种描边、同一套按角色命名的尺寸。

## 状态色调

- `src/lib/tone.ts` 收录五种色调——`busy`、`attention`、`success`、`danger`、`muted`——按标记的形态分为四张表：字形与状态文字用的墨色、徽标用的底色（含自带文字色）、6px 状态点用的填充、整行提示条用的描边加底色。每一对浅深色类名只写一次。
- 已迁移到位：运行状态图标、会话活动字形、徽标色板、消息流的步骤条幅与 goal 条幅、推理组组头、子智能体与面板的待办圆点、上下文占用圆环、MCP 连接状态、模型速度徽标、更新弹窗、初始密码横幅、占位符缺失提示条，以及用量页的错误面板。同一个含义此前琥珀有三种写法（`amber-600`/`amber-500`/`yellow-*`）、绿色有两种；运行状态的旋转指示与失败字形也各提高一档，以在白底上达到 3:1。
- **会话列表的「运行中」沙漏由灰改为全站统一的琥珀**。「压缩中」沿用同一色调，并换用**新的标记**——一条中线，上下各一枚合拢的折角，循环挤压——于是两个进行中的状态改由形状与动效区分，而不再只靠颜色。
- 模块内记录的对比度按标记实际所处的表面重新测得，其中包含本应用在 `styles.css` 里覆盖过的中性色阶：深色下 gray-950 为 `#000000`、gray-900 为 `#0d0d0d`，而此前的数字是按 Tailwind 原色算的。
- 终端的外框配色补上自己的 `success` / `attention` / `danger`，与其余色值一样在 JS 内解析；此前它的状态点在浅色终端上取的也是每一对里的深色那一半。
- 分类色板不并入：图表系列、Token 分桶、时间线阶段与各技能头像底色表达的是身份而非判断，必须保持「新增一种颜色不会被读成新增一档严重程度」。

## 说明改为按需披露

两种形态，由「有没有标题」决定用哪一种：圆圈「?」只出现在标题旁边，没有标题可依附的地方，说明改为自己报出名字的折叠行。

- 新增 `components/ui/info-popover.tsx`：一枚圆圈「?」，其弹层经共用的 `usePortalPanel` 以 portal 挂载并定位，因而不被祖先的 `overflow` 裁剪，并在点击外部、Esc、滚动或改变窗口尺寸时收起。触发器是真正的 `<button>`，带可访问名并指向它所打开的弹层；展开期间该弹层同时作为触发器的描述。
- 新增 `components/ui/help-fold.tsx`：一行紧凑的、自带名字的触发行，展开后说明就地铺在其下方，旋转的是全站同一枚折叠指示。它属于常规文档流，因而不用 portal——采用 WAI-ARIA 的 disclosure 模式，收起时面板留在 DOM 内并置 `hidden`，因此 `aria-controls` 始终指向真实节点。
- 自带标题的区块说明取「?」：技能库页、模型库页的只读提示、MCP Server 区块、Agent State 传输区块、工具表的 `call_description` 列、四处占位符 Prompt 区块，以及 Project 弹窗的新对话默认值区块。
- 密钥保险柜、记忆、定时任务、技能四个 Agent 设置标签页取折叠行：它们的名字在标签栏里、面板内并不重复，「?」在那里没有可依附的标题。
- 解释**语义**的字段提示移到标签旁的「?」：单次请求超时、两项压缩阈值、模型分组的协议说明、新对话默认模型的来源，以及内置管理员初始密码打印在何处。
- 描述取值**形状**的提示保持常驻：「每行一条 `KEY=value`」「每行一个参数」「留空即不限」、允许字符规则、预算的 `k`/`m` 后缀。它们是边输入边看的。
- `Field`、`Input`、`Textarea` 与 `PasswordInput` 为此新增 `info` 参数。带上它时，字段改用 `htmlFor` 关联标题，而不再用 `<label>` 包裹控件：按钮属于可标注元素，嵌进去会把标题从输入框那里抢走。
- `test/disclosure-anchor.test.ts` 以 TypeScript 解析器解析真实 JSX 来强制这条依附规则：任何前面没有标题兄弟节点的 `InfoPopover` 都会让它失败并报出文件与行号——注释与相邻的 `<Button>` 都不算标题。

## 一族图标

- `GlyphIcon` 成为唯一的线性图标渲染器（24×24、描边 1.7、`currentColor`），并新增 `filled` 变体。`group-list.tsx` 的 `Icon` 此前是它逐字节相同的第二份实现，现改为包装它；另有 25 处内联 `<svg>` 换成了共用组件或共用路径。
- 重复字形各自收归一处：表单控件的下拉小箭头、关闭叉、折叠指示、文件夹轮廓、外链标记、对话页私有的三条统计路径，以及 `panels-toolbar` 里重新声明的渲染器。
- 描边 1.6 与 1.8 已清除；该族统一为 1.7，1.5 留给另立画布的两枚双笔画标记，2 与 2.2 留给对勾、圆环仪表与折叠指示。
- `src/lib/icon-scale.ts` 把每个尺寸按角色而非数字命名，图标与文字的间距同理。已应用到此前互相不一致的同角色元素：折叠卡片组头的状态图标、分组头的动作按钮与行首字形、智能体卡片的统计行、技能卡片的按钮组、输入区的触发胶囊与菜单行，以及轨迹页的导出按钮。
- 三部分各配新测试：色调覆盖度与「状态文件不得内联色板类名」、弹层的 ARIA 与它所迫使的字段布局、图标族的描边集合与「每个字形只有一份」。
