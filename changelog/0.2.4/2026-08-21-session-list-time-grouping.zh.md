# 会话列表的时间分组,以及会话详情中的 Agent

- **Date:** 2026-08-21
- **Type:** feature
- **Scope:** `web`
- **PR:** [#389](https://github.com/Prism-Shadow/penguin-harness/pull/389)

[English](2026-08-21-session-list-time-grouping.md)

会话侧边栏的列表选项在「按工作区分组」「按 Agent 分组」之外新增第三种分组方式:按时间分组,按每个会话的最近活动切分为近一天 / 近一月 / 更早——与行内简短时间戳、最近更新排序读取的是同一个时间戳。空的时间段不显示,该选择与另两种一样持久化。会话页右上角的详情卡片也在 Model 上方新增了 Agent 一行。

## 细节

- 一个时间段横跨全部 Agent 与全部工作区,因此子智能体 / 定时任务 / 已归档三个文件夹与列表的翻页行下移到时间段之下,合为项目级的一组,计数与拉取扇出按全部 Agent 汇总;时间段自身的「更多」只展开已加载的行。
- 分组折叠、会话置顶与手动拖拽排序在时间分组下与其他分组一致;手动顺序按项目 + 分组方式分别存储,新分组从自己的顺序开始。
- 头部的新建按钮跟随分组方式,时间分组下新建一个对话。
- 轨迹观测页的目录树保留「工作区 / Agent」两种切换——它的行是没有活动时间戳的 Trace 文件——存储的时间分组偏好在该页按工作区分组读取。
- `MoreRow` 新增可选的无障碍名称,供措辞不是共用「更多」的行使用。
