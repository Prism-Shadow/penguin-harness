# 终端面板在被别的东西顶替时会真正关闭

- **Date:** 2026-08-20
- **Type:** fix
- **Scope:** `web`

[English](2026-08-20-terminal-panel-swap.md)

有两种情况下，终端在用户看来已经被关掉了，却仍然留在屏幕上。

## 打开聊天面板是关闭侧边窗格，而不是把它停在后面

左侧或右侧的终端窗格与 Agents / 工作区面板共用同一块位置，而此前打开面板只是把窗格挤到它后面——于是再关掉面板，终端就自己回来了，没人要求它回来。从用户的视角看，打开面板正是关掉终端的那个动作；关掉面板之后，那块位置应该是空的。

现在它是真的关闭。布局仍然保留，所以重新打开终端会回到它原来那条边、屏幕内容完好——不保留的只是「正在显示」这件事。上下窗格不受影响：它们占的是高度而不是宽度，从来就不争这块位置。

## 终端跟着它所属的对话

在某个对话里打开的终端，会跟着用户进入 Agents、技能库、用户管理——那些页面没有自己的对话，一个 shell 摆在那儿与屏幕上的内容毫无关系。这些页面把终端面板归到一个不持有任何布局的占位作用域，于是它根本不在那里；回到对话则原样恢复，包括屏幕内容。整个过程中 shell 一直在运行，就像任何一次关闭面板那样。
