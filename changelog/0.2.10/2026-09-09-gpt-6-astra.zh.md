# 内置目录收录 GPT-6 Astra：直连与 OpenRouter 各一条

- **Date:** 2026-09-09
- **Type:** feature
- **Scope:** `model-catalog`, `core`, `docs`, `skills`
- **PR:** [#654](https://github.com/Prism-Shadow/penguin-harness/pull/654)

[English](2026-09-09-gpt-6-astra.md)

内置模型目录两处收录了 OpenAI 的 GPT-6 Astra：直连 OpenAI 分组首位的 `gpt-6-astra`，以及 OpenRouter 中 `openai/*` 系列首位的 `openai/gpt-6-astra`。两条都是 1,050,000 Token 上下文，且支持图像输入。

## 细节

- **`gpt-6-astra`（provider `openai`）**——展示名 GPT-6 Astra，1,050,000 Token 上下文，`vision = true`，既不固定 `client_type` 也不固定 `base_url`：与其余直连 OpenAI 条目一样按 id 自动路由，凭证留空时回退到 `OPENAI_API_KEY` / `OPENAI_BASE_URL`。每百万 Token 价格为 $1 / $12.5 / $50（缓存读取 / 缓存写入 / 输出），于 2026-09-09 从 https://developers.openai.com/api/docs/models/gpt-6-astra 读取，其牌价为输入 $10、缓存命中输入 $1、缓存写入 $12.5、输出 $50。`cache_write` 一档记录官方公布的缓存写入价；$10 只适用于不写入缓存的输入，而三档分桶无法表达这一区分。输入超过 272K Token 后各档价格翻倍（输出为 1.5 倍）——与目录对所有分档厂商的处理一致，该行记录基础档。
- **`openai/gpt-6-astra`（provider `openrouter`）**——上下文窗口、视觉标记与 $1 / $12.5 / $50 的价格均与直连行相同，并按 `openai/*` 同组条目的惯例固定 `client_type = "openai-responses"` 与预置的 OpenRouter base URL。于 2026-09-09 从模型 API 与单模型 endpoints API 读取：默认端点即 OpenAI 自身，且 `discount: 0`，因此牌价就是 OpenRouter 的实际计费价。endpoints API 另有 prompt 超过 272,000 Token 后的 overrides，该行不予记录。
- **路由与快速模式与 AgentHub 保持一致。** `resolveModelEnv` 与 `fastModeProtocol` 在 `gpt-5.4` / `gpt-5.5` / `gpt-5.6` 之外新增 `gpt-6` 子串，因此 `gpt-6*` id 解析到 `OPENAI_*` 变量对，并可在 OpenAI 协议上使用快速模式开关（`service_tier: "priority"`）。这对应 AgentHub 的 GPT 客户端在下一个版本中采用的路由；在 PenguinHarness 升到该版本之前，这个 id 只存在于目录中、运行时尚不可路由，因为此处的 `@prismshadow/agenthub` 仍固定在 `^0.4.8`，版本提升是另一次改动。
- 两条都位于目录排序规则要求的位置——分组内按 model id 字典序排列、同一系列的新版本在前——因此 `gpt-6-astra` 位于 `gpt-5.6` 之前，`openai/gpt-6-astra` 位于 `openai/gpt-5.6-luna` 之前。测试固定了这两处位置、两处价格、网关条目的上下文窗口与协议固定值，以及两处路由结果。
- 中英文 `models` 页在预置目录的示例清单中列出 `gpt-6-astra`。`unified-llm-api` skill 的模型 id 表新增一行 GPT-6，路由顺序清单中加入 `gpt-6`，映射快速模式的 GPT 客户端类型也记为 `gpt-6`；`agent-development` 插件版本提升至 `2026-09-09.1`，已安装的副本因此会收到更新提示。

## 兼容性

既有 Project 不会自动获得这两条：预设是在 Project 创建时复制进 `.project_config.toml` 的，此后没有任何机制会改写它们。对已经存在的 Project，请在模型页面使用**同步预设**把它们引入——它只会追加 Project 缺少的目录条目、并更新已有条目中由目录所有的字段，不删除任何内容，也不会改动已存的默认模型与任何凭证。
