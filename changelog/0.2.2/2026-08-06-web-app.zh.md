## 目录浏览在反复点击下不再走错

在列表仍在加载时，于文件面板中再次点击某个文件夹行会让路径段不断叠加（`home` → `home/home` → `home/home/home/home`），把用户搁浅在「路径不存在」上；工作区拾取器也可能在一个较慢的目录响应晚于较新响应到达时被静默改变位置。列表现在与它被拉取时所针对的那个目录绑定（无论时序如何，双击都会算出同一个目标），导航进行中会禁用行与面包屑，拾取器请求被串行化因此只有最新的响应胜出（包括可编辑的路径行），而服务端的 `dir_not_found` 错误改为渲染本地化文案，而不是那条内含畸形路径的英文原始消息。

## 保存 Project 新会话默认值会重置新对话草稿

打开一次 `/chat/new` 就会把当时的 Agent / 工作区 / 审批模式钉进逐用户的草稿缓存，而那份陈旧草稿会遮蔽此后对 Project 新会话默认值的任何改动。保存默认值现在会剥掉对应的缓存钉住项——已打出但未发送的文本、已暂存的 Skill 与芯片都保留——并对同一标签页中打开的草稿页做实时重新播种（否则它那个防抖持久化会把旧值原样写回去）；其他标签页在下次访问时取得该变化。模型的钉住项仍然恰好在默认模型本身改变时释放，从而保持「切换即成默认」的延续行为不变。

## 头像上的更新圆点会自我说明

侧边栏头像的更新指示现在会在悬停 tooltip 与可访问标签中点名可用的版本（与更新那一行的措辞完全一致），而收起态图标栏的头像也显示同样的指示——此前那个圆点没有标签，图标栏则什么都不显示。顺带修掉了版本信息缓存中一处被动订阅者的缺口，使图标栏能看到它挂载期间返回的结果。

## 模型目录以 DeepSeek 为焦点打开

模型页现在默认只展开 DeepSeek 分组；其他厂商分组与用户自定义分组初始为折叠。当搜索查询处于活动状态时，任何含有匹配项的分组会被强制展开（这是派生状态，不持久化），因此结果绝不会藏在折叠的分组里。用户自己的展开/折叠操作按 Project 持久化（localStorage，与侧边栏分组折叠同一套模式），并在下次访问时恢复；没有已存状态时，则适用「只展开 DeepSeek」的默认。

## 模型对话框解释协议，而不是对它发出警告

模型配置对话框的 base URL 字段现在在框内带一个灰色后缀，显示客户端会追加到 base URL 之后的确切路径——OpenAI 兼容条目（网关、自定义分组，以及 DeepSeek/Z.AI/Moonshot/Qwen）为 `/chat/completions`，OpenAI 直连为 `/responses`，Anthropic 为 `/v1/messages`，Gemini 为 `/v1beta/models`（每一条都对照 SDK 的实际请求路径核实过）——取代了原先那句啰嗦的「该模型使用厂商官方协议」警告。预置的原厂直连分组的机制提示（AgentHub 自动路由、环境变量回退）统一为一句面向用户的话：「仅支持 <厂商> 的官方 API 协议；OpenAI 兼容端点请使用自定义模型分组。」

## 「临时工作区」统一

自动创建的会话工作区现在在工作区拾取器及其提示、定时任务表单、服务端/SDK 错误信息、文档，以及 penguin-sdk skill（v19）中，一致称作「临时工作区」/ "temporary workspace"——取代此前混用的「自动临时目录」措辞。持久化的键、id 与磁盘上的 `workspaces/tmp-<8hex>` 形态均未触碰。
