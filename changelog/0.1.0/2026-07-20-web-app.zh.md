Web App 中的聊天输入、会话标题与 Skill 库。

## 聊天输入：按位置触发的斜杠、输入框上方的 Skill 芯片、更宽的 Skill 菜单

`/` 命令菜单现在可从任意光标位置弹出（与 `@` 提及一致），执行命令只移除该 token；已选中的 Skill 以芯片形式显示在输入框上方、紧邻 Agent 芯片；芯片的移除按钮在悬停时改变颜色而不是刷上背景色；Skill 下拉菜单加宽以便描述可读，同时仍能容纳手机屏幕。

## 细节

- 按位置触发的斜杠（`slash-token.ts`，纯函数且有单元测试）：文本开头或空白之后的 `/` 会从光标所在处弹出命令菜单（路径与 URL 永远不会触发），与既有的按位置匹配 `@` 提及保持一致；执行命令只移除 `start..end` 这一段 token，其余文本保留。发送时的 `@` 语义未变——仍然只有位于开头的 `@` 才会触发交接。
- 已选中的 Skill 以芯片形式渲染在输入框上方，与 `@` 交接芯片同处一行（Skill 图标 + 等宽名称 + 移除叉号），从下拉菜单中选取时即刻出现；工具栏上的计数徽章保持同步。
- 芯片的移除按钮（Agent 与 Skill）去掉了悬停背景——改为叉号本身变色。
- Skill 下拉菜单加宽（26rem，并按视口收敛），使描述在桌面端保持可读，同时不会在手机上溢出。
- 模型页的分组测速按钮在 sm 断点以下收缩为纯图标（三个带文字的操作在 390px 宽的头部放不下——由布局 e2e 捕获）。

## 正文满 1000 字符后即开始生成标题

Session 标题现在只要主会话正文流出约 1000 个字符就开始生成，而不再等待整个 Task 结束——长回答不会再冲掉标题素材——并且标题提示词现在会抑制思维链。

## 细节

- Server：输出中继在主会话完整正文流出满 EARLY_TITLE_BODY_CHARS（1000）个字符后，于运行途中触发标题生成器（子会话文本不计入）；生成器自带守卫（标题为 NULL、单飞行），而 Task 完成时的触发保留为短回答的兜底。由一个受开关控制的运行途中测试覆盖，证明提前触发确实发生在运行仍在进行时。
- Core：捕获的助手侧标题素材上限为 1000 字符（用户侧仍为 2000）——标题只需要回答的开头部分。
- 标题提示词新增一条明确规则「立即作答——不要出声思考、不要产生思维链」，并以一个空的 `<think></think>` 块结尾，许多推理模型会把它视作已经闭合的思考阶段（与模型探测所用的手法相同），从而把这次一次性请求的预算留给标题本身。

## Skill 库：更新提醒、无边框分组、强调色图标

当某个 Agent 已安装的 Skill 副本版本低于库中版本时，Skill 库会给出提醒——卡片上的强调色旋转按钮可一键更新所有过期的 Agent，管理安装对话框则会在过期行上标出「更新」按钮。分组小节去掉边框，卡片图标改为置于主题强调色背景之上。

## 细节

- 已安装 Skill 的快照现在会记录每个已安装副本的 `version`（读取 API 本就返回它——数据源是已安装的 SKILL.md frontmatter）。一个纯函数 `outdatedAgentIds` 助手（有单元测试）标记出副本严格旧于库版本的 Agent；未安装的 Agent 以及本地副本**更新**的情况永远不会触发它。
- 卡片页脚：当存在任一过期 Agent 时，出现一个强调色旋转按钮（「有新版本：更新 N 个 Agent 的安装」/ "Update available"）；点击后会在每个过期 Agent 上重新安装当前库副本（再次安装即更新的语义），并给出一次批量成功提示；部分失败时保留已成功的 Agent，并提示第一个错误。
- 管理安装对话框：过期行在「已安装」/"Installed" 旁显示一个强调色的「更新」/"Update" 按钮，仅更新该 Agent。
- 样式：分组小节改为无边框（仅由头部背景承载分组感）；卡片图标改用主题强调色（`--accent-bg`/`--accent-fg`，跟随主题色设置），取代原先带边框的灰色方块。

## 标题剥离 Skill 调用标记；Agent 卡片显示已安装 Skill 数

两项 Web App 增补：生成的标题不再泄漏 `<use_skills>` 块，Agent 卡片显示已安装的 Skill 数量。

- Session 标题在生成前以及兜底路径中都会剥离机器标记：`stripConversationMarkers`（core，已导出）会从送给模型的素材、从模型输出（经 `sanitizeTitle`）以及从服务端的首行兜底中，移除 `<use_skills>…</use_skills>` 与交接 / 定时任务的标记块——因此一次 Skill 调用的标记绝不会成为标题。普通的尖括号文本（例如 `<div>`）不受影响。
- Agent 卡片的统计行新增已安装 Skill 数（打开的书本图标）：agents API / service 依据 `agent_state/skills/<name>/SKILL.md` 目录计算 `skillCount`，与既有的会话 / 工具 / vault key / 定时任务计数并列。

## 斜杠菜单不再超出屏幕；Skill 卡片按钮改为横排浅色

两处 Web App 打磨修复：斜杠命令菜单可能长过视口顶部，以及 Skill 卡片操作的排布再次调整。

- 斜杠菜单（列出 /compact 以及所有已安装 Skill）现在把自身高度限制在 min(20rem, 40vh) 并内部滚动，因此其顶边永远不会离开屏幕；当前选中行会把自己滚动进视野以便键盘导航。
- Skill 卡片操作回到单行横排（仍是等大方块，垂直居中于卡片右缘），三个按钮现在统一采用浅色次级背景。

## 密码字段打磨、模型 key 可见性，以及无边框 Skill 卡片

围绕密码字段、模型 key 输入框与 Skill 库卡片的若干小的体验修复，另有一张重绘的企鹅游戏截图。

- 修改密码对话框的「当前密码」字段现在给出提示，写明内置管理员的默认初始密码（penguin-2026），使忘记密码的用户仍能进入。
- 密码的显示/隐藏切换按钮移出 Tab 顺序（tabIndex -1）：Tab 现在在字段之间移动，而不会落到那个显示按钮上。
- 模型 API key 输入框新增同样的显示/隐藏切换（复用 PasswordInput），以便在保存前核对粘贴进来的 key。
- Skill 库卡片去掉边框；悬停改为给整张卡片铺一层浅灰背景。
- 企鹅雪橇游戏的效果图重绘，使企鹅保持为一个连贯的卡通整体（此前看起来是碎的）；草稿页卡片、其提示词与落地页标签文案中，都把这个游戏示例强调为 2D，并采用更平滑、更温和的难度曲线。

## 管理员初始密码改为 penguin-2026

`admin123` 出现在每一份泄露密码库里，因此 Chrome 会把首次登录标记为已泄露密码；预置管理员现在以 `penguin-2026` 起始——不会被标记、与品牌相关、全小写加一个连字符，因而依然好输入。

该取值在所有出现处一并替换：服务端预置（`ADMIN_INITIAL_PASSWORD`）、发布版安装脚本的首次登录提示、README、文档（快速开始 / web-app / server-api）、博客文章、落地页快速开始文案、截图脚本，以及 e2e 认证辅助函数。「尽快修改」横幅的语义未变。
