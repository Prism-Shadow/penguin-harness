# 校正 macOS 应用图标尺寸

- **Date:** 2026-08-14
- **Type:** fix
- **Scope:** `desktop`
- **PR:** [#281](https://github.com/Prism-Shadow/penguin-harness/pull/281)

[English](2026-08-14-macos-app-icon-size.md)

PenguinHarness 现在使用专门的 macOS 图标母版，品牌图形居中放置于该平台的安全区内，在 Dock 与 Launchpad 中与相邻应用的视觉尺寸一致。

Windows 图标母版与 Linux 图标集保持不变。
