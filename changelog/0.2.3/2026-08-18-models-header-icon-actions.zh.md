# 模型页分组操作在窄行下依然可用

- **Date:** 2026-08-18
- **Type:** fix
- **Scope:** `web`
- **PR:** [#296](https://github.com/Prism-Shadow/penguin-harness/pull/296)
- **Issue:** [#294](https://github.com/Prism-Shadow/penguin-harness/issues/294)

[English](2026-08-18-models-header-icon-actions.md)

模型页的分组标题栏改为按标题行自身的宽度自适应，分组级的每个操作在任何宽度下都保留下来，窄行时变成只有图标的控件。

## 细节

- 标题行成为尺寸容器，其中的操作按这一行自己的宽度响应，而不再看视口宽度。桌面端侧栏会压窄内容列，此时视口报出的仍是桌面断点，而在这些宽度下，厂商名与操作文字曾经互相压字。
- 行变窄时，「新增模型」「统一配置 API key」「测速」以及「获取 API key」链接只去掉文字标签，图标保留；不再有操作被整个藏起来。按钮的文字在 `@3xl` 行宽处回来，链接的文字在 `@4xl` 处回来。
- 每个只剩图标的控件都带有可访问名称，其中同时给出操作和厂商，另有一个写着操作名称的悬浮提示。外链取用页面上原有的外链图标，并在只剩图标时略微放大点击区域。
- 布局端到端用例在 390 到 1920 CSS 像素之间扫过模型页，逐一断言每个操作在各宽度下都可达、文字标签恰好只在带标签的档位可见，以及标题行既不压字也不溢出。预期档位由实测的行宽推导，因为容器阈值以 `rem` 为单位，会随运行环境的根字号变化。
