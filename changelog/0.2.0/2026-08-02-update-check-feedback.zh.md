# Web App：手动更新检查会报告每一种结果

- **Date:** 2026-08-02
- **Type:** fix
- **Scope:** `web`
- **PR:** [#142](https://github.com/Prism-Shadow/penguin-harness/pull/142)

[English](2026-08-02-update-check-feedback.md)

侧边栏用户菜单里的「检查更新」行此前只在没有可见变化时才给出通知；而当它发现更新版本时，那一行是无声变化的。手动检查现在对每一种结果都给出明确反馈：检查进行时显示加载指示与忙碌标签；已是最新时给出成功 toast；发现更新版本时给出点名该版本的成功 toast——与此同时，同一行变为常驻的「有新版本 vX」条目，点击它打开更新对话框（发布说明链接、仅管理员可用的自更新）。查询失败与检查被禁用仍保留各自的错误/信息 toast。这套结果映射是一个纯函数、有单元测试的分类器：禁用优先于失败，失败优先于发现；而「发现」必须点名一个版本，因此 toast 与那一行都绝不会是空的。
