# 站点：0.1.4 发布文章

- **Date:** 2026-07-27
- **Type:** process
- **Scope:** `landing`
- **PR:** [#96](https://github.com/Prism-Shadow/penguin-harness/pull/96)

[English](2026-07-27-sites-and-blog.md)

一篇双语的 **0.1.4** 发布文章，涵盖这一批次的三个主题——Windows 成为一等的安装方式；目标模式让 Task 持续循环，直到目标真正达成而不只是被回复一句；以及 Agent 面板把子 Agent 的扇出变成一张实时调用图。

这篇文章对限制是刻意点明而非避而不谈：Windows 包目前仅有 x64；`input_command` 的 Ctrl-C 是硬杀整棵命令树，而不是中断前台命令；在 Windows 上升级意味着重新运行安装脚本，因为原地的 `penguin update` 在那里仍会拒绝。

该文章截图所用的采集脚本也加入了既有脚本行列，其输出暂存在被 gitignore 的 blog-assets 目录中以便上传到兄弟社区仓库，而不是把图片提交进本仓库。
