# 侧栏导航统一文案与顺序，入口分常驻与可收起

- **Date:** 2026-09-30
- **Type:** feature
- **Scope:** `web`, `ui`, `docs`
- **PR:** [#909](https://github.com/Prism-Shadow/penguin-harness/pull/909)

[English](2026-09-30-nav-pinning.md)

侧栏导航入口统一为中英各一套名称、同一个顺序。每个页面入口都分为常驻或可收起，导航下方的箭头只折叠可收起的入口。新建对话是例外，始终常驻。

## 名称与顺序

- 入口中文依次为新建对话、智能体、模型库、插件市场、机器管理、成本中心、评估中心，英文依次为 New chat、Agents、Models、Plugins、Machines、Cost Center、Evaluation Center。页面清单里模型库移到插件市场之前。机器入口的中文名由「机器」改为「机器管理」，机器管理页的标题和唯一一条提到该页面的提示随之修改。对话页空状态的按钮由「新对话」改为「新建对话」，与它对应的导航入口同名。
- 收起的侧栏也从同一份清单生成页面图标，因此顺序随之更新，并向管理员显示此前漏掉的机器管理。

## 常驻与可收起的入口

- 默认新建对话、智能体、模型库、插件市场常驻，机器管理、成本中心、评估中心可收起，收起区默认展开。两个区域都按清单顺序排列，没有可收起的入口时不显示箭头。
- 鼠标悬停或键盘聚焦时，行尾出现图钉按钮，触屏上始终显示。入口常驻时图钉为实心，提示为「取消常驻」，否则提示「常驻」。把入口拖进或拖出收起区效果相同。
- 新建对话仍在滚动区上方的固定位置，没有图钉按钮，也不能拖动。
- 选择按浏览器保存在 `penguin.sidebarNavPinned`，只记录与默认不同的入口。清单里没有的键会被忽略，没有记录的页面取默认值。已保存在 `penguin.sidebarNavGroupCollapsed` 的折叠状态继续生效，只折叠收起区。
- 公司模式的六个入口仍整组折叠，没有图钉。
- 这些部件属于 UI 包：`SidebarNavGroup` 可在折叠区上方放置常驻入口，可将折叠区设为放置目标，也可省去折叠区；`SidebarNavArea` 是一段可接受放置的常驻入口；`SidebarNavEntry` 是带图钉按钮与拖动手柄的 `NavRow`。`NavRow` 新增 `groupHover` 与 `draggable={false}`，供这类入口中的行使用。
- 文档的 Web App 页面补充了这些入口、图钉和机器管理一行（仅管理员）。
