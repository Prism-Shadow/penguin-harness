# 落地页实时展示 Web App，导航只列独立页面

- **Date:** 2026-10-12
- **Type:** feature
- **Scope:** `landing`, `docs`, `gallery`
- **PR:** [#1076](https://github.com/Prism-Shadow/penguin-harness/pull/1076)

[English](2026-10-12-landing-live-gallery.md)

落地页首页围绕真实的 Web App 重建，应用由组件画廊实时嵌入；落地页与文档站的顶部导航只列独立页面。

## 导航

- 落地页与文档站的导航列出主页、博客、下载、文档、画廊，`md` 断点起排成一行。分区锚点（特色、快速开始、应用场景、评测、CONTRACT.md、功能）及标记它们的滚动跟踪已删除，页脚也去掉了指向已删分区的链接。

## 首页

- 新的顺序：首屏、三个展示块、自进化循环及其演示、一句话构建应用的案例、PenguinHarness 的组成、Agent 周边已经搭好的部分、成本对比、客户案例、最新动态、快速开始、行动号召与社区。CONTRACT.md、功能、Skill 与安全各节连同文案、素材与测试一并删除。
- 旧页面的三处图形动画保留下来，按新页面的样式与文案重做：自进化循环（Optimizer、Evaluator 子 Agent、被测 Agent 从版本 N 到 N+1、三张示意趋势图），放射状结构图（改为 OmniMessage、Penguin SDK 与 Agent State），以及搭积木动画（Agent 开发库与 PenguinHarness 已经搭好的部分对比，不再出现 LangChain 的名字和 1x/100x 倍数）。开启减少动态效果时三处都不播放动画。
- 新的演示视频，中英文各一个，放在社区仓库：循环下方是决策智能体的自进化（同一模型从 84 分到 100 分；被测 Agent 运行 6 次，花费 $0.0373）；案例一节换成一句话构建的法务应用（5 次样件审阅，$0.0423），替换原来的 RAG 应用。封面都取视频自己的标题帧；RAG 的封面图已删除。
- 首屏在定位语的右上角以品牌色上标注明「免费开源」，统计保留三项（去掉模型数量一项），三行目录各以品牌强调色的数量开头：支持模型的 1000+ 写在词典里，自进化算法与评估集的数量取自 `RSI_TOOLKITS` 与 `BENCHMARKS` 的长度。其下是 Web App 的开始页，实时运行。
- 三个展示块左右交替，各由一个实时演示配一句标题、一句说明与一个文档链接：一轮自进化的对话、评估中心里一套 Benchmark 的分数线、插件市场里的自进化工具包。
- 最新动态按日期列出博客索引里最新的四篇产品动态与技术实践，并链接到全部文章。
- 两份词典的文案重写，首页各节去掉了眉题。不再被引用的图片与脚本已删除。

## 实时演示

- `LiveAppFrame` 嵌入画廊的应用框文档（`/gallery/app.html`），打开画廊的某个界面，主题取应用缺省，语言与明暗跟随站点；地址构造、窗口尺寸与路由直接从 `packages/ui-gallery` 导入。框接近视口才加载，就绪之前显示平涂的占位，切换语言或明暗时指向新的文档。
- 框以嵌入方式打开（`embed=1`）：读者点进框之前，应用不抢焦点、不滚动页面，滚轮交给页面。
- `sm` 以下显示画廊的手机窗口；没有精细指针的设备上框只作画面，窗口栏的链接打开画廊里的同一界面。
- 开发时，落地页的服务器把 `/gallery/` 转给以 `BASE_PATH=/gallery/` 运行的画廊开发服务器，做法写在包的 README 里。

## 画廊

- 新界面 `chat-rsi`：项目内置的通用智能体用 `agent-optimization` Skill 优化文档智能体——读 Reference 分数和失分最多的用例的 Trace、做快照、在 `AGENTS.md` 加一条规则、并行四个 `agent-evaluation` 子智能体评测、保留 v15 并写入 scoreboard——中英各一份，评测子智能体与 Test Session 各有自己的历史。
- 演示 Benchmark 的评估随版本攀升，止于这一轮保留的版本；文档智能体的版本即该版本，`AGENTS.md` 里带着新加的规则。
- 模拟插件库把自进化工具包列在「Agent 自进化」、把 Agent 评估列在「AI 应用开发」，取自产品自带插件包的清单与图标；全部内置 Benchmark 取自核心的数据，为此核心新增构建入口 `state/builtin-benchmarks-data`。
- 「新对话」界面改为打开草稿页路由 `/chat/new`；此前的 `/chat` 打开的是最新的对话。
- 嵌入的框（`embed=1`）在其文档获得焦点之前，丢弃焦点调用与向外的 `scrollIntoView`，并把滚轮转给页面。
