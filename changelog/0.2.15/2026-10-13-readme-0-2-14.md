  rising from 84 to 100.

  per language, replacing the RAG docs-expert example.

  API, each with a screenshot and a link to its tutorial.
- Installation is split by what you install: the desktop app, the CLI and server (one table of the
  one-line installers and npm), Docker and offline installs, shortened, then the optional Chrome
  extension.
- Development names the repository's coding-agent Skills in `.agents/skills/` and how an agent
  loads them.
