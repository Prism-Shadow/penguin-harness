# 文档站按任务重新组织，全部页面重写

- **Date:** 2026-09-16
- **Type:** process
- **Scope:** `docs`
- **PR:** [#758](https://github.com/Prism-Shadow/penguin-harness/pull/758)

文档站参照帮助中心的思路重新组织，全部页面的中英文版本都已重写：先写英文，再由英文翻译出中文，每份草稿都对照代码和 Web App 的界面文案核对过。原有页面的地址全部保持可用。

## 细节

- 侧栏分为五个部分。**开始**：产品介绍、快速开始（桌面应用、CLI、Docker、SDK），以及新增的核心概念和更新页面。**使用指南**：Web App、对话、文件面板、定时任务、远程控制、Agent、Skill、模型、成本中心和系统设置。**进阶功能**：评估中心、自我进化、目标模式和公司模式。**工作原理**：架构、服务端启动、OmniMessage、Agent 循环、消息流、核心接口、工具、会话与 Trace。**参考**：CLI、Server API、配置和安全。
- 原来长达 6.3 万字符的 Web App 指南被拆开：`web-app` 改为概览页，对话、文件面板、定时任务、Agent、成本中心、评估中心、系统设置和更新各自成页。其中插件库和模型配置两节并入 `skills` 与 `models`，这两页也从设计部分移到了使用指南。
- 新增三页：`concepts`（按主题分组的术语表）、`remote-control`（把对话绑定到飞书、Telegram、QQ 或微信）和 `updates`。
- 使用指南以任务和编号步骤为主，实现细节集中放在结尾的「工作原理」一节；参考页面里每条命令、路由和配置项都采用统一格式。
- 修正了与代码不一致的内容，其中包括：四种停止原因与错误码、压缩的结束状态、服务端启动流程与 HMR 平台、CLI 作为服务端客户端运行、目标模式的图片规则、公司模式中由服务端强制和仅为约定的部分、Optimizer 与 Evaluator 之间的信息隔离，以及此前未写入文档的数十个路由、选项和设置。
- `packages/core/src/state/agent-state.ts` 中的一条源码注释改为引用 Skill 页面重命名后的标题。
