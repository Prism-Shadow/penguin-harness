# Start page: the ski game example asks for downhill terrain and a crash you get up from

- **Date:** 2026-10-12
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1072](https://github.com/Prism-Shadow/penguin-harness/pull/1072)

[中文版](2026-10-12-ski-game-prompt.zh.md)

The start page's penguin ski example asked for a game that plays more like skiing.

## Details

- **Terrain.** The mountain trends downhill, with steep slopes as well as rolling crests, so the
  penguin speeds up on the way down.
- **Crashes.** A crash no longer ends the run: the penguin gets back up and skis on, losing some
  speed.
- **Skis.** The penguin rides clearly visible skis.
- **Playability.** The prompt asks for an easy start, varied terrain and a smooth speed ramp.
