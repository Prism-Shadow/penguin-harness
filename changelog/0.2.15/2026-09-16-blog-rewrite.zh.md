# 全部博客文章按可读性重写

- **Date:** 2026-09-16
- **Type:** process
- **Scope:** `landing`
- **PR:** [#757](https://github.com/Prism-Shadow/penguin-harness/pull/757)

[English](2026-09-16-blog-rewrite.md)

21 篇博客文章的中英文版本全部重写。每篇先重写英文，再由英文翻译出中文；每份草稿在替换旧文之前，都对照了旧文、产品界面文案和代码逐项核对。

## 细节

- 发布文章（0.1.4 到 0.2.13）、首发文章、模型文章和七月汇总，开头改为简短概述，每项改动单独成节：用户现在能做什么、怎么用、有哪些值得知道的限制。与用户所见无关的内部实现细节已删去。
- 三篇实践文章改成分步教程，包含前提条件、编号步骤和预期结果。`natural-language-training-loop` 从论述改为分步结构，步骤沿用文章原有的提示词。
- 三篇观点文章在开头点明问题和论点，论证的每一步单独成节；带有时间属性的说法保持发布当时的口径。
- 对照每篇文章发布时的代码，修正了过时或错误的说法，例如：0.2.13 文章改为说明「CEO 提议、董事会拍板」是公司 Skill 和手册里的约定，服务端并不强制；0.2.4 文章写明了默认命令策略规则会拦截 `rm -rf` 这类命令；自我进化教程创建的 Agent 改为 `meeting_summary_agent`，因为 Agent id 不允许连字符。界面文字采用文章发布当天应用里的写法（例如 **Set API key for group**、**Costs**、**Trajectory**，中文为「统一配置 API key」「成本中心」「模型仓库」），如今已不成立的说法注明了所指的版本。
- 页内锚点链接改为直接写明所指的小节。
- 标题里没有版本号的文章，开头加了一行说明，写明文章基于哪个版本撰写（0.0.1、0.1.0、0.1.1 或 0.1.2）。
- 中文文章使用中文界面的原文和产品中表示 steering 的术语「插话」，保留面向中文读者的内容（Fireworks 指南中的 AMD 中国站申请路径、本地化的提示词与截图），并确保紧挨中文标点的加粗都能正常渲染。
- landing 包新增对博客目录本身的校验：每篇文章都有中英两个版本，两份 frontmatter 的 `date`、`category`、`pinned` 一致，文章里指向 `penguin.ooo/docs/<slug>` 的链接都能对上文档站实际存在的页面。
