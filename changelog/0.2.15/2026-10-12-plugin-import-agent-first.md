# Import plugin opens on Ask an agent

- **Date:** 2026-10-12
- **Type:** feature

The Plugins page's **Import plugin** dialog opened on **Ask an agent** instead of **From npm**,
and its tabs were reordered to Ask an agent, Upload a zip, From npm, From a link. The plugin docs
list the ways in the same order.
