# Atria Dawn uses the updated model ID

- **Date:** 2026-10-14
- **Type:** fix
- **Scope:** `model-catalog`, `docs`
- **PR:** [#1122](https://github.com/Prism-Shadow/penguin-harness/pull/1122)

[中文版](2026-10-14-atria-dawn-model-id.zh.md)

Changed the Custom preset's model ID from `Atria-Dawn-Preview` to `Atria-Dawn` and its display name to Atria Dawn. Updated the model and configuration documentation to use the new name.

Existing Projects can add `Atria-Dawn` through **Add new models** on the Models page, set its API key, and select it. Stored entries and the selected default are not rewritten.
