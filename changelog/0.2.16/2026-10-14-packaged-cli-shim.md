# Remove the workspace marker from packaged installs

- **Date:** 2026-10-14
- **Type:** fix
- **Scope:** `ci`
- **PR:** [#1124](https://github.com/Prism-Shadow/penguin-harness/pull/1124)
- **Issue:** [#1119](https://github.com/Prism-Shadow/penguin-harness/issues/1119)

[中文版](2026-10-14-packaged-cli-shim.zh.md)

Removed the `pnpm-workspace.yaml` generated by `pnpm deploy` from Docker images and release packages after dependency installation, preventing packaged servers from mistaking their installation directory for a source checkout and writing an error stub to `<data root>/bin/penguin`.

## Details

- Added a Docker smoke check that starts with an old error stub, verifies the server removes it, and runs `penguin --version` and `penguin browser --help` with `/data/bin` first on `PATH`.
