# 对话详情卡：Token 与用时的分项收进「?」，与轨迹观测一致

- **Date:** 2026-10-13
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1095](https://github.com/Prism-Shadow/penguin-harness/pull/1095)

[English](2026-10-13-chat-stats-trace-aligned.md)

对话页详情卡的统计改成与轨迹观测全局统计相同的读法：每个总数的分项都收在它右侧的圆圈「?」里，用的是同一组分项组件。

## 细节

- 「总 Token」新增「?」，列出缓存输入、未缓存输入与输出的 Token 数及各自占总数的比例；缓存命中率仍留在总数后的括号里。
- 「用时」去掉了行内的「（API …，工具 …）」括号，改为「?」，列出模型 API 时间与工具 wall time 及各自占用时的比例，与轨迹观测「用时」一行相同。
- 缓存命中率的计算与格式改用轨迹观测同一组函数。
