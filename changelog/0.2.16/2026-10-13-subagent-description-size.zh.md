# 智能体面板：子智能体描述比名称小一号

- **Date:** 2026-10-13
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1096](https://github.com/Prism-Shadow/penguin-harness/pull/1096)

[English](2026-10-13-subagent-description-size.md)

智能体面板的调用关系图里，每个子节点的第二行是派生它的 `run_subagent` 调用所带的描述，此前与上方的 Agent 名用同一字号，中文描述看上去和名称一样大，甚至更大。现在名称改用正文字号，描述仍用小号字排在下方，三套主题都是如此。

## 细节

- 关系图的节点框、间距和连线改为跟随「字号」设置缩放（按 rem 排布，不再是固定像素），每一档字号下两行文字都放得下。此前白领主题在「特大」档会把描述的下沿截掉。
- 同一字号下，较长的 Agent 名会稍早被截断；节点的 tooltip 仍显示完整的名称与描述。
