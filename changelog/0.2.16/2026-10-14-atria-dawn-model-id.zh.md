# Atria Dawn 更新模型 ID

- **Date:** 2026-10-14
- **Type:** fix
- **Scope:** `model-catalog`, `docs`
- **PR:** [#1122](https://github.com/Prism-Shadow/penguin-harness/pull/1122)

[English](2026-10-14-atria-dawn-model-id.md)

将 Custom 预置模型的 ID 从 `Atria-Dawn-Preview` 改为 `Atria-Dawn`，显示名称改为 Atria Dawn。模型与配置文档同步使用新名称。

已有 Project 可在模型库页面通过**同步新增模型**添加 `Atria-Dawn`，为其设置 API key 后选择使用。已存条目和当前默认模型不会被改写。
