# 智能体面板：子智能体显示自己那次调用的描述

- **Date:** 2026-10-13
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1107](https://github.com/Prism-Shadow/penguin-harness/pull/1107)

[English](2026-10-13-subagent-card-binding.md)

一次回复同时派生多个子智能体时，子智能体可能被挂到别的调用上：它在智能体面板里的节点显示的是那次调用的描述和思考等级，消息流里它的快捷行也落在错误的 `run_subagent` 卡片下。现在子智能体会落在派生它时所用 `prompt` 的那次调用上，实时显示和重新加载后都是如此。

## 细节

- 子智能体一出现仍会立即显示，随后它的开场 prompt 会把它移到携带这段 prompt 的调用上；如果那张卡片已被同批的另一个子智能体占用，两者互换。
- prompt 相同的几次调用，按实际生效的 `agent_id`、`model_id` 和 `provider` 区分，包括省略参数时从父会话继承的值；这些也都相同时，由最早一次仍在运行的调用接纳。
- 会话元数据缺失、无法区分 prompt 相同但配置不同的调用时，子智能体保留原有的卡片绑定。
- 被拒绝的调用即使 prompt 相同，也不会接纳子智能体。
