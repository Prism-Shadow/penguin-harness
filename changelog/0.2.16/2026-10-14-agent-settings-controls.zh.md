# Agent 设置本地化与工具删除

- **Date:** 2026-10-14
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#1111](https://github.com/Prism-Shadow/penguin-harness/pull/1111)

[English](2026-10-14-agent-settings-controls.md)

将 Agent 运行参数和工具设置中的配置键名替换为本地化名称，包括系统提示词、思考等级和访问权限。运行参数及 API 设置复用了新建对话的思考等级菜单，直接显示实际生效的默认等级，不会自动保存覆盖值。空间足够时，API 并发数与审批模式放在同一行。

## 删除工具

为每个内置工具增加了带确认提示的删除入口。删除立即保存，保留其他未保存的参数，并让新建上下文不再暴露或执行该工具。确认提示说明了已有会话采用改动的时机。删除最后一个工具后保留空工具列表。
