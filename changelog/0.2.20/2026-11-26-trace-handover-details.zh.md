# 未能生成完整摘要的压缩在「压缩完毕」行里展示交接内容

- **Date:** 2026-11-26
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1894](https://github.com/Prism-Shadow/penguin-harness/pull/1894)

[English](2026-11-26-trace-handover-details.md)

压缩未能生成完整摘要时，新上下文改以交接内容开头：就地的交接说明（`[context_summary]` 块），或会话内切换模型时的 Trace 交接说明（`[model_switch_from]` 块）。此前对话里看不到这段文字，切换模型时只有分隔线「模型已切换 · A → B · 经 Trace 交接」及其悬停提示。现在交接内容展示在它所接续的那一行压缩行里，与压缩行展示自身详情的方式一致；该行定格为「压缩完毕」，带降级状态图标，由图标说明没有摘要的原因。

## 细节

- **规则**：所有情形同一条规则——某行压缩未能生成完整摘要，其后新上下文开头的那段文字即该行的交接内容。完整摘要的开头不并入任何行，该行照常以「压缩结果」展示摘要。
- **小节**：正文默认折叠，以「交接说明」一节代替「压缩结果」，依次列出：
  - 原因，与图标提示同一措辞；
  - 交接说明点名的 Trace 文件路径（点名时才有）；
  - 去掉标签的交接说明原文。

  长路径在节内折行，全部内容可选中复制。
- **切换模型**：
  - 分隔线保留原有文字，去掉悬停提示。
  - 当前模型不可达时，切换既没有发出压缩请求，也没有写压缩事件对，这一行由交接说明推导，定格为 `completed`，不计用时；图标提示第一行为「原模型不可用，没有请求摘要」。
  - 新上下文尚无完成的轮时再次切换，会把同一条交接说明重写到下一个文件头部；这份副本只让后一条分隔线写作「经 Trace 交接」，不再推导压缩行。
- **实时视图**：就地的交接说明随下一个文件写入 Trace，不在输出流上，实时视图要待重新读取历史后才出现该节；切换模型的交接说明随切换上流，即时出现。
- **数据**：一切取自 Trace 已有的记录，没有新增记录或字段。
