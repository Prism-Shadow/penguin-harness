# 减少应用控件之间的光标切换

- **Date:** 2026-10-15
- **Type:** fix
- **Scope:** `ui`, `web`, `skills`
- **PR:** [#1142](https://github.com/Prism-Shadow/penguin-harness/pull/1142)

[English](2026-10-15-control-cursors.md)

按钮、页签、导航项、文件行和表单选择控件统一改用了箭头光标，减少了鼠标经过密集控件及其间隙时的箭头与手形切换。正文链接和行内链接操作保留了手形；文字输入、拖拽、调整大小、缩放和禁用控件保留了各自的光标。

## 共享控件

- 将控件的默认光标规则统一放入共享 UI 主题，并移除了应用控件中与之冲突的手形样式。
- 更新了前端 skill，要求先检查并复用共享 UI 组件，为通用行为扩展共享组件，并将应用通用的交互规则放入 UI 包。
