# A2UI 表单与选项组件块改用 UI 包的控件绘制

- **Date:** 2026-10-20
- **Type:** feature
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#1257](https://github.com/Prism-Shadow/penguin-harness/pull/1257)

[English](2026-10-20-a2ui-form-blocks.md)

表单组件块可以绘制全部 11 种字段，表单与选项组件块改用 UI 包的控件绘制，不再自带样式，因而随三套主题变化。

## 渲染

- 每种字段对应一个控件：按长度上限截断的单行输入框、三行的多行文本框、`NumberInput`、`Slider`、用于单选的分段控件或单选组、用于多选的 `ChoiceGroup` 胶囊或复选框列、首行为空且在模型未写占位文字时显示「请选择…」的下拉列表、标题与表单其他字段一致的开关行，以及原生的日期、时间与日期时间输入框。
- 必填字段都已作答、每个答案都有效之前，表单的按钮不可用。答案不合规则时，控件显示危险色，下方说明行变为错误行：字段的 `hint`，没有时为以符号写出的被违反的规则，再没有时为「值无效」。在多行文本框里按 Mod+Enter 即填入表单，与在单行输入框里按 Enter 相同。
- 字段从初始值开始；滑块从最小值开始，开关默认关闭。恢复的草稿只取回各字段能接受的内容，未动过的表单不写草稿。
- 选项组件块用 `ChoiceGroup` 绘制选项。
- UI 字符串与 Web App 的中英文词典新增下拉列表的空行文字与兜底的错误行文字。

## 组件画廊

- A2UI 回复页用两个表单展示全部字段种类，因为一个表单至多六个字段。
