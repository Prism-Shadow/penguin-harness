# The built-in library table lists penguin-support

- **Date:** 2026-10-15
- **Type:** process
- **Scope:** `docs`
- **PR:** [#1149](https://github.com/Prism-Shadow/penguin-harness/pull/1149)

[中文版](2026-10-15-penguin-support-library-row.zh.md)

The Built-in library table on the Skills & Plugins page now has a `penguin-support` row in
Office Productivity, in both languages. It names the plugin's Skill and support workbench and
notes that it is not preinstalled on `default_agent`: the default Project's built-in support
agent comes with it, and other agents install it from the library.
