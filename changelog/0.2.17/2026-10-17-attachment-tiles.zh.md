# 附加的图片与文件统一为一套图块，发出的图片不再变成椭圆

- **Date:** 2026-10-17
- **Type:** fix
- **Scope:** `ui`, `web`, `ui-gallery`, `docs`
- **PR:** [#1191](https://github.com/Prism-Shadow/penguin-harness/pull/1191)

[English](2026-10-17-attachment-tiles.md)

白领主题下，发出的图片会显示成椭圆：它用的是控件圆角，而白领把控件圆角设为胶囊（9999px），这个圆角落在非方形的盒子上，就把矩形圆成了跑道形。现在附加的图片与文件由共享 UI 包里的同一套图块绘制——发送前的输入框、发出的消息、插话小块里都是它们——圆角与输入框的 chip 相同，取盒子圆角。

## 细节

- `@prismshadow/penguin-ui` 新增 `AttachmentList`、`AttachmentImage` 与 `AttachmentFile`，全部只接收属性。图片图块高度固定，宽度在上下界之内随图片原比例；超出边界或图片小于图块时，整张图放进图块、底为中性填充，不拉伸、不裁切、不放大。点击放大查看。加载失败的图片保留一个方形图块与图片图标，悬停说明原因。
- 文件图块显示文件类型的图标（文本、代码、压缩包、图片、其他）、文件名（放不下时截断，悬停显示全名），其下为扩展名与大小。
- 输入框把待发送的图片与文件排成卡片顶部的一行图块，每个图块的移除按钮常驻；长文件名先截断，按钮不会被挤出。
- 发出的消息在正文气泡上方显示同样的图块：图片一行、文件一行，只有一个时间页脚。vision 模型以独立图片消息收到的图片并入它所属的那条消息，一条消息因此只有一个对话索引锚点，不再一图一个气泡。「附加文件」提示不再出现，每个文件都有自己的图块。
- 插话小块里的图片与文件排成一行图块，与输入框同一尺寸。
- `MessageBubble` 去掉了 `image` 变体与 `MessageImage`，新增 `MessageAttachments` 承载一条消息的图块行；`ComposerCard` 新增 `attachments` 插槽；`Chip` 去掉了只有输入框文件 chip 用到的 `outline` 样式与大小读数。
- UI 画廊新增「附件」主题：可逐个移除的输入框、发出的消息、插话、从 16 px 图标到 10:1 全景图的各种比例、手机宽度与比任何图块都长的文件名，以及加载失败的图片；一条浏览器用例在每套主题下量取图块。
- 对话使用指南改为描述图块。
