# 博客文章按编号引用来源，离站链接先确认

- **Date:** 2026-10-20
- **Type:** feature
- **Scope:** `landing`, `ui`
- **PR:** [#1252](https://github.com/Prism-Shadow/penguin-harness/pull/1252)

[English](2026-10-20-blog-citations-link-confirm.md)

博客文章把 GFM 脚注渲染为编号引用：紧贴句末标点之前的上标 `[n]` 点击后跳到文末「参考资料」的第 n 条；同一处引用的多个来源合为一组 `[1, 2]`，每个数字各自可点；每一条都能跳回正文中引用它的每一处。文章里的链接改为按目标打开：`#` 链接只在页内滚动；站内页面照旧在新标签页打开；指向其他站点的链接先弹出首页目录行所用的确认框，确认后再在新标签页打开。文章中用来标出关键句的加粗文字，字重与颜色都比正文深一级。

## 细节

- 文章在句末标点之前写 `…a sentence[^1].`（中文为 `文字[^1]。`）引用来源，并在文末以 `[^1]: [Title](https://…)` 定义每个来源；没有 URL 的来源只写标题。列表标题取站点词典（References / 参考资料），文章不写。
- 两种语言的 id 都是 ASCII：条目为 `fn-n`，引用处为 `fnref-n` 与 `fnref-n-k`。回跳链接向读屏软件说明它回到哪一处。
- 站内页面指相对路径，以及 `penguin.ooo`、`www.penguin.ooo` 与页面当前所在主机上的地址；其他主机以及 `mailto:` 等协议都算离站。
- `@prismshadow/penguin-ui/site` 的 `SiteMarkdown` 新增 `remarkRehypeOptions`；它的 `##` 与 `###` 标题保留渲染管线已经给出的 id（脚注列表的标题，即每处引用指向的元素），不再用 slug 覆盖。它还把相邻的多个引用合为一个上标组 `[1, 2]`：括号与逗号是真实文本，复制或进入阅读模式后依然保留；每个数字保留各自的链接、id 与描述；组前的单词连接符（U+2060）让整组与前文留在同一行，不会出现在行首。
- `site-prose.css` 为引用与列表提供浅色与深色样式，跳转落点避开吸顶导航栏并以浅色底标出，打印时列表附带 URL。文章内的 `strong` 在浅色与深色下都设为字重 600、颜色比正文深一级。
