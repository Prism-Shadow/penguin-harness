# 通过局域网地址打开 Web App 时也能授权 TokenDance 密钥

- **Date:** 2026-10-25
- **Type:** fix
- **Scope:** `server`, `web`
- **PR:** [#1328](https://github.com/Prism-Shadow/penguin-harness/pull/1328)

[English](2026-10-25-oauth-callback-origin.md)

以非回环地址的明文 HTTP 打开 Web App（如局域网地址 `http://192.168.1.10:7364`、主机名或 `0.0.0.0`）时，在模型页连接 TokenDance 会被带到一个授权页，页面直接报「授权请求无效」。该授权页只会跳回 HTTPS 地址，或 `localhost`、`[::1]`、`127.x.x.x` 上的明文 HTTP 地址，而服务端交给它的正是浏览器访问时用的地址。

现在只有在该地址能接收跳转时，服务端才请求跳转回来；否则直接以手动模式打开授权流程：不带回调地址，S256 PKCE 照旧。发起接口的返回新增 `mode` 字段，说明流程实际以哪种模式打开。弹窗随之直接进入填写一次性授权码这一步：打开授权页，把页面上显示的授权码粘贴回来。这时不再提供「改回自动跳转」，因为授权页会拒绝跳转。回环地址与 HTTPS 地址上仍默认自动跳转，两种方式之间照常可以切换。
