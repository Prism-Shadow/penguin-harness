# 机器连不上时，对话页说明是哪台机器、重连到了哪一步

- **Date:** 2026-10-19
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1236](https://github.com/Prism-Shadow/penguin-harness/pull/1236)

[English](2026-10-19-machine-offline-chat.md)

打开一个所在机器暂时连不上的对话时，消息区原先以红字显示传输层的报错，其中带着机器的内部 id 与一个本地 SOCKS 端口。现在消息区按别名说明是哪台机器、它的连接处于什么状态，并在机器重新连上后自动加载对话。

## 细节

- 标题写明机器及其状态：正在重连、已停止自动重连、保存的登录密码被拒绝、服务已停止、尚未连接，或不在当前 Project 的机器列表中。状态取自机器管理页所用的同一份机器列表。
- 服务端正在重连或已停止重连时，标题下方是机器管理页同款的重试状态：第几次尝试、距下一次的倒计时，以及「立即重试」或「重试」——请服务端立即尝试连接这台机器。重试被拒时以 toast 说明，按钮可再次按下。其余状态下提供「重试」，重新读取历史消息。
- 传输层的报错收在「技术细节」折叠里。
- 机器重新连上后，无需操作即重新读取历史消息。
- 本服务端上的对话读取历史失败时，仍显示报错与「重试」。
