# 落地页首页不再下载博客

- **Date:** 2026-10-20
- **Type:** fix
- **Scope:** `landing`
- **PR:** [#1231](https://github.com/Prism-Shadow/penguin-harness/pull/1231)

[English](2026-10-20-landing-route-split.md)

落地页的主脚本不再包含博客。首页、博客列表与下载页读取构建时生成的文章 frontmatter 索引；文章的 Markdown 正文及渲染它的代码在打开文章时才下载。演示视频的封面图改为在视频接近屏幕时加载，不再随页面一起下载。

## 细节

- 新增 Vite 插件（`scripts/frontmatter-plugin.ts`，Vite 与 vitest 配置均已注册），在构建时把 `<post>.md?frontmatter` 转成该文章的 frontmatter 记录；每篇文章的正文单独成文件。
- 文章页改为按需加载的路由。直接打开文章时，正文与页面代码同时下载，标题区与正文一并显示；等待期间保留一屏高的空白，页脚不会先露出再被推走。随后预取文章的另一种语言，切换语言时阅读位置不变。指向小标题的链接（`/blog/<slug>#<id>`）在正文就位后滚动到该处。博客列表会在点击前预取文章页代码。
- 旧版本部署引用的文件已不存在时，页面自动刷新一次，不再停在空白页。

## 加载时间

2026-10-20 在一台 Linux 测试机上测量：分别构建 `origin/main`（172c9e4c4）与本改动，用模拟 GitHub Pages 的静态服务器提供（gzip、`max-age=600`），在 Playwright Chromium 中以 DevTools 网络节流与 4 倍 CPU 降速冷启动加载。大小为实际传输字节数，时间取两到三次运行的中位数。

|                                               |  改动前 | 改动后 |
| --------------------------------------------- | ------: | -----: |
| 主脚本                                        |  508 KB | 171 KB |
| 首页在首屏实时演示框之前下载的字节数          |  595 KB | 193 KB |
| 首页首次绘制，桌面，Slow 4G                   |  3.54 s | 1.75 s |
| 首页首次绘制，手机，Slow 4G                   |  3.53 s | 1.73 s |
| 首页首次绘制，桌面，3G                        | 12.06 s | 5.13 s |
| 直接打开一篇文章，正文渲染完成，桌面，Slow 4G |  3.24 s | 2.34 s |
