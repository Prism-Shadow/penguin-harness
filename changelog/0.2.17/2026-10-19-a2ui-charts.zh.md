# a2ui Skill 讲授统计图与系统资源面板

- **Date:** 2026-10-19
- **Type:** feature
- **Scope:** `skills`, `docs`
- **PR:** [#1227](https://github.com/Prism-Shadow/penguin-harness/pull/1227)

[English](2026-10-19-a2ui-charts.md)

`a2ui` Skill 向模型讲授 `chart` 与 `resources` 组件块，`scripts/sysinfo.mjs` 改为输出 `resources` 组件块，文档也介绍了这两者。语法、统计图组件与组件块各有条目：[统计图语法](2026-10-19-a2ui-chart-grammar.zh.md)、[柱状图、横向柱状图与折线图](2026-10-19-basic-charts.zh.md)、[饼图、散点图与仪表](2026-10-19-charts-radial.zh.md)以及[统计图与系统资源组件块](2026-10-19-a2ui-chart-blocks.zh.md)。

## Skill 与文档

- `a2ui` Skill（版本 `2026.10.19.2`）讲授 `chart` 与 `resources`：新增两者的目录行、选用规则（数据符合组合组件的形状时用组合组件，否则用统计图）、统计图数据模型一节和一个统计图示例。它的一行描述列出了统计图与系统资源面板。`metrics` 文档删去系统快照示例。
- `scripts/sysinfo.mjs` 输出 `resources` 组件块：带历史的 CPU 与内存、Linux 上的交换分区与网络、用可重复的 `--disk` 指定的每块磁盘、负载与运行时间。它不再输出 `metrics`，`--lang` 选项已删除，因为组件块里只有数字。
- a2ui 插件的描述与插件库 README 列出了统计图与系统资源面板。
- 「对话 › 富输出组件」介绍统计图和系统资源，「技能与插件」页的表格行列出了这些统计图。
