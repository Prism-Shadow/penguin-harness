# 模型目录同步到 MMSP 0.5.5：MiniMax M3.1 Flash，以及 OpenRouter 与 TokenDance 新条目

- **Date:** 2026-10-23
- **Type:** feature
- **Scope:** `model-catalog`
- **PR:** [#1303](https://github.com/Prism-Shadow/penguin-harness/pull/1303)

[English](2026-10-23-models-mmsp-0-5-5.md)

内置模型目录收入了 MMSP 0.5.5 注册表为 PenguinHarness 已有分组新增的条目。新建 Project 会把它们作为预置写入；已有 Project 通过「添加新模型」获得。

## 变更内容

- **MiniMax：** `MiniMax-M3.1-Flash`，输入 $0.15 / 输出 $0.60 / 缓存命中 $0.015，1,000,000 Token，支持图片输入。
- **OpenRouter：**
  - `minimax/minimax-m3.1-flash`，$0.15 / $0.60 / $0.015，1,048,576 Token，支持图片输入：免费版的免费期已结束，改收付费条目。
  - `recursive/flint-v1.0:free`（Flint），免费，262,144 Token，文本输入，支持推理与工具调用。
  - `deepseek/deepseek-v4.1-flash-1017`，走 DeepSeek 自己的端点，与 `deepseek/deepseek-v4.1-flash` 一样按高峰价存储并声明 DeepSeek 的闲时折扣。
- **TokenDance：**
  - `deepseek-v4.1-flash-1017`，价格与 `deepseek-v4.1-flash` 相同：同样的高峰价、分时规则与 8 折促销。
  - `minimax-m3.1-flash`，CNY 1 / 4 / 0.1，固定走 `https://tokendance.space/gateway` 上的 `ant-messages`。该网关为这个模型返回的 Chat Completions 流，`openai-chat` 无法读取。
- **SiliconFlow：**
  - 新增 `deepseek-ai/DeepSeek-V4.1-Flash`，CNY 1 / 4 / 0.02，支持图片输入。
  - 调价：`DeepSeek-V4-Flash` 改为 CNY 1.5 / 4.5 / 0.15，`DeepSeek-V4-Pro` 的缓存命中价改为 CNY 1。
  - 上下文窗口：`DeepSeek-V4-Flash`、`DeepSeek-V4-Pro`、`LongCat-2.0`、`GLM-5.3` 与 `GLM-5.2` 改为 1,048,576 Token。
