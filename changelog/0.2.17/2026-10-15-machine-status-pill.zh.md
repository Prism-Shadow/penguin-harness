# 机器卡片用带文字的状态胶囊表达状态，机器管理页的展示收进共享 UI 包

- **Date:** 2026-10-15
- **Type:** feature
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#1153](https://github.com/Prism-Shadow/penguin-harness/pull/1153)

[English](2026-10-15-machine-status-pill.md)

机器管理页的机器卡片不再用意义不明的彩色圆点表示状态。每张卡片显示一枚状态胶囊：状态色调的图形加状态词，与机器详情弹窗头部的胶囊相同；状态背后的原因（对端原话的失败原因、ssh 诊断、任务当前的日志行）悬停胶囊即可看到，也计入其可访问名。已连接的机器现在显示「运行中」，与本服务端卡片的用词一致，不再是「已连接」。

## 细节

- 已安装版本从卡片标题行移到统计行，标题行除名称外至多两枚胶囊（本服务端标签或「需要更新」，以及状态胶囊）。
- 机器管理页的展示改由共享 UI 包（`@prismshadow/penguin-ui`）提供：状态胶囊及其状态到外观的映射、任务步骤条、机器卡片、带加载占位的机器列表、机器详情弹窗的工具栏，以及添加对话框的正文、主机列表、主机行与页脚。它们的文字与状态都经属性传入；Web App 在 `features/machines/` 里保留数据接线，各模块与导出不变。
- UI 画廊新增「机器」条目：每种状态的胶囊、每种机器状态一张卡片、列表加载中、带置灰操作的工具栏与添加对话框。
- 前端 skill 记下规则：状态用带文字的胶囊，或悬停提示与可访问名都说明状态的图标，绝不用光秃的彩色圆点。
