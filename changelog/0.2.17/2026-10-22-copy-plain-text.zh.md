# 复制选中的文字粘贴为纯文本，不再带出主题配色

- **Date:** 2026-10-22
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1283](https://github.com/Prism-Shadow/penguin-harness/pull/1283)

[English](2026-10-22-copy-plain-text.md)

在 Web App 里选中文字复制，无论用哪种方式，剪贴板都只写入纯文本，即选区读到的文字。此前 ⌘C / Ctrl+C（以及桌面端的「编辑 › 复制」）由浏览器另写一份内联了页面计算样式的 HTML，粘贴到 Word、备忘录或飞书时带出深色主题的浅色文字与灰黑底块；对话选区菜单的「复制」则只写纯文本。现在两种方式粘贴出来完全相同。

## 细节

- 文档上的一个 `copy` 监听覆盖全部只读内容：对话与智能体面板中子会话的对话、文件浏览面板的预览（Markdown 与源码）、频道消息、Trace 面板、记忆与各处 Markdown 阅读器。它把选区文字写为 `text/plain` 并取消浏览器的 HTML；纯文本与浏览器此前写入的相同。
- 对话选区菜单的「复制」经同一个模块写入，两种方式不会再各走各的。
- 应用自己写入的复制（「复制」菜单项、复制按钮、「复制路径」）在纯 HTTP 地址下也只写纯文本；此前浏览器的复制命令会为其借用的隐藏元素另写一份 HTML。
- 保持原样：可编辑控件（输入框、文件编辑器、表单输入）内的复制、终端自己的复制、已被其他处理接管的复制、空白或由多个区段组成的选区，以及另一个文档里的复制——内置浏览器的页面、文件浏览面板的 HTML 与 PDF 预览。
- 粘贴不再带出列表、粗体、链接与表格等结构；文档站与博客不受影响。
