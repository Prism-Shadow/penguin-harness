# 机器的 Agent 列表只读一次、各处共用，Agents 页与侧栏不再跳动

- **Date:** 2026-10-22
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1291](https://github.com/Prism-Shadow/penguin-harness/pull/1291)

[English](2026-10-22-machine-lists-cache.md)

每台远程机器的 Agent 列表现在只读一次，由 Agents 页、插件库与侧栏共用，并在页面切换与刷新后保留。机器被重新询问、连上或答复缓慢时，这些界面都不再退回占位：界面文字只在数据真的变化时才变。

## 细节

- 浏览器内一份按 Project、服务端与对象分键的缓存承载所有读机器的数据：同一键同时只发一次请求，晚到的旧答复不覆盖新答复；读取进行中或失败时保留上次答复；带回相同数据的答复不改变界面上的任何内容。
- 只在页面挂载（刚答复过则跳过）、机器连上与在那台机器上写入之后询问机器，Agents 页与侧栏共用这次请求。第二台机器连上不再重问第一台，侧栏也不再重问一直保持连接的机器。
- 机器上次的列表照旧记在浏览器存储中，现在从首次绘制起就显示；不可达或读取失败的机器保留上次看到的卡片，断开标记上写明原因。
- Agents 页上，已连接机器的卡片在本次页面加载中得到答复前置灰、不可操作，不显示断开标记，控件提示正在读取该机器；之后再进入本页立即可用，并在后台重新读取。
- 删除 Agent、内核更新或受雇错误后，Agents 页不再换成骨架：重新读取期间列表留在原处。
- 侧栏只在第一份列表到达前显示骨架。列表为空时，机器连上、断开或报出自己的 Agent 不再让「还没有 Session」与骨架行来回切换。
- 每个 Agent 的已装插件现在可记在浏览器存储中（`penguin.agentInstalls.*`），供插件库使用；与机器列表一样只属于本次安装，不会带到新的数据根。
