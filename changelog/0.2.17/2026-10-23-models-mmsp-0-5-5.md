# Catalog sync to MMSP 0.5.5: MiniMax M3.1 Flash, new OpenRouter and TokenDance rows

- **Date:** 2026-10-23
- **Type:** feature
- **Scope:** `model-catalog`
- **PR:** [#1303](https://github.com/Prism-Shadow/penguin-harness/pull/1303)

[中文版](2026-10-23-models-mmsp-0-5-5.zh.md)

The built-in catalog took the rows MMSP 0.5.5's registry added for the groups PenguinHarness ships. New Projects get them as presets; existing Projects pick them up through "Add new models".

## What changed

- **MiniMax:** `MiniMax-M3.1-Flash` at $0.15 input / $0.60 output / $0.015 cache hit, 1,000,000 tokens, image input.
- **OpenRouter:**
  - `minimax/minimax-m3.1-flash` at $0.15 / $0.60 / $0.015, 1,048,576 tokens, image input: the paid listing, since the free variant's free period ended.
  - `recursive/flint-v1.0:free` (Flint), free, 262,144 tokens, text input, reasoning and tool calls.
  - `deepseek/deepseek-v4.1-flash-1017`, DeepSeek's own endpoint, stored at its peak price with DeepSeek's off-peak schedule, like `deepseek/deepseek-v4.1-flash`.
- **TokenDance:**
  - `deepseek-v4.1-flash-1017`, priced as `deepseek-v4.1-flash`: same peak tier, schedule and 20% promotion.
  - `minimax-m3.1-flash` at CNY 1 / 4 / 0.1, pinned to `ant-messages` at `https://tokendance.space/gateway`. The gateway's Chat Completions stream for this model cannot be read by `openai-chat`.
- **SiliconFlow:**
  - New: `deepseek-ai/DeepSeek-V4.1-Flash` at CNY 1 / 4 / 0.02, image input.
  - Repriced: `DeepSeek-V4-Flash` to CNY 1.5 / 4.5 / 0.15, and the `DeepSeek-V4-Pro` cache hit to CNY 1.
  - Context windows: `DeepSeek-V4-Flash`, `DeepSeek-V4-Pro`, `LongCat-2.0`, `GLM-5.3` and `GLM-5.2` moved to 1,048,576 tokens.
