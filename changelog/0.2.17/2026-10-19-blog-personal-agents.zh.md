博客新增一篇观点文章《个人 Agent 需要 Agent 原生云电脑》（`personal-agents-need-a-computer`），中英两版。文章把个人 Agent 拆成能力更强的模型、Agent Runtime 与 Agent 原生云电脑三部分，论证运行时循环已经定型、单次任务沙箱不适合做个人 Agent 的长期宿主，并为用户的应用连接单开一节：连接应当由机器统一持有，作为通往所有应用的统一入口，而不是由每个 Agent 或每段对话各自保存。随后据此对照 PenguinHarness 的运行时、「机器管理」页面与各类连接的作用范围。
