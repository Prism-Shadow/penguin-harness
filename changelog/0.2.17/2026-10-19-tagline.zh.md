「统一、稳定的 Agent 自进化框架」下方的一行由「全自动优化模型 × Agent Harness」（英文：Automatically improve model × agent harness）改为「全自动优化：任意模型 · 任意算法 · 任意 Benchmark」（英文：Fully automatic optimization: any model · any algorithm · any benchmark）。副标题单独成行时，三项之间以间隔号分隔，与「Linux · Windows · macOS」所用的分隔符相同；在句子中则按列举处理，中文用顿号，英文用逗号。

## 细节

- **官网。** 首屏第二行与社交分享卡片（`public/og-cover.png`，由 `scripts/og-cover.html` 重新渲染）换成了带间隔号的新副标题，meta 与 Open Graph 描述则以句子形式写入。手机上首屏这一行只在间隔号之后换行，不会从某一项中间断开，也不会让间隔号出现在行首：中文不拆词，英文的每个 any 与其后的名词连在一起，每个间隔号则由其前的不换行空格与前一项连在一起。
- **README。** 标题下的一行改用带间隔号的写法，保留三项内容的加粗；每个间隔号前是不换行空格，窄窗口里不会有一行以间隔号开头。
- **文档。** 产品介绍的开篇段落与三大支柱上方的一句话概括都改用新副标题；在中文行文中，三项之间以顿号分隔：任意模型、任意算法、任意 Benchmark。
- **包元信息。** 根目录 `package.json` 的 description 随之更新，同样以句子形式写入。
