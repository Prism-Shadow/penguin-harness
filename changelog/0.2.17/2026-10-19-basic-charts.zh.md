# UI 包新增柱状图、横向柱状图与折线图

- **Date:** 2026-10-19
- **Type:** feature
- **Scope:** `ui`, `ui-gallery`
- **PR:** [#1232](https://github.com/Prism-Shadow/penguin-harness/pull/1232)

[English](2026-10-19-basic-charts.md)

共享 UI 包新增由调用方传入的类别与系列绘制的基础统计图，单位标在坐标轴上：`BarChart`、`HBarChart` 与 `LineChart`。它们经 `ChartFrame` 与现有图表原语绘制，因而沿用各主题的图表样式，不新增主题 Token。

## 细节

- `BarChart` 绘制分组柱、堆叠柱，或无间隙的直方图分箱，数值轴总包含零。指向某一列时其余各列变淡，并弹出列有每个系列数值的气泡；缺失的读数显示为「—」。
- `HBarChart` 在同一刻度上绘制各行：从起点量起的数值、从低到高的区间，或从零起首尾相接的多个系列。相接的分段以直角相接，带色调的行取该色调的墨色，堆叠行的分段弹出写明所在行、系列与数值的气泡。
- `LineChart` 绘制在缺失读数处断开的折线、面积图或堆叠面积图。其简洁框架不画网格与数值轴，把数值标在各点上方。可选的描绘动画沿线绘出，在减少动态效果的设置下以及图表滚出屏幕时停止。
- 数值轴从零到一个整齐的上界，分 3–6 步，每步为 1、2 或 5 × 10ⁿ；也可以只围绕读数取整齐的范围。刻度标签不重复，类别标签按实测宽度抽稀，类别没有名称时不画类别轴。系列多于一个时显示图例，指向图例项时其余系列变淡。坐标轴名称排在绘图区四周。
- 图表原语新增无间隙柱、向下填充到下一层的面积带、数据点标签，以及相接端为直角的横条。`ChartFrame` 接受无障碍标签，高度与内边距取自图表的几何参数。
- 一条源码守卫要求每个由统计图组成的 A2UI 组件块都经基础统计图绘制，不自带 SVG、绘制样式或几何计算。

## 组件画廊

- 图表页新增「基础统计图」部分：分组柱与堆叠柱、直方图、按数值、按区间与堆叠的横向柱、带缺口的折线、堆叠面积图与简洁折线。
