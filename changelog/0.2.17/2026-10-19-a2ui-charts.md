# The a2ui skill teaches charts and the system-resource board

- **Date:** 2026-10-19
- **Type:** feature
- **Scope:** `skills`, `docs`
- **PR:** [#1227](https://github.com/Prism-Shadow/penguin-harness/pull/1227)

[中文版](2026-10-19-a2ui-charts.zh.md)

The `a2ui` skill teaches the model the `chart` and `resources` blocks, `scripts/sysinfo.mjs` prints a `resources` block, and the docs describe both. The grammar, the chart components and the blocks have their own entries: [chart grammar](2026-10-19-a2ui-chart-grammar.md), [bar, horizontal bar and line charts](2026-10-19-basic-charts.md), [pie, scatter and gauge charts](2026-10-19-charts-radial.md) and [chart and resources blocks](2026-10-19-a2ui-chart-blocks.md).

## Skill and docs

- The `a2ui` skill (version `2026.10.19.2`) teaches `chart` and `resources`. It adds their catalog rows, the rule for choosing a composite when the data has its shape and a chart when it does not, a chart data model section and one worked chart example. Its one-line description names the charts and the resource board. The `metrics` docs drop the system-snapshot example.
- `scripts/sysinfo.mjs` prints a `resources` block: CPU and memory with their history, swap and network on Linux, every disk named by a repeated `--disk`, the load and the uptime. It no longer prints `metrics`, and `--lang` is gone because the block holds numbers only.
- The a2ui plugin's description and the plugin library's README name the charts and the resource board.
- Chat › Rich output blocks describes Chart and System resources, and the Skills & Plugins row names the charts.
