# 轨迹观测面板改为吸顶的轮次导航与按需展开的读数；命令的退出状态不再算作工具失败

- **Date:** 2026-10-23
- **Type:** feature
- **Scope:** `web`, `ui`, `core`, `server`, `docs`
- **PR:** [#1305](https://github.com/Prism-Shadow/penguin-harness/pull/1305)

[English](2026-10-23-trace-view-2.md)

轨迹观测面板围绕一行吸顶工具条重做：轮次导航从一个显示当前在视轮次的按钮展开，轮次改为以分隔线分行、行尾的上下文圆环点开给出具体 Token 数量，每条事件行只带一枚按记录类别着色的胶囊，思考等级以文字表达。命令跑完后以非零退出码结束或被信号终止的工具调用，在所有展示它的地方都改为普通的完毕态。

## 轨迹观测面板

- 一行吸顶工具条取代了文件胶囊与日期行：Session 有多个文件时为文件选择器，只有一个时为文件标签（序号、日期、大小），其后是轮次按钮与扁平的导出图标；面板滚动到哪里，工具条都留在顶部。
- 文件选择器与轮次按钮展开同一种下拉：按钮为显示当前选项的幽灵按钮；浮层宽度不超出轨迹面板，标题行写明列表名称与数量，其下每个选项一行，当前项填底并打勾。展开时焦点落在当前项；上下方向键在行间移动，Home 与 End 跳到首尾，Esc 关闭并把焦点还给按钮。文件行给出序号与日期，行尾为文件大小。
- 轮次按钮显示当前在视的轮次，随面板滚动更新；文件满两轮才出现。其列表的标题行带数字框，其下列出每一轮（序号、压缩徽标、起始 Prompt 首行、四项读数），不标思考等级。选中某轮即关闭列表、绘制并展开该轮，其行首落在工具条下方。每轮的「回到导航」按钮已移除。
- 视图顶部仍是全局统计。全局统计与轮次改为分节，不再用卡片；每轮一行：序号、压缩徽标、工具调用、命中率、成本、用时，行尾为上下文圆环。Session 的各字段仍在 `session_meta` 行里，该行新增 `provider`。
- 圆环是按钮：悬停给出占用百分比，点击展开本轮读数，每个数只出现一次：输入、命中缓存量与命中率、未命中缓存、输出、输出 TPS，以及上下文占用量与窗口。压缩轮没有上下文快照，同一位置为 Token 图标，点开的列表少了上下文占用一项。输入、命中缓存、输出与 TPS 的数字不再出现在轮次行与展开后的首行上。
- 执行时间线的说明移到标题旁的「?」里。
- 每条事件行只带一枚胶囊，写明记录种类，`text` 与 `inline_data` 并注角色（`text (user)`、`text (assistant)`），颜色照旧按记录类别区分：`model_msg` 为中性色，`event_msg` 为提醒色；文本摘要不再带角色前缀。展开后的 `stop_reason` 徽标只在不是 `completed` 时出现。
- 思考等级以文字表达，不再用胶囊：等级切换处的 `request_begin` 行写作 `thinking_level=medium → high`，文件内首次出现处写作 `thinking_level=medium`。
- 时间线上失败工具的色条外圈改用危险色调令牌，不再用固定的红色。
- `TokenDonut` 新增 `hint={false}`，供放在已命名控件里的圆环使用：自身不带提示，也不带无障碍名称。
- `MenuItem` 可传 `tabIndex`，供整列只占一个 Tab 停靠点的行列表使用。

## 命令的退出状态

- `exec_command` 与 `input_command` 对跑完的命令一律以 `completed` 收尾，与退出状态无关；非零退出码与信号终止仍以 `[exit code: N]` 或 `[terminated by signal X]` 注记结束输出。`fatal` 只用于工具本身的失败（未知工具、参数错误、工具抛出、spawn 失败、超时），`aborted` 用于被拒绝或被中断。
- 对话的工具卡片、Trace 的消息行与时间线以及 CLI 把这样的调用显示为普通的完毕态，不再带红色标记或 `fatal` 徽标。此前写下的记录仍为 `fatal`，按原样显示。
- 成本中心的异常表不再记录被信号终止的命令；spawn 失败与超时照旧记录。把普通非零退出排除在异常表之外的规则一并移除。
- 后台命令的完成回报对非零退出仍写作 `failed`。
- AMSP 记录文档页写明命令的退出状态属于完成的结果。
