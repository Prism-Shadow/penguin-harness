# Markdown 阅读器带目录与页内查找；手册即文件浏览面板

- **Date:** 2026-10-15
- **Type:** feature
- **Scope:** `ui`, `web`, `server`, `ui-gallery`
- **PR:** [#1154](https://github.com/Prism-Shadow/penguin-harness/pull/1154)

[English](2026-10-15-markdown-reader.md)

插件详情（README 与文件浏览器的预览）、Benchmark 题目对话框与文件浏览面板预览里的 Markdown 文档，改由共享 UI 包里的同一个 Markdown 阅读器呈现，并新增目录与页内查找。组织手册改为文件浏览面板本身，浏览手册目录。

## 细节

- **目录**：文档有两个及以上标题（h1–h4）时附目录——阅读器宽度不少于 720px 时为正文旁的目录栏，否则由目录按钮弹出列表。点击条目在阅读器自己的滚动框内滚到该标题，当前小节随滚动高亮。
- **按钮在宿主的标题行**：目录与查找按钮放在宿主已有标题行的末尾、宿主自己的操作之后，样式一致——文件浏览面板的路径栏、文件浏览器的标题行、README 所在「说明」小节的标题。没有标题行的宿主由阅读器在正文上方画一条最小的工具条。
- **页内查找**：点查找按钮，或焦点在阅读器内时按 `find.open`（缺省 Mod+F），查找栏在标题行里取代路径（标题行太窄时另起一行），不盖在正文上：只查渲染后的正文、大小写无关，高亮全部命中，显示「序号/总数」，输入即定位到第一处，Enter 或 ↓ 下一处、Shift+Enter 或 ↑ 上一处，首尾循环。Esc 关闭查找、清除高亮并复原路径，不会传到阅读器外的对话框。焦点不在阅读器内时，该快捷键仍归页面的查找栏或浏览器。
- **插件 README**：改走共享的 Markdown 渲染管线，不再用裸渲染器，代码块带复制按钮、链接在新标签页打开，与其他 Markdown 界面一致。
- **共享的查找机制**：文本匹配、带高亮绘制的 DOM 索引与查找栏的控件行移入 `@prismshadow/penguin-ui`；`lib/find-text.ts` 与 `lib/find-dom.ts` 改为转导出，页面查找栏的控件行改用共享的 `FindField`。高亮按所有者分别绘制，阅读器的查找与页面查找栏各自保留自己的标记；高亮颜色取主题的 info 色调，公式隐藏的 MathML 副本不再参与查找。
- **手册**：页面以文件浏览面板按目录寻址的接口浏览组织的 `handbook/` 目录，渲染的就是 Workspace 文件浏览面板本身，目录树、搜索、工具栏、路径栏、预览、编辑器与右键菜单都与之相同。只保留文件浏览面板没有对应物的部分：打开时预览索引，索引不提供重命名、移动与删除，不提供「添加到对话」。页面自己的标题、说明与「索引 · 每轮先读」标记已去掉；在页面上新建或重命名的名称沿用文件浏览面板的规则，不再套用手册接口的路径规则。
- **服务端**：`GET /api/projects/:projectId/organizations/:orgId/handbook/files` 另返回 `dir`，即手册目录的绝对路径。
- **文件浏览框架**：文件浏览面板的工具栏行、两栏布局与树宽规则移入 `@prismshadow/penguin-ui`（`FilesToolbar`、`FilesPanes`、`useFilesLayout`）；`lib/workspace-tree.ts` 转导出布局函数。渲染视图下的 Markdown 文件，文件浏览面板把「编辑」放在路径栏而不浮在正文上，并可不接对话输入框、可指定不可移动的文件。
- **组件画廊**：内容页展示阅读器在一条带按钮的标题行下读一篇长文档的宽、窄两种形态，中英文各一份。
