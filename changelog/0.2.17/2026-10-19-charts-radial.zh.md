# UI 包新增饼图、散点图与仪表

- **Date:** 2026-10-19
- **Type:** feature
- **Scope:** `ui`, `ui-gallery`
- **PR:** [#1235](https://github.com/Prism-Shadow/penguin-harness/pull/1235)

[English](2026-10-19-charts-radial.md)

共享 UI 包补齐了基础统计图的其余部分：`PieChart`、`ScatterChart` 与 `Gauge`。它们与柱状图、折线图使用同一套图表原语与约定绘制，不新增主题 Token。

## 细节

- `PieChart` 把一个系列画成从十二点钟方向顺时针排列的环形弧段，相邻扇区之间有一条细线；`donut` 让半径内侧 60% 留空。饼图旁的列表图例写出每块的数量与占比，指向某一行时其余扇区变淡。数值为零的扇区不画弧段，但保留图例行。
- `ScatterChart` 在两条数值轴上绘制由 `[x, y]` 点组成的系列，两轴都带调用方给出的单位。每条轴贴合数据自身的范围，因而远离零的读数也能铺满绘图区；指定的 y 轴范围仍然优先。系列多于一个时显示图例，指向图例项时其余系列变淡。非有限值的点被跳过。
- `Gauge` 以 `role="meter"` 展示一个读数相对于总量的比例：带单位的数值，以及表示占比的圆环。读数正常时圆环取强调色，传入色调时取该色调的墨色；未满一圈的圆环两端为圆头。`lone` 显示大号数值，`ring={false}` 保留仪表语义但不画圆环。

## 组件画廊

- 图表页的「基础统计图」部分新增散点图、饼图与环形图，以及仪表。
