# 设置自定义背景后，对话里的工作组头部与展开的行重新吸顶

- **Date:** 2026-10-17
- **Type:** fix
- **Scope:** `ui`, `web`, `ci`
- **PR:** [#1187](https://github.com/Prism-Shadow/penguin-harness/pull/1187)

[English](2026-10-17-chat-sticky-rows.md)

设置了自定义背景后，对话里的工作组头部（「运行中」「运行完毕」）及其下展开的思考行与工具行不再吸在消息流顶部：自定义背景（[#1126](https://github.com/Prism-Shadow/penguin-harness/pull/1126)）让它们随正文滚走，因为透明的吸顶行会把自己的文字叠在下方滚过的内容上。现在两层都重新吸顶，同时仍直接落在背景图上、不加底色条。

## 细节

- 头部或行吸住时，在文字下重绘页面底色与同一张背景图，与外壳自己的背景一样按窗口对齐（共享 UI 包的 `WallpaperBackdrop`），看上去仍是透明的，下方滚过的文字却被盖住；未吸住时什么也不画。
- 背景图以固定背景（`background-attachment: fixed`）绘制，与最大化停靠面的那份副本相同。消息入场动画（`.anim-msg`）改为只向前填充：此前入场结束后仍保持终态，每条消息都留着一个 transform，而在带 transform 的盒子里固定背景会随盒子滚动，吸住的行上的背景图因而会错位、缩放。
- 只有吸住的行绘制它，靠 CSS 的滚动状态容器查询（scroll-state）识别。不支持滚动状态查询的浏览器保持原有行为：设置自定义背景时这些行随正文滚动。减少透明度时不变：行保留主题表面并照常吸顶。
- 未设置自定义背景时没有任何变化。
- 新增 Playwright 场景（`packages/web/e2e/sticky-rows.spec.mjs`），由 CI 的浏览器任务与冒烟用例一并运行：在三套主题下各自于组头与其行之下滚动一段展开的工具输出，分别在有无自定义背景时检查两层都保持吸顶、下方内容不透出，且有背景时吸住的行显示的正是该处背景本身的样子。
