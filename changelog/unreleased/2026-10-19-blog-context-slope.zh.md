# 观点文章：控制上下文斜率

- **Date:** 2026-10-19
- **Type:** process
- **Scope:** `landing`

[English](2026-10-19-blog-context-slope.md)

博客新增一篇观点文章，中英文各一份：《控制上下文斜率是 Agent Harness 的核心职责》（`context-slope`）。文章把一次请求的上下文拆成截距（每次请求在开始工作前就携带的部分）和斜率（每次请求新增的部分），并逐一说明 Skill 渐进加载、落盘的输出上限、CLI 输出和 MCP 工具定义分别压低哪一项。

## 细节

- `context-slope` 配有四张以内联 SVG 绘制的插图，使用共享的插图样式：一次合成测试在有无 16,000 字符输出上限时各次请求的估算上下文体积、随版发布的 Skill 库各内容层级的估算体积、超上限工具输出进入上下文与恢复文件的路径，以及三种 MCP 设计的对照。
- 两张图表的数据来自仓库提示词缓存测试辅助工具在测试夹具上的测量；体积为基于字符的估算值，不是服务商的 Token 计数。
- 落地页博客测试把这篇文章列为观点类的第一篇。
