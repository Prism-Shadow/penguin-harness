# 机器上的终端在重启后仍在,打开终端也能找到它

- **Date:** 2026-08-30
- **Type:** fix
- **Scope:** `web`

[English](2026-08-30-terminal-tabs-survive-restart.md)

跑在机器上的终端,每次重启都会从应用里丢失:它的标签消失,再打开终端就会在那台机器上已有的 shell 旁边另起一个。pty 本身从未有危险——它在那台机器的 server 上,而那个 server 一直在运行。

## 细节

- 终端列表由多个来源汇总——本 server,加上该 Project 能连上的每台机器——并据此把终端标签从每个对话已存储的布局里剔除。页面刚加载时,机器集合和通往机器的转发都还不存在,于是早期的一次刷新只看到本 server,就把那些在别处活着的终端标签剔掉了。剔除现在要等一个完整的画面:机器集合已发布,且每个来源都作了应答。其间仍照常显示较短的列表。
- 打开终端时,寻找可领养的既有 shell 用的是不指明机器的 `/api/terminals`,而它只回答本 server 的情况,因此位于某台机器上的对话永远找不到它在那里已有的 shell。现在改为在同一份多来源列表中查找,并且只领养位于该对话所在机器上的 shell——这正是新建 shell 时已经遵循的规则。
