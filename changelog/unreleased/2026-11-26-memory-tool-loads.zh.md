# 在对话旁打开的「记忆」重新显示 Agent 的记忆

- **Date:** 2026-11-26
- **Type:** fix
- **Scope:** `web`

[English](2026-11-26-memory-tool-loads.md)

从对话的「快捷方式」打开「记忆」时，无论对话在本机还是在远程机器上，都不再一直停在加载状态。对话开始把停靠在其旁边的「记忆」工具计为「记忆」面板已打开：工具一打开就从对话所在的机器读取 Agent 的记忆，读取失败时显示失败原因与「[报告问题]」。

## 细节

- dock 状态新增 `isPanelOpen`，面板自己的标签页与代替它的 Session 工具同样计为已打开。
- 对话页的记忆列表读取，以及「文件」「记忆」「Agent」三个跳转命令的重置，改由 `isPanelOpen` 判断；Session 工具关闭时，对应的跳转命令也随之重置。
- `dock.spec.mjs` 新增一个场景：在写入一条记忆后从「快捷方式」打开「记忆」，再在列表读取失败时打开一次。
