# 检查更新移出系统设置，改到账号菜单

- **Date:** 2026-08-21
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#391](https://github.com/Prism-Shadow/penguin-harness/pull/391)

[English](2026-08-21-update-check-out-of-settings.md)

把检查更新从系统设置弹窗中移出，改到侧边栏用户菜单里紧贴「系统设置」下方的一行。弹窗的**更新**页（见[系统设置弹窗](2026-08-20-system-settings-page.zh.md)）已删除，网页端与桌面端的更新入口自此共用弹窗之外的同一个位置：更新从「两次点击加一个页面」变成菜单里的一次点击。

## 细节

- 菜单里的服务端更新行自己承担手动检查：未知新版本时读作「检查更新」并执行强制查询，查到后就地改为写出该版本，并打开更新弹窗——更新说明链接与仅管理员可用的自更新——而不再跳进设置页。每次检查仍然只以一条提示汇报一种结果。
- 该行右侧显示当前运行的服务端版本号，与并列的桌面客户端行一致；原先作为提示文字的发布日期改由新对话页的版本行承载，那里放得下。
- 两行各自的可见条件不变，且互斥：服务端行在桌面模式下隐藏，客户端行只出现在 shell 自身的窗口里，而登录桌面模式服务器的浏览器两行都看不到。
- 懒加载检查未变——用户菜单首次打开前不发起任何请求——头像上的提示圆点、新对话页的「有新版本可用」徽标，以及桌面端「重启并安装」前的确认步骤同样未变。
- 检查状态与两个弹窗由侧边栏持有，而不是由随菜单卸载的行持有，因此在菜单里点下的检查在菜单关闭后仍会落定并弹出提示。
- 桌面模式之外的非管理员自此只剩「个人」组的几页，设置导航对他们不再绘制分组标题。
- Web App 指南的「系统设置」与「版本与更新」两章按新位置重写，中英文同步。
