# Browse workspace files in a short dock

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** Web App

[中文版](2026-11-24-phone-files-tree.zh.md)

On a short phone screen, the Files panel puts the folder path, search, and file actions on one line. You can tap a file or swipe through the list with the composer and its notices still visible.
