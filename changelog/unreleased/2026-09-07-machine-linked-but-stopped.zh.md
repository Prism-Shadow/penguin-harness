# 连接握着，不等于那边的服务在跑

- **Date:** 2026-09-07
- **Type:** fix
- **Scope:** `web`

[English](2026-09-07-machine-linked-but-stopped.md)

Machines 页会把「连接握着、但最近一次探测发现那边没有服务在跑」的机器显示成 **Connected**，然后因为这一行看起来已就绪，反而不提供 `use`——而 `use` 正是把它重新启动的那个动作。

握着连接不等于存活。连接是**这一侧**的一个 ssh 进程，比对端的服务活得久，它只说明隧道有地方可去，从不说明那边有人应答。此前它在行的读数里直接压过一切；现在以最近一次探测的结果为准，服务已停的机器读作它自己的状态，并给出 `use`，因为那才是重新启动它的动作。
