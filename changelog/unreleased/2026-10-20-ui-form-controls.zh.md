# UI 包新增选项组、数字输入框与滑块

- **Date:** 2026-10-20
- **Type:** feature
- **Scope:** `ui`, `ui-gallery`
- **PR:** [#1256](https://github.com/Prism-Shadow/penguin-harness/pull/1256)

[English](2026-10-20-ui-form-controls.md)

共享 UI 包补齐了此前缺少的表单控件：以胶囊或卡片呈现的一组可按选项、带步进按钮的数字输入框，以及滑块。字段组的图例与单选框的圆点也各自成为组件。它们都只用各主题已有的角色绘制，不新增 Token，因而在朴素、白领、极客三套主题的亮色与暗色模式下自动跟随。

## 细节

- `ChoiceGroup` 把选项画成可换行的一排胶囊或一列卡片，可单选也可多选。单选在按下时立即生效：选项是带 `aria-pressed` 的按钮，键盘行为与单选组一致。整组只有一个 Tab 停靠点，依次落在调用方指定的选项、已按下的选项、第一个选项上；横纵两个方向的方向键以及 Home、End 移动停靠点，到两端回绕，并跳过禁用的选项。卡片以单选框的圆点开头，按下的选项圆点填实，也可由调用方传入自己的标记。多选时胶囊是开关按钮，每个各有停靠点，并以复选框的方框开头、按下后打勾；卡片是真正的复选框，因而多选不会被看成单选。每次变化都按选项原有顺序报告当前选中的选项。选项可以用次级墨色绘制（如「其他…」），可以单独禁用，也可以随整组关闭。
- `NumberInput` 绘制一个数字框，单位在框内，其后一个减号与一个加号按步长调整数值，到达边界时对应按钮禁用。框下方以符号写出范围（`1–10`、`≥ 1`），调用方传入提示时改为显示提示。出错时错误文字取代提示，框线变为危险色。步进计算以 `stepNumber`、`rangeText` 导出。
- `Slider` 是原生的范围输入框：滑块左侧的轨道以强调色填充，右侧取开关关闭时的轨道色；滑块取强调色并带开关圆钮的细线；禁用时填充与滑块变为灰色。旁边以等宽数字显示数值与单位，滑块的 `aria-valuetext` 读出同样的文字。键盘焦点环画在滑块上。
- `FieldLegend` 是字段组 `<legend>` 形态的字段标签样式，带必填标记，`RadioGroup` 的图例改由它绘制。`RadioDisc` 是单选框圆点的装饰性绘制，与原生单选框使用同一组类名。
- 复选框的圆角不超过边长的四分之一，因而在各主题下都保持方形；此前在白领主题下它画成圆形，容易被看成单选框。`CheckboxBox` 是方框的装饰性绘制，与原生复选框使用同一组类名。

## 组件画廊

- 「输入与表单」看板新增「数字」分组：一个带单位的数字输入框、一个停在范围上限的、一个禁用的与一个出错的。另有「日期与时间」分组，展示原生的日期、时间与日期时间输入框。
- 「选择器」看板新增「滑块」分组（百分比、步长 0.1 的 0–1 范围、禁用的滑块）与「选项组」分组。选项组展示：按下即生效并带推荐项的胶囊、可开关的胶囊、以圆点开头并带次级墨色「其他…」的卡片、复选框卡片，以及所有选项均已关闭的已回答问题。
