# 文件浏览面板新增右键菜单，源码视图显示行号

- **Date:** 2026-09-10
- **Type:** feature
- **Scope:** `web`
- **PR:** [#PR](https://github.com/Prism-Shadow/penguin-harness/pull/PR)

[English](2026-09-10-file-browser-context-menu.md)

原先浏览 Workspace 的停靠面板改名为「文件浏览」，并为此前无处安放的单条目操作提供了右键菜单：复制
条目在 Workspace 内的相对路径、把该条目的引用添加到对话、向文件夹上传、下载文件。预览区也可右键，菜单
作用于当前预览的文件，并可把当前选中的内容（而非整个文件）交给对话。

## 细节

- 右键、Shift+F10 与触摸长按都能唤出菜单，文件树行与预览区一致。整棵树共用一个处理器，由手势落点所在
  的行自行解析目标；落在行与行之间时保留浏览器自身的菜单，就地编辑器内同样保留——粘贴文本靠的正是它。
  HTML 与 PDF 预览是 iframe，其中的右键只会到达 iframe，不会传到面板。
- 「添加到对话」把 `@path` 插入到输入框的光标处，草稿其余部分原样保留；文件夹的引用保留末尾斜杠。不会
  发送任何内容，也没有任何解析——`@` 是写给人读的。
- 添加预览中的选中内容则写入一个以 `@path (L3-L7)` 开头的代码块，选中文本逐字保留。行号范围仅在源码
  视图能够确定时给出；围栏长度按需加长，使本身含有围栏的选中内容仍能正确嵌套。
- 源码视图显示行号：代码横向滚动时行号栏吸附在左边缘。行号不可选中，复制按钮复制的内容也不含行号。
