# 对话停靠栏、Session 行菜单里的定时任务，以及定时任务标签页的 AI 路径

- **Date:** 2026-09-02
- **Type:** feature
- **Scope:** `web`, `docs`

[English](2026-09-02-schedule-panel.md)

定时任务从对话本身就能触达了。对话页的停靠栏新增**定时任务**面板，列出绑定到当前 Session 的任务；Session 行菜单新增**创建定时任务**；Agent 设置页的定时任务标签页接入了「让 AI 创建」模式——并有一处不同：在对话内部，AI 路径把请求发送到这段对话，而不是新开一个。

## 细节

- 新的停靠面板种类 `schedules`：当前 Session 的任务（取该 Agent 的任务列表、筛到本会话）、搜索框与全部 / 生效中 / 已暂停 / 已完成筛选，每行为状态字形、任务名与一行人话时间表（`describeSchedule`：「每天 08:00 · 下次 明天 08:00」「每周一 09:00」「每 30 分钟」「一次性 · 9 月 3 日 10:00」，已结束的状态放在句首），owner 另有启停开关与编辑 / 删除菜单，其下是建议列表（每日简报、每周回顾、跟进提醒、监控更新）。列表在面板到前台、窗口重获焦点、可见期间每 30 秒及每次改动后刷新；草稿页说明发送第一条消息后可用。
- 面板的分体式创建按钮：**让 AI 创建**把请求连同面向本会话的固定尾句经对话页发出——智能体空闲时作为一条 Task，运行中作为插话（撞上运行刚结束的竞态时退回为排队的 Task）；对话框也可复制完整提示词。**手动配置**打开目标锁定为本 Session 的表单。
- Session 行菜单的**创建定时任务**（排在消息软件绑定之后）弹出二级选择：**让 AI 创建**跳转到该对话并打开面板与对话框（路由状态，只消费一次），**手动配置**就地打开锁定目标的表单（仅 owner）。
- 定时任务标签页表头改为组件包的分体式**新建**按钮——其 AI 路径发送到 Project 默认 Agent 的新 Session，尾句点名该 Agent、`penguin schedule add` 或 TOML 文件，以及新建 Session 模式——列表为空时以建议代替空表。
- 创建 / 编辑表单从标签页移入 `features/schedules/schedule-form-modal.tsx`，由标签页、面板与行菜单共用，并带 `lockedSessionId` 模式；闹钟字形成为 `components/ui/icons.tsx` 的 `SCHEDULE_ICON`，Agent 卡片的计数、面板与菜单项共用一个标记；`AiCreatePanel` 接受 `byLine` 覆盖。
- Web App 文档以双语描述了面板与菜单项。
