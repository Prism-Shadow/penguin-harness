# Files 面板编辑器的 ✓ 保存并退出、✗ 放弃更改，行号不再闪烁

- **Date:** 2026-10-29
- **Type:** fix
- **Scope:** `web`, `ui`

[English](2026-10-29-file-editor-buttons.md)

Files 面板编辑器的 ✓ 与 ✗ 改为同一图标族、同样大小的一对按钮。✓ 经照常的覆盖确认保存后回到预览，没有改动时直接回到预览；✗ 即「放弃更改」：丢弃未保存的内容并回到预览，不再二次询问。保存快捷键仍是保存后留在编辑器里。

## 细节

- 保存被拒（文件在磁盘上已变更或写入失败）时照旧留在编辑器里；✓ 写回途中又输入的内容也留在编辑器里，作为未保存的改动。
- 行号去掉了自己的底色，与代码同在一个表面上，背景图与半透明主题下同样透出。编辑器或源码视图不自动换行并横向滚动时，代码在行号处被裁去，而不是被带底色的行号块盖住。
- 带行号的代码表面在编辑之间为每一行保留同一个元素。输入只重绘被改动的行：其余各行保留语法颜色与行号；此前第一次按键整份文件的颜色就会消失，每次停顿还要整体重建两遍。
