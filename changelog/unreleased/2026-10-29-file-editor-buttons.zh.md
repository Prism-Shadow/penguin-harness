# Files 面板编辑器的 ✓ 保存并退出、✗ 放弃更改，行号不再闪烁

- **Date:** 2026-10-29
- **Type:** fix
- **Scope:** `web`, `ui`
- **PR:** [#1389](https://github.com/Prism-Shadow/penguin-harness/pull/1389)

[English](2026-10-29-file-editor-buttons.md)

Files 面板编辑器的 ✓ 与 ✗ 改为同一图标族、同样大小的一对按钮。✓ 即「保存并退出」：立即写回文件并回到预览，没有改动时直接回到预览；✗ 即「放弃更改」：丢弃未保存的内容并回到预览，不再二次询问。✓ 与保存快捷键都不再弹出例行的「保存文件」确认框；快捷键仍是保存后留在编辑器里。

## 细节

- 文件在打开之后已在磁盘上变更时，仍会先询问是否覆盖；保存被拒时照旧留在编辑器里；✓ 写回途中又输入的内容也留在编辑器里，作为未保存的改动。
- 离开编辑器后，焦点落在「编辑」按钮上。
- 行号去掉了自己的底色，与代码同在一个表面上，背景图与半透明主题下同样透出；背景图上的行号改用次要文字色。编辑器或源码视图不自动换行时，行号是贴在左缘的一列，横向滚过的代码在这一列处被裁去，而不是被带底色的行号块盖住；裁切每次滚动只改一个元素的样式，长文件横向滚动也不卡顿。用输入法组字时，行号不再随之隐去。
- 带行号的代码表面在编辑之间为每一行保留同一个元素。输入只重绘被改动的行：其余各行保留语法颜色与行号；此前第一次按键整份文件的颜色就会消失，每次停顿还要整体重建两遍。
