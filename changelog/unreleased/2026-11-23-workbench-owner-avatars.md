# Distinguish Agent copies of the same workbench

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`, `ui`, `server`
- **PR:** [#1743](https://github.com/Prism-Shadow/penguin-harness/pull/1743)

[中文版](2026-11-23-workbench-owner-avatars.zh.md)

When different Agents provide the same workbench, each App Center icon shows its owning Agent’s avatar in the upper-left corner. The badge also appears in folders. Each tile opens that Agent’s own workbench.
