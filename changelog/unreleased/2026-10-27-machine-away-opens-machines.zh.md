# 机器连不上时，对话引向机器管理页

- **Date:** 2026-10-27
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1376](https://github.com/Prism-Shadow/penguin-harness/pull/1376)

[English](2026-10-27-machine-away-opens-machines.md)

对话因所在机器未连接而读不到历史时，消息区原先在没有重试状态行时给出的「重试」只会重新读取历史。现在各种状态下（正在重连、已停止自动重连、保存的登录密码被拒绝、服务已停止、尚未连接、不在当前 Project 的机器列表中）都显示「去机器管理」按钮，点击打开机器管理页。服务端正在重连或已停止重连时，带「立即重试」「放弃重试」或「重试」的重试状态行仍在按钮上方。机器重新连上后历史照旧自动重新加载；本服务端上的对话读取历史失败时仍显示「重试」。
