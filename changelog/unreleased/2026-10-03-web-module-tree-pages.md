# The Web App boots a module tree, and every route is a page a module contributes

- **Date:** 2026-10-03
- **Type:** refactor
- **Scope:** `web`, `ui-gallery`

[中文版](2026-10-03-web-module-tree-pages.zh.md)

The Web App now boots a kernel module tree before its first render, with the same `@Module` / `@Provide` / `@Bind` and slots as the server. `src/web-root.ts` is the composition root: `WebRoot` lists the modules, and `bootWeb()` boots them and returns WebApp's root component, which `main.tsx` mounts once the install-scope reconcile has also finished. The UI gallery's framed app goes through the same `bootWeb()`.

The router's pages come from one slot. `web-app/module.ts` declares the `WebApp` interface and its `WebAppSlots`; `WebAppModule` provides it, and its `pages` slot carries each page's key, path, frame (`shell` or `bare`), nav placement, admin and released flags, and order, with the page component as the code half. Each feature that owns a route has a `module.ts` contributing to `WebAppModule.pages` and binding its components: chat, agents, models, plugins, machines, usage and benchmark inside the WebApp; terminal and the two workflow app paths outside it; company as one `/org/*` page whose nested routes live in its own `OrgRoutes`. `src/module.json` and the router's `BUILTIN_PAGES` registry are gone, and `web-app/router.tsx` imports no feature.

The kernel brings arktype into the browser bundle: the production entry chunk grows by about 184 kB (about 55.5 kB gzipped, about 47 kB of it arktype), a cost accepted for running one kernel on both sides. Booting takes 2–3 ms and makes no request.

## Details

- `src/router.tsx` moved to `web-app/router.tsx`, and `lib/pages.ts` to `web-app/page-table.ts`; `mergePages` is unchanged.
- `lib/module-deps.tsx` adds `createDeps()`: a module binds its dependencies into its root component, and the components under it read them with `useDeps()`. The WebApp binds the page table this way; the router, the sidebar and the collapsed rail read it through `useWebAppPages()`.
- The sidebar's nav decisions (`lib/nav-group-collapse.ts`) take the main-nav pages as an argument instead of reading the manifest at load. Nav order and the admin and released rules are unchanged.
- `ifaces.json` is generated by `pnpm gen:ifaces` (the web package's `dev`, `build`, `typecheck` and `test` run it first, and so does the root `gen:ifaces`) and is not committed.
- The web and gallery Vite configs set `esbuild.target` to `es2022`, so the dev server lowers the decorators.
- The boundary test allows `web-root.ts` to import `module.ts` files and nothing else to; the 20 baseline lines for the router's feature imports are gone.
- Nothing users see changed.
