# 对话新增计划模式

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `core`, `server`, `web`, `plugins`
- **PR:** [#1596](https://github.com/Prism-Shadow/penguin-harness/pull/1596)

[English](2026-11-18-plan-mode.md)

在对话输入框的「+」菜单中选择与目标模式并列的**计划模式**，或输入 `/plan`。可以来回讨论需求、提问和修改方案。讨论期间，智能体可以读取文件。运行命令、改动文件和委派任务都要等你批准。

选择**批准并执行**即可开始实施刚审阅的版本。修改方案后，旧版本的批准随即失效。只要计划模式保持开启，下一个任务仍从讨论开始。重新打开对话后，可以继续审阅最新方案。
