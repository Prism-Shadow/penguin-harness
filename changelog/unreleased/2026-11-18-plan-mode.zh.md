# 对话新增计划模式

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `core`, `server`, `web`, `plugins`
- **PR:** [#1596](https://github.com/Prism-Shadow/penguin-harness/pull/1596)

[English](2026-11-18-plan-mode.md)

在对话输入框的「+」菜单里开启**计划模式**。智能体会先和你讨论目标、可选做法和待定问题，也可以画架构图，或在工作区写一份规划文档。方案谈清楚后，可以直接在这段对话里实施。整个过程沿用会话已有的工具权限。
