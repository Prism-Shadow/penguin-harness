# 计划模式成为输入框开关

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `plugins`, `core`, `server`, `web`
- **PR:** [#1596](https://github.com/Prism-Shadow/penguin-harness/pull/1596)

[English](2026-11-18-plan-mode.md)

新的内置插件 `plan` 在对话输入框的 **+** 菜单里加入了**计划模式**，与目标模式并列。开启后输入框里显示一枚标签，你发出的每条消息后面都附上一段提示，请 Agent 先和你讨论目标、可选做法和待定问题，再动手实施。这段提示在对话中显示为折叠的「由 harness 注入」卡片。计划模式不限制任何工具，权限照常生效。开关在整段对话里保持开启，直到你关闭；`default_agent` 预装该插件。

## 细节

- 插件卡片可设 `composerMode: true`，把自己的钩子包作为这样的开关，提供给每个装有它的 Agent。Task 在 `promptHooks`（`POST /api/sessions/:id/tasks`）里列出开着的开关；服务端以用户的原话运行各包 `trigger: "host"` 的 `user_prompt` 命令，把 context 紧随消息发出。排队或打断发出的消息带着各自的 context，插话不带，目标模式不接受开关。
- 哪些开关开着，按对话记在浏览器里。
