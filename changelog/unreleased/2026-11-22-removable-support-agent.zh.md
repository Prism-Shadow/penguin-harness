# Project 所有者可以删除 Support Agent

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `core`, `server`, `web`
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1703

[English](2026-11-22-removable-support-agent.md)

Project 所有者可以在默认 Project 中通过普通 Agent 的确认流程删除预置的 Support Agent。删除后重启仍保持删除状态。新安装仍预置 Support，默认 Agent 和系统 Agent 仍受保护。
