# 首页示例改为填入输入框，不再直接发送

- **Date:** 2026-08-21
- **Type:** feature
- **Scope:** `web`
- **PR:** [#398](https://github.com/Prism-Shadow/penguin-harness/pull/398)

[English](2026-08-21-draft-example-fill.md)

在新对话页点击示例，原先会当场创建 Session 并提交预置提示词。现在点击只填入输入框：提示词进入正文，示例声明的 Skill 在技能下拉里被预选，再由用户自己点发送——发出的正是这张卡片过去自行提交的那条消息。

## 细节

- 提示词以纯文本进入输入框。`[use_skills]` 块仍在发送时组装，因此可见的草稿始终是可编辑的正文，而不是一段标记块。
- 示例的 Skill 只在当前 Agent 已安装时才预选，并且是叠加到已有选择上，而不是覆盖它。
- 已输入但未发送的草稿会保留：提示词空一行后接在其后，两段文字按写下的先后排列。若草稿只有空白字符，则视为空，提示词直接占据输入框。
- 输入框获得焦点，光标停在插入的提示词开头，并把该行滚动到视野内——长提示词不会再落在最后一行上。
- 卡片上的加载指示已移除，只为提交把关的禁用条件一并撤下。行仍会等待当前 Agent 的已安装 Skill 列表：没有它，技能预选会悄悄丢掉示例声明的 Skill。
- 每行的悬浮提示新增一行说明，点明点击是填入输入框，中英文同步。
