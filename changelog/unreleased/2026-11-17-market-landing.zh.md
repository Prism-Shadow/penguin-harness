# 网站的插件页改为插件市场

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `landing`
- **PR:** [#1583](https://github.com/Prism-Shadow/penguin-harness/pull/1583)

[English](2026-11-17-market-landing.md)

官网插件市场提供封面卡片与紧凑列表，浏览器会记住用户的选择。桌面页面将分类与公共榜单放在侧栏，为结果留出至少三列卡片的宽度。手机上用单列浏览，榜单位于结果之后。

可以按分类筛选，按名称、更新时间或精选排序，并从两种布局打开同一插件的详情页。内置插件的封面随站点提供，其他图片来自社区仓库。

官网与应用从同一份官方插件目录读取数据，并为每个包选择同一版本。通过 GitHub 提供安装包的外部工作台可在详情页直接下载经目录固定的版本。目录刷新失败时，仍可浏览最近一次成功读取的内容。
