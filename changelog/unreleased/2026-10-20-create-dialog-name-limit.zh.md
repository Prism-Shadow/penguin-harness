# 创建框把名称上限说在名称字段下

- **Date:** 2026-10-20
- **Type:** fix
- **Scope:** `web`

[English](2026-10-20-create-dialog-name-limit.md)

「新建 Project」「创建 Agent」与「新建组织」三个对话框此前对名称长度来者不拒、按输入原样发送：超过 100 字时服务端以英文拒绝——前两个把提示渲染在 id 字段下、第三个落在带「重试」的错误行上——名称字段本身毫无表示，用户提交之后才知道有上限。三个创建框现在都把上限说在名称字段下（Project 与 Agent 随输入即时提示，组织框在点「创建」时提示，各按自己字段教规则的方式），名称不合上限就不发送，也不靠服务端往返。上限以内的名称照常创建。

## 细节

- 上限 100 与服务端三条创建路由、Project 设置页改名输入所限同值，只写在 `packages/web/src/lib/name-limits.ts` 一处；创建框按发送的取值（去首尾空白后）度量。
- 文案进了中英两本词典（Project 与组织的显示名「显示名最多 100 个字符」、Agent 的名称「名称最多 100 个字符」），英文侧同形。
