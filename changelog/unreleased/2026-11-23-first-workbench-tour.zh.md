# 从对话制作清单工作台

- **Date:** 2026-11-23
- **Type:** change
- **Scope:** `web`, `first-workbench-guide`, `landing`

[English](2026-11-23-first-workbench-tour.md)

在首次模型设置或「设置 → 通用」中打开「我的第一个工作台」。引导随实际操作显示在模型设置、对话和安装好的清单旁。选择模型、发送自己的任务，预览清单后安装并测试条目。收起引导后可以从设置继续。官网演示省略该引导和初始密码修改提示。

已安装旧版的用户可[继续已有引导](2026-11-23-backward-compatibility.zh.md)。
