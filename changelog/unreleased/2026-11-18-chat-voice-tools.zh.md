# 设置项目的默认多模态模型，用语音撰写消息

- **Date:** 2026-11-18
- **Type:** feat
- **Scope:** `web`, `desktop`, `ui`
- **PR:** [#1598](https://github.com/Prism-Shadow/penguin-harness/pull/1598)

[English](2026-11-18-chat-voice-tools.md)

通过模型库的「默认多模态模型」按钮或项目设置，可以指定当前项目的文本生成、图片理解、网页搜索、网页抓取、图片生成、视频生成、语音合成和语音识别模型。每种用途都可以更换或清空，聊天和 CLI 共用这些选择。

指定转写模型后，点击发送按钮旁的麦克风开始录音。波形随麦克风收到的声音起伏。点「完成录音」把转写插在当前光标处，可继续编辑再发送。点「取消」或按 Esc 可丢弃这次录音。展开项目设置中的「润色语音输入」，可为当前项目启用润色、编辑提示词或恢复默认提示词。润色使用已分配的文本生成模型。润色失败会保留原始转写。

指定语音合成模型后，点击助手回复上的扬声器即可朗读，再点一次即可停止。离开会话时会停止播放并释放音频。

项目设置会列出已启用插件提供的模型用途。移除插件后，对应的模型选择、语音输入和朗读入口会隐藏。重新启用后，原先选择的模型会恢复。

浏览器语音输入会按识别模型的要求，将录音转为 16 kHz 单声道 PCM WAV。
