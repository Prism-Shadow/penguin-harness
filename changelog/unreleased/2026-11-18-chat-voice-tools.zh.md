# 选择项目的多模态模型，用语音撰写消息并朗读回复

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`, `plugins`, `desktop`
- **PR:** [#1598](https://github.com/Prism-Shadow/penguin-harness/pull/1598)

[English](2026-11-18-chat-voice-tools.md)

通过模型库的「多模态模型」按钮或项目设置，为每项用途选择项目使用的模型。第一行是图片理解，即项目的视觉模型，它也替不支持图片的模型读图。其下每行对应项目已启用插件声明的一项工具模型绑定（多模态工具插件提供文本生成、网页搜索、读取网页，以及图像、视频、语音的生成与语音识别），显示名称和可选模型。`penguin tools` 命令使用这些模型。在其他标签页或其他机器上的修改会立即反映出来。

在模型库中打开一个模型，即可把它选为所支持用途的模型：每项用途一行，按钮为「设为默认」，当前模型显示「已选用」。卡片上不放按钮，只有一个小标记，悬停提示列出该模型已选用的绑定。聊天的模型选择器不列出工具模型，工具的选择器会列出。

选定语音识别模型后，点击发送按钮旁的麦克风开始录音。录音时同一个按钮变为「完成录音」，工具栏左侧显示取消按钮、录音时长和音量条；发送按钮和其他控件位置不变。录音为 16 kHz PCM WAV，所有语音识别模型都能接收。完成后转写插在当前光标处；取消或按 Esc 丢弃这次录音。「润色语音输入」用项目的文本生成模型（未选定时即默认对话模型）润色转写。选定语音识别模型后它即开启，直到你在项目设置中关闭；在那里也可以编辑润色提示词或恢复默认。润色失败时插入原始转写。

选定语音合成模型后，点击助手回复上的扬声器即可朗读，再点一次停止。音频随会话保存：用同一语音模型再次朗读同一回复时直接播放，不再发起请求，项目成员都能复用。离开会话时停止播放。

打开曾选用工具模型的旧草稿时，会选用项目的默认聊天模型或第一个可用的聊天模型；项目还没有聊天模型时，草稿提供前往模型库的链接，已输入的消息会保留。
