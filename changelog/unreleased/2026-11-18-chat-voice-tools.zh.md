# 在模型库选择工具模型，用语音撰写消息

- **Date:** 2026-11-18
- **Type:** feat
- **Scope:** `web`, `desktop`, `ui`
- **PR:** [#1598](https://github.com/Prism-Shadow/penguin-harness/pull/1598)

[English](2026-11-18-chat-voice-tools.md)

在「模型库 → CLI 与语音模型」中，可以分别为图像生成、视频生成、语音合成、语音转写、网页搜索和网页读取选择已配置的模型。每项都显示提供商与模型名。这些选择与 CLI 共用，选择「未指定」即可解除绑定。支持这些能力的模型卡上可直接设为当前模型。选中另一张卡时，当前标记随即移到新卡。每个项目各自保留六项选择，项目成员可查看现用模型。

指定转写模型后，点击发送按钮旁的麦克风开始录音。结束录音会把转写插在当前光标处，可继续编辑再发送。按 Esc 可取消。选择文字模型并开启「润色语音输入」，可在插入前去除口头重复、补全标点。润色失败会保留原始转写。

指定语音合成模型后，点击助手回复上的扬声器即可朗读，再点一次即可停止。离开会话时会停止播放并释放音频。


模型卡会列出项目中已启用插件提供的操作。移除插件后，对应的模型选择、语音输入和朗读入口会隐藏。重新启用后，原先选择的模型会恢复。
