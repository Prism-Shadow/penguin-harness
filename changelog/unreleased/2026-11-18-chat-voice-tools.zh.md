# 设置项目的默认多模态模型，用语音撰写消息

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`, `server`, `desktop`
- **PR:** [#1598](https://github.com/Prism-Shadow/penguin-harness/pull/1598)

[English](2026-11-18-chat-voice-tools.md)

通过模型库的「多模态模型」按钮或项目设置，可以指定当前项目的文本生成、图片理解、网页搜索、网页抓取、图片生成、视频生成、语音合成和语音识别模型。每项用途占一行：名称和模型选择器；页面用途的说明在标题旁的「?」里。每项工具都沿用聊天的模型选择器，按厂商分组展示兼容的模型。当前项目的 `penguin tools` 命令使用这些默认模型，语音输入和朗读也使用这里选定的语音模型。在手机上打开项目设置时，当前页签会自动滚入视野。

指定转写模型后，点击发送按钮旁的麦克风开始录音。录音时同一个按钮变为「完成录音」，工具栏左侧显示取消按钮、录音时长和音量条；发送按钮和其他控件位置不变。完成后转写插在当前光标处，可继续编辑再发送；取消或按 Esc 丢弃这次录音。在项目设置中打开「润色语音输入」，即用项目的文本生成模型润色转写，润色不单独选模型；也可以编辑润色提示词或恢复默认。润色失败会保留原始转写。

指定语音合成模型后，点击助手回复上的扬声器即可朗读，再点一次即可停止。离开会话时会停止播放并释放音频。

项目设置会列出已启用插件提供的模型用途。移除插件后，对应的模型选择、语音输入和朗读入口会隐藏。重新启用后，原先选择的模型会恢复。

浏览器语音输入会按识别模型的要求，将录音转为 16 kHz 单声道 PCM WAV。

再次朗读同一回复时，复用当前用户在该会话中用同一语音模型生成的音频。刷新后也能重播。朗读、复制和分支按钮在回复下方对齐。

在模型库中打开一个模型，即可把它设为所支持用途的项目默认模型：每项用途一行，按钮为「设为默认」，当前模型显示「已选用」。卡片上不放按钮，只有一个小标记，悬停提示列出该模型已选用的用途。选用新的语音识别模型会替换原来的选择，聊天模型保持原值。打开曾选用工具模型的旧草稿时，会选用项目的默认聊天模型或第一个可用的聊天模型。如果项目还没有聊天模型，可以从草稿前往模型库添加，已输入的消息会保留。
