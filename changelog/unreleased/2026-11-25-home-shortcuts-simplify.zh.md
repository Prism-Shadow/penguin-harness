# 新对话的快捷指令精简为「构建新应用」与「优化已有应用」

- **Date:** 2026-11-25
- **Type:** feature
- **Scope:** `web`, `ui-gallery`
- **PR:** [#1860](https://github.com/Prism-Shadow/penguin-harness/pull/1860)

[English](2026-11-25-home-shortcuts-simplify.md)

新对话页输入框下方的随机示例改为两个固定的快捷指令，居中排列，以胶囊按钮显示。「构建新应用」填入一段提示词，让 Agent 构建新的工作台应用并上线到应用中心；「优化已有应用」打开一个可搜索的应用列表，列出本 Project 在草稿所在机器上的应用（不含系统应用），选中后填入点名该应用的提示词；列表仍在读取或读取失败时，菜单如实说明并提供重试。自定义快捷指令排在两者之后，「换一组示例」与「更多示例」已移除。
