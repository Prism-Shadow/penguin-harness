# Find open system apps in the Apps sidebar

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`

[中文版](2026-11-23-sidebar-running-system-apps.zh.md)

Open the Model Library, Plugin Market or another system app and it appears under **Apps** in the sidebar. Select its row to return to the same page, or use the row menu to minimize, restore or close it. Closing the app leaves its tile in the App Center.
