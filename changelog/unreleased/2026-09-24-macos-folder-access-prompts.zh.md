# macOS 在智能体读取桌面、文稿或下载之前会先征求你的同意

- **Date:** 2026-09-24
- **Type:** fix
- **Scope:** `desktop`

[English](2026-09-24-macos-folder-access-prompts.md)

在 macOS 上，把「下载」（或桌面、文稿、外接盘与网络卷）里的文件夹选作工作区后，所有智能体看到的都是空目录，而且从不弹出授权窗口。macOS 只会替说明了用途的应用去征求用户同意，桌面端此前什么都没声明，于是每次读取都被静默拒绝。

现在应用为这几类位置都写明了用途。智能体或工作区浏览器第一次访问其中之一时，macOS 会询问一次；这次授权覆盖应用的服务端以及它启动的每个智能体 shell，之后可在「系统设置 → 隐私与安全性 → 文件与文件夹」里修改。
