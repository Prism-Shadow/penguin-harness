# Command confinement, with backends as extensions

- **Date:** 2026-08-22
- **Type:** feature
- **Scope:** `core`, `server`, `docs`
- **PR:** [#354](https://github.com/Prism-Shadow/penguin-harness/pull/354)

[中文版](2026-08-22-sandbox.zh.md)

Shell commands an agent runs can now be confined. The harness gained its own sandbox interface — modeled on the DeepSeek Harness design (argv rewriting, honest enforcement reporting, fail-closed) but owned here, so it names three dimensions: `fs-write`, `network` and `mask-paths`. No backend is part of the harness: each is an extension package a deployment installs and names in `extensions.json`, which is why this builds on the [extension mechanism](2026-08-22-extension-mechanism.md).

## Details

- `core` gained the spawn seam: `confineSpawn`, threaded along the existing `proxyEnv` line and applied in `ManagedSession` immediately before spawn. It receives the exact argv, `cwd` and `workspaceDir`, and returns the argv to spawn instead. Mechanism only — it never interprets the argv.
- A backend declares which dimensions it implements; declaring none means filesystem-only. The service routes each policy to a backend covering what it requires, so an unimplemented dimension can never be silently dropped. A requirement nothing covers fails closed, naming what each mounted backend does cover.
- `confine` must return enforcing argv or throw. A throw aborts the spawn and surfaces as the command's spawn error, so a command never runs unconfined because a backend failed.
- Four backend packages shipped: `extension-sandbox-dsh` (the portable DSH adaptor, file effects on all three platforms), `extension-sandbox-bwrap` (Linux), `extension-sandbox-seatbelt` (macOS) and `extension-sandbox-mxc` (Windows, through Microsoft MXC's `processcontainer`). The three native backends implement all three dimensions.
- Confinement settings ride the parked platform context, so a hot push cannot silently un-confine a deployment; they are omitted while pristine, so a default deployment's document stays acceptable to a sandbox-ignorant bundle.
- With no backend inside the platform bundle, the bundle no longer inlines any native-adjacent module, and `deploy.mjs`'s runtime-resolved-natives shim was deleted.
- A default deployment names no extension and therefore confines nothing.
