# Web App 页面带上限定字体、样式表、插件与 `<base>` 的 Content-Security-Policy

- **Date:** 2026-11-10
- **Type:** feature
- **Scope:** `server`, `web`
- **PR:** [#1532](https://github.com/Prism-Shadow/penguin-harness/pull/1532)

[English](2026-11-10-page-csp.md)

服务端提供 Web App 页面时附带 `Content-Security-Policy: font-src 'self' data:; style-src 'self' 'unsafe-inline'; object-src 'none'; base-uri 'self'`，范围是 `index.html`、每个 SPA 回退应答，以及重新验证二者的 304。字体只从服务端自己的源或 `data:` 加载，样式表只从服务端自己的源加载或内联。页面不加载插件对象，`<base>` 元素也不能把相对地址改指其他主机。这是对导入的主题包与任何注入样式的纵深防御，关口仍是主题包的校验器。`img-src` 不设限，因为对话要显示远程图片。暂不设脚本策略，不写 `script-src`，也不写 `default-src`。

## 范围

- 桌面端加载的是服务端自己的地址，窗口同受此策略约束。
- 开发服务器（`pnpm dev`）发送同一个头，违规在开发时即可看到。
- 脚本、样式表、字体与 API 应答照旧不带此头。
- Workbench 页面、插件页面与 Workspace 预览是各有应答的独立文档，不受此策略约束。Workbench 页面仍可从任何地方加载样式表与字体。
- 没有自己应答的框架按浏览器规则继承页面的策略。Files 面板对 HTML 文件的 `srcdoc` 视图就是这样的框架，它用于 Workspace 目录，以及服务端没有独立预览源的时候。在这个视图里，来自其他主机的样式表与字体现在会被拦下。
