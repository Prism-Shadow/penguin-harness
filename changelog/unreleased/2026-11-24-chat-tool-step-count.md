# Count tool calls in the chat activity header

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** Web App, UI
- **PR:** [#1801](https://github.com/Prism-Shadow/penguin-harness/pull/1801)

[中文版](2026-11-24-chat-tool-step-count.zh.md)

Standard, Expanded and Compact count each tool call once and show its count beside the elapsed time. Thinking, retries and results do not add a step. Compact summaries fade in when the visible activity changes and update immediately with reduced motion. Standard is the default until a reader chooses another mode.
