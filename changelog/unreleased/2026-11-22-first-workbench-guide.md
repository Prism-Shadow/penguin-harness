# Build a checklist from your first conversation

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `plugins`, `server`
- **PR:** [#1695](https://github.com/Prism-Shadow/penguin-harness/pull/1695)

[中文版](2026-11-22-first-workbench-guide.zh.md)

New default Agents received **Your first workbench**. The guide connects model setup and selection with a conversation about a task, then generates a checklist from that conversation.

Users can review the checklist, install it on their Agent, test whether items can be saved and completed, and download the workbench as a reusable plugin.
