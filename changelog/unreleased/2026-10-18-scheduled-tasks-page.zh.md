# 全 Project 的定时任务页

- **Date:** 2026-10-18
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1196](https://github.com/Prism-Shadow/penguin-harness/pull/1196)

[English](2026-10-18-scheduled-tasks-page.md)

定时任务存在每个 Agent 各自的文件里，而列出它们的只有某一个 Agent 的设置 › 定时任务标签，于是一个 Project 的全部定时任务没有地方能一次读完。本次加了一个一级页面 —— `/schedules`，导航项「定时任务」—— 按拥有任务的 Agent 分组，列出当前 Project 全部 Agent 的定时任务，读的是会话列表闹钟标记所读的同一份 Project 级列表。该导航项默认收藏置顶，页面与其他置顶项并列，不藏在折叠区里。

## 细节

- 列表带两个筛选。状态分片沿用聊天面板的口径；类型下拉把周期说成人话 —— 一次性、分钟级、小时级、每日、每周、自定义 —— 而不是服务端的 `30m` / `7d` 语法。每个分片带自己的计数；类型由周期推导而非存储，因此不需要服务端改动。
- 两个筛选与搜索框都写进地址（`?status=`、`?type=`、`?q=`），筛好的视图刷新后仍在、也能发给别人；无法识别或过期的值回退为不筛选，未筛选时地址保持干净。
- 点任意一行展开任务全貌：整段 prompt、周期、目标会话、开始与结束时间，以及新建会话时会用的 Workspace 与模型。编辑把任务交给共享表单，表单仍是任务文件的唯一写入口；启用/停用与删除就在旁边，和定时任务的其他写操作一样仅 owner 可用。
- 任务名本身是按钮、整行也可点，因此键盘也能打开明细。
- 每个 Agent 的分组可为该 Agent 新建任务；解析失败的文件一次性报出全部 Agent 的，这是单 Agent 标签页给不了的 Project 级答案。
