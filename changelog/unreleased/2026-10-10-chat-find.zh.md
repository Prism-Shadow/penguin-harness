# 查找栏：在对话、会话列表和文件面板中查找

- **Date:** 2026-10-10
- **Type:** feature
- **Scope:** `web`, `ui`, `docs`
- **PR:** [#992](https://github.com/Prism-Shadow/penguin-harness/pull/992)
- **Issue:** [#991](https://github.com/Prism-Shadow/penguin-harness/issues/991)

[English](2026-10-10-chat-find.md)

Web App 和桌面端新增查找栏。`find.open`（Mod+F：Ctrl+F，macOS 上为 ⌘F）在焦点所在的区域中查找，焦点不在任何区域时查找对话；`find.all`（Mod+Shift+F）一次查找屏上所有区域并列出匹配。匹配在浏览器里对已渲染的页面进行，不向服务器发送任何内容。

## 细节

- 可查找的区域为对话、智能体面板里子 Agent 的对话、侧栏的会话列表和文件浏览面板，各自用 `data-find-region` 声明；`@prismshadow/penguin-ui` 的 `SidebarFrame` 和 `FileTree` 为此新增可选的 `findRegion` 属性。
- `find.open` 和 `find.all` 加入快捷键注册表的「通用」组，可在「系统设置 › 快捷键」中改绑。Mod+F 有意取代浏览器自带的查找，与 `editor.save` 取代「另存网页」同理；macOS 上 ⇧⌘F 另与 Firefox 的全屏相同。对话框或菜单打开时两个命令都不介入；焦点不在任何区域且屏上没有对话时也不介入，浏览器保留自己的查找。
- 匹配经 CSS Custom Highlight API 绘制（`::highlight(penguin-find)`、`::highlight(penguin-find-current)`），不改动 DOM。
- 输入时只更新计数、不滚动。Enter 先显示当前选中的匹配、再跳到下一个，Shift+Enter 往回，`Aa` 区分大小写，在查找栏内按 Escape 关闭。
- 查询停顿后，所查区域内收起的步骤组展开，让其中的内容也能命中；关闭查找栏或清空查询后重新收起。
- `find.all` 最多列出 50 条匹配，每条带所在区域和前后文字；一个按钮在单个区域和所有区域之间切换。
- 所查对话还有未加载的更早轮次时，查找栏提供「加载并继续搜索」：加载上一窗口，并停在读者所在匹配之上最近的一处。
- 文档「对话」页新增「对话内查找」一节，并在快捷键表中加入这两个按键。
- e2e 的模拟 LLM 重新按 core 的标题 Prompt 识别标题请求，标题夹具因此能应答它。
