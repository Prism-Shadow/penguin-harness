# 桌面窗口在丢弃未保存的修改前先问

- **Date:** 2026-10-10
- **Type:** feature
- **Scope:** `desktop`
- **PR:** [#1031](https://github.com/Prism-Shadow/penguin-harness/pull/1031)

[English](2026-10-10-desktop-unload-prompt.md)

此前 Web App 有未保存的修改时关闭或退出桌面应用，关闭会被悄悄取消：页面拒绝卸载时 Electron 不画任何提示。现在由壳来问。

## 细节

- **提问：** 页面有未保存的修改时，关闭窗口、重新加载窗口，或从托盘、应用菜单退出，都会弹出系统对话框，语言跟随 Web App，文字与应用内的提示相同：「放弃未保存的修改？」，按钮为「放弃修改」与「继续编辑」（英文为 "Discard unsaved changes?"、"Discard changes"、"Keep editing"）。弹出前先显示窗口，因此从托盘退出时也在可见的窗口上提问。
- **继续编辑**保留窗口并取消这次退出，之后再关窗口就是普通的关闭（开着托盘时收进托盘）。**放弃修改**放行页面，退出继续进行。
- **退出顺序：** 托盘图标的移除与内嵌服务器的停止改在所有窗口关闭之后（`will-quit`）进行，不再在退出一开始（`before-quit`）就执行。用户取消的退出因此不会留下没有托盘、没有服务器的窗口。
- 关闭到托盘只隐藏窗口、不卸载页面，因此不提问。
