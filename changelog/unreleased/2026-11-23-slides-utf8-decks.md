# AI Slides opens presentations saved with a UTF-8 byte order mark

- **Date:** 2026-11-23
- **Type:** fix
- **Scope:** `use-bento-slides`

[中文版](2026-11-23-slides-utf8-decks.zh.md)

Presentations written by an Agent or a Windows text editor with a UTF-8 byte order mark appear under their titles in Recent and open in the Bento editor. Opening a file preserves its original contents and revision.
