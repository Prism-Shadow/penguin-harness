# Workbenches can play speech with the Project’s voice model

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** Multimodal tools

[中文版](2026-11-23-project-speech-playback.zh.md)

The multimodal tools plugin can return playable audio directly to a signed-in Project member. Workbenches can read text aloud without opening a Session or storing an audio file.
