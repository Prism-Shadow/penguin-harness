# 浏览器面板：后端切换只放在设置里，新标签页显示起始页

- **Date:** 2026-10-12
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#1068](https://github.com/Prism-Shadow/penguin-harness/pull/1068)

[English](2026-10-12-browser-menu-newtab.md)

内置浏览器的菜单不再提供「内置」与「系统 Chrome」之间的切换；没有设置主页时，新标签页显示几个常用网站，而不是空白页。

## 细节

- **菜单。** 内置浏览器的溢出菜单去掉了「浏览器」一组（**内置** / **系统 Chrome**）及其下的 Chrome 连接状态行。
  切换只在**设置 › 浏览器**里进行，配对与已配对的 Chrome 也在那里。Agent 使用你的 Chrome 时，那个界面的菜单仍保留连接
  状态行，旁边是**连接你的 Chrome…**或**管理…**。
- **内置浏览器无法运行时。** 只有账号下已配对 Chrome（无论此刻是否连接）时，面板才提供**改用系统 Chrome**；
  没有配对时不提供切换，而是提示到设置 › 浏览器中配对；管理员关闭了 Chrome 连接时两者都不显示。
- **起始页。** 没有设置主页时，新标签页以方块列出谷歌、必应、百度、GitHub、Stack Overflow 和维基百科，点一下即在这个
  标签页打开，地址栏仍获得焦点。方块用字母标识，绘制时不从网络获取任何东西。底下的页面仍是 `about:blank`；以主页打开的
  标签页不会显示起始页。
- **文档。** 内置浏览器的文档介绍了起始页，并把配对与切换指向设置 › 浏览器。
