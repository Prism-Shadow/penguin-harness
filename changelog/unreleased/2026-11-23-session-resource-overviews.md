# Show running terminals by Session in the App Center

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** Web App

[中文版](2026-11-23-session-resource-overviews.zh.md)

The Terminal overview lists Sessions with live terminals, including archived and subagent Sessions. Closing the last terminal removes its row. Open Terminal from a conversation’s shortcuts to start its first shell. Browser lists Sessions with their open page counts, and Files shows each Session’s Workspace directory.
