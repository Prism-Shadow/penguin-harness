# 服务端终端：内置终端面板与独立页面

- **Date:** 2026-08-14
- **Type:** feature
- **Scope:** `server`, `web`, `desktop`
- **PR:** [#285](https://github.com/Prism-Shadow/penguin-harness/pull/285)

[English](2026-08-14-terminal.md)

Shell 现在跑在服务端，而不是跑在展示它的那个浏览器标签页里：每一个 pty 字节都会喂给守护进程里的一个无头 xterm，因此视图是可丢弃的。刷新页面、移动面板或换一台设备，重绘出的都是那一块完全相同的屏幕——回滚缓冲、颜色、光标、输入模式——而 shell 始终在运行。

## 服务端：`/api/terminals`

- 控制面走 JSON：列出 / 创建（`cwd`、`name`、`cols`/`rows`、`shell`）/ 获取 / 结束，另有纯文本的 `capture`（按行范围）与 `keys`（字面文本，或 `Enter`、`C-c` 这类按键记号），因此不做渲染的客户端同样能驱动一个 shell。未命名的终端按用户各自递增（`tmp`、`tmp 2`、……），并带一个稳定的显示编号，重排也不会让它移位。
- 数据面是 `/api/terminals/:id/stream` 上的二进制 WebSocket，输出会做合并（约 5 ms 窗口，首字节立即冲刷）。接入时会把 pty 尺寸调整为客户端的几何尺寸，随后用一帧 Restore 重绘整块屏幕；这期间产生的输出会被缓冲进来。
- 尺寸只有一个主张者（获得焦点或接入即主张，其他人的更新会被忽略）；会话的寿命长于连接，已退出的会话在一段宽限期内仍可读；每用户 12 个存活 shell；关闭时从 SIGHUP 升级到 SIGKILL（`nohup` 启动的服务端会继承被忽略的 HUP）。
- 落后超过 1 MiB 的观察者会停止接收实时输出，并在其套接字排空后用一帧新的 Restore 重新同步——而不是被断开。
- 起的是用户自己的 shell，并且让他们的 profile 生效：POSIX 上取 `$SHELL` 并加 `-l`，Windows 上取 PowerShell（`pwsh`，否则 `powershell`）而不是 `%ComSpec%`——后者根本不读任何 profile。`PENGUIN_SHELL` 在所有平台上都可覆盖它。这与 agent 执行命令用的那个 shell 不是一回事：那一个为了确定性，仍然优先 POSIX 并带 `-NoProfile`。
- 安全性：一个终端就是一个以服务端 OS 账户身份运行的 shell，它按用户隔离而不按 Project 隔离（他人的 id 一律回 404）；升级握手会校验会话 cookie 以及严格的 `Origin`（精确到 `host:port`，仅 `http(s)`），因为 WebSocket 握手绕过 CORS。不要为你不愿意给 SSH 的账户开启终端。

## Web App

- **终端面板**（`` Ctrl+` ``）：一个多窗格的终端面板，内容区每条边最多一个窗格。标签页标注为 `N: 标题`（稳定编号 + 实时 OSC 标题，`user@host` 会被剥掉），横向拖动可重排，拥挤时会像浏览器那样压缩，并支持滚轮滚动。把一个标签页拖出标签条——或拖动某个窗格的头部——会唤出边缘浮层（边缘感应带、投放靶标、最终落点区域的预览），并把该终端/窗格移到选中的边，必要时在那里新建一个窗格。窗格与主区的边界可拖动调整大小（按边各自记住比例，双击复位）。布局变化从不导致重连：xterm 视图按终端 id 池化，在窗格之间以 DOM 形式交接。
- 终端面板归属于它被打开时所在的那个对话：切换 Session 时，窗格、标签页与显示与否都随之切换，切回来则原样恢复。两种情况下 shell 都继续运行——工具条的终端菜单列出全部存活的终端，选中其中一个即可把它带到当前对话里。
- 左侧或右侧窗格与聊天的 Agents / 工作区面板争的是内容区里同一块横向空间，因此同时只有一个在屏幕上：用户最后要的那个。打开面板会挤开侧边窗格；打开或聚焦终端则会收起面板。三者还共用同一个**宽度**——在其中任何一个上拖出来的宽度，就是下一个打开时的宽度——以及同样的 200ms 滑动：被挤开的一侧是收拢而不是啪地消失，它背后的 shell 与屏幕内容原封不动。上下窗格占的是高度而不是宽度，仍用它们自己的比例。
- 打开时落在上次展示过的存活 shell 上，其次是最新的存活 shell，再次才新建一个；窗格、尺寸、标签顺序、归属关系以及每个窗格当前展示的终端都会被持久化。标签页上的 `×` 会结束那个 shell；结束最后一个会关掉该窗格。分离会把单个终端交给它自己的 `/terminal?id=…` 窗口，而面板保留其余标签页。
- **`/terminal` 页面**：占满窗口且可深链——`?id=` 接入一个已存在的终端（分离时的交接），`?cwd=`/`?name=` 用于参数化新建的终端；接入的 id 会写回 URL，因此刷新或复制链接都能重新接入。
- **聊天工具条**：纯图标的面板切换器——固定的触发按钮，外加悬停展开的「创建」菜单，其中列出 Agents 面板 / 终端 / 工作区，每行带一个固定开关（agents 与工作区默认固定）。终端项显示实时的 shell 数量（用户创建或关闭的那一刻就更新），其固定图标悬停时会列出存活的终端，一次点击即可聚焦。
- 亮色与暗色，作为终端**自己的**设置（用户菜单 → 终端主题）：亮色、暗色，或跟随 App 主题，且默认**暗色**——无论 App 是什么外观，因为终端正是提示符与 TUI 按深色屏调好的地方。切换时就地重绘，shell、回滚缓冲与连接都能挺过去。底色用的是 App 自己的色调而不是终端惯有的炭灰，因此停靠的窗格不再像一扇外来的窗；16 个 ANSI 颜色则保持可辨识，并为亮色模式单独配了一套，在白底上依然清晰。
- 剪贴板：复制用 `Ctrl+Shift+C` / `Ctrl+Insert` / 有选区时的 `Ctrl+C`（无选区仍是 SIGINT）；粘贴用 `Ctrl+V` / `Ctrl+Shift+V` / `Shift+Insert`，走原生 paste 事件（不需要剪贴板权限）。右键复制选区或粘贴，绝不弹出网页菜单；中键粘贴；两者都会让位于自行接管鼠标的程序（vim、htop）。点击视图内任意位置即可聚焦 shell；悬停才显现的控件在键盘聚焦时同样会显现。
