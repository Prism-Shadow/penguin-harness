# 侧栏按需显示会话信息和工作区操作

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `web`, `ui`
- **PR:** [#1593](https://github.com/Prism-Shadow/penguin-harness/pull/1593)

[English](2026-11-18-sidebar-hover-details.md)

每行会话右侧显示最近活动时间。悬停或用键盘聚焦时，原位置切换为操作按钮；按工作区分组时，标题左侧同时显示 Agent 头像。标题位置保持不动。工作区文件夹也在悬停或聚焦时显示「新建对话」和更多操作。触屏上可以直接点按文件夹操作，长按会话可以打开菜单。
