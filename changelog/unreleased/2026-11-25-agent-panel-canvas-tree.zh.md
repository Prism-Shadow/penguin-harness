# Agent 面板调用树改为可自由缩放与平移的画布视图

- **Date:** 2026-11-25
- **Type:** feat
- **Scope:** `web`
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1839

[English](2026-11-25-agent-panel-canvas-tree.md)

Agent 面板中的调用关系树现采用与公司组织架构图一致的交互式画布，支持随所有新增 subagent 节点自动缩放适配完整视图、滚轮/触控板缩放、按住拖拽平移与顶栏缩放按钮，并将轮次分页文案统一为「第 N 轮」。
