# 智能体页面列出每台机器上的 Agent

- **Date:** 2026-09-09
- **Type:** feat
- **Scope:** `web`
- **PR:** [#653](https://github.com/Prism-Shadow/penguin-harness/pull/653)

[English](2026-09-09-agents-page-across-machines.md)

Agent 属于 Project，但它的状态目录是在它运行过的那台机器上创建的。只在某台机器上跑过的 Agent 因此只存在于那里——而智能体页面只按本机的列表构建，根本没有它的一行：没有可点的东西，也没有任何迹象表明它存在（评估中心正是因此没地方挂它的 Benchmark，问题才被发现）。

现在页面会同时问本机与本机持有连接的每台机器，并按 agent id 归并——与评估中心用的是同一套折叠。本机也有的 Agent 由本机描述；只存在于某一台机器上的，以那台机器命名：名字旁边是 `[SSH: prod-1]`，别名保持它自己的大小写。

这样一张卡片能做什么，取决于那台机器能回答什么。**新建对话**会以那台机器为目标打开草稿，临时工作区也建在它上面，于是对话就从 Agent 的状态所在之处开始。卡片上的其余动作——设置及其统计快捷入口、用量、删除——读写的都是本机没有的状态目录，因此置为不可用，把原因放在悬停提示里，而不是让你点完之后收到一个 404。
