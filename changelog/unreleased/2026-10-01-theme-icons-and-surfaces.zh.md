# 各主题自画图标，白领的侧栏改为磨砂，极客的标签统一为一种

- **Date:** 2026-10-01
- **Type:** feature
- **Scope:** `ui`, `web`, `ui-gallery`

[English](2026-10-01-theme-icons-and-surfaces.md)

一轮三套主题共同的修改，另把 UI 包迁移期间合入的组件改用 UI 包重写。

## 改动

- **图标：** 应用画的每个字形都收进同一份注册表，原先散在功能文件里的 53 个一并迁入。每套主题用自己的画法画这份注册表：
  - 通用用 GitHub 的 Octicons。
  - 白领保留线性图标，下衬一层淡色块；装饰性图标按概念取色相，智能体为紫、模型为蓝、插件为绿，依此类推。
  - 极客为 16×16 的像素图标，硬边。
  - 小标记（下拉箭头、对勾、加号、关闭叉、折叠箭头）同样随主题换画法。
  - 版权信息页增加 Octicons（MIT）与 Lucide（ISC）的署名。
- **白领的磨砂：** 对话框背后的遮罩只压暗页面。侧栏改为半透明，透出其后一层柔和的底场；插件与技能图块改为按自身色相着色的磨砂方块。菜单与弹出层保留磨砂。
- **白领的修正：**
  - 初始密码横幅的下沿与阴影完整可见，新建对话页与对话页头之上都是如此。
  - 对话框去掉头尾分隔线。
  - 菜单行收在面板的圆角之内。
  - 分段控件的选中块与轨道圆角同心，三套主题都适用。
- **极客的标签：** 每个徽章与计数都是同一种方形描边标签。插件、模型、机器、目标、轨迹与公司模式各页手写的标签改用徽章；胶囊形的控件取主题的胶囊圆角，极客下即为直角。
- **侧栏：** 页面入口的「常驻」开关改为锁形，常驻时锁上。入口带更新角标时，角标让到开关左侧，不再与它叠在一处。
- **流式活动共用一个组件：** 智能体的工作组（运行中 / 运行完毕）与 harness 卡片（压缩、MCP 连接、后台任务、注入的消息）合并为同一个包组件 `ActivityGroup`；其中的每一行（含工具行）都是 `DisclosureRow`。
- **白领的活动行：**
  - 不画状态图标：运行中与完毕只留文字、说明与紧随其后的小三角。失败保留红叉，标签变为红色，三套主题都如此。
  - 悬停只提亮墨色。
  - 头部下方、行间与展开的输出上方都不画线。
- **设置行：** 设置对话框里单行的设置项在同一主题内等高，与控件种类无关，各项间隔一致；带说明的行只按说明增高，标签不再换行。快捷键、代理选项与公司模式页改用同一种设置行。
- **白领的对话框：** 去掉头部分隔线后，标题与正文之间只留约一行的间距。
- **拖动预览：** 拖动侧栏入口、会话行、分组头或模型分组时，显示一张取主题表面色的不透明卡片。此前浏览器画的是行的半透明副本。
- **较新的组件改用 UI 包：** 以下组件改用共享组件与主题令牌，白领与极客因此对它们生效：
  - 模型选择对话框
  - Workspace 选择器与选择框
  - 内置浏览器的标签条与工具栏
  - 快捷键设置页与录制器
  - 终端按键条
