# 机器页：顶栏一排回到纯图标，卡片里新增服务端根目录

- **Date:** 2026-09-07
- **Type:** improvement
- **Scope:** `server`, `web`

[English](2026-09-07-machines-bar-and-root.md)

顶栏那一排的四个按钮——全选、全不选、启用、停用——去掉文字，也去掉边框，回到纯图标。四个带字的按钮挤在一行会读成一句没人写过的话，而每个图标本身就是该按钮最直白的说明：方框、空方框、插头、拔下的插头。边框跟着文字一起去掉：一个只装着图标的描边按钮，是在本来就看得懂的东西外面又画了一个框，四个排一行就是四个框。剩下的是图标本身，加一个指针找得到的 hover——与展开卡片的那个 chevron 同一形状。文字保留为 tooltip 与无障碍名称。单独出现的动作——配置、新建、强制安装——仍然带字。

卡片展开的详情里新增**服务端根目录**（`PENGUIN_HOME`）。它由 profile 决定——dev 实例访问的是机器上的 dev 安装，绝不会碰旁边的 release 安装——因此两个实例的这个页面可能指着同一台机器却说的是不同的服务端，而此前页面并没有把这一点说出来。已知平台后按该机器自己的写法呈现；本机那一条给出的是本进程自己的根目录。
