# 公司模式：在工位里切换 Model，工位随之更换

- **Date:** 2026-09-20
- **Type:** fix
- **Scope:** `web`

[English](2026-09-20-desk-model-switch.md)

在工位对话里使用 `/model`，原先与普通对话一样是分叉：为该员工的 Agent 在所选 Model 上另开一个普通 Session，窗口随即跳过去。员工条目里的 Model 与 `desks.toml` 里记的工位都没变——组织的日程与 @ 仍发往旧会话、用的还是旧 Model，侧栏的工位打开的也还是旧会话，而人正在说话的那个会话不被组织的任何页面列出。

现在，在员工当前的工位里切换 Model 是员工的事：所选 Model 写入它的员工条目（此后该员工的工位与工单会话都用它），工位更换到新 Model 上，携带来源信息的首条输入发往新工位；员工树与工位列表随即刷新，侧栏跟着走。工单的工作会话、以及已经被替换的旧工位，仍按原来的方式分叉。
