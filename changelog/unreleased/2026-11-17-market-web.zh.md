# 插件库页改为封面卡片的市场，插件详情改为产品页

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`
- **PR:** [#1584](https://github.com/Prism-Shadow/penguin-harness/pull/1584)

[English](2026-11-17-market-web.md)

Web App 的插件库页（`/plugins`）开始读取插件市场的策展（`GET /api/plugins/market`），并按市场排版：页头之下是精选轮播，其下是一行标签与封面卡片网格；服务端给出热度数据时，网格旁另有榜单。插件详情改为盖在市场上的一层产品页，并有自己的地址。

## 细节

- **精选轮播**：策展选中的插件按其顺序轮流作首屏，显示封面、名称、短描述、描述与「查看详情」，声明了快速开始的另有「快速开始」；下方是全部精选的缩略图条。首屏按日在策展允许领衔的插件中轮换。只在「全部」标签、无搜索词且未开启「只显示不兼容的插件」时显示；服务端没有策展时不显示。
- **标签**：首项为「全部」，其后是当前分组方式的各组（按类别、按状态、按内容；不分组时没有标签）。所选标签记在地址的 `?tab=<组>`。分组下拉与新增的排序下拉在标签行末，窗口较窄时另起一行、位于标签之上。原有的可折叠分组及其折叠记忆随之取消。
- **排序**（按浏览器记忆）：精选优先（默认）、最近更新（插件各 Skill、钩子包与 Workbench 中最新的日期版本；服务端模块取索引的更新时间）、本项目在用最多、名称；服务端给出热度数据时另有「热门」（累计安装数）。
- **搜索**在当前标签内筛选；当前标签无匹配而其他标签有时，空态写明全部插件中的匹配数，并附「在全部中查看」。
- **封面卡片**：插件封面（策展经本服务端给出的图片，否则由插件图标与色相绘制的缺省封面）、名称、占两行的短描述、标签（精选的插件首个标签为「精选」，「全部」标签下标出类别，另有「内置」与模块的运行位置），以及信息行：`v<版本>`、状态图标与在用的 Agent 数，文字在悬停提示与无障碍文本里，行尾是卡片操作的图标按钮。手机宽度的单列里卡片横置。
- **榜单**：服务端给出热度数据时，网格右侧（窄栏时在网格下方）的面板以两个标签列出至多十个插件：「热门」按累计安装数，「飙升」按本周新增安装数；点开任一行即该插件的详情。数据还是占位数字时，面板标题旁写「示例数据」，悬停给出原委。没有热度数据时不显示。
- **详情**：盖在市场上的一大层（手机上占满屏幕），可从卡片、轮播或榜单打开，并记在地址的 `/plugins?plugin=<插件名>`：打开即入历史，后退关闭；直接打开该地址即显示，即使当前标签或搜索隐去了它的卡片。自上而下：首屏（封面、图标、「精选」、名称、包名、短描述、标签、主要操作——带 Workbench 且已装在本服务端某个 Agent 上时为「打开」，否则为「管理安装」，其后是更新、快速开始、模块的安装或移除、修复——以及一行信息）、截图（点开为大图），然后是「介绍」与 README、「包含内容」（各 Skill、钩子点、MCP 服务器与 Workbench）、「快速开始」与「MCP 服务器」，旁边一栏是包的信息（版本、类别、作者、许可证、带复制按钮的包名、链接），最后是「文件」。「导出」与「删除」留在页脚。本构建无法完整运行的服务端模块在首屏下写明原因。
- 按内容分组时，索引列出而本服务端尚未安装的包按其索引关键字（`workbenches`、`skills`、`hooks`、`mcp`）归入对应标签，不再一律归入「服务端模块」。
- Agent 设置里的插件详情使用同一产品页，显示该 Agent 的状态与市场的封面。
- 浏览器存储：新增 `penguin.pluginsSort` 记忆排序；不再读取 `penguin.pluginsGroupsFolded`。
- UI 包的 `StatusMark` 新增 `wordless`：只显示图形，文字移到悬停提示之首，并保留给辅助技术。组件画廊的演示接口以内置策展与占位热度数据应答 `GET /api/plugins/market`，其插件库按真实类别列出市场中的插件。
