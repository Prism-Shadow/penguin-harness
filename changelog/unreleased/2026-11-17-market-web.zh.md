# 插件市场支持卡片与列表视图

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `core`, `web`, `ui`, `ui-gallery`
- **PR:** [#1584](https://github.com/Prism-Shadow/penguin-harness/pull/1584)

[English](2026-11-17-market-web.md)

打开应用内的插件市场即可搜索插件、按类别或安装状态筛选，也可以切换卡片和列表。浏览器会记住上次的视图和排序。若搜索只命中其他分类，可以直接查看全部匹配项。

卡片和列表都可查看详情、管理安装和打开已安装的工作台。详情可用链接直接分享，浏览器后退会回到市场。手机上详情占满屏幕。

市场中只由远端提供的插件也会出现在对应的分类下，例如“实用工具”和“娱乐”。

卡片和列表都在右上角显示版本，底部写明有多少个 Agent 已装，或标记「服务端已装」。有更新时可同时看到当前版本和可更新到的版本。点「快速调用」可用当前 Agent 打开示例。
