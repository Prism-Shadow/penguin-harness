# 轨迹面板在一轮结束时自动刷新

- **Date:** 2026-08-26
- **Type:** fix
- **Scope:** `web`

[English](2026-08-26-trace-panel-turn-refresh.md)

轨迹面板此前只在标签页由隐藏转为显示时抓取一次，因此在 Session 仍在工作时打开的 Trace，会一直停在
被读到时的大小与内容。此次将它接到文件面板已经在用的「一轮结束」信号上：轨迹标签页正在显示时一轮
结束，会重新列出该 Session 的 Trace 文件，并重新读取当前选中的那一个。

## 细节

- 会话页的「一轮结束」计数器——在选中 Session 的 `running` → `idle` 边沿递增，并对流分离时发出的
  假 `idle` 做了防护——在交给文件浏览器之外，也交给了轨迹面板，并按这两个读者重新命名。
- 标签页隐藏期间到达的信号不触发任何抓取。隐藏 → 显示的边沿保留了它自己的重新抓取，因此无论期间过了
  多少轮，回到该标签页时面板都是最新的，且只发一次请求，而不是每轮一次。
- 重新列出不动用户的选择：选中的文件仍在列表中时，选中的 pill 保持不变；已经消失的选择则回退到最新
  的文件。
- 选中文件的内容在同一边沿被重新读取。Trace 文件会在 Session 运行期间被不断追加，因此常见的刷新是
  同一个文件变大，而不是出现新文件；只以文件序号为键的加载对这种情况永远不会重跑。
- 刷新屏幕上已有的文件不再清空视图：骨架屏、已折叠的轮次卡片和被固定的时间线行，只有在切换到另一个
  文件时才会丢弃。
