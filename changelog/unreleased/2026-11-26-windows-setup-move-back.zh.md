# Windows 安装程序迁回曾用数据目录时保持迁移历史有效

- **Date:** 2026-11-26
- **Type:** fix
- **Scope:** `desktop`

[English](2026-11-26-windows-setup-move-back.md)

修复了 Windows 安装程序将数据目录迁回曾经使用过（现已清空）的目录时产生的问题。随新副本写入的迁移历史不再把当前新的数据目录本身留在旧路径列表中，避免了迁移完成后 PenguinHarness 因自引用记录而无法启动。

## 细节

- 保存新的迁移历史前，按不区分大小写的方式移除了与新数据目录相同的历史条目，同时保留其余旧目录，并在仅剩一条历史记录时仍保持为 JSON 数组格式。
- 扩展了 Windows 数据目录测试脚本，覆盖以不同大小写迁回曾用目录及单条历史记录的场景。
