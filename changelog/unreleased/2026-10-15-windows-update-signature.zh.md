# Windows 更新支持签名证书更换

- **Date:** 2026-10-15
- **Type:** fix
- **Scope:** `desktop`, `web`, `ci`, `docs`
- **PR:** [#1144](https://github.com/Prism-Shadow/penguin-harness/pull/1144)
- **Breaking:** yes — 0.2.16 及更早版本安装的 Windows 客户端会拒绝新签名主体，需要手动安装一次下一个版本。

[English](2026-10-15-windows-update-signature.md)

Windows 更新不再比较签名证书名称，保留了 Authenticode 有效性检查和更新源中的 SHA-512 校验。缓存安装器在进入可安装状态前接受验签，安装前还会再次检查签名。缺失、无效或无法验证的签名都会被拒绝。

安装前检查拒绝的安装器会被丢弃，网页或原生更新流程会显示错误，并允许重新检查和下载更新。

网页对话框收到桌面端安装失败的状态后会结束重启等待，显示错误和重试按钮，不再等到重启超时。

## 细节

EVSign 签名钩子会对每个签过的文件验签。发布前检查改为在缺少时间戳或签名后文件元数据不匹配时失败。安全文档记录了对发布渠道安全的依赖，不再将固定发布者作为更新的信任依据。

## 兼容性

0.2.16 及更早版本安装的客户端仍使用内置的发布者校验，会拒绝新证书签名的安装器。手动安装一次下一个版本即可，之后的更新照常安装。
