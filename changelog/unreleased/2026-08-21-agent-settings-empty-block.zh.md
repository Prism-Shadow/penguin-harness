# Agent 设置：虚线框空状态，导入技能移到列表下方

- **Date:** 2026-08-21
- **Type:** refactor
- **Scope:** `web`

[English](2026-08-21-agent-settings-empty-block.md)

Agent 设置标签页的两处布局调整。「导入技能」按钮从技能标签页的页首移到已安装列表下方——保险柜与
定时任务标签页的新增按钮本就放在这个位置。另外，四处可能为空的区块——技能、保险柜、定时任务，以及
工具标签页的 MCP Server 列表——不再以一行裸文字提示，改为共用同一个 block：圆角、虚线边框，文字
水平垂直均居中。

## 细节

- 导入动作的弹窗未作改动——推荐的对话安装、zip 上传、覆盖确认与错误 toast 行为照旧，变的只是位置，
  且仍在已安装列表加载完成前保持禁用。页首去掉按钮后，该标签页的说明折叠行占满面板宽度，与其他标签
  页一致。
- 在 `src/components/ui/empty-state.tsx` 中于 `EmptyState` 旁新增 `SettingsEmpty`，四处区块统一
  指向它，不会各自漂移。block 最小高度 6rem，垂直居中才有落点；文字沿用原有的灰度层级，圆角取自它
  所替代的表格或列表。
