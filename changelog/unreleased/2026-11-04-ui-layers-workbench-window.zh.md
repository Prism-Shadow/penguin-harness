# 工作台标签页成为聊天旁的独立窗口，可透明，全站统一层级

- **Date:** 2026-11-04
- **Type:** fix
- **Scope:** `ui`, `web`, `ui-gallery`, `skills`, `docs`
- **PR:** [#1472](https://github.com/Prism-Shadow/penguin-harness/pull/1472)

[English](2026-11-04-ui-layers-workbench-window.md)

对话页的标签条现在在其下方区域的两个并列窗口之间切换：聊天窗口（工具行、对话记录、输入框与停靠栏）和工作台标签页的页面。聊天里的任何东西都不会再盖到工作台上，工作台页面可以透明，Web App、共享 UI 包与组件画廊里的每个 z-index 都改为同一套层级中的具名层。

## 窗口

- 停靠栏属于聊天窗口。显示工作台标签页时，聊天窗口仍保持挂载与布局，但不绘制，指针、键盘焦点与辅助技术都触达不到；切回「聊天」后，停靠栏、尺寸、滚动位置与已输入的文字都和离开时一样。工作台页面占满标签条以下的整个区域，标签条带有工作台提示行时也不例外。
- 内置浏览器的页面是从窗口外按坐标盖到停靠栏槽位上的：现在显示工作台标签页时它会离开槽位，被全屏的另一侧停靠面盖住的部分也会被裁掉。
- 在工作台标签页上按停靠栏快捷键（右侧或底部停靠栏开关、终端开关、新建终端）时，先切回聊天窗口，再在那里执行该快捷键的动作。
- 页内查找不再搜索被工作台标签页盖住的对话，也不搜索已收起的停靠栏。
- 工具行的详情卡片与对话索引现在显示在全屏停靠面之上，此前会被它盖住。在详情卡片里点「停止」弹出确认框时，卡片随之关闭。

## 页面透出应用的底色

- 不设背景的工作台页面是透明的：主题的页面色、白领的底面或用户的自定义背景会透过页面显示出来，与对话页一致。页面框架跟随应用的明暗配色（color scheme），浏览器不再在它后面垫一层不透明底。
- 页面自己设置的背景照常生效。`/workbench-ui.css` 新增 `--wb-canvas`，即应用不透明的页面色，供需要实底的页面使用（`body { background: var(--wb-canvas); }`）；TSX 页面使用 `var(--ui-canvas)`。
- 占满应用的全页工作台改用主题的画布色，不再固定为白色或黑色。
- `penguin-plugin` Skill（2026.11.04.1）与文档的工作台一节已写明上述规则。

## 统一的层级

- `packages/ui/src/layers.css` 按绘制顺序声明各层：`behind`、`sticky`、`sticky-head`、`raised`、`handle`、`window-overlay`、`dock`、`dock-handle`、`menu`、`modal`、`popover`、`toast`、`tooltip`、`drag-preview`，形式为 `--layer-*` 属性与 `z-<层名>` 工具类；行内样式用 `layer("<层名>")` 取用。
- 每个窗口（聊天、工作台窗口、全页工作台）各自是一个层叠上下文，所有浮层都经 portal 挂到 `document.body`，位于各窗口之上。
- `packages/web/src`、`packages/ui/src` 与画廊外壳中的每个 z-index 都改为具名层；共享 UI 包的 `layer-scale` 测试遇到裸数值或未声明的层名即失败。
