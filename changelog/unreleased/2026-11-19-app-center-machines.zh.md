# 应用中心列出 Project 各台机器上的应用

- **Date:** 2026-11-19
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1637](https://github.com/Prism-Shadow/penguin-harness/pull/1637)

[English](2026-11-19-app-center-machines.md)

管理员打开应用中心时，在本服务端的应用之后，还会列出 Project 各台机器上 Agent 的应用。每台机器经本服务端的代理读取，哪台先应答就先显示它的图块，不必等其他机器。

## 细节

- 机器上的图块在名称下方注明机器名；它在排列中的键为 `<machineId>:<agentId>/<workbenchId>`，因此两台机器上 id 相同的 Agent 的同名 Workbench 是两个图块。本服务端应用的键不变。
- 图块的窗口、整页与 Agent 设置都进入它所在的机器；「从应用中心移除」也写在那台机器上。机器上 Agent 的「工作台」子页面增加了「展示到应用中心」开关，移除的应用可以从这里重新加入。
- 每台机器最近一次的应答按标签页保存（`sessionStorage`），不含图标与路径。机器不可达时保留它的图块，淡显且不可打开，网格下方的提示写明是哪台机器；读取失败时提示附「重试」。机器重新连接后立即重新读取。
- 这些副本按数据根、账号、Project 与机器区分；机器拒绝访问或离开 Project 的机器列表、账号登出、数据根变化时一并丢弃。
- 某台机器尚未应答时调整图块排列，它的图块仍跟在已保存排列中原先的前一个图块之后；所在分组仍在时留在该分组里。
