# 用量图表重构为带范围与精度控件的时间序列

- **Date:** 2026-08-20
- **Type:** feature
- **Scope:** `web`, `server`, `docs`
- **PR:** [#371](https://github.com/Prism-Shadow/penguin-harness/pull/371)

[English](2026-08-20-usage-charts.md)

围绕同一条时间轴重构了成本中心的图表。页面新增日期范围档位——「最近一小时」「最近一天」滑动窗口、日历式近 7 / 30 / 90 天（默认近 7 天）、或自定义起止日期——以及时间序列精度选择（按分钟 / 小时 / 天 / 周 / 月；可选项随档位变化，最近一小时以分钟桶呈现）。所有图表都按所选范围与精度绘制：

- 占比饼图与各模型进度条被并排的**两张请求与成功率图**取代：一张按 Agent 拆分，一张按模型拆分。每张图中，单个时间桶的请求数是一根按对象分段堆叠的柱、走左侧计数轴，每个对象的成功率各自成一条虚线、走右侧 0–100% 轴并沿用该对象的色相——虚线与 Token 图的命中率曲线同理，用来标明这条线属于右轴——图例置于图下方。两个维度同屏可见——不再有维度切换，两张图也都不以合计视图开场。请求数最高的四个对象各占一个经色觉无障碍校验的色相，其余折叠为一条中性色序列，标签写明折叠了多少个。某个桶内该对象没有计入成功率的请求时，它的折线在那里断开，而不是在自己根本没运行过的区间上画一条平直的 100%。悬停某个桶会列出每个已绘制对象的请求数与成功率，外加该列合计；悬停图例项则淡出其余对象。
- Token 图保留三段堆叠柱，并新增缓存命中率虚线平滑曲线，绘制在柱子前方、走独立的右侧 0–100% 轴。曲线连续——无缓存流量的桶记 0、不留缺口——悬停列内任意位置即给出整桶信息：三段 Token 数与命中率。柱宽自适应卡片宽度，不再横向滚动。
- 成本保持折线带点（每个数据点一个圆点，外加面积填充），按所选范围绘制。

命中率曲线的平滑采用单调三次插值（Fritsch–Carlson 切线），绝不越过数据本身。空桶以零值点出现、显示 0 而非「—」。图表不出现滚动条；图表区上方只有范围与精度两个全局控件。异常面板去掉了滚动容器——高度只由分页限制，服务端返回的首页从 20 行缩减为 10 行。

## 细节

- `GET /usage` 新增可选查询参数 `granularity`（`minute` / `hour` / `day` / `week` / `month`，默认 `day`）与 `fromTs`/`toTs`（ISO 时间戳界定的滑动窗口，须成对给出；`minute` 精度必需，并把所有按范围统计的聚合细化到时刻级）。响应新增 `granularity`、`series`（零值补齐的时间桶，携带 Token 分项、成本、请求数与每桶成功数）、`byAgentSeries` 与 `byModelSeries`（与 `series` 按下标对齐的各对象请求与成功计数；各自忽略本维度的过滤条件，因此图表始终呈现该维度的完整拆分）。既有字段保持不变。范围 × 精度过大、会产生超长序列的组合返回 400。
- 分钟与小时桶按服务器本地时钟划分（与既有按日聚合键使用同一时区）；周桶以 ISO 周的周一为键，月桶以 `yyyy-mm` 为键。
