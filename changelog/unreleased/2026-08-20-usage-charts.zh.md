# 用量图表改为平滑时间序列并增加范围与精度控件

- **Date:** 2026-08-20
- **Type:** feature
- **Scope:** `web`, `server`, `docs`
- **PR:** [#371](https://github.com/Prism-Shadow/penguin-harness/pull/371)

[English](2026-08-20-usage-charts.md)

围绕同一条时间轴重构了成本中心的图表。页面新增日期范围快捷选项（近 7 / 30 / 90 天，或自定义起止日期）与时间序列精度选择（按小时 / 天 / 周 / 月——可选项随范围变化），所有图表都按所选范围与精度绘制：

- 各 Agent 调用次数改为平滑折线，每个 Agent 一种颜色（头部 Agent 使用各自经过色觉无障碍校验的色相，长尾折叠为中性色的「其他」），替代原来的占比饼图。
- 成功率改为固定 0–100% 刻度上的单条平滑折线，替代原来的各模型进度条。
- Token 图保留三段堆叠柱，并新增缓存命中率曲线，绘制在柱子前方、使用独立的右侧 0–100% 轴；柱宽改为自适应卡片宽度，不再横向滚动。
- 成本改为平滑折线 + 面积。

平滑采用单调三次插值（Fritsch–Carlson 切线），曲线绝不越过数据本身——100% 的成功率不会被插值拱过 100%；空闲的时间桶也会以零值点出现，而不是被折线悄悄跨过。图表不出现滚动条；图表区上方只有范围与精度两个控件。异常面板去掉了滚动容器——高度只由分页限制，服务端返回的首页从 20 行缩减为 10 行。

## 细节

- `GET /usage` 新增可选查询参数 `granularity`（`hour` / `day` / `week` / `month`，默认 `day`），响应新增 `granularity`、`series`（零值补齐的时间桶，携带 Token 分项、成本、请求数与每桶成功数）与 `byAgentSeries`（与 `series` 按下标对齐的各 Agent 请求序列）。既有字段保持不变。范围 × 精度过大、会产生超长序列的组合返回 400。
- 小时桶按服务器本地时钟划分（与既有按日聚合键使用同一时区）；周桶以 ISO 周的周一为键，月桶以 `yyyy-mm` 为键。
