# Use Tencent Hy4 on OpenRouter or TokenDance

- **Date:** 2026-11-19
- **Type:** feature
- **Scope:** server

[中文版](2026-11-19-hy4-models.zh.md)

Hy4 accepts text and images in chat. Select `tencent/hy4` in OpenRouter or `hy4` in TokenDance. Each uses its gateway’s context window and token prices.

New projects include both models. In an existing project, choose **Add new models** in the model library to add them and keep your current selections.
