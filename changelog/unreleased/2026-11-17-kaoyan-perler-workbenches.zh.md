# 两个内置工作台应用：考研记忆卡与拼豆创作工作台

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `plugins`, `server`, `desktop`, `docs`
- **PR:** [#1586](https://github.com/Prism-Shadow/penguin-harness/pull/1586)

[English](2026-11-17-kaoyan-perler-workbenches.md)

插件库新增两个只含应用的插件：`kaoyan-flashcards`（考研记忆卡，Kaoyan Flashcards）和 `perler-studio`（拼豆创作工作台，Perler Studio）。两者都不含 Skill，也都不预装：从插件库安装到某个 Agent 上之后，应用才会出现在对话旁和应用中心里。

## 细节

- 考研记忆卡是考研题库：六个科目共 295 道示例题，按间隔排期复习，带错题本和收藏；9 篇背诵资料，可标记、遮重点；可把 `.docx`、`.pdf`、`.txt`、`.md` 文件或粘贴的文字导入为卡片和背诵资料；可导出 JSON 备份。题库是 `ui/data/decks.json`，一行一道题，需要时 Agent 可以直接加一个题库。
- 拼豆创作工作台把一张图片变成拼豆图纸，边长 29 到 104 格，也可在 4 到 200 格之间自定义。它会推荐各项参数并说明理由，按感知色差（CIEDE2000）把每一格匹配到内置色卡或用户导入的色卡，可导出 PNG 图纸、CSV、JSON 和 A4 打印页。其中「基础 29 色（参照 Hama 色号）」按 Hama 的色号编号，应用内注明与该品牌无关联。
- 两个应用都按设备语言显示中文或英文界面；顶栏的切换按钮可就地切换语言，并记住选择。题目与背诵资料保持中文。
- 学习进度和设置保存在工作台自己的状态里，每个 Agent 各自一份，换一个浏览器也能看到；卸载插件会一并删除。两个应用都不会联系自己服务器以外的任何主机。
- 服务器的插件库测试和桌面端构建的打包检查把工作台算作插件的组成部分，与 Skill、Hook 包并列。
