# 文件汇总下方列出记忆更改,侧边面板展示差异

- **Date:** 2026-08-20
- **Type:** feature
- **Scope:** `web`
- **PR:** [#375](https://github.com/Prism-Shadow/penguin-harness/pull/375)

[English](2026-08-20-memory-change-list.md)

Task 更改过 Agent 记忆时,对话现在会在两处展示出来。Task 末尾的文件汇总卡正下方新增一张记忆更改卡——每个主题文件一行,以 icon+tooltip 标注作用域(用户记忆或工作区记忆)与更改类型(写入 / 编辑)。聊天侧边面板改为双页签结构——「文件」与「记忆」,复用共享的下划线页签——记忆页签内分两级:列表(两个作用域的主题列表,与 Agent 设置记忆标签页同一份数据,本次对话更改过的主题带标记)与单条记忆的详情——正文本身以 GitHub 式整文件行差异呈现本会话的更改:新增行绿底、删除行红底插在原位、未变行为上下文,frontmatter 不参与比较;返回按钮退回列表。点击卡片行直达该条记忆的详情、差异即刻可见;经页签本身进入则始终落在列表。未触及记忆的 Task 不显示此卡。

## 详情

- 行来自结构化工具记录:成功完成、路径落在会话记忆根(`<agent_state>/memory/`)下的 `write_file` / `edit_file` 调用,按文件合并为一行——整文件写入的权重高于其后的原地编辑——且每次调用保留可回放材料(编辑的新旧字符串、写入的完整内容)。
- 整文件差异靠把本会话的调用在当前内容上**逆向回放**重建会话前文本:编辑按新→旧逐个撤销(要求锚点唯一;`replace_all` 回退全部出现),整文件写入是截止点——转录中不存在更早版本,正文按全新内容渲染并附说明。某次调用无法撤销时(文件另有会话外改动),正文正常渲染、附说明,逐次调用差异折叠可查作兜底;仅动了 frontmatter 的更改直接说明,不渲染空差异。
- 各作用域的 `MEMORY.md` 索引与 `.workspace` 标记文件被过滤:索引几乎随每次主题变更连带改写,单列会使每行都翻倍。
- 经不透明 `exec_command` shell 所做的更改(包括删除——不存在内置删除工具)没有结构化信号,不会列出,与文件汇总卡既有的局限一致。
- 仅统计根会话的 Task;subagent 的记忆写入属于其自身 Agent。
- 服务端列表未收录的已更改文件仍可达:追加到其作用域分组,详情里展示差异,内容无法加载时给出提示。
- 记忆管理(添加 / 编辑 / 删除)仍在 Agent 设置的记忆标签页;记忆页签的列表头部可跳转过去。窄视口下面板沿用既有的底部 Sheet,页签栏与两级导航一并生效;切换会话时页签重置为「文件」、记忆页签重置为列表。
