# 文件汇总下方列出记忆更改

- **Date:** 2026-08-20
- **Type:** feature
- **Scope:** `web`

[English](2026-08-20-memory-change-list.md)

Task 更改过 Agent 记忆时,回合末尾的汇总现在会展示出来:文件汇总卡正下方新增一张记忆更改卡,每个主题文件一行,以 icon+tooltip 标注作用域(用户记忆或工作区记忆)与更改类型(写入 / 编辑)。卡片头部可跳转到 Agent 的记忆标签页,即这些文件的完整视图;未触及记忆的 Task 不显示此卡。

## 详情

- 行来自结构化工具记录:成功完成、路径落在会话记忆根(`<agent_state>/memory/`)下的 `write_file` / `edit_file` 调用,按文件合并为一行——整文件写入的权重高于其后的原地编辑。被拒绝或失败的调用不会出现。
- 各作用域的 `MEMORY.md` 索引与 `.workspace` 标记文件被过滤:索引几乎随每次主题变更连带改写,单列会使每行都翻倍。
- 经不透明 `exec_command` shell 所做的更改(包括删除——不存在内置删除工具)没有结构化信号,不会列出,与文件汇总卡既有的局限一致。
- 仅统计根会话的 Task;subagent 的记忆写入属于其自身 Agent。
