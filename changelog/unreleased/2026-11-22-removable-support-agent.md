# Allow Project owners to remove the Support Agent

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `core`, `server`, `web`
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1703

[中文版](2026-11-22-removable-support-agent.zh.md)

Project owners can delete the preinstalled Support Agent in the default Project using the usual Agent deletion confirmation. It stays deleted after a restart. New installations still include Support, and the default and system Agents remain protected.
