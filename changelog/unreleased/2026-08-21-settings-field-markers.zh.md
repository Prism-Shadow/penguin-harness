# 必填只有一种标法

- **Date:** 2026-08-21
- **Type:** refactor
- **Scope:** `web`
- **PR:** [#396](https://github.com/Prism-Shadow/penguin-harness/pull/396)

[English](2026-08-21-settings-field-markers.md)

设置面板此前用三种方式标注必填：红色星号、在旁边的标签里补一个「可选」、或者什么都不标。现统一
为一条规则——**必填字段带红色星号，可选字段不带任何标记，标签与占位符都不写「可选」**。被塞进标
签的解释文字随之移出，沿用[解释文字收进问号](2026-08-21-settings-disclosure.zh.md)那一批定下的
分工：决定取值形态的文字留在字段的可见提示里。

## 标记与实际行为不符

- **上传限制**（系统设置）：单个附件与单条消息两个 MB 字段留空都会被拒绝保存，此前均未标记，现
  在都带上星号。
- **添加记忆**（Agent 设置 → 记忆）：内容字段决定该弹窗两个按钮是否可用，此前未标记，现在带上
  星号。

## 标签里自带标记

- **安全策略**（Project 设置）：规则编辑器的三个字段仅靠占位符区分，于是「名称」与「正则表达
  式」必填的唯一线索，就是「描述」上的那两个字。三个字段现在都有真正的标签，两个必填项带星号。
- **新建 Project**：显示名此前写作「显示名（可选，缺省为 Project id）」。标签现在只留名称，缺省
  规则改为字段下方的提示——与「创建 Agent」对话框一贯的写法一致。
- **定时任务**（Agent 设置）：「结束时间（可选）」与「Workspace（可选，留空自动创建临时工作
  区）」去掉了这两个字；Workspace 的缺省说明改为可见提示，与 Project 设置 → 默认值中的同一字段
  保持一致。

## 只有一个星号

这个标记此前被手写了三份，其中一份漏掉了暗色模式的墨色，红得比其他副本更亮。现在统一为一个
`RequiredMark`：模型页的新建分组与模型对话框中的自定义标签行经由 `FieldLabel` 使用它，Trace 查
看器的工具 schema 表格也用它标注必填属性。
