# 机器状态胶囊只写词，行内短标签共用一种胶囊

- **Date:** 2026-10-15
- **Type:** fix
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#1162](https://github.com/Prism-Shadow/penguin-harness/pull/1162)

[English](2026-10-15-label-pill.md)

机器的状态胶囊不再带图形：「运行中」和其他状态都是一个词加上它的色调。它与旁边的「本服务端」标签形状完全相同，两者都由共享 UI 包新增的标签胶囊 `Pill` 绘制，不同标签之间只有色调不同。

## 细节

- `Pill` 就是小号、浅底的徽标，没有其他选项：每种色调的高度、内边距、圆角、字号与描边都相同，只写词不带图形，可附一句悬停说明。
- 机器管理页与机器详情弹窗里，状态、本服务端标签、版本与「其他 Project 已安装」都改为 `Pill`；旁边的「需要更新」胶囊也取同一形状，Agent 卡片上的同样如此。
- 模型库的标签（默认、视觉、免费、推荐）、模型选择器的标签、已归档对话的来源胶囊、Agent 的版本、评估中心浏览器里的「被测 Agent 不可见」以及公司页头的公司状态，都改由 `Pill` 渲染；原本就是这个样子的小标签——目标状态、频道里的「@我」、手册的索引标记、Trace 轮次的压缩标记与任务序号、版本说明里的「当前版本」、Agent 表单里的「推荐」——也一并改用 `Pill`。
- UI 画廊展示每种色调的标签胶囊，以及卡片标题行的一组标签。
