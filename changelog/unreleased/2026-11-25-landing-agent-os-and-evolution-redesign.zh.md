# 站点导航统一与 Harness OS 及自进化平台重设计

- **Date:** 2026-11-25
- **Type:** feature
- **Scope:** `ui`, `web`, `landing`, `docs`, `ui-gallery`

[English](2026-11-25-landing-agent-os-and-evolution-redesign.md)

落地页、文档站与主题包统一复用 `@prismshadow/penguin-ui/site` 的 `SiteNav` 与 `SiteMobileNav` 导航栏组件，并将 `RFCs` 收纳进「更多」下拉菜单。产品开始页与官网首页统一采用「Harness OS」命名：首页首屏副标题更新为「千万个 AI 应用的统一自进化底座」，目录计数统一为 `1000+` 支持模型、`10+` 自进化算法与 `20+` 评估集；「构建你的第一个自进化 Harness OS」章节精炼文案，应用中心改成一块不断被填满的主屏，一句话接一句话地生成应用，多个应用同时安装；「任意 Agent 的统一自进化平台」章节把多个被测 Agent 各自的评估与改进循环，同准确率、成本、耗时三条进化趋势放进同一个工作台，每有一个循环走完一轮，曲线就前进一步。
