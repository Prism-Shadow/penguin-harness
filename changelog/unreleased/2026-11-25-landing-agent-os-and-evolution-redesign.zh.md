# 站点导航统一与 Harness OS 及自进化平台重设计

- **Date:** 2026-11-25
- **Type:** feature
- **Scope:** `ui`, `web`, `landing`, `docs`, `ui-gallery`

[English](2026-11-25-landing-agent-os-and-evolution-redesign.md)

落地页、文档站与主题包统一复用 `@prismshadow/penguin-ui/site` 的 `SiteNav` 与 `SiteMobileNav` 导航栏组件，并将 `RFCs` 收纳进「更多」下拉菜单。产品开始页与官网首页统一采用「Harness OS」命名：首页首屏副标题更新为「千万个 AI 应用的统一自进化底座」，目录计数统一为 `1000+` 支持模型、`10+` 自进化算法与 `20+` 评估集；「构建你的第一个自进化 Harness OS」章节精炼文案并为应用中心加入应用图标汇聚、一句话生成与安装动效；「任意 Agent 的统一自进化平台」章节将自进化工作流与自进化工作台融合至左栏，右栏折线图展示准确率上升、成本与耗时逐步下降的进化趋势。
