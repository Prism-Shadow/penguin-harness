# 桌面应用可以从命令面板打开第二个窗口

- **Date:** 2026-10-04
- **Type:** feature
- **Scope:** `desktop`, `server`, `web`

[English](2026-10-04-desktop-new-window.md)

桌面应用原先只有一个窗口：再次启动只会把已有窗口调到前面，应用内也没有任何入口可以再开一个。

## 改动

- **新建窗口：** 在桌面应用的窗口里，命令面板列出「新建窗口」。选中后再打开一个窗口，显示同一个应用、同一份数据。在浏览器里打开应用时没有这一项。
- **打开方式：** 页面请求服务端（`POST /api/desktop/window`，仅限 shell 自己的会话），服务端经现有的消息通道通知 shell，由 shell 打开窗口。页面仍然不能自行打开指向应用的窗口。
- **新窗口：** 遵循拆出的终端窗口的规则。关闭即关闭，不会隐藏到托盘；会话结束时自行关闭。其中不提供内置浏览器：内置浏览器的标签页只存在于主窗口。
- **主窗口：** 不变。隐藏到托盘、崩溃后重新加载、重新登录的仍然只有它。
- **旧版桌面应用搭配新版服务端：** 应用会忽略这一请求，不会打开窗口。
