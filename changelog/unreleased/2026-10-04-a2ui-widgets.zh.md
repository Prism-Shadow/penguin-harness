# A2UI 小组件：天气、时钟、倒计时与指标，以及组件块的重新设计

- **Date:** 2026-10-04
- **Type:** feature
- **Scope:** `core`, `ui`, `web`, `skills`
- **PR:** [#983](https://github.com/Prism-Shadow/penguin-harness/pull/983)

[English](2026-10-04-a2ui-widgets.md)

A2UI 组件目录（[2026-10-03-a2ui-blocks.zh.md](2026-10-03-a2ui-blocks.zh.md)）新增四个一眼可读的小组件——`weather`、`clock`、`countdown` 与 `metrics`——原有的选项、表单、步骤、提示框与 Mermaid 图也按同一套设计重新绘制。天气与指标是模型连同读取时间一起给出的快照；时钟与倒计时按查看者自己的时钟运行。两个新的技能脚本把真实的天气与系统数据直接输出为现成的组件块。

## 改动

- **组件目录：** `weather`（某地的天气，11 种天气状况，可附逐小时与未来几天的预报，配会动的线条插画）、`clock`（一到四个 IANA 时区或本地时间，数字、指针或两者兼有，每秒走动）、`countdown`（距一个 ISO 日期时间还剩多久，到点后显示一行到点文字）与 `metrics`（一个组件块里放一到八个指标）。指标分为 `reading`（读数）、`used`（已用）、`remaining`（剩余）与 `progress`（进度）四种，可画环形或条形仪表、历史走势与变化量，`warn` 与 `danger` 阈值按 `worse` 指定的方向判断并着色。系统资源、进度条与额度或预算余量都用这一个组件表达。
- **快照带时间：** 天气与指标新增 `asOf` 日期时间，显示在小组件头部。缺少时检查脚本给出 `no_as_of` 警告；自审清单新增第 8 问：小组件里的每个数字是否真实并带有时间。新增 L1 代码 `invalid_datetime`、`invalid_timezone`、`duplicate_zone`，新增 L2 警告 `no_as_of`、`weather_hourly_long`、`metrics_too_many`。小组件不是提问，后面可以接正文。
- **小组件外框：** 四个小组件共用 `WidgetSurface` 与新的 `ui-widget` 样式钩子。白领主题画成浅底色块、内嵌白色小块，极客主题画成细线框、数字用等宽字体，朴素主题保留卡片。core 的 `a2ui` 模块新增渲染与纯文本降级共用的格式化函数：数字、温度、剩余时间与指标的色调。
- **动效：** 每幅天气插画循环演示其天气（雨落、雪飘、云移、闪电），逐小时温度线只绘入一次。循环动效采用主题的实时节奏，在减少动态效果时静止，小组件滚出视野时暂停，时钟也随之停止走动。
- **重新设计：** 短的选项改成一排小标签，长的改成带圆点的卡片列；表单里短的单选字段改成分段控件，短的多选改成一排可切换的小标签，数字字段加上受上下限约束的 −/+ 按钮；步骤改成带编号的时间线；Mermaid 图的外框改用表面底色。每个组件块在回复落定后按主题的显现方式出现。
- **其他出口一律纯文字：** CLI 与消息渠道把每个小组件显示为文字——天气是一行标题加详情、逐小时与未来几天，时钟每个时区一行，倒计时是剩余时间，指标每项一条并标出注意、警告或已完成——天气与指标的末尾附上 `asOf` 时间。
- **脚本：** 技能附带 `scripts/weather.mjs`，读取 Open-Meteo（无需密钥，支持中文地名）并输出 `weather` 组件块；以及 `scripts/sysinfo.mjs`，通过 Node 的 `os` 与 `fs` 模块读取 CPU、内存、磁盘、负载与运行时间并输出 `metrics` 组件块。两个脚本均为手写、无依赖，可在 Windows、macOS 与 Linux 上运行，默认输出可直接粘贴的围栏，加 `--json` 时输出裸 JSON。技能要求模型使用它们，而不是凭记忆写数字。
- **技能与文档：** a2ui 技能与组件参考补充了四个小组件及其示例，插件版本升至 `2026.10.04.1`。对话页的「富输出组件」一节列出了这些小组件，UI 画廊的内容页也加入了它们的示例。
