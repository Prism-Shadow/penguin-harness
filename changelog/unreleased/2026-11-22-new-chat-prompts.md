# Quick prompts on the new chat page

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `web`, `ui`

[中文版](2026-11-22-new-chat-prompts.zh.md)

The new chat page centers the composer under the product name. Suggested prompts appear as buttons below it. Shuffle deals a different set without changing the draft. Saved shortcuts appear alongside suggestions and can be added, edited and removed. Project totals and the version sit below the shortcuts.
