# The a2ui skill teaches every form control and drops the prose checks

- **Date:** 2026-10-20
- **Type:** feature
- **Scope:** `skills`, `docs`
- **PR:** [#1255](https://github.com/Prism-Shadow/penguin-harness/pull/1255)

[中文版](2026-10-20-a2ui-forms.zh.md)

The `a2ui` skill and the docs teach the form's eleven field kinds and no longer mention prose checks. The grammar, the controls and the blocks have their own entries: [forms grammar](2026-10-20-a2ui-forms-grammar.md), [choice group, number input and slider](2026-10-20-ui-form-controls.md) and [form and choice blocks](2026-10-20-a2ui-form-blocks.md).

## Skill and docs

- The `a2ui` skill (version `2026.10.20.2`) teaches the eleven kinds: the catalog row, a kinds table with each control's answer and fill line, the rules for picking a kind, and a worked form with a dropdown, a slider, a date and a switch. Its instructions no longer mention prose checks or a prose score, and its rubric has seven questions. The writing rules stay as advice, so the skill's one-line description is unchanged.
- Chat › Rich output blocks describes the form's controls and its validation, and the plugin library's README names them.
