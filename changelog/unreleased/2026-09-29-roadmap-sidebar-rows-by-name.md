# The sidebar's roadmap rows show the room's name only

- **Date:** 2026-09-29
- **Type:** fix
- **Scope:** `web`

[中文版](2026-09-29-roadmap-sidebar-rows-by-name.zh.md)

A row in the sidebar's **ROADMAPS** section now reads like a channel row above it: the roadmap glyph and the room's name. The grey `#n` at the end of the row is gone, and so is the `#n name` hover text; a name too long for the row still shows in full on hover, as any truncated sidebar name does. The number stays where a roadmap is referred to by it — the room's roadmap column and the plugin's All roadmaps page. Which roadmaps the section lists, their order and the expand are unchanged.
