# Session 绑定飞书机器人

- **Date:** 2026-08-25
- **Type:** feature
- **Scope:** `server`, `web`, `docs`
- **PR:** [#464](https://github.com/Prism-Shadow/penguin-harness/pull/464)

[English](2026-08-25-feishu-session-bridge.md)

新增消息渠道绑定，飞书（Lark）为首个渠道：Session 绑定到自建飞书应用后，发给机器人的消息以普通用户输入进入该 Session，AI 完成的回复再转发回飞书会话。

## 细节

- 两处管理入口共用同一个绑定编辑器：会话行菜单的「绑定到飞书…」对话框，与对话页右侧面板栏新增的「消息软件」停靠面板（排在轨迹面板之后，管理当前会话的绑定）。编辑器包含 App ID / App Secret / API 域名表单、教程链接、凭据测试、「发送测试消息」探测（需连接中且机器人收到过消息）与带确认的解绑；已保存的 Secret 只以全站统一掩码作为占位符展示（输入即替换、留空即保留），已绑定的行显示一枚小纸飞机标识。
- 保存与启用拆分为两件事：「保存」只保存凭据、从不建立或断开连接（唯一例外——已启用绑定在保存新凭据时用新凭据重启连接器，存储配置与在线连接永不背离）；独立的「启用连接」开关用已存凭据即时建立或断开连接（表单有未保存修改时置灰并提示先保存凭据）。新绑定默认停用；服务端启动只连接已启用的绑定。
- 侧栏会话行的悬停按钮改形：归档保留为直接按钮，删除按钮换成实心三圆点「更多」按钮——点击即在按钮处打开该行的完整右键菜单（菜单新增了仅靠右键难以发现的配置类操作），删除移入菜单（仍为危险样式）。
- 服务端以带渠道判别列的 `messaging_bindings` 表存储绑定（一个 Session 一个绑定，同一渠道下一个机器人账号一个绑定——409 `feishu_app_in_use`；`enabled` 为存储的连接意图），并经渠道连接器接缝运行消息桥——每个启用绑定一条长连接事件流，飞书连接器为首个实现。入站文本以 `queueIfBusy` 按普通输入框口径发起 Task（无标记块、无特殊 sender，模型不知道消息来自飞书）；其他消息类型收到双语「仅支持文本」回复；每个完成的任务把助手文本镜像回最近的会话（群聊回复到原消息），按飞书文本消息大小上限分段；有工具调用等待审批时发送一行指向 Web 界面的提醒。
- `/api/sessions/:sessionId/messaging/feishu` 下新增接口（get / put / state / delete / test / test-message）：Secret 在所有响应中掩码、留空重存时保持原值，读取与测试对任意 Project 成员开放、写入仅限所有者。删除 Session 连带删除其绑定。
