# 从工作台任意页面直接退出

- **Date:** 2026-11-19
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1623](https://github.com/Prism-Shadow/penguin-harness/pull/1623)

[English](2026-11-19-close-workbench-window.md)

在英语工作台里连续切换几节课后，点一次右上角的关闭按钮就会回到应用图标。从分组打开时，关闭后回到原分组。浏览器的后退键仍可逐页回看课程。关闭分组、退出从应用中心打开的整页也以同样的方式返回，键盘焦点回到对应的图块。

## 细节

- 返回借助浏览器的 Navigation API 直接回到宿主自己的那条应用中心记录，跳过应用框架内留下的页面。不支持该 API 的浏览器改为把当前记录替换成网格或分组，此后的后退要先走过应用内的页面才离开应用中心。
- 打开的分组只从地址读取（`?folder=<id>`），页面不再另存一份，也不再绕过路由单独监听浏览器历史。
