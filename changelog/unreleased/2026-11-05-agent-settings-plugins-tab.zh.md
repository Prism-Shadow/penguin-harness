# Agent 设置新增「插件」标签页，工作台可以关闭

- **Date:** 2026-11-05
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#1497](https://github.com/Prism-Shadow/penguin-harness/pull/1497)

[English](2026-11-05-agent-settings-plugins-tab.md)

Agent 设置页新增**插件**标签页，取代**技能**、**钩子**和**工作台**三个标签页。它列出 Agent 装了哪些插件、每个插件带来了什么（Skill、钩子包、MCP Server、工作台），以及状态：**已安装**、**可更新**、**不完整**或**不在插件库**。插件那一行在落后于插件库或缺部件时提供**更新**；Project owner 还能**卸载**，确认框先逐项列出部件，然后一次请求删除全部部件。自己创建或导入的 Skill、钩子包和工作台列在最后的**不属于插件**里。`?tab=skills`、`?tab=hooks` 和 `?tab=workbenches` 地址会打开插件标签页，并长期保留。

## 细节

- 标签页顶部是**导入**（Skill、钩子包或工作台，沿用原标签页的对话框）和**浏览插件库**（打开插件市场页面，并把这个 Agent 设为当前 Agent）。
- **启用技能**和**技能提示词**、**启用钩子**，以及新增的**启用工作台**放在一起，都只有 Project owner 能改，成员只能看到状态。此前**启用技能**和**技能提示词**任何成员都能改。
- 每个工作台有自己的开关。关闭的工作台，或者**启用工作台**关闭时的所有工作台，不再出现在对话旁的标签里，也不能以全屏页面打开；历史、恢复、导出和移除照常可用。版本较旧的机器上不显示这些开关。
- 插件市场页面的**卸载**改为同一个请求，不再逐个部件删除，并且只对 Project owner 提供。有部件没能删除时，提示会写明部件和原因；机器版本太旧、不支持这个请求时，提示先更新那台机器。
- 插件装上的 MCP Server 列在插件下面，写明还缺什么，并链接到编辑它的**工具**标签页。
