# Models page group actions collapse to icons on narrow layouts

Group headers on the models page adapt to the width the row actually has (the desktop sidebar can narrow it while the viewport stays wide), and no group action disappears anymore when space runs out: "Add model", "Set API key for group", "Speed test", and the "Get API key" link now collapse to icon-only controls, dropping just their text labels. Every icon-only control keeps an accessible name and a hover tooltip with the full label.

Labels reappear as the row grows, and group headers no longer overlap or overflow at any width.
