# 影响较大的操作先确认

- **Date:** 2026-10-01
- **Type:** feature
- **Scope:** `web`

[English](2026-10-01-consequential-confirms.md)

逐一检查了 Web App 中破坏性或难以撤回的操作。原先点一下就执行的，现在都先弹出应用统一的确认框。

## 改动

- **新增确认：**
  - 移除 Project 成员
  - 停止运行中的后台进程
  - 对机器强制重装、停止使用机器、批量更新落后的机器
  - 关闭公司模式（确认前开关保持打开）
  - 恢复工作流版本
  - 运行插件定义的管理操作
  - 恢复默认头像
  - 清空组织草稿
  - 命令策略恢复缺省
  - 导入 Agent State 快照：现在一律先问，快照版本更高也要确认
- **未保存的修改：** 丢弃前先问。包括在 Agent 设置里切换标签页或返回、手册编辑中取消或改选文档，以及关闭任一渠道有改动的消息绑定对话框。
- **已输入的文字：** 点击示例任务或已保存的快捷指令，要替换输入框里已有的文字时先问。
- **模型库的每个「同步预置」入口** 都先弹同一个确认；「全部复原」快捷键只覆盖了一条时也要确认。
- **色调：**
  - 移除模块插件改用危险标记。
  - Skill 与钩子的上传覆盖、快照导入的版本冲突提示改用保存与覆盖所用的中性铅笔。
- **措辞：** 破坏性确认的按钮写动作本身（删除、卸载、离任），不再写笼统的「确认」。
