# A narration across every language

- **Date:** 2026-09-23
- **Type:** feature
- **Scope:** `web`

When an activity has more than one language, a narration's asset editor lists it in each
one, as Loom's audio panel did: the language's script, whether it still needs translating
or its English line changed, whether it is spoken yet, and **Open** to switch to that
language.
