# 对话框、表单与页面里的行内报错提供「[报告问题]」

- **Date:** 2026-11-19
- **Type:** feature
- **Scope:** `web`, `ui`

[English](2026-11-19-report-inline-failures.md)

对话框、表单、面板里或代替页面显示的行内报错，属于失败时在文字之后提供「[报告问题]」，与提示条自 [2026-11-19-report-every-failure](2026-11-19-report-every-failure.zh.md) 起遵循的规则相同（penguin-harness-design [#476](https://github.com/Prism-Shadow/penguin-harness-design/pull/476)）。拒绝与原来完全一样，不带入口：密码错误、名称已存在、无权限、对象不存在、服务端驳回的字段。屏幕上的措辞不变。

## 细节

- 公司模式：概览、组织架构、工单、日历、财务与手册页面加载或刷新失败时；频道的详情与消息；工单；侧栏的频道与工位列表；新建组织、组织设置与删除确认，以及模型字段；频道与员工的对话框。
- Agent：设置页及其记忆、插件、Vault、定时任务与 API 标签页；创建 API Key，以及并发数与对话设置；创建 Agent（其插件库、目录里的 Skill 与创建本身）；添加 Vault 条目；保存 MCP Server；zip 导入；删除 Agent。
- 模型：模型列表、添加分组对话框（协议检测、端点的模型列表、导入）、OAuth 对话框与 Key 授权对话框。以拒绝结束的流程（授权已过期、已被使用或被驳回）只显示文字；失败的流程（连不上服务商、没有拿到可用的 Key、Key 没能保存）提供入口。
- Project 与用户：创建与重命名 Project、成员、对话默认设置与命令策略；用户列表、添加用户、重置密码与删除用户。
- 设置：Agent API、Chrome 扩展与公司模式三个开关，已归档对话列表与个人资料。
- 评测中心与定时任务：创建与导入 Benchmark、Benchmark 列表与 Benchmark 的用例；定时任务列表与定时任务表单。
- 插件：导入对话框里失败的 npm、链接或 zip 安装，插件的 MCP 设置，以及没能读取的插件库。
- 登录与账户：登录表单与修改密码对话框。
- 内置浏览器的导入对话框与配对码、重命名对话、在文件夹选择器里新建文件夹。
- 对话：上下文面板的组成、记忆的内容与记忆列表，以及草稿的 Agent 选择器在机器的 Agent 列表没能读取时。
- 恢复面板里的 harness 历史：历史本身、某个版本的改动与其模块树，以及失败或未能按时完成的回滚。
- `ActivityGroup` 在可展开的标题行上也显示 `actions`：放在展开正文的末行、完整的说明之后，保留了步骤的失败活动同样提供「[报告问题]」。
- `PickerList` 的空列表文字与公司页面的错误行可以是节点。
