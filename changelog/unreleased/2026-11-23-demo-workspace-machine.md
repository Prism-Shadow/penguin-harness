# Keep demo conversations on their workspace machine

- **Date:** 2026-11-23
- **Type:** fix
- **Scope:** `ui-gallery`, `landing`

[中文版](2026-11-23-demo-workspace-machine.zh.md)

Opening a local conversation in the live demo shows it once in the workspace sidebar. A conversation created on the simulated remote machine remains available in that machine’s workspace, including when both machines use the same directory path.
