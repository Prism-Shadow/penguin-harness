# Workspace 选择器改为文件浏览弹窗

- **Date:** 2026-09-24
- **Type:** feature
- **Scope:** `web`, `server`, `docs`
- **PR:** [#858](https://github.com/Prism-Shadow/penguin-harness/pull/858)

[English](2026-09-24-workspace-finder-modal.md)

所有 Workspace 选择器（对话草稿页的胶囊按钮，Project 设置、定时任务、公司弹窗与新建智能体弹窗中的表单字段，以及侧边栏的新建工作区按钮）改为打开文件浏览弹窗，不再是下拉菜单。交互沿用各平台文件管理器的习惯，尤其是 Windows 资源管理器。触发按钮外观不变，宿主收到的仍是所选文件夹及其所在机器。

## 弹窗

- 侧边栏以**常用**开头：家目录，加上被浏览机器所在平台的标准文件夹中该机器上实际存在的那些——Windows 为桌面、下载、文档、图片，macOS 为桌面、文稿、下载，Linux 为桌面、文档、下载、图片；Windows 另在**此电脑**下列出各盘符。其后是**最近使用**（本 Project 最近 Session 所在的 Workspace），选择器提供机器选择时另列**机器**；选择机器即从该机器的家目录开始浏览。
- 常用可以编辑：标题旁的 **+** 把当前文件夹加入常用，右键菜单可加入任意文件夹；悬停时出现的 **×** 或右键菜单可移除任一项，默认项也可移除。改动按机器保存在当前浏览器中。
- 工具栏左侧是后退、前进、上一级与刷新四枚图标按钮，右侧是外观如输入框的**地址栏**：点击路径中的某一段即打开该文件夹，点击地址栏其余位置（或按 ⌘⇧G，其他平台为 Ctrl+Shift+G）即变为可编辑的路径，Enter 前往、Esc 恢复原状；路径不存在时仍弹出提示并停留在当前文件夹。最右侧为筛选框。
- 当前文件夹以列表展示，文件夹在前，显示名称与修改时间；除双击或 Enter 外，每个文件夹行末尾另有一个进入箭头。文件以灰色显示、不可选择；隐藏条目仍不显示。
- **右键**（触屏长按、键盘 Shift+F10）弹出菜单：文件夹为打开、选择此文件夹、添加到常用或从常用中移除、复制路径，文件只有复制路径；列表空白处针对当前文件夹，另有刷新。侧边栏条目同样支持右键菜单。
- **选择**取选中的文件夹，未选中时取当前文件夹。原选择器提供的「改用临时工作区」链接保留在底栏。
- 键盘：↑/↓ 移动，Enter 或 ⌘↓ 打开，⌘↑ 回到上级，⌘[ / ⌘] 后退 / 前进，⌘Enter 选择，输入名称前缀即选中，Esc 取消（非 macOS 平台以 Ctrl 代替 ⌘）。打开时在上级文件夹中选中当前 Workspace。
- 手机上弹窗铺满全屏，侧边栏收进切换按钮。

## 无法读取的文件夹

- 目录 API 对服务无权读取的文件夹返回 `403 dir_permission_denied`，不再返回空列表；本机与通过 ssh 浏览的机器均如此。
- 弹窗在文件夹区域说明无法读取；服务运行在 macOS 上时，提示前往「系统设置 → 隐私与安全性 → 文件与文件夹」允许访问。
- 目录列表现在包含文件、每个条目的类型与修改时间、服务器的平台，Windows 上另含各盘符根目录。
