# Workspace 选择器改为 Finder 式弹窗

- **Date:** 2026-09-24
- **Type:** feature
- **Scope:** `web`, `server`, `docs`

[English](2026-09-24-workspace-finder-modal.md)

所有 Workspace 选择器（对话草稿页的胶囊按钮，Project 设置、定时任务、公司弹窗与新建智能体弹窗中的表单字段，以及侧边栏的新建工作区按钮）改为打开 Finder 式弹窗，不再是下拉菜单。触发按钮外观不变，宿主收到的仍是所选文件夹及其所在机器。

## 弹窗

- 侧边栏列出个人收藏（家目录，以及该机器上实际存在的桌面、文稿、下载；Windows 另列各盘符根目录）、最近使用（本 Project 最近 Session 所在的 Workspace），选择器提供机器选择时另列机器；选择机器即从该机器的家目录开始浏览。
- 当前文件夹以列表展示，文件夹在前，显示名称与修改时间；文件以灰色显示、不可选择；隐藏条目仍不显示。
- 工具栏有后退 / 前进、可点击的路径面包屑与筛选框。**前往文件夹**（macOS 上为 ⌘⇧G，其他平台为 Ctrl+Shift+G）取代原来可编辑的路径行；路径不存在时仍弹出提示并停留在当前文件夹。
- **选择**取选中的文件夹，未选中时取当前文件夹。原选择器提供的「改用临时工作区」链接保留在底栏。
- 键盘：↑/↓ 移动，Enter 或 ⌘↓ 打开，⌘↑ 回到上级，⌘[ / ⌘] 后退 / 前进，⌘Enter 选择，输入名称前缀即选中，Esc 取消（非 macOS 平台以 Ctrl 代替 ⌘）。打开时在上级文件夹中选中当前 Workspace。
- 手机上弹窗铺满全屏，侧边栏收进切换按钮。

## 无法读取的文件夹

- 目录 API 对服务无权读取的文件夹返回 `403 dir_permission_denied`，不再返回空列表；本机与通过 ssh 浏览的机器均如此。
- 弹窗在文件夹区域说明无法读取；服务运行在 macOS 上时，提示前往「系统设置 → 隐私与安全性 → 文件与文件夹」允许访问。
- 目录列表现在包含文件、每个条目的类型与修改时间、服务器的平台，Windows 上另含各盘符根目录。
