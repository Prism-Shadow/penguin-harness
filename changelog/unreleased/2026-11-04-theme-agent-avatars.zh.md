# Agent 画成笑脸圆球企鹅，每套主题各有画法

- **Date:** 2026-11-04
- **Type:** feat
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#1467](https://github.com/Prism-Shadow/penguin-harness/pull/1467)

[English](2026-11-04-theme-agent-avatars.md)

没有自己图片的 Agent 不再画成淡色方块上的首字母，而是一只笑脸圆球企鹅：整只企鹅就是一个圆，深色的头罩下是宽大的浅色脸，配豆豆眼、小喙、微笑与两只短鳍。每个 Agent 都是同一张笑脸，颜色则各不相同——由 id 得到十二色之一。每套主题用自己的风格画它，打开的页面在切换主题的同时即重画。

## 细节

- 朴素画在圆角方块上；白领与卡通画在圆形上；极客为方块上的 16×16 像素画，16px 起每格对齐整像素。没有自己画法的主题显示朴素的画法。
- 微笑在任何尺寸都看得见。32px 以下脸上是两颗粗圆点和一道宽的笑弧，省去小喙——小尺寸下喙会和笑弧糊在一起；32px 起小喙在笑弧之上。20px 起显示腮红，48px 起眼睛带高光。
- 颜色是十二色之一，由 Agent id 经与此前相同的哈希得出，取最近的十二个色相之一，Agent 保留此前的色系，换主题、换明暗、改名颜色都不变。浅色模式企鹅为该色相的深色、脸为浅色；深色模式保留企鹅本来的配色：中间调的身体、近白的脸与深色眼睛。身体对底色与各主题的页面至少 3:1，眼睛对脸至少 4.5:1。
- 不再画首字母：每个头像旁都有 Agent 的名字或悬停提示，而多数头像只有 14–18px，字母与企鹅挤不下。
- 公司模式里组织未设图片的员工同样显示企鹅。用户头像与自定义模型分组的字母方块不变。
- 画廊的「头像」页以当前主题的画法列出十二个 Agent，再把各主题的画法并排列出，尺寸为 16、24、48、96px。
