# 每套主题把 Agent 画成自己风格的企鹅

- **Date:** 2026-11-04
- **Type:** feat
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#1467](https://github.com/Prism-Shadow/penguin-harness/pull/1467)

[English](2026-11-04-theme-agent-avatars.md)

没有自己图片的 Agent 不再画成淡色方块上的首字母，而是一只站立的小企鹅：每套主题是同一个角色，按 Agent 换颜色，沿用字母方块的克制画法——企鹅以 Agent 的墨色画在同色相的淡色底上，脸与肚皮镂空露出底色，另有两点眼睛、小喙与双脚。每套主题用自己的风格画它，打开的页面在切换主题的同时即重画。

## 细节

- 朴素画在圆角方块上；白领为更圆的企鹅、画在圆形上；极客为方块上的 16×16 像素画，16px 起每格对齐整像素。没有自己画法的主题显示朴素的画法。
- 颜色是十二色之一，由 Agent id 经与此前相同的哈希得出，取最近的十二个色相之一。Agent 保留此前的色系，换主题、换明暗、改名颜色都不变。浅色模式底色淡、墨色深；深色模式底色为深色调、墨色浅。墨色对底色至少 4.5:1，对各主题的页面至少 3:1。
- 不再画首字母：每个头像旁都有 Agent 的名字或悬停提示，而多数头像只有 14–18px，字母与企鹅挤不下。
- 公司模式里组织未设图片的员工同样显示企鹅。用户头像与自定义模型分组的字母方块不变。
- 画廊的「头像」页先以当前主题的画法列出十二种颜色，再把各主题的画法并排列出，尺寸为 16、24、48px。
