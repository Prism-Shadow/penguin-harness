# 公司模式作为应用中心应用的设计草案：组件画廊与官网页

- **Date:** 2026-11-27
- **Type:** feature
- **Scope:** `ui-gallery`, `landing`

[English](2026-11-27-company-app-draft.md)

组件画廊新增一个可操作的公司模式草案，把它改成由 agent-company 插件贡献给应用中心的应用；官网新增 `/company` 页面，实时嵌入这个草案。已发布的 `/org` 页面和服务端没有改动。

## 细节

- 画廊的 mock `/api/contributions` 现在返回一个插件页面 `agent-company.app`。它声明为应用中心应用，用 iframe 渲染：和其他应用一样在应用中心窗口里打开，也能单独在 `/app/<project>/system_agent/company` 打开。
- 应用（`company.html`）完全在浏览器里用演示数据运行，支持中英双语，并通过现有的 frame 消息跟随宿主的主题、语言和位置。
  - **收件箱：** 等你处理的、进行中的、已结束的。
  - **工单：** 看板分为执行中、验证中、等你拍板和已完成几列。每张工单都能在抽屉里打开，日志默认折叠。
  - **团队：** 主理、执行者和验证者。
  - **手册：** 规则和教训，可以回滚 Skill。
  - **新建组织：** 从目标或模板创建。
- 收件箱处理三类事项：
  - **决策卡** 使用 A2UI 的 `ChoiceBlock`，选定的答案会写进工单和手册。
  - **交付** 可以验收、在 Agent 工作台里打开，或附上理由打回。打回会计一轮、记一条教训，并把执行者的 Skill 升一个版本。
  - **被熔断的工单** 在达到打回上限或预算上限时停下，显示一个可以由用户解除的熔断。
- “和主理对话”和“我来接手”通过 `penguin:navigate` 转到普通对话。
- 画廊新增两个界面 `company` 和 `company-new`，在嵌入的 Web App 里打开这个应用。
- 官网的 `/company` 页面（静态构建中为 `/company/`）有四个部分：
  - 实时画廊窗口，标为设计草案。
  - 区分多 Agent 产品的四个问题。
  - 应用用到的平台接口。
  - 取舍：保留、改变、以后再做、不做。
