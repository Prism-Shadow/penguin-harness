# 公司模式作为应用中心应用的设计草案：组件画廊与官网页

- **Date:** 2026-11-27
- **Type:** feature
- **Scope:** `ui-gallery`, `landing`
- **PR:** [#1916](https://github.com/Prism-Shadow/penguin-harness/pull/1916)

[English](2026-11-27-company-app-draft.md)

组件画廊新增一个可操作的公司模式草案，把它改成由 agent-company 插件贡献给应用中心的应用；官网新增 `/company` 页面，实时嵌入这个草案。草案里一个会话就是一件活。已发布的 `/org` 页面和服务端没有改动。

## 细节

- 画廊的 mock `/api/contributions` 现在返回一个插件页面 `agent-company.app`。它声明为应用中心应用，用 iframe 渲染：和其他应用一样在应用中心窗口里打开，也能单独在 `/app/<project>/system_agent/company` 打开。
- 应用（`company.html`）完全在浏览器里用演示数据运行，支持中英双语，并通过现有的 frame 消息跟随宿主的主题、语言和位置。
- 应用的页面是组织会话的一张列表，用的是侧栏自己的会话行：
  - **分组：** 等你、进行中、已完成。一件活本身或它下面任何一个子会话有操作等你批准，这件活就排进「等你」。
  - **子会话：** 成员委派出去的会话缩进在它的任务下面。
  - **点开一件活** 会通过 `penguin:navigate` 在 Web App 里打开那个会话。每件演示任务都对应画廊 mock 数据里已有的会话，所以批准是在真实的对话页上完成的。
  - **行菜单** 可以复制会话 ID，也可以停止一件运行中的活，连同它的子会话。
  - **新任务** 打开 Web App 的新建对话。
- **新建组织** 从目标或模板开始，模板写明成员，以及他们什么时候自己开会话。
- 画廊新增两个界面 `company` 和 `company-new`，在嵌入的 Web App 里打开这个应用。
- 官网的 `/company` 页面（静态构建中为 `/company/`）有四个部分：
  - 实时画廊窗口，标为设计草案。
  - 区分多 Agent 产品的四个问题。
  - 应用用到的平台接口。
  - 取舍：保留、改变、以后再做、不做。
