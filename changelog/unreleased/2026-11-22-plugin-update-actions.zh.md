# 从 Agent 设置和插件市场更新已装插件

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1702](https://github.com/Prism-Shadow/penguin-harness/pull/1702)

[English](2026-11-22-plugin-update-actions.md)

管理员可以在插件市场或 Agent 设置的已装插件上更新本机插件库中的下载包。确认框列出已装版本和目标版本，下载时显示进度，完成后两处刷新可更新的 Agent 副本。即使落后的是当前选中 Agent 以外的在线 Agent，市场卡片也会显示「更新」。
