# Agent 的插件标签页拆为四个子页面：插件、技能、钩子与工作台

- **Date:** 2026-11-12
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#1549](https://github.com/Prism-Shadow/penguin-harness/pull/1549)

[English](2026-11-12-agent-settings-plugin-subpages.md)

Agent 设置页的插件标签页拆为四个子页面，用标签条下方的分段选择切换，同一行右端是当前子页面的操作。每个子页面都是 `?tab=` 的一个取值：`plugins`（缺省）、`skills`、`hooks` 与 `workbenches`，被它取代的旧标签页地址因此打开对应的子页面。四个子页面共用一次对该 Agent 清单的读取。

## 细节

- **插件**以插件市场的卡片列出这个 Agent 的插件，分**已安装**（Agent 带有其任一部件的插件）与**可安装**（Agent 一个部件都没有、且带 Skill、钩子包、MCP Server 或工作台的库内插件）两组，页头是搜索框与**打开插件市场**。任何成员都能在卡片上安装和更新，Project 所有者能卸载；stdio Server 的命令、更新将改写的部件和卸载将删除的部件都先确认，同插件市场。机器上的 Agent 从那台机器的插件库安装，机器版本早于卸载接口时提示先更新机器。
- 插件详情即插件市场的详情弹窗：头部是该 Agent 上的状态，不显示「N 个 Agent 在用」，README 与文件取自 Agent 所在的服务端，另有**在这个 Agent 上**一节按类别列出部件，插件库有而 Agent 没有的部件标**缺失**；每类通往各自的子页面（MCP Server 通往工具标签页）。详情有自己的地址 `?tab=plugins&plugin=<插件名>`。
- **技能**、**钩子**与**工作台**各有自己的开关、本类全部部件的一张列表，以及取代原「导入」菜单的导入按钮；技能子页面保留技能提示词。插件安装的部件在名称后带拼图标记，写明来源插件并可打开其详情；移除这样的部件时，确认文案写明它由哪个插件安装。
- 钩子包行改用共享列表行，与 Skill 行形制一致。
- 智能体页上 Skill、钩子包与工作台的计数打开对应子页面，应用中心的**在 Agent 设置中查看**打开工作台子页面。
- 这里读到的应答交给插件市场的缓存，那个页面因此无需重新询问就能显示在这里做的安装。
- 文档改写为四个子页面，并写明每个开关所在的子页面。
