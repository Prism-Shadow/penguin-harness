# 列表页统一以卡片进入详情，机器管理页改为卡片列表

- **Date:** 2026-10-09
- **Type:** feature
- **Scope:** `web`, `ui`
- **PR:** [#1010](https://github.com/Prism-Shadow/penguin-harness/pull/1010)

[English](2026-10-09-page-rules-machines.md)

菜单里的各个列表页现在遵守同一条规则：点击卡片即进入该条目的详情——Agent 设置与 Benchmark 是整页，模型、插件与机器是弹窗。卡片主体任意处点击即进入，键盘经卡片标题（链接或按钮）进入，卡片本身不充当控件。机器管理页按智能体列表的样式重做为卡片列表，卡片上没有的内容都在机器详情弹窗里。

## 智能体、模型库与评估中心

- Agent 的名称现在是进入其设置页的链接，点击卡片主体任意处同样进入。卡片上的其他控件（新建对话、设置、各项统计、成本、删除、更新胶囊）各自生效，不会同时进入设置页。只存在于某台机器上的 Agent 在本服务端没有设置页：名称是纯文本，卡片不可进入。
- 点击模型卡片的任意位置打开其配置弹窗，点击已发布 Benchmark 的卡片进入其页面；警示条自己的按钮与遮罩卡片上的删除按钮仍各自生效。

## 机器管理

- 页面与智能体页同宽，每台机器一张卡片，本服务端在首。卡片标题行是别名（悬停显示机器 ID）、以单个标记表示的状态（状态词与原因在悬停提示里）和已装版本，机器装着与本服务端不同的版本时另有「需要更新」胶囊；其下是服务端根目录，以及连接方式、对端服务的端口和上次检查时间。只有该机器有排队或进行中的任务时，中段才显示流水线步骤条。
- 状态标记是取状态色调的圆点；任务失败显示危险色的叉，连不上的机器显示 attention 色调的警示图形。
- 卡片只有一个主动词——「启用」，装着另一版本时换成「更新」——和配置 ssh 主机的齿轮；「停用」在弹窗里。本服务端的卡片没有操作。点击卡片主体打开机器详情弹窗。
- 机器详情弹窗与模型弹窗同宽，顶部是一段头部：服务器图块、以单个状态胶囊表示的状态（取状态色调的图形加一个通俗的状态词，原因——失败的原话、ssh 的诊断——悬停图形显示）、已装版本，以及一行说明这台机器经什么方式连接。「基本信息」逐项列出事实，每个标签前带图形、名称通俗：连接方式、主机地址、数据目录、远端服务（连不上时其下以淡色写出 ssh 的原话）、上次检查（「4 分钟前 · 10-10 18:54」：相对时间之后以淡色附上具体时间）、已安装版本及是否最新、安装时间，末行是淡色的机器 ID 与复制按钮。「处理进度」把排队中、进行中或失败的任务列成六个步骤，逐步标出已完成、进行中、失败或未开始；顺利完成的任务只留一行，日志收在「查看日志」里，任务进行时默认展开。任务失败时写明停在哪一步、附对端原话，「重试」（失败允许时另有「强制安装」）就在其下。「操作」先给出这台机器该做的那一件事——「更新」「启动服务」「连接」或「重试连接」——旁边写明它做什么，然后是以细线小标题分开的「维护」（安装程序、重新连接、重启服务、配置 ssh）与「退出」（停用、断开、移出 Project）两组，每个操作占一行、按钮旁写明它做什么；该做的事已是「连接」或「重试连接」时不再另列「重新连接」。暂时不能执行的操作留在原位并置灰，那一行改为写明原因：有任务在进行、没有可安装的版本、当前没有连接、连不上这台机器。弹窗要说的都直接写出，悬停只留给状态胶囊的图形。停用、断开、移出 Project 与强制安装都会先确认。
- 状态词更通俗，卡片标记与弹窗状态胶囊一致：英文界面里服务在运行、但没有连接的机器显示 **Not connected**（原为 Offline）；「运行中」「有新版本」「已连接，服务未运行」取代「服务中」「待更新」「已连接，未在提供服务」（英文 Running、Update available、Not running、Connected, not running、Not checked 取代 Serving、Behind、Stopped、Connected, not serving、Unchecked）。已装到本服务端所能推进的程度为止的机器改用 muted 色调而非 attention：没有什么在等人处理。
- 「全部更新（n）」移到标题下，改为各页面批量更新共用的提示区：「n 台机器待更新」、「现在升级」（确认同前）与「忽略」——忽略在本次浏览内有效，直到又有机器落后或本服务端版本变化。
- 选择栏及其批量启用、停用已移除；每个操作都在对应机器的卡片或弹窗上。

## 更新胶囊

- 「需要更新」胶囊（包括智能体卡片上的内核更新胶囊）由危险色改为 attention 色调：落后不是失败，红色只留给失败与破坏性操作。
