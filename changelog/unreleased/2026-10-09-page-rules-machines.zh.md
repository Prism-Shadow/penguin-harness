# 列表页统一以卡片进入详情，机器管理页改为卡片列表

- **Date:** 2026-10-09
- **Type:** feature
- **Scope:** `web`, `ui`
- **PR:** [#1010](https://github.com/Prism-Shadow/penguin-harness/pull/1010)

[English](2026-10-09-page-rules-machines.md)

菜单里的各个列表页现在遵守同一条规则：点击卡片即进入该条目的详情——Agent 设置与 Benchmark 是整页，模型、插件与机器是弹窗。卡片主体任意处点击即进入，键盘经卡片标题（链接或按钮）进入，卡片本身不充当控件。机器管理页按智能体列表的样式重做为卡片列表，卡片上没有的内容都在机器详情弹窗里。

## 智能体、模型库与评估中心

- Agent 的名称现在是进入其设置页的链接，点击卡片主体任意处同样进入。卡片上的其他控件（新建对话、设置、各项统计、成本、删除、更新胶囊）各自生效，不会同时进入设置页。只存在于某台机器上的 Agent 在本服务端没有设置页：名称是纯文本，卡片不可进入。
- 点击模型卡片的任意位置打开其配置弹窗，点击已发布 Benchmark 的卡片进入其页面；警示条自己的按钮与遮罩卡片上的删除按钮仍各自生效。

## 机器管理

- 页面与智能体页同宽，每台机器一张卡片，本服务端在首。卡片标题行是别名（悬停显示机器 ID）、以单个标记表示的状态（状态词与原因在悬停提示里）和已装版本，机器装着与本服务端不同的版本时另有「需要更新」胶囊；其下是服务端根目录，以及连接方式、对端服务的端口和上次检查时间。只有该机器有排队或进行中的任务时，中段才显示流水线步骤条。
- 状态标记是取状态色调的圆点；任务失败显示危险色的叉，连不上的机器显示 attention 色调的警示图形。
- 卡片只有一个主动词——「启用」，装着另一版本时换成「更新」——和配置 ssh 主机的齿轮；「停用」在弹窗里。本服务端的卡片没有操作。点击卡片主体打开机器详情弹窗。
- 机器详情弹窗分三节：「连接」（ssh 别名及其指向的主机、服务端根目录、状态、对端服务、上次检查、已装版本，末行是淡色的机器 ID 与复制按钮）、「任务」（当前或最近一次任务的步骤条与输出，附「重试」，失败允许时另有「强制安装」）、「操作」（启用或更新、停用，然后是服务端原本就逐步提供的单步操作——「安装」「连接」「重启」「断开」「移出 Project」，悬停说明各自的作用——以及配置 ssh 主机）。停用、断开、移出 Project 与强制安装都会先确认。
- 「全部更新（n）」移到标题下，改为各页面批量更新共用的提示区：「n 台机器待更新」、「现在升级」（确认同前）与「忽略」——忽略在本次浏览内有效，直到又有机器落后或本服务端版本变化。
- 选择栏及其批量启用、停用已移除；每个操作都在对应机器的卡片或弹窗上。

## 更新胶囊

- 「需要更新」胶囊（包括智能体卡片上的内核更新胶囊）由危险色改为 attention 色调：落后不是失败，红色只留给失败与破坏性操作。
