# 选择哪些工作台显示在聊天标签页

- **Date:** 2026-11-19
- **Type:** feat
- **Scope:** `server`, `web`
- **PR:** [#1624](https://github.com/Prism-Shadow/penguin-harness/pull/1624)

[English](2026-11-19-workbench-chat-tabs.md)

在 Agent 设置的「插件 → 工作台」里，常从应用中心使用的工作台可以关闭「在聊天标签页显示」。聊天页会跳过这个工作台的源码和页面，应用中心和全屏入口仍可打开它。每个 Agent 分别保存选择，重启和升级工作台后仍然有效。已有工作台默认继续显示在聊天标签页。
