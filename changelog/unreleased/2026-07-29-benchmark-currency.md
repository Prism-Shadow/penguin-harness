# Web App: Benchmark costs follow the selected display currency

Benchmark cost trends, evaluations, cases, and individual runs now use the display currency selected in settings.

## Consistent cost formatting

Benchmark cost values previously fell back to USD because the page did not pass the selected currency to the shared money formatter. The trend chart axis and tooltip, evaluation totals, case totals, and individual run costs now all follow the same USD or CNY preference as the model library, Cost center, chat, and Trace views; score and duration formatting are unchanged.
