# Build your first checklist in chat

- **Date:** 2026-11-24
- **Type:** feature
- **Scope:** `web`, `desktop`, `first-workbench-guide`
- **PR:** [#1825](https://github.com/Prism-Shadow/penguin-harness/pull/1825)

[中文版](2026-11-24-first-workbench-onboarding.zh.md)

When you first open a conversation on an agent with the guide installed, the guide highlights the next control. In a new chat the prompt appears above the message box. Once the conversation starts, the guide follows the latest reply and scrolls with the conversation. Select the guide title to fold or expand its instructions. Connect a model if needed, send your task, then use the reply to generate and install a checklist on that agent. Open the checklist to test it with a temporary item.

You can dismiss the guide at any point and resume from **Settings → General**. The public product demo skips onboarding.
