# 模型设置的字段按自身单位的实际宽度留位

- **Date:** 2026-09-11
- **Type:** fix
- **Scope:** `web`
- **PR:** [#683](https://github.com/Prism-Shadow/penguin-harness/pull/683)

[English](2026-09-11-price-unit-overlap.md)

模型设置对话框中有五个输入框在自身框内绘制单位，此前都用固定内边距为其留位。现在每处留位都按该单位实际
渲染出的宽度实时测量得出，无论解析到的字体、界面字号与所选货币把单位撑成多宽，数值与它之间都保持相同
间距。

## 细节

- 三个价格字段左端是货币符号、右端是 `/M tok`。右侧留位比该单位在默认界面字体下占用的宽度窄 1.2px，
  于是在任意字号、两种货币与两种界面语言下，数值都会与 `/M tok` 相撞。
- 上下文窗口与最大输出长度两个字段带 `Token` 单位，其固定留位比该单位实际占用的宽度宽 5.8–7.3px。二者
  现在与价格字段留出同样的实测间距。
- 最大输出长度的占位文字在英文下宽于其半宽单元格，而输入框按 padding box 而非数值区域裁剪，于是占位文字
  一路顶到单位处，显示为 `Empty = inherit agent set Token`。该行两个字段现在都会把过长的占位文字以省略号
  收尾，完整文案仍保留在字段的悬停提示中。
