# Web App: dismissible password banner, /model hint, agent list and tab order polish

Four UI fixes from one review pass (#252, #253, #254, #255):

- **Dismissible initial-password banner (#254).** The top banner urging a change away from the seeded password gains a close X at its right edge — a flat glyph with no background fill, hover darkening only, matching the "Change now" link's colors. Dismissal is permanent per user: it is stored server-side in `ui_prefs` (`initialPasswordBannerDismissed`), so it holds across devices and browsers. The banner renders only after the preference is hydrated — a dismissed banner never flashes — and fails open to visible when the preference request errors.
- **Locked-model chip hint and cursor (#252).** After a session locks its model, clicking the read-only model chip now toasts just 输入 /model 切换模型 / "Type /model to switch models" instead of the long parenthetical about new-session continuation, and the chip's hover cursor changes from the question-mark `cursor-help` to `cursor-pointer` — it is a clickable button, and this was the codebase's only `cursor-help`.
- **Agent list settings button (#253).** The per-agent Settings button rendered a hand-rolled gear path that had drifted from the sidebar's canonical lucide gear and looked muddy at 13px, with an icon color one shade dimmer than its own label. The canonical gear now lives in the shared icon module, the sidebar imports it from there, and the button's icon inherits the label color like its New Chat neighbor.
- **Agent detail tab order and stat row (#255).** The detail tabs settle into the canonical order Overview, System Prompt, Runtime, Tools, Skills, Memory, Vault, Schedules (Memory moves from third place; the zh tab label Prompt becomes 系统提示词, en "System Prompt"), and the agent list's clickable stat icons mirror the same order between the session count and the updated-at time. The stat row also drops its per-item `min-w` reservation — short counts no longer leave lopsided holes — with the uniform flex gap widened from `gap-x-2.5` to `gap-x-4` so the row keeps breathing room.
