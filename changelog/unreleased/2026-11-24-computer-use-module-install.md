# Enable the Computer Use server module from its market card

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** `web`, `computer-use`
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1807

[中文版](2026-11-24-computer-use-module-install.zh.md)

Administrators can enable the bundled Computer Use module for the current Project from the plugin’s install flow, including when its Skill is already installed on an Agent. The card reports the module’s live state. The driver download reports when Computer Use is switched off on the machine.
