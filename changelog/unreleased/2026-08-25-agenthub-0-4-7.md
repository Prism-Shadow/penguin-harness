# AgentHub 0.4.7: Gemini function responses ride in their own contents

- **Date:** 2026-08-25
- **Type:** fix
- **Scope:** `core`

[中文版](2026-08-25-agenthub-0-4-7.zh.md)

`@prismshadow/agenthub` moves to 0.4.7. The Gemini client there splits a message that mixes tool results with other content into consecutive same-role contents, fixing the Vertex AI 400 `Requests ending with a model turn are not supported.` that hit every request whose trailing user message carried a tool result together with text — an interrupted turn's carry-over resent with the next prompt, or tool outputs folded into a mid-task compaction request. A session that ran into it kept failing identically on every retry and resend until the context was discarded; with the split, those same requests go through, and the pnpm release-age exemption rolls forward to the new version.
