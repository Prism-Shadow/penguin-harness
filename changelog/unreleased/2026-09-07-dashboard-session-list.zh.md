# 看板的计数可以展开成它所计的会话

- **Date:** 2026-09-07
- **Type:** fix
- **Scope:** `web`, `server`

[English](2026-09-07-dashboard-session-list.md)

看板的**待审核**计数此前把子智能体会话也算了进去，而侧栏把这类会话收在默认折叠的文件夹里——于是把看得见的会话全部打开，计数也降不下来。现在两个计数都不再包含子智能体会话：它们属于派生它们的那个对话，那才是人会打开的那一行。计数为零时不再显示，行内与页头皆然。

## 细节

- 点一行的计数，会展开它背后的会话，每个会话一行：侧栏的状态标记、截断到一行的标题、会话 id 的短尾。点某一行即打开该对话、标记为已读、并把它的 Agent 设为当前——在另一台机器上的会话亦然。
- `GET /api/projects/:projectId/sessions/overview` 现在带上每个会话的 Agent、已生成的标题、以及来源（`schedule` / `subagent`），与侧栏文件夹据以分类的来源一致。
