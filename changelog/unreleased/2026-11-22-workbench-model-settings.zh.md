# 工作台可以打开模型库

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `server`, `ui`, `web`
- **PR:** [#1693](https://github.com/Prism-Shadow/penguin-harness/pull/1693)

[English](2026-11-22-workbench-model-settings.md)

工作台可以打开所属 Project 的模型库来配置提供方，并沿用现有的模型选择器。连接机器上的工作台会提示用户在该机器上配置模型。

如果默认智能体已经安装「我的第一个工作台」，项目所有者可以直接从首次连接供应商的弹窗进入引导。
