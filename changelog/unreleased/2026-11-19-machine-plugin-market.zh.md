# 插件市场列出 Project 各台机器上的插件

- **Date:** 2026-11-19
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1618](https://github.com/Prism-Shadow/penguin-harness/pull/1618)

[English](2026-11-19-machine-plugin-market.md)

管理员打开插件市场时，页面经本服务端的代理逐台读取 Project 各台机器的插件库、插件注册表索引与它运行的服务端模块。机器下拉增加「所有机器」并作为缺省：先列本服务端的卡片，再列各台机器上与本服务端不同的卡片，卡片注明所在机器。

## 细节

- 在机器的卡片上安装或移除服务端模块，记入本服务端 Project 的插件表（`[plugins.<machineId>]`），再由机器同步下发到那台机器，由它从自己的来源下载插件包。Project 只为某台机器列出的模块，可以在那台机器的卡片上移除，不再显示为「所有机器共用」。
- 在机器的卡片上安装插件库中的插件，装到那台机器上的 Agent；快速调用也在它上面打开草稿。
- 每台机器的应答按标签页保存，不含路径与 MCP 配置。机器不可达时保留它的卡片，标题下方的提示写明是哪台机器，读取失败时附「重试」。它的 Agent 安装要等机器重新连接，服务端模块的安装与移除不必等。
- 详情链接所指的机器已没有该插件时，打开本服务端的卡片。
- 机器的卡片在共享封面卡片标题下方的 `origin` 一行写出机器名（这一行本身属于[陈列模块](2026-11-17-market-showcase-ui.zh.md)）。

本改动的应用中心部分单独发布，见[应用中心跨机器](2026-11-19-app-center-machines.zh.md)。
