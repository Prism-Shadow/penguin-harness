# 共享 UI 包新增模拟数据集与四个整页示意，供组件画廊使用

- **Date:** 2026-09-16
- **Type:** feature
- **Scope:** `ui`
- **PR:** [#763](https://github.com/Prism-Shadow/penguin-harness/pull/763)

[English](2026-09-16-theme-fixtures-screens.md)

`@prismshadow/penguin-ui` 新增 `fixtures/` 与 `screens/`：前者是一套中英双语的类型化模拟数据，后者是四个静态
整页组合，由主题画廊在 `/screens/:name` 渲染。Web App 不引用其中任何一个，应用外观与此前完全一致。

## 模拟数据

- 取自落地页截图所用的「构建 Claude Code 文档专家」会话，扩展为两轮运行：用户与助手轮次，已完成和流式输出中的
  思考与正文，以及工具调用——带输出的 `exec_command`、`read_file`、带 diff 的 `edit_file` 与 `write_file`、
  附带子会话记录的 `run_subagent`，还有一条等待审批的命令。
- 同一次运行的 Trace（文件列表、全局统计、每轮执行时间线与事件行）、取自内置模型目录的十个模型、Workspace
  文件树与文件预览、侧栏会话分组，以及一家公司：员工、覆盖全部列的工单和一周的日历事件。
- 界面文案取自 Web App 的两本词典；为字体页与排版基础页准备了混排中文、拉丁字母、代码与数字的字样文本。
- 画廊各模块所需的数据集：每种色调一条通知与两条浮条、一份含一个非法字段和一个被服务器策略锁定字段的提供方
  表单、一份带快捷键与一个危险项的消息右键菜单、六行密钥库记录、四个已安装插件、命令面板的两个分组，以及
  一周分三档的 Token 用量。其中的颜色、版本号、图标、快捷键与数值序列与语言无关，放在 `fixtures/shared.ts`；
  按语言区分的只有文字。
- `en` 与 `zh` 由同一份结构（`fixtures/dataset.ts`）生成，只有文字不同；`fixturesFor(lang)` 返回对应语言。

## 整页示意

- `chat`：运行中的 Task，含侧栏、展开的 diff、运行中的子智能体、待审批命令、带附件标签的输入框，以及正在流式输出
  子会话回复的子智能体停靠面板。
- `traces`：轨迹观测停靠面板，含全局统计、单轮执行时间线、图例与事件行。
- `settings`：对话之上的分页设置对话框，停在「外观」页，并展开一个说明浮层。
- `login`：装饰画布上的登录卡片。
- 示意只使用令牌工具类与已声明的样式钩子，各主题通过自身令牌取值改变其外观；组件逐波迁入共享包后，替换其中的占位部件。
- 包以 `@prismshadow/penguin-ui/screens` 导出（`SCREENS`、`screenById`）。

## 去 AI 味

整页示意改为遵守主题工作的组件规则，画廊所展示的因此是规则要求的样子，而不是当初草稿的样子。

- 被删除的样式钩子从标记中移除：对话、设置页与 Trace 面板背后不再有氛围渐变与栅格，登录页背后不再有点阵
  （电路走线保留——它是登录页在三个主题中唯一的装饰），审批块不再有角标，按钮与卡片不再在悬停时改变圆角，
  按钮标签也不再是等宽大写。控件改为从 `--ui-radius-control` 取形状。
- 保留的每个钩子都落在承载它的组件上：设置对话框的玻璃属于 `Modal`，其说明浮层的玻璃属于 `FloatingPanel`，
  输入框的玻璃属于 `ComposerCard`，导航栏分组标题是 `PagedDialog` 的 eyebrow，侧栏与调用关系的分组标题是
  `GroupHeader`，diff 是 `DiffViewer`，代码块是 `CodeBlock`。对话框的页面标题改为普通 `h2`——display
  字面留给一个页面唯一的展示标题——并去掉了导航栏已经显示过的太阳图标。
- 状态重新成为一个词：运行状态以说明文字字号、句首大写、按色调着墨呈现（`运行中`、`待审批`、`失败`），五个
  词在两本词典中都有，而不再是 10–11 px 的大写加宽字距。整页示意中不再有小于 `.75rem` 的文字。
- 待审批块保留琥珀色底，但其上方改用中性分隔线，工具短名改为等宽文本而非标签；子会话快捷入口从工作组内部
  的带框卡片改为其调用下方的一行；Trace 的全局统计改为带横线的分节，执行时间线直接放在该轮正文里，两者都
  不再自带盒子；输入框的停止按钮是一个实心控件，而不是浅色危险底上的危险色图标。
- `Pill`、`IconSquare` 与手写的环形转圈替换为 W1 组件形状的占位件，将来替换只是改名：`Badge`（`tone`、
  `variant`，`soft` 取中性边线）、`IconButton`（静止时无底色，仅 `pressed` 时填充，label 必填）与
  `Spinner`（`xs` / `sm` / `md` 对应 10 / 12 / 14，含 `tone` 与 `label`）。其中转圈是真组件：它位于
  `src/components/icons/spinner/spinner.tsx`——唯一允许旋转的文件——绘制一段圆弧，主题通过
  `.ui-live[data-live="spinner"]` 重新设定其节奏。
- 主题色色块的十六进制取值移入模拟数据（身份数据本就该放在那里），每个色块在两本词典中都有了名字。
