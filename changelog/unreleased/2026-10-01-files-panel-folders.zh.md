# 文件浏览面板：新建文件夹与文本文件、文件夹重命名、代码编辑器式的编辑，以及新建对话页上的面板

- **Date:** 2026-10-01
- **Type:** feature
- **Scope:** `web`, `ui`, `server`, `docs`
- **PR:** [#938](https://github.com/Prism-Shadow/penguin-harness/pull/938)

[English](2026-10-01-files-panel-folders.md)

文件浏览面板新增**新建文本文件**和**新建文件夹**，文件夹可以重命名和移动，编辑器像代码编辑器一样停在原处；新建对话页上可以为选定的文件夹打开面板，侧栏 Workspace 分组新增的**打开文件浏览**也会走到这里。

## 新建文件与文件夹

- 目录树顶栏的**新建**菜单建在当前目录，文件夹的右键菜单建在该文件夹内，目录树下方的空白处建在 Workspace 根目录。
- 随后弹出名称框。文本文件的名称默认是 `untitled.txt` 并选中 `untitled`，名称里的 `/` 会同时建出中间的文件夹；按 Enter 即创建。
- 新建的文件夹在目录树中展开并成为当前目录。新建的文本文件是空文件，建好后在编辑器中打开；编辑器里有未保存的修改时则只建不开。
- 名称已被占用时拒绝，不写入任何内容，对话框停在该名称上。服务端 `POST files/create` 返回 409 `target_exists`，且不跟随该路径上的符号链接。

## 文件夹重命名

- 文件夹与文件共用**重命名 / 移动**对话框，整棵移动；目标已存在、或要移入文件夹自身之下时拒绝。
- 文件夹没有版本标记，因此不带前置条件移动。`POST files/move` 接受文件夹，对带 `ifVersion` 的文件夹返回 400。
- 展开的文件夹、当前目录和打开中的文件都跟到新路径。文件的重命名同样跟过去，预览不再停在旧路径上等待。

## 代码编辑器式的编辑

- **编辑**打开的编辑器停在预览滚动到的位置，光标位于可见区第一行行首。
- 保存后编辑器仍然打开，光标、选区和滚动位置都不动。`PUT files/content` 在 `ETag` 里带回写入后的版本，下一次保存带着它。
- 一轮对话结束后，若打开的文件已被改写而编辑器里没有未保存的修改，编辑器直接换成新内容，保留光标所在行与滚动位置。有未保存的修改时保留文本，标出**磁盘上已变更**，保存时照旧先询问。
- **退出编辑**（×，原为**取消**）回到预览，预览停在编辑器滚动到的位置。

## 没有 Session 时的文件浏览面板

- 新建对话页工作区胶囊右侧的**文件浏览**开关，为胶囊里选定的文件夹打开停靠栏的文件浏览面板；改选文件夹即换根。**添加到对话**会加到新对话的输入框里。临时工作区下开关不可用，悬停提示说明原因。
- 侧栏 Workspace 分组的 **…** 菜单为每个指向单一文件夹的分组提供**打开文件浏览**。当前页面已在该文件夹上时在原处打开面板，否则打开该文件夹的新建对话页并打开面板。
- 面板经 `/api/projects/:projectId/workspace-files` 按路径寻址这样的文件夹：操作与 Session 的文件路由相同，授权落在 Project 访问权上。其中的 HTML 以同源沙箱预览。

## 复制

- 文档写明**复制相对路径**把相对 Workspace 的路径写入浏览器所在电脑的剪贴板，经明文 HTTP 访问时同样如此。明文 HTTP 下的回退由 [#523](https://github.com/Prism-Shadow/penguin-harness/pull/523) 实现，现在有一个浏览器测试（`files-folders.spec.mjs`）覆盖它。
