# 应用中心的窗口可以最小化，应用继续运行

- **Date:** 2026-11-19
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`
- **PR:** [#1640](https://github.com/Prism-Shadow/penguin-harness/pull/1640)

[English](2026-11-19-app-window-minimize.md)

从应用中心打开的应用现在可以最小化，如同 Windows 的窗口或 Chrome 里留着的标签页：标题栏在「全屏打开」「关闭」左边新增「最小化」按钮。最小化回到网格，应用继续运行，点击其图块恢复同一个窗口。关闭仍会结束应用。

## 细节

- 最小化的应用 iframe 不卸载，只是不绘制、不可达，页面状态、计时器、声音与连接都保留。关闭才卸载它，再次打开即新开一个 iframe。
- 在窗口里按浏览器后退改为最小化，不再关闭。
- 运行中的应用在图块图标下方带一道短横，名称与悬停提示写明「运行中」；分组里有运行中的应用时，分组图块同样带短横并写明个数。点击运行中应用的图块，或在其菜单中选「打开」，都恢复它的窗口，构建中也可以。
- 可同时有多个运行中的应用。离开应用中心去其他页面时它们照常运行，回来仍在。切换 Project 结束上一个 Project 的应用，从应用中心列表消失的应用随之结束，离开应用外壳（全屏打开、刷新、退出登录）结束全部应用。
- 窗口从应用中心页移到页面区域上的常驻层：`WebAppModule.layers` 的贡献可带 `area: "page"`，挂在主栏内、页面之后，因此盖住页面，换路由也不卸载。
- 运行中的应用集合放在 `lib/running-apps.ts`，供任何界面读取：`useRunningApps()` 列出当前 Project 运行中的应用（键、Agent、Workbench、机器、标题、图标，以及窗口是否在前），`useRestoreApp()` 以其 `?app=` 地址把它恢复到主区域，此后最小化回到恢复前所在的页面。
- 共享 UI 包新增应用窗口的标题栏 `AppWindowBar`：应用图标与名称，行尾依次是最小化、全屏与关闭，除关闭外都可省略。组件画廊的「布局」板展示三个按钮齐全与只有关闭两种。
