# 首页 Agent 自动进化演示

- **Date:** 2026-10-28
- **Type:** feature
- **Scope:** `landing`, `ui-gallery`, `ui`
- **PR:** [#1375](https://github.com/Prism-Shadow/penguin-harness/pull/1375)

[English](2026-10-28-hero-evolution-walkthrough.md)

首页第一个实机演示进入可见区域后，自动输入并发送 Agent 优化请求。对话通过 Web App 现有界面展示了评估、规则修改、并行复测，以及从 81 到 88.5 的分数提升，随后打开评估中心，展示这套评估集的分数曲线。演示节奏缩短了约四分之一。

窗口栏在“在画廊中打开”旁增加了暂停和播放按钮。暂停时停止输入、流式步骤和自动跳转，播放时从原处继续，并保留剩余等待时间。按钮与 AMSP 播放器共用同一控件，仅在自动演示期间显示。

演示在用户操作时交还控制，保持外层页面的焦点和滚动位置，并在用户要求减少动态效果时保持静止。其他实机演示保留了原有行为。
