# The Plugins page's settings button is labelled "Settings"

- **Date:** 2026-09-29
- **Type:** fix
- **Scope:** `web`

[中文版](2026-09-29-plugins-header-settings-label.zh.md)

The gear button in the Plugins page header (admin only) is now labelled, in its text, tooltip and accessible name, "Settings" (in Chinese, "设置") instead of "Plugin settings". It opens the Settings dialog, whose name is "Settings"; the label now says so.
