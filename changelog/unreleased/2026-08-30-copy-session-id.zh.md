# 从 Session 行的菜单复制它的 id

- **Date:** 2026-08-30
- **Type:** feature
- **Scope:** `web`

[English](2026-08-30-copy-session-id.md)

Session 的 id 此前只能从对话头部的详情卡片取得。现在它也是 Session 行自身的一个动作,与置顶、重命名、归档、删除同处一个菜单——点行上的省略号按钮或右键该行即可打开。

## 细节

- 该动作沿用详情卡片的标签与图标,同一个值在任何地方都是同一个标记。
- 它紧挨重命名——两者都关乎"这是哪个 Session",而非"对它做什么";归档、子 Agent、定时这些文件夹行同样提供该动作,那正是需要 id 的场合。
- 悬停时的直接动作不变:只有归档,以及打开菜单的省略号。
- 复制以 toast 确认,而不是惯常的按钮上打勾——在菜单行上执行动作会关掉承载该按钮的面板。
