# 桌面外壳按预算重载崩溃的页面

- **Date:** 2026-08-23
- **Type:** fix
- **Scope:** `desktop`
- **PR:** [#412](https://github.com/Prism-Shadow/penguin-harness/pull/412)

[English](2026-08-23-desktop-renderer-reload-budget.md)

渲染进程消失会留下一个空窗口，外壳因此会重载页面。此前这个重载既无条件也无上限：一个每次加载
都崩溃的页面会全速无限重载，而窗口正在拆除时上报的崩溃则会去重载一个已销毁的 `webContents`。
现在重载会跳过正常退出和正在进行的退出，并且只有三次机会，用完后崩溃的页面就留在原地，由
View 菜单里的 Reload 作为回到正常状态的入口。

## 细节

- 页面成功加载并稳定一分钟后预算重置——和内嵌服务器的重启预算同一形状，因此几天后才发生的崩溃
  是从满额开始，而不是从已耗尽的计数开始。
- `clean-exit` 被排除在外：这个原因表示渲染进程是有意退出的。
- 每次尝试以及预算耗尽都会打印一行带原因的 `[shell]` 日志。
