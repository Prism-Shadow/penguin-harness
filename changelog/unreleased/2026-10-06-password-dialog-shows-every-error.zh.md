# 修改密码对话框把每一次保存失败都显示出来

- **Date:** 2026-10-06
- **Type:** fix
- **Scope:** `web`

[English](2026-10-06-password-dialog-shows-every-error.md)

修改密码对话框里保存失败时，页面可能什么都不显示。除新密码强度不够以外的错误都被放在旧密码输入框下，而首次登录的会话和桌面窗口自己的会话不显示这个输入框。

- 不属于任何输入框的失败——请求被拒、网络失败、服务端出错——现在显示在对话框自己的一行里，位于按钮上方。
- 当前密码不对仍显示在旧密码输入框下；该输入框不显示时，显示在对话框的那一行。
- 新密码强度不够仍显示在新密码输入框下。
