# Benchmark cards show the title before the id

- **Date:** 2026-11-03
- **Type:** fix
- **Scope:** `web`, `landing`
- **PR:** [#1424](https://github.com/Prism-Shadow/penguin-harness/pull/1424)

[中文版](2026-11-03-benchmark-card-title-first.zh.md)

On the Evaluation Center's Benchmark cards, which the landing page's live demo also passes through, a long id no longer shortens the title beside it. The title takes the row first; the id gets only the room left over and is cut off with an ellipsis there, and hovering it shows the whole id.
