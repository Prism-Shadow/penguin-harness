# 通过第一次对话制作任务清单

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `plugins`, `server`
- **PR:** [#1695](https://github.com/Prism-Shadow/penguin-harness/pull/1695)

[English](2026-11-22-first-workbench-guide.md)

新建的默认 Agent 预装了「我的第一个工作台」。用户可以在引导中配置和选择模型，与 Agent 商量一项任务，再根据对话生成清单。

用户可以预览清单，将它安装到当前 Agent，测试任务能否保存和勾选，也可以把工作台下载为可复用的插件。
