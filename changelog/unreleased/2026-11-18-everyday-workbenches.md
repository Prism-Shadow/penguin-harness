# Five new games and tools in the App Center

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `plugins`, `server`, `desktop`

[中文版](2026-11-18-everyday-workbenches.zh.md)

The built-in library added five workbenches. Install each one separately on an Agent, then open it from the App Center. Each workbench saves its own data with that Agent and follows the interface language.

## Utilities

- Fridge Keeper tracks ingredient quantities, storage locations and best-before dates.
- Action Minutes keeps decisions and assigned tasks for each meeting and exports the minutes as a text file.

## Entertainment

- Tabletop Desk tracks turn order and rounds, logs dice rolls with modifiers, and keeps scene notes.
- Party Charades runs timed turns for two teams sharing a screen, with a bilingual prompt deck and a scoreboard.
- Daily Draw keeps one prompt per day and a journal of the reader's reflections.
