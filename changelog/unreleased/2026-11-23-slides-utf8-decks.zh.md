# AI PPT 可打开带 UTF-8 字节顺序标记的演示文稿

- **Date:** 2026-11-23
- **Type:** fix
- **Scope:** `use-bento-slides`
- **PR:** [#1719](https://github.com/Prism-Shadow/penguin-harness/pull/1719)

[English](2026-11-23-slides-utf8-decks.md)

Agent 或 Windows 文本编辑器写入的演示文稿即使带有 UTF-8 字节顺序标记，也会在「最近编辑」中显示文稿标题，点开即可在 Bento 编辑器中继续编辑。打开文件时保留原内容和修订。
