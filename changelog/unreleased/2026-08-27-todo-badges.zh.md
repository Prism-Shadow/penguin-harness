# 技能更新、预置模型更新与未预期错误都有了红点，并且可以解除

- **Date:** 2026-08-27
- **Type:** feature
- **Scope:** `web`, `server`
- **PR:** [#510](https://github.com/Prism-Shadow/penguin-harness/pull/510)

[English](2026-08-27-todo-badges.md)

原先只标记软件更新与 Agent 内核更新的手机式红点，现在也标记三件「该处理、但用户也可能合理地选择不处理」的事：**技能库**的技能更新、**模型库**的预置模型更新，以及**成本中心**的未预期错误。每个红点都沿一条不断裂的路径指向真正处理它的控件，并且每个红点都能被放下。

## 三条路径

- **技能库**——侧栏的「技能库」入口与收起态侧栏的技能图标，终点是卡片上的「更新安装」按钮：它会在所有落后的 Agent 上重装库中副本。判定依据是 Agent 列表新增的 `skillUpdates` 字段，因此不额外发一次请求；执行更新会重新拉取该列表，红点随之消失。
- **模型库**——「模型库」入口，终点紧挨着「同步预置」按钮。与该按钮一样仅限 Owner：成员在这条路径尽头没有可操作的控件，因此不会看到红点，其背后的探测请求也根本不会发出。
- **成本中心**——「成本中心」入口，终点是异常面板。只统计 `unexpected`（业务 4xx 是服务端有意拒绝，不算），范围是**该页面打开时默认的最近 7 天**，因此表格里一定有红点所说的那些行。

移动端菜单按钮仍然对全部路径显示同一个红点；当其中混有未预期错误时，措辞由「有可用更新」放宽为「有待处理事项」——错误怎么读都不是一次更新。

## 如何解除

真正去做就会解除：更新技能、同步预置。而对于「看过之后决定不做」的情形——刻意不跟随目录的模型表、已经读过并理解的错误——每个页面的标题下都有一行安静的提示说明在等什么，旁边是**标记为已处理**（成本中心为**标记为已读**）。

解除时保存的不是「已隐藏」，而是被放下的那件事的**签名**：技能名加库中版本、会被改动的模型引用、最新一条错误的时间戳。只有在等待的东西仍然完全是那一份时红点才保持熄灭，因此更高的技能版本、改动了别的模型的目录发布、更新的一条错误，都会让它重新亮起。解除的含义是「这一次先不处理」，而不是「以后都别提」。

标记按 Project 存在 `localStorage`，沿用 `session-seen.ts` 为「API 未建模的已读标记」立下的先例：按浏览器而非按账号，且不跨标签页同步。丢失一个标记的代价只是再解除一次红点。

## 细节

- `lib/todo-badges.ts` 以纯函数写下三条判定与解除规则，并附单元测试：跨 Agent 按技能去重计数、与顺序无关、两个 Agent 落后程度不同时取较高的库版本、来自过旧服务端而没有该字段的 Agent 列表、两个规模相同但内容不同的预置差异、最旧行已被淘汰的错误窗口，以及「同一件事解除后不再亮、更新的一件事会亮」。
- `features/models/catalog-sync.ts` 新增 `catalogDelta`：把同步动作自己的问题问在**已保存**的模型表上，而不是页面的行状态。这样红点与按钮不可能对「是否有事可做」给出不同答案，并有测试把各种表形态同时喂给两者以维持这一点——红点指向一个回答「已是最新」的按钮，正是这里要避免的失败。
- `AgentSummary.skillUpdates` 列出内置库已经超过的已安装技能，并带上可用的版本号。它在原本就要走一遍的那次扫描里算出：对 `SKILL.md` 的存在性检查变成了对同一个几 KB 文件的读取。库中没有的技能——来自 zip 或用户选择的目录——永远不会被列出，因为它们没有可落后的库版本。
- `GET /usage/errors` 新增可选的 `kind`（`unexpected` / `expected`），红点据此只取一行，而不是为了两个数字去拉整份看板聚合。超出该集合的 `kind` 返回 400，而不是一页悄悄为空——那会被读成「没有错误」。
- 两个探测请求按 Project 缓存在模块层，由与更新检查同一个 eager 拥有者在每个浏览器会话中各取一次，并且同样 fail-soft：探测不可达时判定保持关闭，什么也不说。
- Agents 列表上的「内核需要更新」胶囊变淡了。其底色现在以同行的灰色 `Badge` 为标尺——浅色下相对卡片 1.09 : 1、深色下 1.11 : 1，而那枚邻居是 1.10 : 1 与 1.18 : 1——不再比它响亮五分之一。文字颜色未变，浅色 7.67 : 1、深色 9.13 : 1，余量充足。
- 新增六条双语文案：每条路径一句（从红点的 tooltip 一路原样带到页面提示）、放宽后的合并措辞，以及两个解除操作的标签。
