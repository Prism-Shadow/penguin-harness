# Workspace 选择器以带路径的按钮提供临时工作区

- **Date:** 2026-09-30
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#907](https://github.com/Prism-Shadow/penguin-harness/pull/907)

[English](2026-09-30-finder-temp-button.md)

Workspace 选择器的左下角改为一枚按钮「从临时工作区开始」，取代原先带下划线的链接和「留空自动创建临时工作区；指定时必须是服务器上已存在的目录」这句提示。

## 细节

- 凡是选择器允许不选目录的地方（对话草稿、Project 设置 → 默认值、定时任务表单），这枚按钮都在，无论当前是否已选目录；未选目录时按钮带勾选标记。
- 按钮文字后以弱化的小字显示临时工作区将建在的位置 `…/agents/<agent>/workspaces/tmp-…`，完整路径在悬停提示里。路径由 Agent 配置的 `stateDir` 推得。不知道 Agent（默认值里未设置默认 Agent）或正在浏览其他机器时，按钮只显示文字，悬停提示说明规则。
- 这句提示同时从选择器的悬停提示、Project 设置 → 默认值与定时任务表单的 Workspace 字段下移除；公司工作区字段也去掉了自己的那一版。
- 公司工作区选择器的按钮为「使用组织自己的目录」，新建 Agent 弹窗的为「不从目录导入」；侧边栏的新建工作区选择器没有这枚按钮。
- 窄屏下先截断路径、再截断文字，取消与选择保持原宽。
