# Markdown 表格的统一基础样式：横向滚动盒、避免多余换行、斑马纹与悬停

- **Date:** 2026-10-19
- **Type:** feature
- **Scope:** `ui`, `web`, `docs`, `landing`, `ui-gallery`
- **PR:** [#1222](https://github.com/Prism-Shadow/penguin-harness/pull/1222), [#1224](https://github.com/Prism-Shadow/penguin-harness/pull/1224)

[English](2026-10-19-markdown-tables.md)

对话回复、频道气泡、各处 Markdown 阅读器、文档站与博客中的 Markdown 表格改用同一套基础样式，由 UI 包里的同一个渲染 pass 与同一份样式表产出，不再每个站点各写一套规则。表格占满所在正文列，短格、数字与代码不换行，超出列宽时在自己的盒内横向滚动；行间以横线分隔并带斑马纹，指针所在行高亮。

## 细节

- 每张 Markdown 表格放进自己的横向滚动盒，表格元素仍是表格。表宽占满所在正文列，各列按内容分配宽度；比正文列更宽的表格在盒内横向滚动，不再挤压列宽或撑宽页面。
- 单元格按内容分类。正文格全为数字的列（可带千分位、正负号、货币符号、百分号或 `ms`、`KB` 这类短单位）连同表头右对齐并使用等宽数字，列中出现 `-` 或 `n/a` 不影响判定。不超过 36 个显示列的格（CJK 字符计 2）不换行；更长或含换行的格可以换行，但不窄于 20rem（频道气泡内为 15rem），表格需要横向滚动时，长说明也只占两三行，而不是堆成高高的一格。行内代码在格内从不断行。作者用 GFM 冒号指定的对齐始终优先。
- 表头为次级墨色、中等字重，下接主线色的横线；每个正文行以弱线色的横线收尾。不画外框、不画竖线、表头不铺底。
- 偶数行铺一层由文字颜色派生的淡色，有指针的设备上悬停行再深一档。两者都是墨色的半透明叠加，因而在三套主题、亮暗模式、频道气泡内与自定义背景下观感一致，且不改变文字对比度。应用内表格格内的行内代码底色同样取墨色的半透明叠加，在斑马纹行与悬停行上始终比所在行深一档，不会隐没其中。
- 回复仍在流式输出时该 pass 也会运行，表格从第一行起就有滚动盒与列分类，定稿渲染不会改变它们。
- 博客带边框、表头铺底的表格与文档站的全网格表格改为共享样式。
- `NO_REHYPE_PLUGINS` 更名为 `STREAMING_REHYPE_PLUGINS`；新增 `SITE_REHYPE_PLUGINS`，`SiteMarkdown` 把表格 pass 追加在宿主自己的 rehype 插件之后。

## 组件画廊

- 内容看板新增「表格」分组：Markdown 正文中一张八列宽表与一张短的键值表，Markdown 阅读器示例中也有一张表格。
- 对话演示里索引 hooks 文档的回复多了一张宽表，站点看板的文章里也有一张宽表。
