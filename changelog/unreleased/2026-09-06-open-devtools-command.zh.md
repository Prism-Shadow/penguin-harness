# 从命令面板打开开发者工具

- **Date:** 2026-09-06
- **Type:** feature
- **Scope:** `desktop`, `server`, `web`

[English](2026-09-06-open-devtools-command.md)

桌面端的命令面板（Ctrl/Cmd+P）新增「打开开发者工具」一项，与安装 `penguin` 命令、检查更新并列。

View 菜单一直可以切换开发者工具，其快捷键（Ctrl+Shift+I，macOS 为 ⌥⌘I）也照常生效；但 Windows 与 Linux 上菜单栏是隐藏的，于是想看一条控制台报错就只剩一个没人告诉过你的快捷键。放进面板是为了让它可被找到——尤其是在别人请你把报错复制出来的时候。

它以独立窗口而非停靠面板的形式打开：读取报错时页面不会被重新排版；已经打开时再次执行只是把那个窗口聚焦。

该入口只在桌面端出现：打开开发者工具的是宿主进程，走的是其他 shell 动作共用的 `/api/command` 通道，而普通服务端不提供任何宿主命令。在浏览器里，浏览器自带的开发者工具就是答案。
