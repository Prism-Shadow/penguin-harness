# 打开开发者工具：命令面板，以及 F12

- **Date:** 2026-09-06
- **Type:** feature
- **Scope:** `desktop`, `server`, `web`

[English](2026-09-06-open-devtools-command.md)

桌面端的命令面板（Ctrl/Cmd+P）新增「打开开发者工具」一项，与安装 `penguin` 命令、检查更新并列。**F12** 同样能打开，Ctrl+Shift+I 也能。

View 菜单一直带着开发者工具，但 Windows 与 Linux 上菜单栏是隐藏的，想看一条控制台报错就只剩一个没人告诉过你的按键；而菜单自身的快捷键并不可靠——Chromium 会先把按键交给页面，页面消费掉 Ctrl+Shift+I 它就到不了菜单。现在 shell 在 `before-input-event` 上先于页面接住 F12 与 Ctrl+Shift+I，与 F10 唤出菜单栏是同一条路径；命令面板那一项则让同一个动作不靠按键也能找到。

它以独立窗口而非停靠面板的形式打开：读取报错时页面不会被重新排版；已经打开时再次执行只是把那个窗口聚焦。

页面不认识的宿主命令现在会被跳过而不是照读：shell 经安装包抵达用户，页面靠热推送抵达，因此 shell 比它所服务的页面新是常态——而这是第一条把它变成现实的命令，它让一个更旧的页面整页空白。

该入口只在桌面端出现：打开开发者工具的是宿主进程，走的是其他 shell 动作共用的 `/api/command` 通道，而普通服务端不提供任何宿主命令。在浏览器里，浏览器自带的开发者工具就是答案。
