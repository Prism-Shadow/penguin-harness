# CLI prompt for steering a running task

- **Date:** 2026-11-22
- **Type:** fix
- **Scope:** `cli`
- **PR:** [#1699](https://github.com/Prism-Shadow/penguin-harness/pull/1699)

[中文版](2026-11-22-cli-steering-prompt.zh.md)

In `penguin chat`, typing during a running task shows `> Steer` to the left of the draft. If the task finishes before you press Enter, the draft stays at the ordinary `>` prompt.
