# 技能卡片与异常表格不再越出手机宽度的视口

- **Date:** 2026-08-23
- **Type:** fix
- **Scope:** `web`

[English](2026-08-23-phone-width-overflow.md)

Web App 有两处在手机宽度下把自己排得比屏幕更宽，各自都让读者够不到本该看到的东西。现在两处都留在
视口之内。

## 技能库

- 技能卡片的操作按钮——快捷调用、管理安装、更新安装——被带到屏幕右缘之外，又被分组区块裁掉，因此
  一个都点不到。卡片网格现在在 `sm` 断点以下显式声明单列轨道，不再任其隐式生成，卡片也就不会再被
  撑到足以完整容纳其中最长的那条描述。

## 成本中心

- 最近异常表格把消息列压缩到零宽度，并把其余三列推出右缘，连带整个页面横向滚动。表格现在写明四列
  所需的最小宽度，并在自己的盒子内横向滚动，页面本身不再滚动。
