# 右侧停靠栏的浮动入口

- **Date:** 2026-09-02
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#586](https://github.com/Prism-Shadow/penguin-harness/pull/586)

[English](2026-09-02-dock-floating-launcher.md)

对话页新增了 AssistiveTouch 式的右侧停靠栏浮动入口：桌面宽度下右侧停靠栏收起时，一枚半透明圆形按钮浮在对话正文右缘、下方带一行小字，点击即以它为圆心向左展开一段半圆弧，弧上是各停靠面板加终端的入口、每枚都标着自己的名称，选中即在右侧停靠栏打开对应面板——停靠栏一出现，浮动入口随之消失。此前停靠栏的面板只能经工具行上的开关打开，而用户可能根本注意不到那个按钮。

## 细节

- 静止态：44px 的半透明圆形，带毛玻璃与柔和阴影，悬停 / 聚焦前保持低调（键盘用户有可见焦点环），显示工具行同款「右侧栏」图标，球下方在同款玻璃底上印着它的名字——只有一枚图标说不出它开的是什么，可访问名也以这个词开头。它位于对话正文内——工具行与输入区之间——因此连同小字都不会盖住二者。
- 点击、Enter 或 Space 展开圆形入口：`PANEL_KINDS` 中的每种面板经共享的面板元信息生成（日后新增的种类自动出现），外加终端——与停靠栏选单一致，认领无人持有的活动 Shell，否则新建。入口落在以球为圆心、向左展开的半圆弧上——自正上方经正左方到正下方，按角度均分、顺序自上而下——名称常驻显示在图标旁（弧两端改为居上 / 居下），因此可见名称就是按钮的可访问名，无需悬停即可读到。球靠近正文上缘或下缘时，弧收窄为放得下的那一段，入口连同名称始终留在对话内。方向键沿弧自上而下移动焦点、球排在序列之首；Esc（焦点回到圆球）、点击别处或滚动即收起。
- 待审批的琥珀小点随球显示（智能体入口上也有），规则与工具行右侧栏按钮一致，并计入圆球的可访问名。
- 圆球可沿右缘拖动，小位移阈值让短按仍是点击；拖离边缘或拖过正文两端有阻尼，松手弹回。位置是一条全局偏好 `penguin.dock.launcherY`，以对话正文高度的比例存储并容错解析（无效值回落到居中）。
- `prefers-reduced-motion` 下不做弹簧与展开动画：即时显隐。
- 各项决策——是否显示、钳制（含为小字预留的高度）、比例往返与解析、拖动边界、弧的几何与收窄——集中在 `features/dock/dock-launcher-state.ts`，配有单元测试（`test/dock-launcher-state.test.ts`）。Web App 文档与设计文档已补充该入口的说明。
