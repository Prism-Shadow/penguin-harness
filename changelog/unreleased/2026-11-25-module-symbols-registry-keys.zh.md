# 全部模块符号改为注册表键

- **Date:** 2026-11-25
- **Type:** fix
- **Scope:** `core`, `server`, `cli`, `ui`, `plugins`

[English](2026-11-25-module-symbols-registry-keys.md)

一次安装可能把同一个包链接两份——直链与 pnpm 虚拟存储副本——两个模块实例不共享普通 `Symbol()` 的值，任何靠它们承载的身份都会在实例边界处静默失效。其余全部模块符号改为注册表键（`Symbol.for`，`penguin-harness.*` 命名）：固定哨兵用固定键；按实例唯一的身份（转义图层、未保存表单条目、浏览器槽位与工作台分组、单次调用的停止哨兵）用「按模块副本加盐、按调用计数」的键，保持唯一。
