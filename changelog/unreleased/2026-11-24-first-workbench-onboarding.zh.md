# 在对话中制作第一个清单工作台

- **Date:** 2026-11-24
- **Type:** feature
- **Scope:** `web`, `desktop`, `first-workbench-guide`

[English](2026-11-24-first-workbench-onboarding.md)

首次进入已安装引导的 Agent 对话时，下一步要用的控件旁会出现简短提示。按需连接模型后，把你的任务发给 Agent，即可根据回复生成清单并安装到该 Agent。打开清单后，可以用临时条目测试它。

你可以随时收起引导，在**设置 → 通用**中继续。官网产品演示会跳过引导。
