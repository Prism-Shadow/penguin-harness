# 在对话中制作第一个清单工作台

- **Date:** 2026-11-24
- **Type:** feature
- **Scope:** `web`, `desktop`, `first-workbench-guide`
- **PR:** [#1825](https://github.com/Prism-Shadow/penguin-harness/pull/1825)

[English](2026-11-24-first-workbench-onboarding.md)

首次进入已安装引导的 Agent 对话时，引导会高亮下一步要用的控件。新对话的提示位于输入框上方。发送消息后，引导显示在最新回复下方，随对话内容一起滚动。点击引导标题即可折叠或展开说明。按需连接模型后，把你的任务发给 Agent，即可根据回复生成清单并安装到该 Agent。打开清单后，可以用临时条目测试它。

你可以随时收起引导，在**设置 → 通用**中继续。官网产品演示会跳过引导。
