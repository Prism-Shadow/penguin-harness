# 第四套主题：手绘风格的卡通

- **Date:** 2026-11-04
- **Type:** feature
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#1473](https://github.com/Prism-Shadow/penguin-harness/pull/1473), [#1495](https://github.com/Prism-Shadow/penguin-harness/pull/1495)

[English](2026-11-04-theme-cartoon.md)

设置 › 外观与画廊的主题切换新增第四套主题卡通（Doodle，id `cartoon`）：纸面与墨线、平涂实色，每个框的边都是一笔手绘线，框的底色精确止于线内，浅色与深色（深色纸上的粉笔）两种明暗。

## 细节

- 手绘线：每种形状（控件、面板、胶囊、复选框的小方框、标签页与圆球）都是一圈按固定种子画好的圆角轮廓（`packages/ui/scripts/draw-doodle-edges.mjs`），起笔落在框内一丝、再顺势画到线上。脚本由同一组点画出笔线，以 CSS `border-image` 九宫格贴上：页面上成批出现的形状用一张两倍尺寸的 PNG，经 `image-set` 贴上，框的线在每次重绘时是复制而非重画（`packages/ui/scripts/raster-strokes.mjs`，不新增依赖），其余形状仍用 SVG；脚本还写出一条 `clip-path: shape()` 轮廓，其各点按九宫格的拉伸方式随框伸缩。控件、气泡与通知自身的底色因而在任何尺寸下都裁到线内，缩放时也不会重新抖动。卡片与代码块的底色不做裁剪，改用脚本求出的 CSS 圆角，在轮廓的每个角上都落在笔线之下；悬停、选中、语气底色与强调色预设仍由 CSS 着色。不支持 `shape()` 的浏览器（Chrome 135、Safari 18.4、Firefox 141 之前）改为把底色留在线条所在的边框之内。
- 有底色或描边的按钮、文本输入框、选择框与本人的消息气泡经新的样式钩子 `ui-edge` 取得这条线，卡片、代码块、工具调用、通知与回复里的小组件经各自已有的钩子取得它；画成胶囊或圆形的宿主改用胶囊形。卡片、代码块、通知与小组件上的线画在框内内容之上，行与标题条自身的底色也止于线内。对话中 Agent 的工作步骤（活动卡片与单行提示）改用铅笔细线而不是笔线，长时间的运行不会变成数百个手绘框；周围的气泡、输入区与卡片仍保留笔线。其余三套主题对 `ui-edge` 为空操作。
- 浮层（对话框、菜单、弹出层、提示、输入区及其斜杠菜单）由一张贴图整体绘出：底色、笔线，以及落在 12 px 外扩边距里的柔和投影。投影因而随手绘轮廓成形，不运行任何 `filter`；输入区获得焦点时整圈改用圆珠笔蓝重画。启动器的圆球与展开的按钮画成圆形。
- 键盘焦点画在线内，因为线外的焦点环会被裁掉：主题的圆珠笔蓝焦点环内缩 3 px，按钮上环内再垫一圈纸色，有底色的按钮上同样看得清；获得焦点的输入框整圈改用蓝笔重画。强制色彩模式下不套用笔线、裁剪与浮层贴图，宿主自身的边框、圆角与焦点环以系统颜色回来。
- 脚本还画出供各区块放置的纸面记号：荧光笔带、蓝色铅笔括号，以及横竖两向的铅笔线。
- 主题的配方拆为 `packages/ui/src/themes/cartoon/` 下的分片，由 `cartoon.css` 导入。令牌契约、对比度与 de-slop 测试把主题文件连同其分片一起读取，并跳过配方私有的 `--_*` 属性；新增的卡通测试检查主题中的贴图与裁剪与脚本所画一致、配方读取的每一项都有画出、图表之外不运行 `filter`；对比度测试在获得焦点的控件所处的每种底面上按 3:1 测量焦点环。
- 字体：拉丁为 Shantell Sans（`@fontsource-variable/shantell-sans`，SIL OFL 1.1），中文为霞鹜文楷 GB 屏幕阅读版 1.530（SIL OFL 1.1）。文楷只打包其网页版中覆盖 GB2312 字符表全部字符的 48 个分片（2.8 MB），由 `packages/ui/scripts/vendor-wenkai.mjs` 从锁定版本的 `lxgw-wenkai-screen-web` 包中原样取出；更罕用的字回退到 Noto Sans SC。两种字体都随许可全文列入版权信息。
- 强调色：主题自带的强调色与其他主题一样为黑白；强调色选择新增五个画笔预设（马克笔橙、圆珠笔蓝、草绿、蜡笔红、葡萄紫）。
- 当前版本不认识的主题 id（例如较新的版本经账号同步写入的）仍按缺省主题显示，存储值保持原样。
- 新增五个区块钩子，主题可以按区块整体打扮：`ui-start`（新建对话的首页）、`ui-library`（模型库的分组与卡片）、`ui-ledger`（用量汇总卡、公司指标块、Benchmark 卡片的分数）、`ui-empty`（空状态）与 `ui-run`（对话工具栏的运行指示，现为 `RunStatus`）。标签、复选框与单选框加入 `ui-edge`；加载标记与空状态插图在每种画法下各画一份，由主题显示自己的；统计图的填充纹样与滤镜（`ChartDefs`）每页定义一次；统计图的填充标记从自身颜色取填充。当前对话在侧栏的那一行对辅助技术标为当前页。朴素、白领与极客三套主题的外观不变。
- 运行状态：表示正在运行的字（工具栏的运行指示、运行中工作组的标题、工具调用名、思考行）改为墨色，下面垫一道荧光笔带；进行中的步骤以一段向前推进的铅笔涂线表示进度；加载标记改为铅笔螺旋；流式输出的光标改为一小笔斜向的笔触；导航栏中选中的行（页面或当前对话）不再用灰色底，而是整行划上荧光笔带，并在行首的页边画一道蓝色铅笔括号。荧光笔带与括号本身不动；涂线、螺旋与光标在减弱动效时停住。
- 侧栏、对话与空状态：本人的消息改用圆珠笔蓝描边，运行中插话的气泡按控件尺寸绘制；活动卡片的各步骤以铅笔线挂在卡片标题之下，每一步旁是虚线引导线，最后一步接实线 `└`。导航栏与页面之间以一条铅笔线分隔，「新建对话」画在铅笔虚线框里，列表的分组标签后跟一小段铅笔线；手机抽屉中的侧栏同样如此，选中的行也像导航栏中一样划上荧光笔带并画出括号。空状态在文字上方画一道铅笔小涂鸦，槽位形式为四角带刻线的铅笔虚线框。
