# Choose the Windows desktop data directory

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** desktop, core, cli, server

[中文版](2026-11-23-windows-data-location.zh.md)

Windows Setup can store server data and the desktop profile on a different drive. An upgrade keeps the current location unless you select another folder. [Moving existing data](2026-11-23-backward-compatibility.md) covers verification and retained copies.
