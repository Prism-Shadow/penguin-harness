# 画廊改成可以点着逛的文档式站点

- **Date:** 2026-09-27
- **Type:** process
- **Scope:** `ui-gallery`, `ui`

[English](2026-09-27-gallery-docs-site.md)

组件画廊原本是一整页厚重的卡片、变体胶囊和抽屉。现在它是一个首页加每个模块一页，版式照产品的文档站来做，讲交互的演示也真的能上手操作。

## 站点

- 首页开头是一扇可以点的应用外壳：按真实比例的窗口，侧栏能在对话、智能体、插件、模型、成本、评估和设置之间切换，内容取自各模块现成的合成。会话能打开，侧栏能收成图标栏，输入框能写提示词并流式得到脚本化回答，停靠面板的标签能切换。下面按组列出全部模块。
- 每个模块在 `/c/<模块>` 有自己的一页：左侧是带搜索的分组导航，中间是模块标题和一句说明、每个变体一节，末尾是部件、令牌与源码，右侧是本页目录。三主题对比按节进行。
- 顶栏放主题（通用 / 白领 / 极客）、强调色、根字号、语言、视口、对比与减少动效控件；窄屏下导航收进抽屉。

## 三类演示

- **动画**：值得观看的运行过程（流式回复、运行到结束、数字累加）。平时停在完成态，点了才播一遍，与之前相同。
- **交互**：由读者亲手操作——菜单与弹窗能开能关，侧栏能收起，输入框能打字发送，目录能展开，模型表能排序筛选，表单会校验。这些不再用计时动画假装，「重置」可以恢复原样。
- **静态**：只有一帧。

## 通用主题的分组标签

真实应用的分组标签（会话标签、时间分组）是小号大写并加字距的文字；通用主题的眉题现在照样复刻，画廊里的侧栏读起来和应用一致。
