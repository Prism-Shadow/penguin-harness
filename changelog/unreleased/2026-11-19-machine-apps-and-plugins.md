The App Center and plugin market added apps and plugins from machines connected to the project. Each machine’s entries appear as it answers.

## Working across machines

Apps with the same name keep their own machine labels and window, settings and full-screen destinations. A plugin’s details, installation and quick start use the machine that supplies it. The browser remembers recent catalogs for the signed-in account and project. If one machine disconnects, its cached entries remain visible while the others stay usable.
