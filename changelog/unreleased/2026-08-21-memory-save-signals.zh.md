# 记忆提示词明确了何时保存

- **Date:** 2026-08-21
- **Type:** change
- **Scope:** `core`, `docs`
- **PR:** [#397](https://github.com/Prism-Shadow/penguin-harness/pull/397)

[English](2026-08-21-memory-save-signals.md)

内置 `memory.prompt` 原本只说了什么值得保存，没有说什么时候该注意到它，判断完全交给模型。现在它点明了产生长期事实的时机：

- 用户再次提出同一诉求，或对 agent 产出的结果表示不满——保存他们真正想要的做法，连同原因；
- 反复讲到的习惯、约定或开发实践；
- 交代过一次、否则还要再问一遍的可复用信息——姓名、地址、各类标识、服务地址，以及一切读起来像在填表的内容。

「重复」被写成强信号而非硬性条件，因此长期偏好只讲一次同样成立；拿不准是否值得记住时，提示词要求 agent 在对话里直接询问用户。

## 细节

- 该提示词是受 kernel 管理的配置叶子。`2026-08-21` 这一代的 `memory.prompt` 哈希就地修订（该代尚未发布）；此前五代已冻结的哈希保持不变，因此存量 Agent 若仍是旧版默认值会被识别出来并由 kernel 更新推进。手工改过提示词的 Agent 保留自己的版本，不会拿到这段新内容——在记忆标签页恢复默认即可采用。
- 配置说明的记忆章节同步补了一句同样口径的说明，中英各一处。
