# PenguinHarness repositioned as the Unified and Stable RSI Framework

- **Date:** 2026-10-10
- **Type:** process
- **Scope:** `landing`, `docs`, `web`, `tooling`
- **PR:** [#1030](https://github.com/Prism-Shadow/penguin-harness/pull/1030)

[中文版](2026-10-10-rsi-positioning.zh.md)

The product copy moved from an "open-source, local-first multi-agent app development platform" to the **Unified and Stable RSI Framework**: automatically improve model × agent harness. The READMEs, the landing page, the docs introduction and the Web App's draft screen led with the [RSI toolkits](2026-10-10-rsi-toolkits.md), then the one-sentence agent app, then the cost.

## Details

- **READMEs.** The hero line, the tagline and **Why PenguinHarness** were rewritten. The three reasons were reordered: the most comprehensive agent self-evolution framework came first, followed by the one-sentence agent app and the cost comparison, each keeping its video or chart. The plugin table gained the Agent Self-Evolution row.
- **Landing page.** The hero read "Unified and Stable RSI Framework" (zh: 统一、稳定的 Agent 自进化框架) over "Automatically improve model × agent harness", with two stat tiles (1000+ models, 100% open source) and three catalogue rows under them: supported models (each logo linking to the vendor's site), self-evolution algorithms (Default unlinked; OPRO, APE, ACE and AWM to their papers) and Benchmarks (the five built-ins by kind: data analysis, software engineering, business automation, scientific research and terminal tasks, each to its upstream repository). An external link in these rows opened a confirmation dialog first and the page only in a new tab. The pillars, the RSI loop and security sections, the cases ("One sentence builds an AI app, one sentence starts self-evolution": the RAG docs expert, and APE on the demo task shipped with `ape-rsi-toolkit`), the closing call to action and the footer tagline followed. The sled game left the landing page; its images stayed in the repository. The Skills section's Agent Self-Evolution card held the four `default-rsi-toolkit` Skills and the four algorithm Skills. `src/lib/rsi-stats.ts` carried the three catalogues, pinned by a test to the library's `rsi` plugins and to core's built-in Benchmarks and their upstream links; the same test held the APE case's prompt to that toolkit's quick start, word for word.
- **Docs.** The introduction described PenguinHarness as the Unified and Stable RSI Framework, and its third pillar named the RSI toolkits.
- **Web App.** The draft screen became a start dashboard that fits one screen at a laptop viewport. The brand block kept the subtitle "The most comprehensive agent self-evolution platform"; under it came three metric tiles of one shape, each leading with a big total — this Project's agents, the self-evolution algorithms (the plugin library's `rsi` toolkits) and this Project's Benchmarks — that opens the page listing it, and each carrying its most recent item in a quieter line beneath: the agent whose Agent State changed last, with its version; the toolkit the user last picked or started here (remembered per browser), with a Start button that fills the composer with the plugin's quick start — or Install and start, confirmed first, when the selected agent lacks it — and a menu over its name to pick another; and the most recently evaluated Benchmark with its latest score, opening its page. Under the composer came the example folders: "Build an AI app from one sentence" (open on arrival), "Web pages and mini games", "Evaluate and optimize agents" (with an import-a-Benchmark example) and "Scheduled tasks", followed by the user's shortcuts — the folders down one column and the open folder's rows beside them, stacked on a phone. The counts line and the "Reproduce self-evolution algorithms" folder went away; the tiles carried the counts and the toolkit tile the demos.
- **Package metadata.** The root `package.json` described PenguinHarness as the Unified and Stable RSI Framework.
