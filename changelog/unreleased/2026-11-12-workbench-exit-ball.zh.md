# 全页工作台的退出入口改为悬浮球：可拖动、贴边、收起

- **Date:** 2026-11-12
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`
- **PR:** [#1546](https://github.com/Prism-Shadow/penguin-harness/pull/1546)

[English](2026-11-12-workbench-exit-ball.md)

全页工作台（`/app/<project>/<agent>/<workbench>`）右下角的文字按钮「退出全屏」换成了一枚 46px 的毛玻璃圆球，球面是退出图标，仍在原来的角落。点击、Enter 或 Space 与原按钮一样退出；球可以拖到左右任一侧边缘，也可以收起，不再遮住工作台自己的页面。

## 细节

- **拖动。** 鼠标、触屏与手写笔均可；位移不足 4px 的按下仍算点击，拖动之后的那次点击不会退出。球跟随指针，不越过窗口带、不出页面，松手后弹到球心所在一侧的左缘或右缘、距边 16px。按下期间一层透明遮罩盖住页面，工作台的 iframe 不会吞掉指针；其余时间只有球本身接收事件。
- **收起。** 悬停或键盘聚焦时，球朝页面内侧的上角出现一枚小「×」（「收起到边缘」）；把球推出所在一侧的边缘再松手同样收起，推得足够远时球会变淡示意。收起后该边同一高度留下一枚细把手（「显示退出按钮」），点击即恢复悬浮球。命令面板的「退出全页模式」不受影响。
- **记住位置。** 所在一侧、高度（占页面高度的比例）与是否收起作为一条浏览器偏好保存在 localStorage `penguin.workbench.exitBall`，所有全页工作台共用，不随账号同步。页面尺寸变化时球在页面内重新就位，不改写已存的值；读不出的值回落到右下角，存储被禁用只是记不住位置。
- **共享 UI。** 这枚球是 UI 包新增的 `FloatingBall`（拖动阈值、贴边、收起与恢复、经 `onChange` 交还的受控位置、拖动遮罩），建在停靠栏浮动球的 `LauncherBall` 之上——其下方小字改为可选——并新增两个部件：`LauncherDismiss`（角上的「×」）与 `LauncherEdgeHandle`（边上的把手）。几何计算是一个纯函数模块 `floating-ball-geometry.ts`。组件库的「按钮」页有一块单独的演示区。
