# Trace 逐请求记录思考等级；轮次头部一行显示，新增轮次导航

- **Date:** 2026-10-22
- **Type:** feature
- **Scope:** `core`, `server`, `web`, `ui`
- **PR:** [#1295](https://github.com/Prism-Shadow/penguin-harness/pull/1295)

[English](2026-10-22-trace-view.md)

每条 `request_begin` 记录现在带上该请求发出时的思考等级，轨迹观测据此标出等级切换的位置。每轮卡片头部改为一行四项读数，新增的轮次导航列出文件中的每一轮，可跳转到某轮，也可从某轮回到导航。

## `request_begin` 上的思考等级

- `request_begin` 新增可选字段 `thinking_level`：引擎为该请求实际发送的等级——Session 钉住的等级，否则为该上下文开启时读到的等级。普通请求与压缩请求都带该字段。未发送任何等级时（如父会话无等级时派生的子会话）不带该字段。
- 引擎每次请求只解析一次等级，记录与发给模型的请求用同一个值。`LLMInterface` 新增可选属性 `defaultThinkingLevel`，由 `GenerativeModel` 提供；发给模型的请求与此前逐字节相同。
- 这是「AMSP 记录不新增字段」规则的一次明示例外，出于用户要求：`session_meta` 不记录等级，而等级可以在上下文中途更换。
- Trace 分析把该字段复制到每次请求上（`RequestSpan.thinkingLevel`）。此前写入的 Trace 没有等级：不做迁移、不回写，界面上也不显示等级。

## 轨迹观测

- 轮次卡片头部只在一行内显示工具调用次数、缓存命中率、成本与用时，按此顺序。窄宽度下该行尾部省略，悬停显示四项读数的整句。本轮输入（含命中缓存量）、输出、输出 TPS 与上下文占用圆环移到展开后的轮次正文首行。
- 全局统计下方新增轮次导航，列出每一轮的序号、起始 Prompt 的首行与四项读数。点击某行即绘制、展开并滚动到该轮，数字框按轮次号跳转。每轮卡片头部有「回到导航」按钮。列表支持方向键、Home、End 与 Enter。文件不足两轮时不显示导航。
- 等级发生变化处（含文件内首次出现的等级），`request_begin` 行与所在轮的导航行以胶囊标出新等级。悬停胶囊显示切换内容，如「中 → 高」。`request_begin` 行的摘要显示为 `thinking_level=<等级>`。
- `StatChip` 新增 `inline` 形态，用于整行一起截断的读数行。
