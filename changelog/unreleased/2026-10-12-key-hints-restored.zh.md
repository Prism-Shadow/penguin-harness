# 承载屏幕上没有的信息的悬停提示重新显示

- **Date:** 2026-10-12
- **Type:** fix
- **Scope:** `ui`, `web`
- **PR:** [#1051](https://github.com/Prism-Shadow/penguin-harness/pull/1051)

[English](2026-10-12-key-hints-restored.md)

悬停提示的规则只在元素没有自己的文字、或文字被截断时才弹出提示。于是那些承载屏幕上没有的信息的提示——点击会丢弃什么、快捷键、文件夹名背后的完整路径、控件为何置灰——在带可见文字的控件上不再出现；头像首字母和当图标用的字母也被算作可见文字，让为它们命名的提示一并失效。规则现在不计这类文字，补充可见文字的提示经标记后照常显示。

## 细节

- `hintAllowedFor` 不再把 SVG 内与 `aria-hidden` 内的文字算作元素自己的文字，为头像命名的提示因此重新显示（会话行的 Agent、收起侧栏的账号、公司模式图标栏的工位、Benchmark 已测的 Agent）。查找栏的 `Aa`、会话行的待审批数、工具栏按钮的角标计数与标签的 × 改为 `aria-hidden` 的标记，待审批数改由隐藏文字命名。
- 带 `data-tooltip-extra` 标记的 `data-tooltip` 在文字完整可见时也显示；`<Tooltip extra>`、`NavRow` 与 `Chip` 的 `tooltipExtra`、`FormPickerTrigger` 的 `titleExtra` 打同一标记。`Badge` 的 tooltip 与 `BetaBadge` 的 title 一律带标记；`Breadcrumbs` 在开头的目录收进「…」时标记其路径；`DockTabs`、`Legend` 与 `FileTree` 在提示多于标签时标记。
- 按提示类别，已标记的有：
  - 点击的后果：后台进程列表的「清除已退出」与「移除」、「转入后台执行」、插件的「导出」与「快速开始」、记忆的「导出」与「导入」、协议与视觉的两个「检测」按钮、快速模式、「占满应用」、「插话」与「排队」、工作区选择器的「选择」与不选文件夹按钮、输入框里的交接、换模型、技能与目标标签、消息连接的启用开关。
  - 控件置灰或状态异常的原因：Agent API 面板的「运行」、测速或 MCP 测试失败、无效的组织、定时任务或员工、阻塞的工单、损坏的工作流、在磁盘上被改过的文件、锁定的插件设置、位于其他机器上的 Agent。
  - 快捷键：新建对话、查找栏的范围切换、选择器的路径编辑、模型选择器的分组标签。
  - 完整值：文件夹名背后的工作区路径、记忆分组的工作区、子智能体的 Session id、模型选择器里的模型 id、数据路径胶囊、引用标签的路径、Trace 文件的日期与大小、相对时间背后的绝对时间、折叠错误的首次时间。
  - 含义：插件标签与插件状态、模型的折扣条款、权限预设、频道消息的跳数标签、上下文面板的排行标题、已逾期的截止日期、日历事件的员工与结果、新版本徽标、草稿页示例的描述。
