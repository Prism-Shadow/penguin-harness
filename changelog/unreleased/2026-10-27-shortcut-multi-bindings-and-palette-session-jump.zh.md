# 快捷键可挂多个绑定；面板内补全会话 id

- **Date:** 2026-10-27
- **Type:** feature
- **Scope:** `web`, `ui`, `server`

[English](2026-10-27-shortcut-multi-bindings-and-palette-session-jump.md)

一条命令可以挂多把快捷键。快捷键设置页把每个绑定画成一枚可单独删除的徽章，录制按钮录到的键加入该命令而不是替换原有绑定——给一个动作加第二把键不再以丢掉第一把为代价。删掉加上的键就回到默认；全部删空则该命令显式未绑定；默认键本身也可以同样删除，行尾的恢复按钮照旧一键还原。把 Ctrl+P 录成命令面板的第二把键后，浏览器标签页里这组键就交给面板、不再触发打印，行内提示会说明这一点。

存储形式（`ui_prefs.keybindings`）里一条命令的绑定是一个键串数组；旧版本写的单个键串仍按一个绑定读取，服务端两种形态都接受，并把一条命令限制在八把键以内。

在命令面板里输入会话 id 的开头（`session-…`）即补全该会话：条目显示它的标题，旁边是运行状态（运行中、压缩中或空闲）和它的会话 id，回车跳到它的聊天页。过长的 id 在条目的次要行里截断显示。补全基于侧栏已装载的会话，同时按输入的前缀向会话列表现查——任何已装载页之外、属于机器的会话同样给得出；合并后的条目按最近活动排序，至多二十条。应用见过的会话会一直被记住——侧栏的取数与此前的现查答案都算——因此下一个与已问前缀共享开头的前缀能立刻给出记住的会话，而现查仍会发出；来源尚未答完时，一条可见的等待指示（转轮加文字）会标出这一状态。

## 细节

- 匹配在按下的组合命中任意一把绑定时触发该命令；冲突检测与行内提示（浏览器保留的组合、桌面菜单也在用的组合）都按整个列表读取。
- 面板条目可带一行次要文字（`detail`），以弱色画在标题之后；调用方的补全（`suggest`）以原始查询为输入，其结果列在静态过滤结果之后。
- 补全的来源尚未答完时，面板在已就绪的动作上方画一条等待行（唯一的转轮组件加上调用方给它的文字）；列表为空时它取代空态句。它是一条状态行，永远不会成为可选项。
