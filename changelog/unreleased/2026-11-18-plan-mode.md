# Plan mode as a composer switch

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `plugins`, `core`, `server`, `web`
- **PR:** [#1596](https://github.com/Prism-Shadow/penguin-harness/pull/1596)

[中文版](2026-11-18-plan-mode.zh.md)

The new built-in `plan` plugin added **Plan mode** to the chat composer's **+** menu, next to Goal mode. While it is on, a chip shows in the composer and a prompt follows each message you send, asking the Agent to discuss the goal, the alternatives and the open decisions with you before it carries the work out. The prompt shows in the conversation as a folded "injected by harness" card. Plan mode restricts no tool; your permissions apply as usual. It stays on for the conversation until you turn it off, and it is preinstalled on `default_agent`.

## Details

- A plugin card can set `composerMode: true` to offer its hook package as such a switch on every Agent that has it installed. A Task names the switches that are on in `promptHooks` (`POST /api/sessions/:id/tasks`); the server runs each package's `trigger: "host"` `user_prompt` command on the user's words and sends its context behind the message. A queued or interrupting message carries its contexts with it, a steered one carries none, and a goal takes no switch.
- Which switches are on is kept per conversation in the browser.
