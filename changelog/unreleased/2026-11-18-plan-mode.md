# Plan mode for conversations

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `core`, `server`, `web`, `plugins`

[中文版](2026-11-18-plan-mode.zh.md)

Choose **Plan mode** beside Goal mode in the chat composer, or use `/plan`. Discuss a task, ask questions and revise the proposal. During discussion, the Agent can read files. Commands, file changes and delegation wait for approval.

**Approve and execute** starts the version you reviewed. A revision invalidates previous approval buttons. Each subsequent task starts in discussion again until you choose **Exit Plan mode**. The server remembers the mode and the latest proposal when you reopen a conversation.
