# Plan mode for conversations

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `core`, `server`, `web`, `plugins`
- **PR:** [#1596](https://github.com/Prism-Shadow/penguin-harness/pull/1596)

[中文版](2026-11-18-plan-mode.zh.md)

Choose **Plan mode** beside Goal mode in the chat composer. The Agent discusses the goal, alternatives and open decisions with you and can sketch an architecture diagram or write a planning document in the workspace. Once the approach is clear, it can implement it in the same conversation. Your usual tool permissions apply throughout.
