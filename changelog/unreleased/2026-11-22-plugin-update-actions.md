# Update installed plugins from Agent settings and the marketplace

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `web`

[中文版](2026-11-22-plugin-update-actions.zh.md)

Administrators can update a downloaded package in the plugin library from the marketplace or an installed plugin in Agent settings. Both show the installed and target versions before downloading, report progress and refresh the available Agent updates. The marketplace also offers **Update** when an online Agent other than the selected one has an older copy.
