# Mobile landing layouts

- **Date:** 2026-08-27
- **Type:** fix
- **Scope:** `landing`

[中文版](2026-08-27-landing-mobile-layout.zh.md)

Refined the landing page for narrow phone viewports while preserving the desktop presentation and page narrative.

## Details

- Kept the announcement carousel inside its mobile clipping boundary and condensed the expanded navigation into a two-column menu.
- Prevented the hero positioning lines and four platform proof points from clipping at 320–390 px widths, and centered the supported-model marks in predictable rows.
- Let case prompts wrap on phones, added a compact mobile self-improvement flow, and replaced horizontally clipped benchmark tables with readable result cards.
- Tightened scenario-card padding so production stories remain easy to scan on narrow screens.
