# AgentHub 0.4.9：GPT-5.6 能读取大尺寸截图，不再拒收

- **Date:** 2026-09-02
- **Type:** fix
- **Scope:** `core`, `cli`
- **Issue:** [#573](https://github.com/Prism-Shadow/penguin-harness/issues/573)

[English](2026-09-02-agenthub-0.4.9.md)

`@prismshadow/agenthub` 从 0.4.8 升到 0.4.9（agenthub [#194](https://github.com/Prism-Shadow/agenthub/pull/194)）。在 `gpt-5.6-*` 会话里附上大尺寸截图不再报 `400 The image you provided requires N patches after processing, exceeding the limit of 30000`：client 从 data URL 的文件头读出图片尺寸，若按模型默认细节会超限，就以 `detail: "high"` 发送，API 便把它缩到 2,500 patch 之内读取。未超限的图片照旧发送，其他模型不受影响。

## 细节

- 修复位于 AgentHub 的 GPT-5.6、OpenAI Responses 与 OpenAI Chat 三个 client，因此官方 `gpt-5.6-*` 行与 OpenRouter 的 `openai/gpt-5.6-*` 行同样覆盖，提示词与工具返回里的图片一并适用。
- `pnpm-workspace.yaml` 的 `minimumReleaseAgeExclude` 条目由 0.4.8 改为 0.4.9。每次 bump 都落在 pnpm 的发布时限之内，所以这条随 bump 移动，而不是像原注释说的那样删除。
