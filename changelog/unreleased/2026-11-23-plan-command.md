# Select Plan mode with /plan

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** CLI, Web, plugins/plan

[中文版](2026-11-23-plan-command.zh.md)

In an ordinary conversation with the Plan plugin enabled, select `/plan` to turn on Plan mode and keep writing. The Web composer and CLI also accept `/plan` followed by a message. The mode stays selected for subsequent messages until switched off.
