# 落地页移动端布局

- **Date:** 2026-08-27
- **Type:** fix
- **Scope:** `landing`
- **PR:** [#475](https://github.com/Prism-Shadow/penguin-harness/pull/475)

[English](2026-08-27-landing-mobile-layout.md)

优化了落地页在窄屏手机上的布局，同时保留桌面端展示与页面叙事。

## 细节

- 将公告轮播严格裁切在移动端内容区内，并把展开导航收拢为两列菜单。
- 让首屏定位文案与四项平台特点在 320–390 px 宽度下保持统一字号并自然换行，同时让支持模型的图标按稳定行列居中展示。
- 让案例提示词在手机端自动换行，新增紧凑的移动端自进化流程，并用易读的结果卡片替代横向截断的 Benchmark 表格。
- 收紧应用场景卡片的内边距，让生产案例在窄屏下仍便于浏览。
