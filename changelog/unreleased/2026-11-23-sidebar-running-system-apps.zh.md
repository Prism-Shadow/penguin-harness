# 在侧栏「应用」中找到已打开的系统应用

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1713

[English](2026-11-23-sidebar-running-system-apps.md)

打开模型库、插件市场等系统应用后，侧栏的「应用」组会列出该应用。点对应的行可回到上次查看的位置，行菜单可最小化、恢复或关闭它。关闭后仍可从应用中心的图块重新打开。 长列表可在组内滚动，仍能直接使用下方的工作区。
