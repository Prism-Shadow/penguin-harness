# 经 Trace 交接的模型切换在「压缩完毕」行里展示交接内容

- **Date:** 2026-11-26
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1894](https://github.com/Prism-Shadow/penguin-harness/pull/1894)

[English](2026-11-26-trace-handover-details.md)

会话内切换模型时，若压缩没有产出摘要，或当前模型不可达，切换会改经 Trace 文件交接历史。此前对话里只有一条分隔线「模型已切换 · A → B · 经 Trace 交接」及其悬停提示；现在分隔线之上多了一行压缩行，像压缩行展示自身详情那样展示这次交接。该行定格为「压缩完毕」，带降级状态图标，由图标说明没有摘要的原因。

## 细节

- **压缩没有产出摘要**：交接内容并入那次压缩自己的降级行。
- **当前模型不可达**：切换既没有发出压缩请求，也没有写压缩事件对，这一行由新上下文开头的交接说明推导，定格为 `completed`，不计用时；图标提示第一行为「原模型不可用，没有请求摘要」。
- **行的正文**：默认折叠，以「交接说明」一节代替「压缩结果」，依次列出：
  - 原因，与图标提示同一措辞；
  - Trace 文件路径；
  - 去掉标签的 `[model_switch_from]` 交接说明原文。

  长路径在节内折行，全部内容可选中复制。
- **分隔线**：保留原有文字，去掉悬停提示。
- **被重写的交接说明**：新上下文尚无完成的轮时再次切换，会把同一条交接说明重写到下一个文件头部；这份副本只让后一条分隔线写作「经 Trace 交接」，不再推导压缩行。
- **数据**：一切取自 Trace 已有的记录，没有新增记录或字段。
