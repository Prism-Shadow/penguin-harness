# 导入模型分组时可以勾选要导入的模型

- **Date:** 2026-10-29
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#1385](https://github.com/Prism-Shadow/penguin-harness/pull/1385)

[English](2026-10-29-import-pick-models.md)

模型库的**新增分组 → 导入模型**不再一步导入端点列出的全部模型。按钮改为**获取模型列表**：在字段下方按端点返回的顺序列出模型，每个模型 id 一行、带复选框，默认全部勾选。按钮随之变为**导入 {n} 个模型**，只把勾选的模型保存到新分组，分组的 base URL、协议与密钥仍只写一次；一个都没勾选时按钮不可用。

## 细节

- 列表上方显示已勾选数与列出总数，并有**全选**与**全不选**。模型多于 10 个时另有按模型 id 筛选的框；两个批量操作只作用于筛选后显示的行，筛选不会改动被隐藏行的勾选。
- 列表在自己的区域内滚动，模型再多，上方的字段和弹窗底部的按钮也不随之移动。
- 无法保存的 id（为空、超过 200 个字符、含控制字符）与重复的 id 不进入列表，仍计入结果里的跳过数；取消勾选的模型不计入跳过数。
- API key、base URL 或协议与获取列表时不同时，列表隐藏；三项都改回原值时，列表连同勾选一起恢复。
- 获取列表或保存模型期间，API key 与协议同 base URL 一样不可编辑；双击**获取模型列表**时，第二次点击不会触发导入。
- 英文界面的结果与进度提示在数量为 1 时改用单数（"1 model"、"1 entry"）。
