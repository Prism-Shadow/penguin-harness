# 设置 → 外观可以在三个主题之间切换

- **Date:** 2026-09-29
- **Type:** feature
- **Scope:** `web`, `ui`
- **PR:** [#892](https://github.com/Prism-Shadow/penguin-harness/pull/892)

[English](2026-09-29-theme-switching.md)

Web App 的外观设置新增主题选择——通用（Primer）、白领（Frost）、极客（Console），同时提供五档字号、字体组合，以及当前主题自己的一组强调色。每项选择即时生效，按浏览器记住。默认字号改为 16px，即原来最小的一档。

## 外观设置

- **主题**：在通用、白领、极客之间选择；**明暗**保留浅色、深色与跟随系统。
- **强调色**：「随主题」之后列出当前主题自己的可选色。其他主题的可选色会被保留：在当前主题下按主题自身的强调色显示，切回列出它的主题后恢复。「随主题」色块按它实际对应的颜色绘制；极客自身的强调色改为黑白（浅色下近黑、深色下近白），原先的橙红保留为一个可选色。
- **字号**：五档——特小 14px、小 15px、中 16px（新的默认）、大 18px（原来的默认）、特大 20px。旧版本里选过的字号按像素延续，见[向后兼容](2026-09-29-backward-compatibility.zh.md)。
- **字体**：英文与中文字体分别选择，默认都随主题；等宽字体始终由主题决定。
- 新增 **版权信息** 页面，位于「个人」分组末尾，所有账号（包括桌面应用窗口）都能打开：逐一列出内置字体的名称、使用它的主题、许可名称，并可展开查看许可全文。MiSans 的字体声明从账号菜单移到了这里，成为列表中 MiSans 的一项。

## 主题落到真实应用

- 应用窗口、侧边栏的导航行与分组标题、设置对话框的导航栏、菜单行、工作分组及其中的思考与工具调用行、输入卡片、菜单、弹出层、提示与对话框、设置行、页面标题和标签栏都挂上了主题钩子，白领与极客会像在画廊里一样重新组织它们——包括白领运行中文字上的流光和极客的转录式步骤。通知（浮动提示与提示条）以及用量、上下文和评分图表也挂上了钩子，各主题按自己的方式绘制。除新的默认字号外，通用主题的外观不变。
- 开关的圆点与实心强调色按钮的文字改由主题提供颜色：浅色强调色的轨道上圆点依然可见，任何强调色填充上的文字都清晰可读。

## 提示、下拉选择与计数

- Web App 里所有悬停提示都改用应用自己的提示框（即侧边栏图标栏原来用的那种），不再用浏览器自带的提示：短暂停留即出现，键盘聚焦时同样显示，并随主题变化。提示只在文字本身看不到时出现：图标按钮、图表标记，或文字被截断时（此时完整显示原文）。原本只靠提示命名的元素，屏幕阅读器仍能读出名称。
- 复制按钮复制后只把图标短暂换成对勾，按钮文字和提示都不会变成「已复制」。
- 下拉选择与菜单统一为一种样式：设置里下拉框的面板、行距、悬停与选中状态和勾选标记，同样用于输入框的模型、思考等级、权限与技能选择，智能体、机器、协议与组织选择，以及所有菜单。
- Session 标题旁的待审批计数改为注意色的纯数字，不再带圆角底色。

## 图表随主题变化

- 所有图表都改由一套共用的图表部件绘制——柱子、折线、折线下的填充、数据点、网格与坐标标签，以及轨迹时间线的色条：成本中心的请求、Token 与成本图，上下文环形图，评估中心的评分图与小折线，智能体的活跃度小折线，以及轨迹时间线。各部件的样式由主题决定：配色、柱宽、圆角、描边与填充、线宽与曲线形态、数据点形状以及折线下的填充。
- 白领用柔和不刺眼的淡色，柱子为不加边框的浅色圆角柱，曲线平滑，网格很淡；极客用细而实心的柱子加 1px 边框、阶梯状的 1px 线条、方形数据点和虚线网格。通用主题的图表与此前一致，只有轨迹时间线改用与其他图表相同的配色：深色模式下各色条深一档，审批等待色条在两种模式下都略深一些。

## 白领与极客的细化

- 白领改用平静、偏冷的米白：侧栏与主区只靠底色区分（没有内缩卡片、圆角或阴影），分组靠柔和底色而非线条——设置项收在一整块柔和的底色里——对话框不透明、圆角 20px，状态小标签不带边框，图标为柔和的单色。
- 极客精简到终端般朴素：卡片、行与菜单就是页面本身加一条细线，去掉了底色与阴影；提示条与提示弹窗改为状态行（`[ OK ]`、`[WARN]`、`[FAIL]`、`[INFO]`、`[NOTE]`）。
- 设置里开关的圆点随主题的间距缩放，不再超出极客的轨道；外观页的两个字体选择始终保持在一行。

## 更平静的深色模式

- 深色模式把近白留给标题与强调，正文低一级，在各页面表面上的对比度不低于 11:1；次要文字不低于 6:1，时间戳、占位符等辅助文字不低于 4.5:1。通用主题的深色画布抬离纯黑，`dark:` 类名背后的灰阶随之调整。
- 极客主题中，消息、输入框里的文字与 Session 标题改用无衬线阅读字体；导航、标签、步骤行与代码仍为等宽。极客的工作分组不再加框，白领的工作分组步骤与标题对齐。
- 白领的对话框改为不透明（只有菜单、弹出层与提示保留磨砂），手机宽度下应用铺满屏幕、四周不留空白。
