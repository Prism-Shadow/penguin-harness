# Offer to switch the default model and pin provider balance when saving any group key

- **Date:** 2026-11-25
- **Type:** feat
- **Scope:** `web`
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1850

[中文版](2026-11-25-provider-switch-default-model-prompt.zh.md)

Saving an API key for any provider group now offers to switch the project's default model to that group (showing the provider name in parentheses for both the current and offered models) and pins the provider's balance to the bottom-left footer when accepted.
