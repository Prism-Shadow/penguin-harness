# Build a checklist from a conversation

- **Date:** 2026-11-23
- **Type:** change
- **Scope:** `web`, `first-workbench-guide`, `landing`

[中文版](2026-11-23-first-workbench-tour.zh.md)

Start **Your first workbench** from initial model setup or Settings → General. The guide stays beside the model settings, conversation and installed checklist. You choose the model, send your task, review the checklist, install it and test a saved item. Dismiss the guide and reopen it to continue. The homepage demo omits the guide and the initial password reminder.

Existing installations can [resume their guide](2026-11-23-backward-compatibility.md).
