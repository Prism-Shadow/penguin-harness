# 使用 Gemini Nano Banana 2.1 生成图片

- **Date:** 2026-11-19
- **Type:** feature
- **Scope:** `model-catalog`, `core`, `server`, `cli`
- **PR:** [#1613](https://github.com/Prism-Shadow/penguin-harness/pull/1613)

[English](./2026-11-19-nano-banana-21.md)

模型库通过 MMSP 0.5.11 加入了 Google 和 OpenRouter 的 Gemini Nano Banana 2.1。已有项目可在模型库点击**同步新增模型**添加这两个预设。当前选用的模型会保留。

## 服务商

- Google 的 `gemini-nano-banana-2.1` 通过 Interactions API 接收文本、图片和视频，最多可输入 131,072 个 token。
- OpenRouter 的 `google/gemini-nano-banana-2.1` 通过 Images API 接收文本提示词，可生成 1K 或 2K 图片。
- 公开价格按每百万 token 计算，输入为 1.50 美元，文本或思考输出为 7.50 美元，图像输出为 30 美元。模型库中这两个预设的对话输出单价留空。
