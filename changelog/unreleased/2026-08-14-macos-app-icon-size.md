# Match the macOS app icon size

- **Date:** 2026-08-14
- **Type:** fix
- **Scope:** `desktop`
- **PR:** [#281](https://github.com/Prism-Shadow/penguin-harness/pull/281)

[中文版](2026-08-14-macos-app-icon-size.zh.md)

PenguinHarness now uses a dedicated macOS icon master with the brand artwork centred inside the platform's safe area, matching the visual size of neighbouring apps in the Dock and Launchpad.

The Windows icon master and Linux icon set remain unchanged.
