# 适合手机的看板：哪里在干活，哪里需要人

- **Date:** 2026-09-04
- **Type:** feature
- **Scope:** `web`, `server`
- **PR:** [#815](https://github.com/Prism-Shadow/penguin-harness/pull/815), [#618](https://github.com/Prism-Shadow/penguin-harness/pull/618), [#643](https://github.com/Prism-Shadow/penguin-harness/pull/643)

[English](2026-09-04-dashboard.md)

新增一个页面，入口在用户菜单的**设置**下方，适合手机屏幕，只回答一个问题：哪些工作区有会话正在运行，哪些工作区有会话自你上次打开后已经完成——也就是侧边栏的绿点，计成数字。每个工作区一行、两个计数，页头重复两个总数。计数为零时不显示。

## 细节

- 点一个计数，会展开它背后的会话，每个会话一行：侧栏的状态标记、截断到一行的标题、会话 id 的短尾。点某一行即打开该对话、标记为已读、并把它的 Agent 设为当前——在另一台机器上的会话亦然。
- 两个计数都不包含子智能体会话：它们属于派生它们的那个对话，那才是人会打开的那一行。
- 项目的会话所在的每台服务器都会被询问：本机，以及本机与之保有连接的每台机器。来自其他机器的行带有那台机器的名字。已安装但没有连接的机器、以及没有应答的机器，会在列表下方计数说明，而不是悄悄消失。无权列出机器时，页面只读本机。
- 自动创建的临时工作区按机器合并为一行，与侧边栏的分组方式一致。
- 等待人处理的行排在前面，其次是最忙的。页面打开期间每十五秒刷新一次，切回该标签页时也会立即刷新。
- `GET /api/projects/:projectId/sessions/overview` 返回项目内所有 Agent 的每个未归档会话——它的 Agent、工作区、状态、是否运行过、最后活动时间、标题与来源。已读与未读是浏览器本地的标记，所以计数在页面里完成。
- 在同一浏览器的另一个标签页或窗口中打开过的会话，在这里也算已读，侧栏与看板皆然。浏览器拒绝保存已读标记时（隐私模式、存储配额已满），切回标签页也会保留内存中的标记，不会让读过的会话重新显示为未读。
