# 适合手机的看板：哪里在干活，哪里需要人

- **Date:** 2026-09-04
- **Type:** feature
- **Scope:** `web`, `server`
- **PR:** [#618](https://github.com/Prism-Shadow/penguin-harness/pull/618)

[English](2026-09-04-dashboard.md)

新增一个页面，入口在用户菜单的**系统设置**下方，适合手机屏幕，只回答一个问题：哪些工作区有会话正在运行，哪些工作区有会话在等待审批。每个工作区一行，每行两个数字，别无其他——没有会话列表，没有标题，没有操作。页头重复这两个总数。

## 细节

- 项目的会话所在的每台服务器都会被询问：本机，以及每台能够到达的机器。来自其他机器的行带有那台机器的名字。没有应答的机器会在列表下方计数说明，而不是悄悄消失。
- 自动创建的临时工作区按机器合并为一行，与侧边栏的分组方式一致。
- 等待人处理的行排在前面，其次是最忙的；页面打开期间每十五秒自动刷新。
- 服务端通过 `GET /api/projects/:projectId/sessions/overview` 回答项目内所有 Agent 会话按工作区的计数：状态不是 idle 的会话计为运行中，有审批等待决定的会话计为待审核。已归档的会话不计。
- 该页面不在侧边栏的导航分组里；它的入口是用户菜单中「系统设置」正下方的一行。
