# 适合手机的看板：哪里在干活，哪里需要人

- **Date:** 2026-09-04
- **Type:** feature
- **Scope:** `web`, `server`
- **PR:** [#618](https://github.com/Prism-Shadow/penguin-harness/pull/618)

[English](2026-09-04-dashboard.md)

新增一个页面，入口在用户菜单的**系统设置**下方，适合手机屏幕，只回答一个问题：哪些工作区有会话正在运行，哪些工作区有会话自你上次打开后已经完成——也就是侧边栏的绿点，计成数字。每个工作区一行，每行两个数字，别无其他——没有会话列表，没有标题，没有操作。页头重复这两个总数。

## 细节

- 项目的会话所在的每台服务器都会被询问：本机，以及每台能够到达的机器。来自其他机器的行带有那台机器的名字。没有应答的机器会在列表下方计数说明，而不是悄悄消失。
- 自动创建的临时工作区按机器合并为一行，与侧边栏的分组方式一致。
- 等待人处理的行排在前面，其次是最忙的；页面打开期间每十五秒自动刷新。
- 服务端通过 `GET /api/projects/:projectId/sessions/overview` 返回项目内所有 Agent 的每个未归档会话——它的工作区、状态、是否运行过、最后活动时间。页面按侧边栏画图标的规则从中计数：状态不是 idle 计为运行中，已完成的会话自本浏览器上次打开它之后又有活动则计为待审核。已读与未读是浏览器本地的标记，所以计数在页面里完成，而不在服务端。
- 该页面不在侧边栏的导航分组里；它的入口是用户菜单中「系统设置」正下方的一行。
