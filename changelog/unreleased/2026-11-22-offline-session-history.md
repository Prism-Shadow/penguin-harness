# Read recent messages while a remote machine is disconnected

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `server`, `web`

[中文版](2026-11-22-offline-session-history.zh.md)

Opening a conversation on a disconnected machine now shows the machine name and connection status. You can read the recent messages from the last sync. If the hub has no saved messages for that conversation, the page says so. Once the machine reconnects, the conversation refreshes automatically.
