# 头像菜单的更新行变为「应用信息」弹窗

- **Date:** 2026-10-02
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#950](https://github.com/Prism-Shadow/penguin-harness/pull/950)

[English](2026-10-02-app-info-dialog.md)

头像菜单里**设置**下方的那一行现在叫**应用信息**（英文 About）。它打开一个弹窗，集中放应用的身份、链接、软件更新、更新日志与版权信息；原来单独的「软件更新」弹窗和设置对话框里的「版权信息」页随之移除。

## 细节

- **菜单行。** 标签恒为**应用信息**，右侧浅色显示当前版本号。更新有动静或在等待时，标签下方多一行更新文案——检查中…、新版本 vX 可用（带主题色圆点）、正在下载 vX 42%、重启以更新到 vX、正在重启…——头像上的角标因此仍能走到它自己的那句话。该行对所有会话可见，包括浏览器登录桌面模式服务端的会话：它能看到版本与更新日志，但没有更新控件。
- **弹窗**自上而下：应用图标、产品名、版本号与构建日期，以及两枚按钮——**主页**（https://penguin.ooo/）与 **GitHub**；**软件更新**区块，状态与操作与原弹窗一致，唯一的变化是打开弹窗不再强制检查——区块显示最近一次已知结果，按**检查更新**才重新检查；**更新日志**，随构建打包的双语列表，收录从 0.1.0 到 0.2.13 的每个已发布版本，按版本号降序，每版一到五条短句，当前运行版本标**当前版本**；**版权信息**——版权一行，以及一个折叠行，展开后是原设置对话框「版权信息」页的字体与图标许可。
- **更新日志数据**位于 `packages/web/src/lib/release-notes-data.ts`，在发布准备时与 `RELEASE.md` 一同写入，其他 PR 不改动该文件。桌面应用因此可离线显示。
- 文档的「更新」页改为指向新的菜单行与区块；Web App、Docker 与 Server API 页也改用弹窗的新名称。
