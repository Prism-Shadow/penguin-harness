# Use familiar keyboard shortcuts for navigation and panels

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** `web`, `desktop`

[中文版](2026-11-24-default-navigation-shortcuts.zh.md)

Use Cmd+B on macOS or Ctrl+B on Windows and Linux to show or hide the sidebar, including while composing a message. The desktop app also supports Cmd/Ctrl+K for Session search, Cmd/Ctrl+N for a new chat, Cmd/Ctrl+Alt+B for the right dock and Cmd/Ctrl+J for the bottom dock. The web app keeps the browser-friendly bindings for those actions. Shortcut settings and tooltips show the current host’s bindings.
