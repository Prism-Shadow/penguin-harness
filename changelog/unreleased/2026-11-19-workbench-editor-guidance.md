# Workbench authoring guidance for document editors and AI conversations

- **Date:** 2026-11-19
- **Type:** docs
- **Scope:** `plugins`, `skills`
- **PR:** [#1619](https://github.com/Prism-Shadow/penguin-harness/pull/1619)

[中文版](2026-11-19-workbench-editor-guidance.zh.md)

The `penguin-plugin` Skill gained a guide to organizing file commands, saving from an embedded editor, and choosing a chat model for one document. It showed authors how to compare a recurring task with an established app and test the result with a saved item, such as a presentation template or a book reopened at the last paragraph read. It also included checks for sending a follow-up on the selected model and expanding a turn's activity on a phone.
