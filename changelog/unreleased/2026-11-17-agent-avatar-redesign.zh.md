# Agent 的缺省头像换成更亲切的小企鹅，并各有配饰

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `ui`, `ui-gallery`

[English](2026-11-17-agent-avatar-redesign.md)

Agent 没有自己的图片时画的那只企鹅重画了：一只近景的圆滚滚小企鹅，大眼睛、橙色小喙、头顶一撮绒毛、两团腮红，取代原先「深色圆环里套一张小脸」的圆球。每个 Agent 的企鹅另有八选一的配饰，与颜色一样由 Agent 的 id 决定。Agent 自己的图片、底色块的形状与落盘数据均不变。

## 细节

- 企鹅占满色块：圆球贴着色块底边，浅色的脸向下连到肚皮，身体只是头罩与两侧。各尺寸是同一张脸；20px 起显示腮红，24px 起眼睛带高光，48px 起再加一点小高光。
- 喙在所有颜色、两种明暗下是同一种橙色。
- 配饰为无、围巾、毛线帽、鸭舌帽、耳机、小芽、蝴蝶结、眼镜之一：取 id 哈希值除以 360 的商对 8 取余（颜色取的是余数），因此十二种颜色与八种配饰两两都会出现。配饰用色相环对面那一格的腮红色。
- 内置的通用 Agent（`default_agent`）仍为绿色，不戴配饰。
- 三种画法的名字与所属主题不变：`flat` 圆角方块底（朴素）、`soft` 圆形底（白领、卡通）、`pixel` 方块底（极客，配饰同样逐格画出）。
- UI 包新增导出 `AGENT_ACCESSORIES`、`agentAccessory(id)`、`AGENT_BEAK` 与 `avatarHash(key)`；`AgentColors` 新增 `beak` 与 `accent`。
- 画廊的头像看板改画 14、18、24、48、96px，十二个示例 Agent 依次轮换配饰，并另起一行逐个标出配饰名称。
