# Pin saved shortcuts ahead of examples in a new chat

- **Date:** 2026-11-24
- **Type:** feature
- **Scope:** Web App
- **PR:** [#1810](https://github.com/Prism-Shadow/penguin-harness/pull/1810)

[中文版](2026-11-24-chat-starter-actions.zh.md)

Saved shortcuts take the first positions below the composer. Examples fill the open positions. Choose More examples to see the remaining prompts by name. The shortcut editor and example shuffle stay within reach when the pane narrows.
