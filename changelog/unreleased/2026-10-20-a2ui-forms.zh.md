# A2UI 表单：齐备的基础控件、统一的答案规则，不再检查纯文本

- **Date:** 2026-10-20
- **Type:** feature
- **Scope:** `core`, `ui`, `web`, `ui-gallery`, `skills`, `docs`

[English](2026-10-20-a2ui-forms.md)

回复里的表单可以用全部基础控件提问：单行或多行文本、数字、滑块、单选或多选、下拉列表、开关、日期、时间，或日期加时间。答案是否有效由同一条规则判定，填入按钮、控件下方的说明行与保存的草稿共用它。检查脚本不再检查组件块之外的文字。

## 表单

- 字段种类增至 11 种：`text`、`textarea`、`number`、`slider`、`single`、`multiple`、`select`（2–30 个选项的下拉列表）、`switch`、`date`、`time` 与 `datetime`。滑块必须给出 `min` 与 `max`。
- 新增字段属性：`hint`（控件下方的说明行，答案不合规则时即为错误行）、`maxLength`（text 至多 500，textarea 至多 2000）、`pattern`（仅 text，须整段匹配）与 `default`（初始答案，类型随种类而定）。
- 新增检查码：`not_for_kind` 取代 `number_only`，凡是放在不读它的种类上的字段都报此错；`default_invalid` 拒绝不满足本字段规则的初始值。种类不支持的 `placeholder`、下拉选项上的 `description` 报警告并被丢弃。
- 填入文本仍为每个字段一行「问题：答案」。开关写作 `Yes` / `No`（是 / 否），数字与滑块写数值加单位，日期时间的日期与时间之间为空格；多行文本另起一行，每行缩进两格。开关与滑块总有值，因此总会填入一行。
- 纯文本降级（CLI、消息渠道）中，每个字段一行，写明它接受什么：选项、范围、格式或「是 / 否」，随后是初始值与说明。

## 渲染

- 必填字段都已作答、每个答案都有效之前，表单的按钮不可用。答案不合规则时，控件显示危险色，下方说明行变为错误行：字段的 `hint`，没有时为以符号写出的规则，如 `1–10`、`YYYY-MM-DD`。
- UI 包新增控件：`ChoiceGroup`（选项片或选项卡片）、`NumberInput`（减号与加号按钮，单位在框内）、`Slider`、`FieldLegend` 与 `RadioDisc`。画廊在「输入」与「选择器」下展示它们，并补上数字与日期时间输入。
- 选项块与表单块改用 UI 包的控件（`ChoiceGroup`、`NumberInput`、`Slider`、`Select`、`Textarea`、`ToggleRow`），不再自带样式，随三套主题变化。

## 检查脚本

- 删去对组件块之外文字的检查：长句、长段、被动语态、含糊词、过深的列表与大段无分隔文字。报告只剩错误与块警告两节，自查清单删去「是否自然」一问。
- 无错误时总分即 L2 分数，门槛仍为 70，因此至多两条块警告的回复可以通过。

## 技能与文档

- `a2ui` Skill（版本 `2026.10.20.2`）讲解 11 种字段：目录行、列出各控件答案与填入行的种类表、选择种类的规则，以及一个含下拉列表、滑块、日期与开关的表单示例。说明里不再提文风检查与文风分。写作规则保留为建议，因此 Skill 的一行描述不变。
- 「对话 › 富输出组件」介绍表单的控件与校验方式，插件库 README 列出这些控件。
