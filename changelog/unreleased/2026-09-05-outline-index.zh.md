# 对话索引列出每一轮，与加载了什么无关

- **Date:** 2026-09-05
- **Type:** feature
- **Scope:** `web`, `server`
- **PR:** [#623](https://github.com/Prism-Shadow/penguin-harness/pull/623)

[English](2026-09-05-outline-index.md)

消息流旁的快速跳转刻度轨、以及窄屏上的顶栏索引，现在列出整段对话的每一轮，而不再只是恰好加载着的那几轮。服务端维护一份对话索引——每轮的轮号、在 Trace 中的位置、问题与回答预览——由切分消息窗口的同一次扫描顺手算出、随之缓存，并以 `GET /api/sessions/:id/outline` 提供。已加载的轮保留实时预览；点击其他任意一轮即在该处打开对话记录（与实时末尾脱钩），窗口一上屏跳转即完成。索引在每次 Task 结束时刷新；服务端没有该接口时，刻度轨保持原样。
