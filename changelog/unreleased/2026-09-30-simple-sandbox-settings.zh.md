# 权限菜单改为命名的预设

- **Date:** 2026-09-30
- **Type:** feat
- **Scope:** `server`, `web`, `ui`

[English](2026-09-30-simple-sandbox-settings.md)

输入框的权限按钮不再分三段列出各档位，而是列出预设：Full Access、Always Ask、Workspace Write、Read Only，管理员还会看到「更多…」。每个预设是文件模式、网络与审批方式的一个命名组合，选一次就把三者一起保存到会话上。

- **预设做什么，写在它的悬停提示里。** 悬停在预设上会说明它封住什么、放开什么，以及本机能否实施。本机没有后端能实施的预设仍列出，但置灰并标注「未安装」或「不可用」，与此前的档位一致。
- **按钮用预设为会话的档位命名。** 没有预设匹配的档位（在完整设置里改出来的，或由旧版本客户端设置的）显示为「自定义」，提示里列出三个实际值。会话另有屏蔽路径或只读临时目录时，菜单顶部显示「高级设置生效中」。
- **沙盒卡片有一张预设表。** 「更多…」打开设置对话框插件页上的「沙盒」卡片，卡片顶部是一张表，每个预设一行：名称、文件模式、网络、询问模式（即审批方式），以及「操作」一组图标——图钉表示是否进菜单，拖动手柄，以及「…」菜单，内有「设为默认」和（仅新增预设上的）「删除」。默认行在名称后标「（默认）」。每个名称旁有「?」说明这一行的用途：内置预设各有一句（仅工作区可写：适合日常编码）；新增的预设，或改过取值的内置预设，则逐项说明三个取值的作用。选择类单元格以文字显示取值的完整名称，点击后弹出选项小菜单。拖动手柄时该行浮起并显示落点；聚焦手柄后按上下方向键也可移动。这个顺序就是输入框权限菜单的顺序。「添加预设」新增一行（仅工作区可写、完全访问、每次询问、不固定）；只有新增的行可以删除，且作为默认时不能删除。改名不改映射；Full Access 只能改名、取消固定或设为默认；手工为其锁定单元格写入的值会被忽略。名称按词换行；窗口窄于表格最小宽度时表格横向滚动，而不是挤压名称。
- **说明文字收进标题旁的「?」**，所有设置卡片一致：卡片说明、每个字段与表格的说明都如此。格式要求（屏蔽路径：每行一个绝对路径）仍显示在字段下方。
- **新会话从默认预设开始。** 表中一行为默认，未改动时为 Workspace Write。开关打开时，新会话与输入框草稿取该行的文件模式、网络与审批方式；默认行不做任何封禁时（Full Access），新会话不进入沙盒。改动默认只影响此后新建的会话。卡片不再有单独的封禁模式与网络字段；默认预设出现之前存下的设置，在管理员设定默认行之前继续按其封禁模式与网络执行。卡片把起点与之完全相同的那一行标为默认；没有这样的行时不标任何一行，并以一条提示写明实际生效的值（见[向后兼容](2026-10-02-backward-compatibility-sandbox-switch.zh.md)）。
- **沙盒卡片顶部有「启用」开关。** 它决定新建会话是否进入沙盒；已有会话保留自己的策略。关闭时，新会话拥有完全的文件与网络访问，只受审批模式约束，输入框的权限菜单改为列出四种审批模式而不是预设；在这里选择只改会话（或草稿）的审批模式，不动其沙盒策略。关闭期间预设与默认都保留，重新打开后照旧生效。全新安装默认关闭。开关出现之前保存的设置，只要有任何封禁（封禁模式不是「关闭」、网络不是完全开放，或设置了屏蔽路径）即视为打开，见[向后兼容](2026-10-02-backward-compatibility-sandbox-switch.zh.md)。开关关闭时，卡片只显示这个开关：没有预设表、高级选项、提示，也没有后端自身的设置。
- **临时目录与屏蔽路径移入「高级选项」折叠区**，默认折叠，位于开关与预设表之下。
- **打开开关时，若本机没有适用于其操作系统的沙盒后端，会询问是否安装**：Linux 为 `@penguinharness/sandbox-bwrap`，macOS 为 `@penguinharness/sandbox-seatbelt`，Windows 为 `@penguinharness/sandbox-wsl`。对话框带下载标记，选项为「安装」与「暂不」，另有「不再询问」，由本浏览器按机器记住。安装走插件页的同一条安装路径，装到当前项目的该机器上；无论选哪项，开关都保持打开。
- 设置分组新增 `table` 字段类型：行固定，列可以是 `string`、`boolean` 或 `enum`，单元格可以锁定。只存与声明不同的单元格，被拒的单元格按 `<字段>.<行>.<列>` 点名。`unavailable` 可以指向表的某一列。表格可以声明 `rowChoice`：单选一行，存入同组中选项为各行 id 的 `enum` 字段，画作被选行名称后带括号的标题，在该行的「…」菜单里选定；`pin`：把一个布尔列画成图钉按钮，每种状态各有提示；`columnGroup`：相邻几列上方的分组标题；以及 `extensible`：可新增行（只有新增的行可删除）并调整所有行的顺序，以 `"$added"` 与 `"$order"` 增量存储。单选列可以指向新增的行，也可以不指向任何行；保存后若它指向表里已不存在的行，保存会被拒绝。列、行与 `enum` 选项可带 `description`（行及其选项的说明就是该行的「?」），字段可带格式提示 `hint`（`hintZh`），显示在字段下方，`description` 则收进「?」。
- 设置字段可以标记 `advanced: true`；插件页在每张卡片上都把这类字段收进折叠区。
- 沙盒的设置条目新增 `backend`（`installed`、`recommended`）；其分组新增 `enabled` 与 `defaultPreset`，去掉 `mode` 与 `network`。配置可以把一个布尔字段声明为 `switch`：它关闭时，页面只画这一个字段。
- **非管理员能看出哪些预设只有管理员能选。** 比服务端沙盒设置更宽的预设（默认为 Workspace Write 时，即文件模式为关闭的 Full Access 与 Always Ask）对非管理员置灰并标「仅管理员」，悬停说明它超出了本服务器的沙盒上限；管理员不受影响，会话当前所在的预设也不受影响。被拒绝的选择不改动会话，由 toast 说明原因。
- UI 包的 `ConfirmModal` 新增 `glyph`，用于指定左侧标记。以 portal 方式弹出的 `Dropdown` 在面板定位后才把焦点移到第一项；此前用键盘打开时焦点留在触发按钮上，方向键也无效。
- API 中会话的 `sandbox` 对象新增三个只出现在响应里的字段：`presets`（整张表，含未固定的行）、`advanced` 与 `switchOn`（沙盒开关）。chat defaults 也带上它们，另加 `defaultApprovalMode`：开关打开时默认预设的审批方式。创建时未指定审批方式的会话取这一项；无人值守的会话仍为 `allow-all`：组织的会话、定时任务与工作流创建的会话。预设表的每一行在比服务端设置更宽时带 `aboveCeiling: true`，与以 `403 sandbox_forbidden` 拒绝非管理员选择的是同一次比较。
- `PATCH /api/sessions/:sessionId` 先完成全部校验（含沙盒的上限与可实施性）再写入任何字段：被拒的请求什么都不落盘。原先它先写审批方式，被拒的预设选择会只存下审批方式那一半。
