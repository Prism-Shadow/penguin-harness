# 权限菜单改为命名的预设

- **Date:** 2026-09-30
- **Type:** feat
- **Scope:** `server`, `web`

[English](2026-09-30-simple-sandbox-settings.md)

输入框的权限按钮不再分三段列出各档位，而是列出预设：Full Access、Always Ask、Workspace Write、Read Only，管理员还会看到「更多…」。每个预设是文件模式、网络与审批方式的一个命名组合，选一次就把三者一起保存到会话上。

- **预设做什么，写在它的悬停提示里。** 悬停在预设上会说明它封住什么、放开什么，以及本机能否实施。本机没有后端能实施的预设仍列出，但置灰并标注「未安装」或「不可用」，与此前的档位一致。
- **按钮用预设为会话的档位命名。** 没有预设匹配的档位（在完整设置里改出来的，或由旧版本客户端设置的）显示为「自定义」，提示里列出三个实际值。会话另有屏蔽路径或只读临时目录时，菜单顶部显示「高级设置生效中」。
- **沙盒卡片有一张预设表。** 「更多…」打开设置对话框插件页上的「沙盒」卡片，卡片顶部是一张表：每个预设一行，各列是名称、是否进菜单，以及文件模式、网络与审批方式。改名不改映射；Full Access 只能改名或移出菜单。另有 Workspace Write with Ask 与 Denied All 两个预设，默认不进菜单。表格放在圆角描边的框里，表头浅底；名称是行内输入框，「进菜单」是开关，Full Access 锁定的格显示取值与锁标记。
- **沙盒卡片顶部有一个开关。** 它决定新建会话是否进入沙盒；已有会话保留自己的策略。关闭时，新会话拥有完全的文件与网络访问，只受审批模式约束，输入框的权限菜单改为列出四种审批模式而不是预设。关闭期间封禁模式、网络与预设都保留，重新打开后照旧生效。全新安装默认关闭。开关出现之前保存的设置，只要有任何封禁即视为打开，见[向后兼容](2026-10-02-backward-compatibility-sandbox-switch.zh.md)。
- **缺省封禁模式、网络、临时目录与屏蔽路径移入「高级选项」折叠区**，默认折叠，位于开关与预设表之下。
- **打开开关时，若本机没有适用于其操作系统的沙盒后端，会询问是否安装**：Linux 为 `@penguinharness/sandbox-bwrap`，macOS 为 `@penguinharness/sandbox-seatbelt`，Windows 为 `@penguinharness/sandbox-wsl`。选项为「安装」与「暂不」，另有「不再询问」，由本浏览器按机器记住。安装走插件页的同一条安装路径，装到当前项目的该机器上；无论选哪项，开关都保持打开。
- **保存预设表不改变任何封禁。** 预设只为组合命名。会话照旧保存自己的封禁模式、网络与审批方式，沙盒策略照旧只读卡片里的其余字段。
- 设置分组新增 `table` 字段类型：行固定，列可以是 `string`、`boolean` 或 `enum`，单元格可以锁定。只存与声明不同的单元格，被拒的单元格按 `<字段>.<行>.<列>` 点名。`unavailable` 可以指向表的某一列。
- 设置字段可以标记 `advanced: true`；插件页在每张卡片上都把这类字段收进折叠区。
- 沙盒的设置条目新增 `backend`（`installed`、`recommended`），其分组新增 `enabled` 字段。
- API 中会话的 `sandbox` 对象新增三个只出现在响应里的字段：`presets`（整张表，含未进菜单的行）、`advanced` 与 `switchOn`（沙盒开关）。chat defaults 也带上它们。
