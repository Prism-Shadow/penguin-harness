# Remote-control docs describe QQ images, files and voice

- **Date:** 2026-11-27
- **Type:** process
- **Scope:** `docs`

[中文版](2026-11-27-docs-remote-control-qq-media.zh.md)

The remote-control page no longer says QQ carries text only.

## Details

- The QQ section states that text, images and files travel in both directions, that voice arrives as QQ's transcript, and that a quoted message reaches the agent as a blockquote.
- It also states that a file uses one of the message's replies and only while no text waits for the last one, and that a file with no reply left or one QQ refuses leaves a one-line note in the chat and an error record.
- The shared incoming-media and outgoing-file sections list QQ alongside the other channels.
