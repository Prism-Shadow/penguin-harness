# AI 角色对话：原创角色在舞台上和你聊天，有表情，也有记忆

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `plugins`, `docs`
- **PR:** [#1590](https://github.com/Prism-Shadow/penguin-harness/pull/1590)

[English](2026-11-17-plugin-character-chat.md)

新增内置插件 `character-chat`（AI 角色对话）：在 Agent 的对话旁增加「角色」标签页，并在应用中心增加一个图块。它不预装，需要时从插件库安装到 Agent 上。

## 细节

- **角色通信室。** 桌面并排显示角色和可滚动的对话，手机把立绘放在对话上方。切换角色时保留未发送的草稿。可以直接点选开场话题，或自己输入。
- **角色。** 加入企鹅邮差啾啾、气象观测员晴晴、夜班图书管理员阿任和山间茶师小麦。角色可以眨眼、随回复变换表情，在说话时动嘴。
- **记忆本**：每个角色一本，记着它了解到的关于你的事，每条一行并注明日期，每一条都能删，也可以「全部忘掉」。它是工作台的文件（`.files/characters/<id>/memory.md`），保留最新的 120 条。
- **友谊** 随聊天的天数加深，每天至多涨一天的量，共五级；升级时提示一次。
- **角色卡编辑器**：名字、一句话介绍、身体、颜色、穿戴、地点、第一句话和一页设定，立绘随改随画，可以试十种表情。身体可以是企鹅、机器人、茶壶精、猫或二次元人物（发型、发夹或眼镜）。角色卡可以下载为 `.card.md` 文件再导入。「替我写」让 Agent 根据一句话写一张角色卡；Agent 在普通对话里写好的角色卡，一秒内出现在角色列表中。
- **只做对话的 Session。** 每个角色的对话都是以 `deny-all` 审批模式打开的工作台 Session（[#1588](https://github.com/Prism-Shadow/penguin-harness/pull/1588)），开场消息也写明没有工具：一句话或一张导入的角色卡都不能让它执行任何操作。你中途停止的回复只保留你说的话，不显示错误。
- **`character-chat` Skill** 在普通对话里扮演角色卡，同时照常用工具做实事；还能编写或导入角色卡，并在你要求时整理角色的记忆本。
- 界面按设备语言显示中文或英文，可切换，工作台会记住选择。朗读只使用本机语音。页面不从服务器以外加载任何内容。
- 插件归入「娱乐」。
