- **范围：** `docs`

[English](2026-08-24-security-docs.md)

参考区新增"安全模型"页，按用户实际遇到的顺序以场景组织：先列功能清单，然后是首次登录（Web 与
桌面）、修改密码的四条路径、本机自动化、远程机器——明说"对机器的 ssh 访问权等于其上的 CLI 权限"——
以及收回访问权，收在这套设计围绕的泄露场景上：数据根备份泄露是一次针对其中模型 key 的凭据轮换事件，
而不是会话伪造事件。底层机制（令牌格式、磁盘清单、网络暴露面）集中在文末备查。
