# 插件市场按应用商店的样子列出插件：每个插件一个页面，安装在它的按钮上进行

- **Date:** 2026-11-27
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`

[English](2026-11-27-plugin-market-layout.md)

参照大家熟悉的应用商店，重排了插件市场的布局与安装流程：以图标为首的紧凑卡片，每个插件一个自己的页面，安装在插件的按钮上就地进行，安装中要做的决定一页一页地问。

## 细节

- 16:9 封面卡片换成以图标为首的商店卡片：插件图标、名称、两行描述、一行简短信息，卡底是唯一的安装按钮，卡片之间留出更宽的间距。列表视图改为每个插件一行、以分隔线隔开，放得下时并排两行。封面移到插件页。
- 每个插件有了自己的页面 `/plugins/<插件名>`（机器上的卡片另带 `?machine=<机器 id>`）：头部是图标、名称、一句话简介、作者、版本与标签，头部右侧是安装按钮与快速开始，「更多」菜单里是停用服务端模块、从服务端卸载与导出；封面排在图片的首位，事实栏新增「更新时间」。头部滚出视野后，顶部固定一条带同一个按钮的窄栏。旧的详情地址 `/plugins?plugin=<插件名>` 会打开这个页面；「返回」回到市场原来的标签、搜索与滚动位置。
- 安装按钮就地承载安装：服务端安装进行中时，按钮显示当前步骤并在底边带分段进度条，插件图标套上安装圆环，装好后变为下一步操作（安装、打开、N 个 Agent 已装、更新或重试）。按钮在各状态下宽度不变。进行中的安装由页面加载保存，在网格、插件页与 Agent 的「插件」页之间切换都不中断；在 Agent 的「插件」页，插件包更新会在那一行的按钮上显示当前步骤。
- 安装面板改为安装步骤：一个对话框里的几页——装到服务器、选择智能体、完成——带步骤指示、「上一步」与「下一步」，只列这次安装会经过的页；成员请管理员安装时只有一页。插件包更新在确认之后改为在按钮上进行，不再在确认框里等待。
- 「全部」标签按当前分组分节，每节两行卡片并带「查看全部」；新增「已安装」视图（`?view=installed`，由页头的「已安装」打开），列出在用的插件，可更新的在前，并带「全部更新」。
- 「用 AI 修复」移到说明当前构建无法完整运行该插件的提示条旁。
- 共享 UI 包新增 `InstallButton`、`StepIndicator`、`StoreCard` 与 `StoreGrid`，`ProductGallery` 新增首位图片 `lead`，组件画廊为它们各加了样例。
