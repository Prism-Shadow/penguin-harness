# 模型卡片上的价格色点

- **Date:** 2026-10-10
- **Type:** feature
- **Scope:** `web`, `ui`

[English](2026-10-10-model-price-heat.md)

模型页的每张卡片在第三行开头加了一枚色点，按模型的价格沿一条由冷（便宜）到热（昂贵）的连续色阶着色，扫一眼列表就能看出价格高低，不必逐个读数字。价格移到了该行行首、紧跟色点，排在上下文与 key 状态之前。

## 细节

- 色点编码的是每百万 Token 的综合单价：（缓存未命中价 × 3 + 输出价）÷ 4，取当前实际计费价，即牌价扣除进行中的促销与当前生效的空闲时段优惠。这正是卡片印出的价格，每到整点重新读取，所以 DeepSeek 一行的价格减半时，色点同一时刻变冷。人民币价格按美元比较，显示币种只改变数字。
- 色阶为对数刻度、固定区间：每百万 Token 0.125 美元为最冷端，32 美元为最热端，区间外取端点色。因此同一种颜色无论搜索、分组折叠或 Project 如何，都代表同样的价格。
- 悬停色点时显示综合单价与一个档位词：低于 0.5 美元为「低」，至 2 美元为「中等」，至 8 美元为「高」，8 美元及以上为「很高」。免费模型（「免费」徽标即其标记）与未填价格的模型没有色点。
- 页头标题旁的「?」对所有用户给出图例（成员先看到只读说明）：色点编码的内容、以阶梯色块条呈现的色阶及其上方的四个档位词，以及按显示币种标出的两端与中点价格。
- 共享 UI 包新增热力色阶：每个主题、每种模式各四个色标（`--ui-heat-1` … `--ui-heat-4`：蓝灰、青、古铜、橙，桥接为 `bg-heat-1` … `bg-heat-4`），在两色标之间按 OKLCH 混色的 `heatColor(t)`，以及 `HeatDot`。三套主题、两种模式下，色阶上每一点在画布、卡片底色与卡片悬停底色上都不低于 3:1，最热一端保持橙色，远离危险色的红。组件库的颜色基础页展示了这条色阶。
