# 自定义背景图片

Date: 2026-10-14
Type: feature
Scope: web, ui
PR: [#1126](https://github.com/Prism-Shadow/penguin-harness/pull/1126)

[English](./2026-10-14-custom-background.md)

设置 → 外观现在支持选择本地背景图片。选好图片后显示预览、透明度滑块、显示方式和对齐选项，调整即时生效，并保存在当前浏览器或桌面端。

## 控件

- 支持铺满、适应、平铺或按存储尺寸显示，并提供九个对齐位置。
- 可在同一行更换或移除图片，移除后恢复主题原有背景。
- 左侧菜单栏和手机顶部菜单栏呈现半透明毛玻璃效果；系统开启减少透明度时，保留不透明底色。
- 聊天输入区、停靠面板和浏览器工具栏可透出背景。卡片、表格和统计统一保留轻微底色，覆盖首页和机器列表，面板放大后保持同一张背景。
- 启用背景图片时，运行、思考和工具调用行不再填充底色，并随内容滚动。时间轴标签保持透底，缩放后的色条裁切在标签列之外。
- 搜索框、次要按钮、停靠标签和分段筛选统一使用半透明底色及轻微悬停反馈，首页 Agent 和工作区选择按钮遵循同一规则。机器、智能体、模型、插件、成本与评估卡片共用 UI 库的卡片底色，分组中的插件行不再叠加一层填充。
- 背景预览与上下设置行连续衔接，不再出现多余的内侧圆角。
- 支持最大 20 MB 的 PNG、JPEG 和 WebP 图片，在本地缩放、压缩，不会上传。弹窗、编辑器和终端保留各自的底色。
