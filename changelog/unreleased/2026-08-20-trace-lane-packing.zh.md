# 轨迹时间线将同名工具调用合并到共享行

- **Date:** 2026-08-20
- **Type:** feature
- **Scope:** `web`
- **PR:** [#362](https://github.com/Prism-Shadow/penguin-harness/pull/362)

[English](2026-08-20-trace-lane-packing.md)

缩短了轨迹观测时间线的高度:同名工具且时间区间互不重叠的工具调用现在共享一行,不再每次调用各占一行,连续串行调用同一工具(如一长串 `exec_command` 或 `read_file`)从 N 行收敛为一行。只有不同名工具、或同名但时间重叠(并行执行)的调用才另起新行。

## 细节

- 按工具名做贪心 first-fit 装箱(`lane-packing.ts`):调用按开始时间依次放入该名字下第一个空闲的行;端点相接不算重叠。行内永不混入不同工具名,同名的多行保持相邻,名字按各自最早调用时间排序。
- 仍在运行的调用会占用其所在行直到 Task 结束,同名的后续调用会另起新行,不会叠画在其上。
- 条形渲染、悬停/点击高亮、与事件列表的联动、缩放/平移行为均未改动,只改变了行的分配。
