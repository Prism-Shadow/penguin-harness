# 共享 UI 包与落地页去掉 AI 味

- **Date:** 2026-11-02
- **Type:** fix
- **Scope:** `ui`, `landing`, `web`, `docs`, `skills`
- **PR:** [#1423](https://github.com/Prism-Shadow/penguin-harness/pull/1423)

[English](2026-11-02-penguin-ui-deslop.md)

按产品负责人的 AI 味清单清理了公开站点共用的组件和落地页现有页面，去 AI 味检查学会了能机械判定的几条，落地页的首个代码块也变轻了。

## 共享 UI 包

- 文档站侧栏的分组标签与目录标题改为常规大小写、不加字距，并不再挂应用的眉题钩子，画廊切换主题时不会改动它们。
- 站点胶囊与搜索框快捷键提示由 11px、10px 改为 12px；实色胶囊只保留底色，去掉同色调描边。
- 语言菜单按钮去掉下拉小箭头；GitHub 链接的名称改为「GitHub, 3,111 stars」。
- `SiteCodeCard` 拆到单独的模块（`site-code-card.tsx`，仍由 `@prismshadow/penguin-ui/site` 导出），只放命令卡片的页面不再在首个代码块里带上正文代码块和语法表。
- `tokens.ts` 加载时计算的几个值标为纯计算，用不到它们的打包产物会把它们去掉。

## 去 AI 味检查

- 规则 8 识别任意粗细的彩色左边框，包括品牌色阶和样式表里的 `border-left`。
- 规则 14 识别正值的字面字距类与 `letter-spacing`，公开站点的规则不再借用应用的眉题钩子过关。
- 新增规则 23：文字不小于 12px，类名、样式表的 `font-size` 与 SVG 的 `fontSize` 都查。统计图标记的 9px、11px 标签列入白名单。
- 新增规则 24：同一行的几项之间不用中圆点，查词典与单独成段的文本子节点。Web App 现有的中圆点列入白名单，归 W10 清理。
- `packages/landing/test/deslop.test.ts` 用规则 2、8、13、14、21、23、24 检查落地页。

## 落地页

- 页面滚动时各节不再淡入上滑；背景光斑只靠 `transform` 移动。
- 没有小于 12px 的文字，`text-[13px]`、`text-[1.7rem]` 这类字面字号改为字阶里的字号；AMSP 页的主标题小一档，名称不再给每个首字母上色。
- 下载页去掉「下载」标题上方的「下载」眉标，快速开始的步骤标签不再是大写品牌色小字。
- 条目之间的中圆点改为留白或句内标点：平台列表、Benchmark 脚注、页脚版权（文档站与画廊同步）、文章日期与分类，以及 AMSP 页的读数。
- Benchmark 柱状图从零起画，每根柱子以徽标标明（下方表格写全每一行），并按显示宽度排版；自进化趋势图同样按显示宽度排版。
- 两段演示视频的说明改为灰色的运行花费；复述视频内容的说明与趋势图下方的注释已删除。A2APP 的需求原文改用正文字体。
- 箭头悬停不再位移，浏览器框去掉三个窗口圆点，页尾行动号召去掉边框，AMSP 记录列表去掉彩色边线，首页深色模式下的卡片改为实色。
