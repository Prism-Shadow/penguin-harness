# 约定俗成的图形标记不再带仅复述其动作的悬停提示

- **Date:** 2026-10-02
- **Type:** fix
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#952](https://github.com/Prism-Shadow/penguin-harness/pull/952)

[English](2026-10-02-redundant-tooltips.md)

标题旁用于展开说明的圆圈「?」（`InfoPopover`，以及所有经 `info` 用到它的字段、行、卡片、页面与对话框）悬停时不再显示「说明」提示：标记紧挨着标题，本身已说明它是什么，点击即展开说明。同一规则应用到 Web App 中无需提示即可读懂的标记——侧栏分组的折叠 chevron、搜索框的清除 ×、密码横幅与内置浏览器标签页的关闭 ×、工单的子工单折叠 chevron——以及复述屏幕上已有文字的提示（目标预算字段下方已有的说明段落、标题栏的「运行中」、三个复述自身字段标签的选择器）。它们都保留 `aria-label`。

## 细节

- Session 行的 ⋯ 按钮改名为「更多操作」，不再是「更多」。
- 公司模式中被截断的工单、收件箱与会话标题，提示改为完整标题（需要时附 id），不再是「打开工单」/「打开会话」；记忆变更卡片的行提示完整路径，评估运行的模型单元格提示 `provider/model`。
- 删除了十余个只能复述自身可见文字、从未显示过的 `data-tooltip`。
- 画廊的面包屑在被截断时提示地址本身，而非复制动作。
