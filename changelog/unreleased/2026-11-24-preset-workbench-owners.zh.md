# 将客服与自进化工作台预装到各自的智能体

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** Core, Web App, UI Gallery
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1812

[English](2026-11-24-preset-workbench-owners.md)

新建 Project 时，自进化工作台预装在默认智能体，默认 Project 的客服工作台预装在 PenguinHarness Support。两者使用应用中心的智能体工作台菜单，可隐藏或移除。可移除工作台的插件卡片省去「内置」标识。将自进化工作台添加到主屏幕时，图标与应用中心一致。
