# 插件安装链的镜像改走 Settings 页，不再是部署配置

- **日期：** 2026-11-17
- **类型：** change
- **范围：** `server`

发布索引的 CDN 镜像此前是一个部署侧环境变量，装一份改写规则的 JSON 数组——用户够不着的形状、也不该让用户去写的格式。现在镜像改成一个设置组，落在 Settings 对话框的 Plugins 页（插件镜像）：一份本构建已知的镜像清单，按所选顺序排在源自己的地址之后尝试，内置规则把两处取数的地址映射到每个镜像自己的形状。默认不带任何镜像：只走源自己的地址。改动即时生效，无需重启。

镜像供给的一切都按源地址同样的方式校验——索引文档走同一个解析器、每个 release 资产照条目的 sha512 核对、npm 安装完成后照 npm 自己的安装记录事后核验——镜像带来的只可能是一次取数失败，不会是被篡改的字节。规则是本构建自己的、固定的形状；用户手写的模式永远不会跑到取数上。

环境变量与部署级规则清单已移除：镜像是一个用户做的服务选择，不是部署配置。npm 从哪里取包本身仍由旁边的 Plugin sources 组管。
