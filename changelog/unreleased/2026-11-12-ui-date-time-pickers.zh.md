# 共享 UI 包新增日期与时间选择器

- **Date:** 2026-11-12
- **Type:** feature
- **Scope:** `ui`, `ui-gallery`, `web`
- **PR:** [#1547](https://github.com/Prism-Shadow/penguin-harness/pull/1547)

[English](2026-11-12-ui-date-time-pickers.md)

共享 UI 包（`@prismshadow/penguin-ui`）新增四个选择器字段——`DateField`、`TimeField`、`DateTimeField` 与 `DateRangeField`——日历参照 Material 3 的 date pickers，时间为 iOS 式滚轮。写出的值与原生输入框相同（`YYYY-MM-DD`、`HH:mm`、`YYYY-MM-DDTHH:mm`，本地时间、不带时区），调用方把原生输入框换成它们时，存储的内容不变。组件画廊的「输入与表单」页以它们取代了原生输入框。

## 细节

- **字段**沿用共享的控件外观，与同档的 Input、Select 同高、同焦点环，按读者的语言区域书写值：2026年11月12日 / Nov 12, 2026，14:30 / 2:30 PM，区间写作两个完整日期，2026年11月1日-2026年11月16日 / Nov 1, 2026 – Nov 16, 2026。未选时显示占位文字；非必填且有值时，以清除叉号代替日历或时钟标记；必填、校验失败与禁用的状态与其他字段一致。传入 `name` 时，值同时写进一个隐藏输入框随表单提交。
- **日历**为 Material 3 的 docked 形态：在字段下方的浮层中打开（下方放不下时在上方），经 portal 盖在对话框与对话记录之上；窄于 640px 时为 Material 3 的 modal 形态——贴底的全宽面板，下衬遮罩，顶部写出字段标题。按语言区域排列星期，只写一个字（zh-CN 周一在前：一 二 …；en-US 周日在前：S M …），悬停显示全称；固定六周、高度不变；日期格取主题的控件形状（白领为圆盘，极客为方块），选中日以强调色填充，今天以强调色文字加一圈细线标出，`min` / `max` 之外的日期变淡且不可选；表头为年份与月份两个菜单按钮（先后随语言区域）、‹ › 翻月与「今天」。点菜单按钮，网格原处换成三列的月份或年份菜单，当前项以强调色填充；点选即回到网格，再点该按钮则原样收起。翻到的新月份按主题的显现动效出现。浮层沿用各主题自己的底色、圆角、描边、阴影、字号、悬停与焦点环，不取 Material 3 的色调容器、大圆角、涟漪与大号标题。
- **滚轮**用于小时、分钟，以及 12 小时制的上午/下午：鼠标滚轮每格移动一行（触控板每滑过一行的高度移动一行），也可点按某一行或拖动，手指滑动时为带吸附的原生滚动，且都不会带动背后的页面滚动；分钟步长（1、5、15）决定分钟行。键入数字即跳到对应的值，无法再输入更长的值时焦点移到下一个滚轮，因此输入「1430」即为 14:30；Enter 或「完成」关闭浮层。日期时间字段在日历下方放一行时间与「完成」，点时间胶囊换出滚轮。
- **区间字段**的日历上方有一行标题，写出当前区间，尚未点选的一端写「开始日期」或「结束日期」。两次点按选定两端、先后不限，两端之间的日期铺一条平色带，第三次点按重新开始；「确定」写入区间并关闭浮层，「取消」、Esc 与点外部都不写入。打开时显示区间结束日所在的月份；不带快捷区间，预设由调用方自己的控件承担。
- **键盘与辅助技术**：字段是一个按钮，以标题和值命名，打开一个有名称的对话框；网格遵循 ARIA 日期网格模式（方向键、Home / End、Page Up / Page Down，加 Shift 为一年、Enter）；月份与年份菜单是 listbox（方向键、Home / End、Enter 或空格）；每个时间滚轮是一个 spin button（↑ / ↓、Page Up / Page Down、Home / End、键入数字或字母、Enter）；清除叉号的点按区域不小于 24px；Esc 关闭浮层且不关闭外层对话框，焦点回到字段。
- 日期按日历日本身计算，从不经过读者所在时区，因此在格林尼治以西或跨夏令时都不会错一天。文案与语言区域来自 `UiStrings` 新增的 `dates` 组，Web App 从中英两份词典填入。
