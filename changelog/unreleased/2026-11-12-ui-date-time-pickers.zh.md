# 共享 UI 包新增仿 iOS 的日期与时间选择器

- **Date:** 2026-11-12
- **Type:** feature
- **Scope:** `ui`, `ui-gallery`, `web`

[English](2026-11-12-ui-date-time-pickers.md)

共享 UI 包（`@prismshadow/penguin-ui`）新增四个仿 iOS 日历与滚轮的选择器字段——`DateField`、`TimeField`、`DateTimeField` 与 `DateRangeField`——写出的值与原生输入框相同（`YYYY-MM-DD`、`HH:mm`、`YYYY-MM-DDTHH:mm`，本地时间、不带时区），调用方把原生输入框换成它们时，存储的内容不变。组件画廊的「输入与表单」页以它们取代了原生输入框。

## 细节

- **字段**沿用共享的控件外观，与同档的 Input、Select 同高、同焦点环，按读者的语言区域书写值：2026年11月12日 / Nov 12, 2026，14:30 / 2:30 PM，区间写作 2026年11月1日至12日 / Nov 1 – 12, 2026。未选时显示占位文字；非必填且有值时，以清除叉号代替日历或时钟标记；必填、校验失败与禁用的状态与其他字段一致。传入 `name` 时，值同时写进一个隐藏输入框随表单提交。
- **日历**在字段下方的浮层中打开（下方放不下时在上方，窄于 640px 时为贴底的全宽面板），经 portal 盖在对话框与对话记录之上：按语言区域排列星期（zh-CN 周一在前，en-US 周日在前），固定六周、高度不变；选中日为强调色圆盘，今天以强调色文字加一圈细线标出，`min` / `max` 之外的日期变淡且不可选；有 ‹ › 翻月与「今天」。点按月份标题，网格换成月份与年份滚轮。翻到的新月份按主题的显现动效出现。
- **滚轮**用于小时、分钟，以及 12 小时制的上午/下午：滚动带吸附，支持鼠标滚轮与鼠标拖动，停在色带中的那一行即为取值；分钟步长（1、5、15）决定分钟行。日期时间字段在日历下方放一行时间，点其胶囊换出滚轮；区间字段两次点按、先后不限，两端之间的日期铺一条平色带，并把调用方给的快捷区间显示为选项片。
- **键盘与辅助技术**：字段是一个按钮，以标题和值命名，打开一个有名称的对话框；网格遵循 ARIA 日期网格模式（方向键、Home / End、Page Up / Page Down，加 Shift 为一年、Enter）；每个滚轮是一个 spin button（↑ / ↓、Page Up / Page Down、Home / End、键入数字或字母）；Esc 关闭浮层且不关闭外层对话框，焦点回到字段。
- 日期按日历日本身计算，从不经过读者所在时区，因此在格林尼治以西或跨夏令时都不会错一天。文案与语言区域来自 `UiStrings` 新增的 `dates` 组，Web App 从中英两份词典填入。
