# A2UI 统计图与系统资源组件块，以及基于基础统计图重建的数据小组件

- **Date:** 2026-10-19
- **Type:** feature
- **Scope:** `ui`, `web`, `ui-gallery`
- **PR:** [#1238](https://github.com/Prism-Shadow/penguin-harness/pull/1238)

[English](2026-10-19-a2ui-chart-blocks.md)

回复中可以绘制 `chart` 与 `resources` 组件块，指标与天气小组件也改为基于同一套基础统计图重建，单独的统计图、统计图组件块与组合小组件共用一套绘制。

## 渲染

- 统计图组件块经基础统计图绘制每一种图：折线与面积用 `LineChart`；柱状用 `BarChart`，横向时用 `HBarChart`，其中堆叠图每个类别一行，行末写出合计；直方图画成无间隙的柱，分箱标签形如「0–10 ms」；饼图用 `PieChart`；散点图用 `ScatterChart`；仪表画成单独的一个指标块。各系列依次取图表配色，数值带单位与小数位输出，并以数据摘要作为图表的无障碍名称。
- 系统资源组件块为每个读数（CPU、内存、交换分区、负载、运行时间）画一个指标块，按固定阈值着色；磁盘画成 0–100% 刻度上的横条；网络画成接收与发送速率的折线，下方注明读数次数。
- 指标块中凡是相对于总量的读数都经 `Gauge` 绘制，外观不变。天气卡片的逐小时部分是简洁框架的 `LineChart`，每日各行是 `HBarChart` 的区间横条，粗细由 4 px 改为 6 px，并采用主题的横条样式。
- 小组件内的列表不再继承回复正文的列表缩进。
- UI 字符串与 Web App 的中英文词典新增统计图摘要与系统资源组件所用的文字。

## 组件画廊

- A2UI 回复页展示一个柱状图和一个系统资源面板，其中的指标示例改为 API 配额、预算、带历史的测试运行与延迟。
