# Gemini 4 Hydrogen and seven tool models in Penguin Go

- **Date:** 2026-11-21
- **Type:** feature
- **Scope:** `model-catalog`

[中文](2026-11-21-penguin-go-model-presets.zh.md)

The Penguin Go preset group includes Gemini 4 Hydrogen for chat. Gemini 3.1 Flash Image generates images, Gemini Omni 1.2 Flash generates video, Gemini 3.8 Flash TTS and DeepSeek TTS synthesize speech, and DeepSeek ASR, Search and Fetch handle transcription, search and page reading.

Existing Projects can import these presets with **Add new models** in the model library.
