# 图像工作室和项目多模态工具

- **Date:** 2026-11-18
- **Type:** feature
- **Scope:** `plugins`, `multimodal-tools`
- **PR:** [#1599](https://github.com/Prism-Shadow/penguin-harness/pull/1599)

[English](2026-11-18-image-studio.md)

从应用中心或智能体标签页打开图像工作室，描述图片，选择画幅。每次生成都有独立会话，由智能体调用项目绑定的图像模型。在历史记录中重新打开创作，可以预览、下载该会话生成的图片，也能查看失败或取消的记录。

项目关闭生图插件后，仍可查看和下载已有作品。重新启用插件即可继续创作。

新建项目的默认智能体自带多模态工具技能。它能通过 Penguin 命令行搜索和读取网页、生成图片或视频、转写录音、合成语音。现有智能体可以从「实用工具」中安装。
