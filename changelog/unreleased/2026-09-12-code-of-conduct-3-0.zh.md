# 行为准则升级到贡献者公约 3.0

- **Date:** 2026-09-12
- **Type:** process
- **Scope:** `docs`
- **PR:** [#704](https://github.com/Prism-Shadow/penguin-harness/pull/704)

[English](2026-09-12-code-of-conduct-3-0.md)

## 细节

- `.github/CODE_OF_CONDUCT.md` 与其中文版改用贡献者公约 3.0，取代 2.1，两份都取自该公约自己发布
  的正文——英文取自 [version/3/0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)，
  中文取自[官方 zh-cn 译本](https://www.contributor-covenant.org/zh-cn/version/3/0/code_of_conduct/)，
  而不是我们自行翻译。两份一起升级：行为准则是治理文件，让两种语言停留在不同版本，等于读者受哪套
  规则约束取决于他打开的是哪个文件。
- 3.0 重组了整份文档。「我们的准则」拆成**受鼓励的行为**与**受限制的行为**（另有 2.1 没有对应内容
  的**其他限制行为**）；「执行」与「处理方针」变为**通报问题**与**处理与弥补伤害**；「责任和权力」
  一节不再存在。四级处理阶梯保留但改了名称——警告、暂时限制活动、暂时停权、永久封禁——且每一级除
  后果之外，还明确写出对当事人**弥补**方式的期待。
- 举报入口不变：在 Discord 上私信维护者。3.0 把这里留为采用方占位符，填入的就是 2.1 已有的说法。
- 3.0 的第二个占位符——提示采用方「若已有既定流程请改写本节」的那段方括号注释——不予保留。本项目没
  有另设流程，这套阶梯就是政策本身；把写给自己的备注留在一份约束社区的文件里并不合适。
- 归属声明随版本变更：3.0 由 Organization for Ethical Source 维护、以 CC BY-SA 4.0 发布，取代 2.1
  的归属声明。许可协议正文的链接予以保留——CC BY-SA 4.0 要求引用它的改编作品附上该链接。FAQ、资源
  两处链接与对 Mozilla 处理阶梯的致谢则不再保留：3.0 其实仍然带有这三项，但它们指向公约自身的材料，
  并非本项目读者所受约束的条款。
