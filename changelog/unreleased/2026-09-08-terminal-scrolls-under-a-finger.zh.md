# 手指可以滚动被程序接管的终端

- **Date:** 2026-09-08
- **Type:** fix
- **Scope:** `web`

[English](2026-09-08-terminal-scrolls-under-a-finger.md)

手机上的终端，只有在里面没跑东西时才能用手指滚动。一旦某个全屏程序接管了鼠标——Claude Code 就是这样，所有同类 TUI 也是——拖动就失效了：xterm 恰恰对这类程序关掉了自己的触摸滚动，而它们才是最需要滚动的。Claude Code 画在备用屏（alternate screen）上，那里终端根本没有回滚缓冲，转录由它自己保存，也只有在收到滚轮上报时才移动。手机没有滚轮，于是最新一行以上的内容全都够不着。

现在单指拖动就是那个滚轮：拖动的位移在手指位置上变成 wheel 事件，经由 xterm 分发，因而会按程序实际开启的鼠标协议编码；每移动一行的高度滚一行——转录跟着手指走，而不是被甩出去。点按仍然是点按：位移超过阈值之前什么都不滚，因此「点按即点击」照样能送达会响应点击的程序。鼠标没有被接管时，xterm 自己的触摸滚动原样保留，滚的仍是回滚缓冲。

终端也不再把这个手势交给浏览器（触摸设备上给终端表面加 `touch-action: none`）：一旦浏览器认定这是页面滚动或下拉刷新，手势中途就不再可取消，终端也就把它丢了。
