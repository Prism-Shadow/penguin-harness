# 优化官网主页层级与下载体验

- **Date:** 2026-08-27
- **Type:** fix
- **Scope:** `landing`, `docs`

[English](2026-08-27-landing-homepage-refinement.md)

在不删除原有产品章节的前提下重新整理官网主页，并让桌面端下载选项更易浏览。

## 细节

- 恢复首页完整章节编排，将一句话生成应用的案例视频移到首屏之后，同时保留三大特色、LangChain 对比、应用场景、评测、契约、产品功能、Skills、安全与社区章节。
- 围绕 PenguinHarness 名称与精简的开源、本地优先定位重新整理首屏，保留顶部公告横幅，并恢复线上旧版的紧凑高度与特点字号；保持中英文主文案单行展示，将版本号放入更窄的桌面端下载按钮，恢复仅变色且无垂直位移的悬停反馈，并以间距更舒展、整体居中的八个纯品牌标志展示模型支持范围。
- 在三个产品截图标签下恢复智能体仓库、技能库、定时任务、子 Agent、成本中心与多用户管理六张首页能力卡片。
- 在进化流程图与趋势卡片下恢复中英文自我进化演示视频，包括对应海报与完整一轮的说明文字。
- 修正 LangChain 对比动画，让左右两种构建方式按同一周期重置，并让人工构建侧从底部开始逐块垒起。
- 精简官网与文档导航，移除“案例”快捷入口并将自进化章节归入“特色”，同时保留首页中的完整章节内容。
- 在官网与文档导航中加入实时 GitHub 星标数量，并在数量加载期间使用中性的短横线代替星形图案。
- 将下载源测速报告压缩为带手机信号格的两行手动选择器，让两个下载源在完成测速前即可手动选择，复用 ZCode 的彩色 macOS、Windows 与 Linux 标志，在每个平台卡片右上角显示版本号胶囊，并保留下载操作中的安装包后缀。
- 将快速开始拆分为安装与启动两步，仅在命令行安装后展示 Web UI 与 CLI 启动选项，并为 Linux、macOS 与 Windows 的全部离线包补充 Release 制品直链。
- 在离线安装包对应位置上方为命令安装明确标注“在线安装”，并重写两个生产应用场景，突出团队使用 PenguinHarness 自动开发 Agent 后再部署到生产环境的过程。
- 删除桌面端下载页的介绍段落，将英文 `agent` 文案统一为小写，并让导航与首屏主要操作保持单行显示。
