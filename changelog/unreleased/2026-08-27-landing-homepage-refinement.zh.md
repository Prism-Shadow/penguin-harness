# 优化官网主页层级与下载体验

- **Date:** 2026-08-27
- **Type:** fix
- **Scope:** `landing`, `docs`

[English](2026-08-27-landing-homepage-refinement.md)

在不删除原有产品章节的前提下重新整理官网主页，并让桌面端下载选项更易浏览。

## 细节

- 恢复首页完整章节编排，将一句话生成应用的案例视频移到首屏之后，同时保留三大特色、LangChain 对比、应用场景、评测、契约、产品功能、Skills、安全与社区章节。
- 围绕 PenguinHarness 名称与精简的开源、本地优先定位重做首屏，并排展示桌面端下载与命令行安装按钮，在按钮下标注版本号，同时保留四项紧凑的产品特点。
- 在官网与文档导航中加入实时 GitHub 星标数量。
- 将下载源测速报告压缩为带手机信号格的两行手动选择器，复用 ZCode 的彩色 macOS、Windows 与 Linux 标志，并为所有下载操作补充版本号与安装包后缀。
