# Install the Support and Self-Evolution workbenches on their owning Agents

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** Core, Web App, UI Gallery

[中文版](2026-11-24-preset-workbench-owners.zh.md)

New Projects install the Self-Evolution Workbench on the default Agent. The default Project installs the Support workbench on PenguinHarness Support. The App Center shows their Agent workbench controls, including hiding and removal. Plugin cards for removable workbenches omit the built-in badge.
