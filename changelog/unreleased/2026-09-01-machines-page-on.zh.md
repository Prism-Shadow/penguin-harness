# Machines 页面正式放开

- **Date:** 2026-09-01
- **Type:** feature
- **Scope:** `web`
- **PR:** [#577](https://github.com/Prism-Shadow/penguin-harness/pull/577)

[English](2026-09-01-machines-page-on.md)

两处改动，让前面整条栈建起来的功能变得可达：

- Machines 页面在 web 清单里的条目标为已发布，侧边栏对管理员显示这一行——清单早就为此留着这道闸。它的路由一直挂着，此前缺的只是入口。
- 侧边栏的**新建工作区**选择器给出机器那一行，于是工作区可以建在某台机器上，而不只是本机。

这两处所展示的东西此前都已经写好也测过，缺的只是入口。把它单独留成一个改动，是为了让「放开这个功能」成为一个有日期的决定，与让它成为可能的代码分开——也为了万一要收回去，那是回退几行，而不是回退一个功能。

两处入口实际上都只对管理员生效：它们读的那个列表对其他人一律 `403`，而非管理员直接敲 URL 进来，会拿到页面自己的拒绝。
