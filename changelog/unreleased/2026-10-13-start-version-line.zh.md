# 应用首页：版本行在任何宽度下都位于副标题之下

- **Date:** 2026-10-13
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1102](https://github.com/Prism-Shadow/penguin-harness/pull/1102)

[English](2026-10-13-start-version-line.md)

应用首页的版本行（「v0.2.15 · 最近更新日期 10月13日」，有新版本时后面跟着更新提示）在任何窗口宽度下都排在同一个位置：副标题之下，与产品名左对齐。

## 细节

- Logo 与右侧产品名、副标题、版本行的总高度对齐；窄屏下限制最大尺寸，为换行后的文字留出空间。
- 统计面板与品牌区同排时，版本行延伸到面板下方，连同更新提示始终排成一行。此前它在一些宽度下跟在产品名后面，在另一些宽度下落到产品名下方，还可能在「最近更新日期」之后断开，或者让更新提示单独占一行。
- 手机上一行排不下时，只在短语之间换行：更新提示先整体移到下一行，其次是日期。应用信息弹窗里的版本行按同样的规则换行。
- 手机上使用特大字号时，产品名在 Penguin 与 Harness 之间换行，页面不再被撑出横向滚动。
