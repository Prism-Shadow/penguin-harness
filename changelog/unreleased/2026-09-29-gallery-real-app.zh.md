# 画廊改为框住真实的 Web App

- **Date:** 2026-09-29
- **Type:** process
- **Scope:** `ui-gallery`, `ui`, `web`, `landing`
- **PR:** [#892](https://github.com/Prism-Shadow/penguin-harness/pull/892)

[English](2026-09-29-gallery-real-app.md)

画廊过去用替身合成重搭应用界面，与真实界面越走越远。现在它直接在框中挂载 Web App 本身，接一个浏览器内的演示 API，仍是无需服务端的静态站点。

## 画廊展示什么

- 首页就是可完整点击的真实应用。每个界面——对话（空闲、运行中、思考中、等待审批）、新对话、智能体及其设置、定时任务、插件市场、模型库、机器、成本中心、评估中心、设置（含外观）与登录——各有一页。
- 演示数据包括已登录的管理员、带智能体与 Session 的 Project、运行中的工具调用与思考、取自内置目录的模型、插件、用量、评估与定时任务，中英文各一套。发送消息会流式返回预设回复；需要真实服务端的操作会给出只读提示。终端不可用。
- 顶栏收为一行：主题、语言与明暗留在栏上，强调色、字号、带标签的英文与中文字体选择以及视口收进弹出面板。它们通过应用自身读取的同一组偏好驱动框内应用；面板同时标明实际渲染的英文、中文与等宽字体，以及以像素计的字号。
- 画廊的下拉选择与悬停提示沿用应用自己的样式，深色模式与落地页共用同一套中性配色。

## 细节

- `packages/ui` 中的替身模块、界面、首屏与模拟数据已删除，画廊的 `/embed` 与 `/screens` 路由一并移除；基础令牌展板与字体页保留。
- Web App 为此加了两个小接口：`App` 可接收初始路由，设置对话框可按请求直接打开到指定页。
