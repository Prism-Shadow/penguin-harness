# Markdown 阅读器带目录与页内查找；手册改用文件浏览面板的框架

- **Date:** 2026-10-15
- **Type:** feature
- **Scope:** `ui`, `web`, `ui-gallery`

[English](2026-10-15-markdown-reader.md)

插件详情（README 与文件浏览器的预览）、Benchmark 题目对话框、文件浏览面板的预览与组织手册里的 Markdown 文档，改由共享 UI 包里的同一个 Markdown 阅读器呈现，并新增目录与页内查找。手册的浏览界面改用 Workspace 文件浏览面板的框架重建。

## 细节

- **目录**：文档有两个及以上标题（h1–h4）时附目录——阅读器宽度不少于 720px 时为正文旁的目录栏，否则收进阅读器工具钮弹出的列表。点击条目在阅读器自己的滚动框内滚到该标题，当前小节随滚动高亮。
- **页内查找**：点工具钮里的查找，或焦点在阅读器内时按 `find.open`（缺省 Mod+F），打开只查渲染后正文的查找框：大小写无关，高亮全部命中，显示「序号/总数」，输入即定位到第一处，Enter 或 ↓ 下一处、Shift+Enter 或 ↑ 上一处，首尾循环。Esc 关闭查找并清除高亮，不会传到阅读器外的对话框。焦点不在阅读器内时，该快捷键仍归页面的查找栏或浏览器。
- **插件 README**：改走共享的 Markdown 渲染管线，不再用裸渲染器，代码块带复制按钮、链接在新标签页打开，与其他 Markdown 界面一致。
- **共享的查找机制**：文本匹配、带高亮绘制的 DOM 索引与查找栏的控件行移入 `@prismshadow/penguin-ui`；`lib/find-text.ts` 与 `lib/find-dom.ts` 改为转导出，页面查找栏的控件行改用共享的 `FindField`。高亮按所有者分别绘制，阅读器的查找与页面查找栏各自保留自己的标记；高亮颜色取主题的 info 色调，公式隐藏的 MathML 副本不再参与查找。
- **手册**：树窗格有按路径过滤的搜索框，以及「新建文档」「全部折叠」两枚操作；工具栏依次为目录树开关、文档的面包屑、索引标记、修改时间与文档操作（删除；编辑时为取消与保存）；分隔条调整树宽，窄于 480px 时单栏显示树或文档并可返回。「编辑」打开文件浏览面板的就地编辑器，保存写回文件后回到阅读。目录树的显隐与宽度只在本页内保持。
- **文件浏览框架**：文件浏览面板的工具栏行、两栏布局与树宽规则移入 `@prismshadow/penguin-ui`（`FilesToolbar`、`FilesPanes`、`useFilesLayout`）；Workspace 文件浏览面板与手册都用它们布局，`lib/workspace-tree.ts` 转导出布局函数。
- **组件画廊**：内容页展示阅读器读一篇长文档的宽、窄两种形态，中英文各一份。
