# 收藏的侧栏入口不再随列表滚动，公司模式的入口也可以收藏

- **Date:** 2026-11-05
- **Type:** feature
- **Scope:** `web`, `ui`

[English](2026-11-05-sidebar-fixed-favorites.md)

「新建对话」和收藏的页面入口一起移到了 Project（公司模式为组织）切换器下方的固定块里，滚动会话列表时不再跟着滚走。可收起的入口和折叠条仍随列表滚动。公司模式的六个入口也能以同样的方式收藏。

## 细节

- 固定块内各行的间距与收起区里行与行的间距相同，「新建对话」下方多出的空隙没有了；固定块与列表之间的间距不变。
- 窗口或手机抽屉的高度放不下两者时，列表保留几行的高度，固定块改为在自己的区域内滚动。
- 公司模式下，星形按钮、在两区之间拖动、键盘焦点跟随移动的入口，以及折叠，都与开发模式一致。缺省不收藏任何入口，所以在收藏第一个入口之前，侧栏和以前一样。
- 公司模式的收藏按浏览器保存在 `penguin.sidebarCompanyNavPinned`，与开发模式的 `penguin.sidebarNavPinned` 分开，在一种模式里点星标不会移动另一种模式的入口。
- 还没有组织时，公司模式的六个入口保持禁用、不显示星形按钮，按已保存的选择分别留在各自的区域。
- 收起的图标栏没有变化。
- UI 包里，`SidebarFrame` 的 `pinned` 槽位放「新建对话」和收藏的入口，且不随列表滚动；`SidebarNavGroup` 不再接受 `pinned` 入口，没有可收起的入口时什么也不画。
