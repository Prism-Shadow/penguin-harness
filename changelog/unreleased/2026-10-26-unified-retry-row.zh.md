# 机器重连与模型请求重试共用一行；重连 5 次后宣告失败，可随时放弃重试

- **Date:** 2026-10-26
- **Type:** feature
- **Scope:** `core`, `server`, `web`, `ui`, `ui-gallery`, `docs`
- **PR:** [#1344](https://github.com/Prism-Shadow/penguin-harness/pull/1344)

[English](2026-10-26-unified-retry-row.md)

本服务端保持连接的机器，现在连续失败 5 次（原为 8 次）后停止自动重连并宣告失败，首次尝试前等得更久，用户也可以随时放弃重试。机器管理页、那台机器上的对话，以及对话里正在重试的模型请求，进行到哪里都只占一行：等待时为「23 秒后尝试第 4/5 次重连」或「23 秒后发起第 3/10 次请求」，「立即重试」和「放弃重试」是同一行里的链接样式文字。失败的原因收在句末的带圈问号里。

## 服务端

- 重连连续失败 5 次即停止这一轮（`reconnect.maxAttempts` 为 5）。机器断开后首次尝试前等待 15 秒，此后每次失败翻倍，不另设上限。有任务在处理的机器多久再看一次，不变。
- `POST /api/projects/:projectId/machines/:machineId/stop-reconnecting` 立即停止正在等待或正在尝试的一轮（`reconnect.gaveUp: "cancelled"`，`nextAt: null`），此后直到「重试」「启动服务」或本服务端重启都不再尝试。已在进行的那次尝试不会被打断：连上了，机器即为已连接；失败了，之后不再安排。已连接的机器、已停止的一轮不受影响。答复机器列表，或 `404` `unknown_machine`。
- 放弃重试时某次尝试仍在进行，随后再按「重试」，会把这次尝试算作新一轮的第 1 次，不再并行发起第二次。保存的密码被拒的机器，重新保存密码后会立即试一次，无论此前是否放弃过重试。

## 核心

- `@prismshadow/penguin-core/interfaces` 导出 `DEFAULT_MAX_TURN_ATTEMPTS`（10，引擎每轮尝试次数的默认上限，首次请求也算在内），给重试编号的宿主据此显示引擎自己的上限。

## 机器管理页与对话

- 卡片中段、详情弹窗的「重新连接」分节，以及机器连不上的对话里，重试行依次为：「23 秒后尝试第 4/5 次重连」，带「立即重试」与「放弃重试」；「正在尝试第 4/5 次重连」，带「放弃重试」；「5 次重连均失败」「已放弃重试」，以及重试也不会好转的 ssh 失败「重连失败，需先解决 ssh 问题」，均带「重试」；「登录被拒，已停止重连」不带任何操作。倒计时在句中逐秒刷新。
- 在卡片和对话里，上次失败的原因收在句末的带圈问号里，以「上次失败」为题；ssh 失败与密码被拒时，问号里是解决办法。详情弹窗的重试行不带问号：分节在它下面先写已持续多久，再写出完整的上次失败。
- 重连失败的机器（5 次均失败，或遇到重试也不会好转的 ssh 失败）换用新的状态胶囊「重连失败」，与重试行的叉同为危险色，卡片与详情弹窗一致；「重连已停止」改为专指用户放弃了重试，与重试行的暂停标记同为 attention 色。
- 卡片中段较窄时，两个操作一起换到句子下面。

## 模型请求的重试

- 对话里模型请求重试留下的那一行改用同一行：等待时「23 秒后发起第 3/10 次请求」，带「立即重试」与「放弃重试」；发出时「正在发起第 3/10 次请求」；发出后「已发起第 3/10 次请求」；运行在此结束时「6 次请求均失败」，带「重试」。次数计入本轮每一次请求（首次请求也算），分母是引擎的上限。两个操作的作用不变，「放弃」改称「放弃重试」。
- 原因与服务方原话收进问号，不再写在行里。

## UI 包与组件画廊

- `RetryStatus` 改为一行：标记、句子、`reason` 对应的问号（可选的 `reasonTitle` 作为面板第一行），以及链接样式的操作。新增阶段 `cancelled`（attention 色的暂停）与 `retried`（淡色的转向箭头）；`gaveUp` 改用危险色的叉。`countdown` 返回剩余秒数下的整句，`label` 是时刻到达后显示的句子，`size`（`xs` / `sm`）取代 `layout`。`RetryActions` 一律画成链接样式。
- `MachineStatusPill` 新增 `reconnectFailed` 状态（危险色）。
- 新增主题令牌 `--ui-link-decoration`，决定链接样式按钮静止时有没有下划线：Primer 与 Frost 为 `none`，Console 的链接与正文同色，为 `underline`。Console 里所有链接样式按钮因此静止时就带下划线。
- 组件画廊的「重试」主题展示两种尺寸下的机器重连阶段，以及模型请求重试的四种状态；模拟 API 也响应新路由。
