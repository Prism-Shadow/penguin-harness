# Find activity runs from the sidebar

- **Date:** 2026-09-29
- **Type:** feat
- **Scope:** `web`, `activities`

The sidebar now has a collapsed "Activity runs" folder below the session groups, in every grouping mode. It lists the loaded activity-run sessions by product code, then under their activity's name, which links back to the activity. Each run opens its transcript. Activity runs still stay out of the regular session groups, and in workspace mode their per-run workspaces no longer appear as empty groups.
