# 副标题改为「全自动优化：任意模型 任意算法 任意 Benchmark」

- **Date:** 2026-10-19
- **Type:** process
- **Scope:** `landing`, `docs`, `tooling`
- **PR:** [#1215](https://github.com/Prism-Shadow/penguin-harness/pull/1215)

[English](2026-10-19-tagline.md)

「统一、稳定的 Agent 自进化框架」下方的一行由「全自动优化模型 × Agent Harness」（英文：Automatically improve model × agent harness）改为「全自动优化：任意模型 任意算法 任意 Benchmark」（英文：Fully automatic optimization: any model, any algorithm, any benchmark）。

## 细节

- **官网。** 首屏第二行、meta 与 Open Graph 描述，以及社交分享卡片（`public/og-cover.png`，由 `scripts/og-cover.html` 重新渲染）都换成了新副标题。手机上首屏这一行只在三项之间换行，不会从某一项中间断开：中文不拆词，英文的每个 any 与其后的名词连在一起。
- **README。** 标题下的一行保留了三项内容的加粗。
- **文档。** 产品介绍的开篇段落与三大支柱上方的一句话概括都改用新副标题；在中文行文中，三项之间以顿号分隔：任意模型、任意算法、任意 Benchmark。
- **包元信息。** 根目录 `package.json` 的 description 随之更新。
