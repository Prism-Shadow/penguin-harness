# 设置与草稿随账号保存

- **Date:** 2026-10-26
- **Type:** feature
- **Scope:** `server`, `web`, `ui-gallery`, `docs`
- **PR:** [#1339](https://github.com/Prism-Shadow/penguin-harness/pull/1339)

[English](2026-10-26-settings-follow-account.md)

设置页上的偏好与 Web App 里尚未发送的草稿，从浏览器移到了服务端的账号里：在另一个浏览器或桌面应用登录同一账号，看到的是同样的主题、语言和草稿。每个浏览器仍保留一份缓存，用于首帧显示，以服务端的副本为准。升级后的浏览器会把自己原有的设置和草稿交给账号一次，详见[向后兼容](2026-10-26-backward-compatibility.zh.md)。

## 随账号保存的内容

- 偏好：主题、明暗、强调色、字号、字体、背景图片及其显示设置、终端主题、工具短名、快捷方式悬浮球开关、界面语言、货币、任务完成通知，以及输入区的运行中发送模式。工作模式、个人公司模式开关与快捷键原本就存在账号里。
- 草稿：新建对话的草稿与每个会话的输入框，连同其中选好的 Workspace、Agent、模型与审批模式；停放的草稿对话；公司模式频道的输入框；新建组织表单；回复中 A2UI 表单尚未提交的作答。
- 仍留在浏览器的：面板与文件树宽度、停靠栏布局、侧栏与分组的折叠、置顶与手工顺序、悬浮球停靠的位置、插件页「只显示不兼容的插件」的筛选、上次打开的 Project 与 Agent，以及在该浏览器里关掉的提示。

## 细节

- `ui_prefs` 增加了上述偏好键，`PUT /api/me/prefs` 会校验它们的形状。背景图片单独存放在 `user_background_images` 表中，经新增的 `GET|PUT /api/me/background-image` 读写（不超过 1 MiB 的 data URL）；`ui_prefs.backgroundImageId` 指向这张图，只有该接口会写它。
- 新增 `GET|PATCH /api/me/drafts`，数据存于 `user_drafts` 表，键的形式为 `<kind>:<id>`。单条草稿上限 256 KiB，每个账号至多 200 条、合计 4 MiB，超出时先淘汰最久未写的草稿。删除 Session、Agent 或 Project 时，所有用户关于它的草稿一并删除。两张表由迁移 `2026-10-26-user-drafts` 新增。
- Web App 在渲染登录后的界面之前，先读取账号的偏好与草稿，等待时间有上限。改动立即写入浏览器缓存，随后合批发到服务端，多个浏览器之间以最后一次写入为准。服务端尚未确认的改动会记在浏览器里，下次登录时以它为准。登出前会先发送尚未发出的改动；在登录页上选的语言或明暗，会存进随后登录的账号。
- 某个浏览器从未获得通知权限、而账号已开启通知时，该浏览器里的通知开关显示为关，并在行内说明原因；在这里打开开关即会申请权限。
- 已连接机器上的会话，其草稿存在用户登录的这台服务端上，Web App 删除会话时会一并删除。
