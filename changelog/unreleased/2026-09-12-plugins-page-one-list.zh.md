# 插件页合为一张列表：插件库的分类与插件源同一形态

- **Date:** 2026-09-12
- **Type:** fix
- **Scope:** `web`

[English](2026-09-12-plugins-page-one-list.md)

插件页不再像两页叠在一起。页面标题为「插件市场」，插件源——本部署可为 Project 安装的插件包——作为插件库各分类之下的又一个可折叠分区，放在同一个容器里：同样带数量的分区头、同样无边框的行、同样按插件名取色的图标块。插件源的行保留其标签行（许可证与关键词），「内置」标记从安装按钮旁移到该标签行中。

插件源分区现在也位于页面的内容列之内。此前它渲染在插件库所用的限宽容器之外，宽窗口下会撑满整行，而上方的插件库仍居中。
