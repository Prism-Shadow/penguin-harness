# Web App: switch accounts from the sidebar

The bottom-left account menu gained a **Switch account** entry, and the login page now offers the accounts that have already signed in on this browser, so moving between two accounts is a click and a password instead of retyping the username.

## Switch account

The account menu's bottom block reads Change password → … → Switch account → Sign out. Switching ends the current session and returns to the login page — the same exit as signing out, named for the intent behind it, and hidden in desktop mode for the same reason Sign out is (the desktop shell owns sign-in and never shows a password).

## Remembered accounts

Every account that signs in on a browser is remembered there, most recent first, and listed above the login form: clicking one fills the username and puts the cursor in the password box; the row's ✕ makes the browser forget that account again. The list is capped at eight entries.

Only user ids are stored, in `localStorage` — no passwords, no tokens, nothing beyond what watching someone sign in would reveal. Sessions themselves are unchanged: one HttpOnly cookie, one active account, and the password is still required on every switch. A browser that has never seen a sign-in opens on the plain form as before.
