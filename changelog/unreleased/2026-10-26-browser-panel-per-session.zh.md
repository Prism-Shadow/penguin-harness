# 浏览器面板只留在打开它的 Session 里

- **Date:** 2026-10-26
- **Type:** fix
- **Scope:** `web`
- **PR:** [#1335](https://github.com/Prism-Shadow/penguin-harness/pull/1335)

[English](2026-10-26-browser-panel-per-session.md)

从停靠栏显示着内置浏览器的 Session 切到一个自己没有浏览器标签页的对话时，浏览器面板也会在那里打开，
里面是一个新开的新标签页；切到新建对话（`/chat/new`）时同样如此。切换的那一次渲染里，离开的
Session 的面板还挂载着，「面板显示时始终保留一个标签页」的规则因此为目标对话新开了页面，这个页面又把
浏览器面板带进了它的停靠栏。

## 细节

- 新标签页规则只看屏幕上那个对话自己的停靠布局：只有该对话的布局显示着浏览器面板时，才为它新开页面。
  在一个 Session 里打开浏览器不再让另一个 Session 也打开，切回原 Session 时面板按离开时的样子显示，
  新建对话不带浏览器面板，除非在那里自己打开。
- 停靠布局的存储（`penguin.dock.layout`）格式未变，已有的布局照常读取。
