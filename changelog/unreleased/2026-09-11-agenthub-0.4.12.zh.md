# AgentHub 0.4.12：工具读到的图片能穿过严格校验的 OpenAI 兼容网关送达模型

- **Date:** 2026-09-11
- **Type:** fix
- **Scope:** `core`, `cli`, `docs`

[English](2026-09-11-agenthub-0.4.12.md)

`@prismshadow/agenthub` 从 0.4.11 升至 0.4.12（agenthub [#209](https://github.com/Prism-Shadow/agenthub/pull/209)）。在走 `openai-chat` 协议的模型、Kimi K3 行或 `glm-5.3-flash` 行上使用 `read_image`，不再报 `400 Failed to deserialize the JSON body into the target type: data did not match any variant of untagged enum ChatCompletionRequestToolMessageContent`：client 把工具的图片放进本轮 tool 消息之后的 user 消息，即 Chat Completions schema 唯一记载的位置，而不再塞进 `tool` 消息。校验 schema 的网关此前会拒绝整个请求，该轮随即以这个错误终止。

## 详情

- 修复位于 AgentHub 的 `openai_chat`、`kimi_k3` 与 `glm5_3` 三个 client，因此所有钉在 `openai-chat` 上的行（TokenDance、OpenRouter、Fireworks、SiliconFlow、Qwen 各组以及自定义 OpenAI 协议条目）、Moonshot 直连行和 `glm-5.3-flash` 行一并生效。这些 client 的每条工具结果现在都以纯字符串发出。Responses 协议的 client 不受影响。
- `pnpm-workspace.yaml` 的 `minimumReleaseAgeExclude` 条目改为 0.4.12，替换 0.4.11。
- 最后几处 `gpt5_6` 写法（模型页的快速模式表格与一个 core 测试标题）改为 `gpt6`，即 AgentHub 0.4.11 给该 client 的名字。
