# 随产品提供默认 Agent 的插件

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** Server, CLI, Desktop
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1783

新 Project 的默认 Agent 预装 Agent 公司、电脑操作技能、持续学习和企鹅支持。电脑操作的桌面服务仍需管理员启用。新 Project 启用工作台历史的原生 Git 模块。已有 Project 保留原有模块配置，其中新建的普通 Agent 也会把工作台修改记入自己的 Git 历史。
