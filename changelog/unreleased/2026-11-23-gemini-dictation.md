# Use an audio-capable Gemini model for dictation

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `server`, `multimodal-tools`
- **PR:** https://github.com/Prism-Shadow/penguin-harness/pull/1784

[中文版](2026-11-23-gemini-dictation.zh.md)

Project owners can choose a Gemini model for Speech recognition when its configured service supports audio input and text output. Dictation asks for the spoken words in the original language. The existing polish setting controls any subsequent editing.
