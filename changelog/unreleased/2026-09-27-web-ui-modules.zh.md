# Web App 模块：终端自带词典、入口与测试

- **Date:** 2026-09-27
- **Type:** refactor
- **Scope:** `web`, `skills`

[English](2026-09-27-web-ui-modules.md)

引入 Web App 模块——一个带公开入口、自带中英词典片段与独立测试项目的特性目录——并把终端做成第一个模块。界面文字与行为均无变化。

## 细节

- 终端的界面文字从两本应用词典移入终端自己的词典片段，应用词典改为按引用挂上它；组件照旧读 `S.terminal.*`。关闭 shell 的两条确认文字从 Dock 段归入终端段。
- 模块目录外对终端的全部引用（路由、应用外壳、对话页、会话界面视图与 Dock 的三个文件）改为经由模块入口。
- Web 包的测试新增模块清单；vitest 配置按清单为每个模块生成一个测试项目，`vitest run --project terminal` 单独运行终端的测试；边界测试在引用绕过模块入口、或超出模块声明的依赖时失败。
- 终端链接、触屏按键栏、终端连接与触摸滚动的单元测试迁入模块目录，并新增终端词典片段的测试。
