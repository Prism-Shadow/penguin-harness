# 关闭停靠栏的最后一个标签后，停靠栏留在启动页

- **Date:** 2026-11-27
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`

[English](2026-11-27-dock-start-page.md)

关闭对话停靠栏里的最后一个标签后，停靠栏不再自动收起，而是留在原处、保持原来的大小，显示启动页：「+」菜单里的全部操作按原顺序排成应用中心样式的图块。从工具行按钮拉开的空停靠栏也显示这个启动页，取代了原先的面板列表。

## 细节

- 启动页的图块与「+」菜单里的同名项做同一件事。在对话的右侧停靠栏和窄屏的合并面里，这一组就是对话的「快捷方式」：先是「应用中心」，然后是各个面板，每个都作为对话的会话工具打开。底部停靠栏列出它能放的面板。命令行终端、文件浏览和浏览器沿用应用中心里的图标；有快捷键的面板把按键写在图块的悬停提示里。
- 右侧停靠栏和全屏时，图标在上、名称在下，列数跟着停靠栏的宽度变，各行尽量一样长；底部停靠栏和窄屏的合并面改成图标与名称并排的行。方向键在图块之间移动焦点，Enter 打开。
- 最后一个标签关闭后，启动页淡入。原本落在标签 × 上的焦点移到第一个图块；在输入框等别处的焦点不受影响。全屏的停靠栏仍保持全屏。
- 收起停靠栏只靠它自己的控件：头部 ×、工具行按钮、快捷键，以及显示终端时的 Ctrl+`。标签被移走时停靠栏照旧收起，比如移到另一侧，或应用移到另一段对话旁。代替对话布局里已有面板显示的会话工具关闭时，原布局照原样恢复。
- 应用中心的图块与启动页改用 UI 包新增的 `LaunchTile` / `LaunchGrid`，组件画廊的「布局」页里有示例。`DockModule.panels` 的 `lead` 不再影响任何排序。
