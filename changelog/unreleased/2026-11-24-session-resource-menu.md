# Browser and Terminal directories in the Apps sidebar

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** `web`

[中文版](2026-11-24-session-resource-menu.zh.md)

Opening Browser or Terminal in a conversation now keeps it in that Session’s Dock. Opening its resource directory from the App Center adds one entry to the Apps sidebar. Selecting a Session in the directory keeps that entry available.
