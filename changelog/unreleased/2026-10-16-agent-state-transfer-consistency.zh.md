# 串行执行 Agent State 传输

- **Date:** 2026-10-16
- **Type:** fix
- **Scope:** `server`

[English](2026-10-16-agent-state-transfer-consistency.md)

对每个 Agent 的快照创建和包导入执行了串行调度。并发导入根据前一次传输提交的版本执行检查，失败的传输释放队列，让后续请求继续执行。

## 细节

- 按 Agent 目录的真实路径建立传输队列，让文件系统别名共用队列，并在平台重载后保留进行中的队列。
- 读取当前 vault 遇到文件缺失以外的错误时停止导入，保留原有 vault。
- 替换和回滚均失败时，在暂存目录保留原有 Agent State，并在错误中包含恢复路径。
- 打包或发布快照失败后，清理未完成的快照文件。
- 添加了 HTTP 场景，覆盖并发传输、文件系统别名、平台重载、独立 Agent、从归档创建 Agent，以及真实文件系统错误后的恢复。
