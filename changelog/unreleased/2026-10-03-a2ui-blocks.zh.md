# 回复可以带 A2UI 组件块：选项、表单、步骤、提示框与图表

- **Date:** 2026-10-03
- **Type:** feature
- **Scope:** `core`, `ui`, `web`, `server`, `cli`
- **PR:** [#968](https://github.com/Prism-Shadow/penguin-harness/pull/968)

[English](2026-10-03-a2ui-blocks.md)

回复现在可以在 Markdown 里用围栏携带一个小型可信组件目录中的组件——```` ```a2ui ```` 内放一个 JSON 对象，或 ```` ```mermaid ````——由 Web App 用自己的组件与主题绘出。新的预装插件 `a2ui` 告诉模型何时、如何使用它们，附带 STE 风格的写作规则，以及一个检查脚本，让模型知道草稿写得对不对、好不好读。

## 变更

- **组件目录：** `choice`（一个问题、2–7 个选项，可多选、可「其他…」、可标推荐）、`form`（1–6 个字段：单选、多选、文本、数字）、`steps`（操作步骤，警告与注意在步骤之上、说明在其下）、`callout`（说明、提示、注意、警告），以及 Mermaid 图（按需加载、严格安全级别、配色取自主题令牌，可切换查看源码）。
- **交互：** 选中选项或填好表单，会把纯文本填入输入框——选项的取值，或每个字段一行「问题：答案」——在用户按发送之前不会发出。只有主对话里最新的一条回复可交互；更早的回复、子会话与轨迹页只读展示。回复流式输出期间组件块显示占位，落定后一次绘出；解析不了的块显示源码，并在其上写明第一处错误。
- **其他出口一律纯文字：** CLI 与消息渠道（飞书、Telegram、QQ、微信）把每个组件块换成可读的 Markdown——选项变成编号列表，末尾写「回复编号或直接写出你的答案。」存储的消息与 Trace 保留原样。
- **单一语法源：** `@prismshadow/penguin-core/a2ui` 是无依赖的模块，持有组件目录的结构定义、围栏解析、校验、Mermaid 结构检查、中英文 STE-lite 文风检查、评分与纯文本降级；渲染、降级与检查脚本共用它。
- **检查脚本**（`skills/a2ui/scripts/check.mjs`，由该模块经 `pnpm build:a2ui-check` 打包，只用 Node 内置模块）报告会让渲染失败的错误（L1：JSON、未知类型、缺字段、取值限制、重复标签、禁用的 Mermaid 指令）、增加阅读负担的警告（L2：组件或选项过多、提问后还有内容、组件前没有引出的正文）与文风警告（长句、被动、含糊词），给草稿打分（有任一错误则总分为 0），加 `--rubric` 时打印自查清单。技能要求模型对任何含组件的草稿运行它，三轮内改好，仍不通过的块改用文字表达。
- **可扩展：** UI 包的 `registerA2uiRenderer` 可新增或替换组件类型，与停靠面板注册表同一类接缝。
- **文档：** 对话页新增「富输出组件」一节；插件列入插件 README 与文档的技能页。
