# 工作区选择器：Use this dir 用的是你输入的路径

- **Date:** 2026-09-28
- **Type:** fix
- **Scope:** `web`

[English](2026-09-28-workspace-picker-typed-path.md)

在工作区选择器里输入路径、不按 Enter 直接点 **Use this dir**，现在用的就是输入的路径。此前按钮取的是输入之前列出的目录（新打开的选择器里就是 server 的主目录），界面上没有任何提示，新会话也就建在那个目录里。

## 细节

- 输入的路径与当前列出的目录不同时，先交给 server 确认，选择器按确认后的目录收起。
- 输入的路径不存在或无法读取时，沿用已有的「目录不存在或无法访问」提示，路径框恢复原值，不提交任何目录，选择器保持打开。
- 首次列目录失败、但已经输入了路径时，按钮也可以点。
