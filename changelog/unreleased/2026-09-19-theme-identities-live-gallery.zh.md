# 三套主题拉开差异，画廊按需演示交互

- **Date:** 2026-09-19
- **Type:** process
- **Scope:** `ui`, `ui-gallery`
- **PR:** [#795](https://github.com/Prism-Shadow/penguin-harness/pull/795)

[English](2026-09-19-theme-identities-live-gallery.md)

重新设计了 Frost 与 Console，三套主题不再共用同一副轮廓；组件画廊新增动态变体，在每套主题下逐帧演示交互。Primer
逐像素不变；Web App 在主题切换开放前只渲染 Primer，因此同样不变。

## 主题

- 尺寸不再跨主题共享。新增的间距单位令牌桥接为 Tailwind 的 `--spacing`，所有间距与尺寸工具类随主题缩放：Primer
  保持原生的 0.25rem，Frost 更宽松（0.28rem，正文 15px），Console 更紧凑（0.225rem，正文 13px）。`text-sm` 与
  `text-xs` 跟随各主题的正文与小字字阶。
- Frost 恢复 Sierra 式的色场：应用窗口后铺暖色底场，导航列落在底场上，主列是悬浮的圆角薄片；盒子圆角更大，控件为
  胶囊形，标题用常规字重的大字号。
- Console 改为 opencode.ai 式的等宽界面：导航、按钮、标签、标题、徽章与表格用 Commit Mono，阅读面（消息正文、回答
  的 Markdown、输入框）仍用 IBM Plex Sans。浅色为纸白、深色为暖近黑，保留橙色强调色与直角；窗口通栏并以细线分隔，
  选中的导航行前有 `>`，带头部的框把标题嵌在顶线里。
- 新增第七个样式钩子 `ui-shell`，挂在应用窗口上（`data-slot="nav"` / `"main"`），唯一宿主是 `AppShell`。新增令牌
  `--ui-font-ui` 作为界面字体（`body` 读它），与阅读用的 `--ui-font-sans` 分列。
- 令牌契约由 188 个增至 210 个：外壳一组、`--ui-font-ui`、间距单位，以及用于进出、显现与尺寸变化的 11 个动效令牌。

## 动效

- 组件用四个数据属性声明动效——`data-presence` 配 `data-side`、`data-backdrop`、`data-reveal` 与
  `data-layout-motion`——由 `theme.css` 按主题的令牌演绎：Primer 淡入加 4px 位移，Frost 从 0.96 弹入、模糊渐清并
  逐词显现流式文本，Console 逐格跳变、不淡入。减少动效下一律直接呈现终态。

## 画廊

- 六个模块各新增一个动态变体：流式回复（对话）、输入并发送（输入区）、收起与展开（侧栏与导航）、打开与关闭（浮层：
  菜单、对话框、通知）、运行到结束（状态）与展开目录（文件）。每个变体是一组帧，卡片按时钟逐帧播放并循环。
- 卡片在视口内时自动播放。卡片底部有走带控件：播放与暂停、重播、上一帧与下一帧、点击跳转的帧标签，以及 0.5× /
  1× / 2× 变速。比较模式下三套主题共用该卡片的时钟，同一时刻停在同一帧。
- `/embed?module=&variant=&frame=&play=` 可定位到某一帧，动态变体缺省暂停在最后一帧。动态变体的截图命名为
  `<模块>--<变体>@<帧>.png`，加 `--variants all` 时逐帧出图。卡片暂停时，路径标注当前帧。
- 「基础」的动效板可逐项重放，间距与形状板展示间距单位与外壳。

## 主题，第二轮

- 三个结构钩子让三套主题在**组织方式**上分开，而不只是颜色：`ui-icon-decor`（标签已经说明了的图标——通用保持单色，白领
  按角色着色，极客直接不画，因此极客的图标明显更少）、`ui-tree`（会嵌套的行——通用是描边盒，白领在卡片内画柔和参考线，
  极客不要盒子，用 CSS 画 `└`/`├` 连线）、`ui-field`（带标签的控件行——通用维持现状，白领标签在上、控件撑满，极客是固定
  标签列的表格行）。钩子增至十个。
- 每套主题各列一组强调色预设：通用保留 `blue / green / violet / rose / amber` 与现有取值，白领另给五个暖而含蓄的色相，
  极客给五个终端色相。当前主题未列出的存储值不着色（由主题自带的强调色顶上），切回列出它的主题即恢复，偏好本身不丢。
- 令牌增至 215 个：新增「结构」一组，承载树的缩进阶梯、连线色与字段的标签列宽和间距。
- 三套主题有了中文名：通用（Primer）、白领（Frost）、极客（Console）；id 不变。

## 画廊重做

- **不点就不动。** 场景现在挂在它所结束的那个变体上，卡片停在完成态；点播放才走一遍并停住。`live-*` 变体取消，并回静态
  变体，每个模块的缺省变体都带场景。
- 页首是**首屏**——产品名、一句话、两个按钮，以及一整扇当前主题下的应用窗口：可点会话、可切停靠面板、可在输入区打字，也
  可播放自己的场景。它放在共享 UI 包里，落地页可以直接引用。
- 新增四个模块：首屏、弹窗与确认、用 AI 创建、空状态与引导，共十九个；弹窗相关的部件从「浮层」移了过来。
- 侧栏给齐了应用里有的控件：主题（中文界面用中文名）、明暗、**强调色**（当前主题自带的预设，按各自颜色作色标）、**根字号**
  （16 / 18 / 20 px，改的就是真实根字号）、语言、视口、比较与减少动效。URL 新增 `accent=` 与 `view=`。
- **窄屏两头都顾**：`view=phone` 把任意模块放进 390px 的框里看，画廊自身也把侧栏收进顶栏抽屉、卡片单列、横向不滚动。

## 画廊按应用尺寸呈现

- **应用区域按应用的宽度排版。** 模仿应用窗口某一部分的模块在 `module.ts` 里声明其设计宽度（`viewport`）：整扇窗口
  （侧栏与导航、首屏）为 1280px，主列里的内容（对话、输入区、页面、公司看板、弹窗、空状态、用 AI 创建、浮层、文件）为
  956px。卡片按这个宽度排版，再把画面等比缩到卡片宽，换行与截断都与应用一致。`/embed` 与截图按该宽度原尺寸输出；窄屏
  视图仍用 390px 的框。
- **替身向应用看齐。** 侧栏首行是收起按钮与 Project 切换器，导航文案与应用一致（新建对话、插件市场）且不带计数；Session
  标题带三个控件，会话按工作区分组，运行中显示沙漏，底部用户行带角色。对话头部、输入区控件行（`+`、审批模式、带数量的
  技能、斜杠提示、上下文占用、思考等级、模型、发送）、统计行与停靠面板的文案均与应用一致；未开右侧面板的对话显示「快捷
  方式」悬浮球。「页面」模块改为真实的插件页与带创建按钮组的智能体页；页面标题、文件面板与公司模式的文案改用应用的原词。
- 新增一个守护测试：画廊与应用共有的每条文案，都在中英两种语言下与应用自己的词典（`packages/web/src/lib/strings.ts`
  与 `strings-en.ts`）逐字比对。
- `/screens/<name>` 的工具栏改为合成图上方的一条横栏，不再浮在输入区上面。
