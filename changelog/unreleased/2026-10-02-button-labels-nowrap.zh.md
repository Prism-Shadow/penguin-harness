# 按钮文字不再换行

- **Date:** 2026-10-02
- **Type:** fix
- **Scope:** `ui`, `web`
- **PR:** [#954](https://github.com/Prism-Shadow/penguin-harness/pull/954)

[English](2026-10-02-button-labels-nowrap.md)

按钮文字改为始终单行显示。此前中文界面下，Project 设置 › 通用里的「保存」在任何窗口宽度下都被挤成一字一行。对所有页面、设置、Project 设置与应用信息三个对话框以及主要弹窗做了一次自动检查（390、1024 与 1440 px，中英两种语言，「中」与「特大」两档字号，三套主题），其余几处也一并找出。

## 细节

- **按钮：** `Button` 与文件选择器借用的按钮外观改为单行显示文字，分段控件的选项也是：宽度够时平分，不够时每项至少保留自己文字的宽度。分段控件的选项还可以为手机宽度提供一个较短的文字，完整文字仍作为它的名称。应用里手写的文字按钮（切换项、行内操作、可点的链接）同样改为单行。
- **由按钮周围的布局让位：**
  - Project 设置 › 通用：显示名输入框恢复原定宽度、在手机上更窄，「保存」因此有了足够的位置。
  - 对话框底栏、设置页的操作行以及各种样式的提示条（连同其中的操作组）在按钮放不下一行时换到第二行。
  - 输入框上方的上下文窗口提示在手机上把两个按钮放到单独一行，不再把提示文字挤成每行几个字。
  - 设置 › 个人资料：手机宽度下头像一行的控件换到第二行并右对齐，不再伸出对话框。
  - 组织概览：主栏放不下按钮时（笔记本宽度配大字号），指标条改为两行两列，「第一步」卡片减少每行的列数；看板的计数按钮保持单行。
  - 组织财务：手机上的周期切换独占标题下方的一整行，每个选项只显示月份。
  - 终端页：过长的连接错误截断显示、最多占工具栏一半，全文留在悬停提示里，不再把「新建终端」按钮挤出工具栏。
- **规则成文：** `.agents/skills/penguin-harness-frontend/SKILL.md` 新增一节，写明按钮文字永不换行、由周围的布局让位，列出四种让位方式，并点明设置行里分段控件的陷阱。
