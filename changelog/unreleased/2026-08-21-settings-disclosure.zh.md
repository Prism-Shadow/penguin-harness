# 设置页的解释文字收进圆圈问号

- **Date:** 2026-08-21
- **Type:** refactor
- **Scope:** `web`
- **PR:** [#392](https://github.com/Prism-Shadow/penguin-harness/pull/392)

[English](2026-08-21-settings-disclosure.md)

设置页此前把解释写成灰色段落与副标签，每次进入都要先滚过一遍。现改为遵循 Web App 其余部分的
同一条规则：页面或行的**含义**由标题旁的圆圈问号按需展开，只有决定取值形态的文字留在屏幕上。

## Project 设置

- 安全策略页开头是一段五句话的说明，涵盖模型接触 shell 的两条路径、模型收到的固定拒绝文案、
  匹配算法以及绕过的边界。该段被压缩为两句并收进页面标题旁的问号；规则编辑器仍保留可见的
  「正则表达式」占位符。
- 该对话框的页面标题新增可选说明位，其余页面也可以挂载说明。

## 系统设置

- 每一行偏好设置——语言、币种、CLI 会话、主题、终端主题、字号、主题色、修改密码——的副标签
  都移到了行标题旁的问号里。
- 代理选项的页级段落移到页面标题旁的问号，由分页对话框外壳统一绘制；共享的页面框架随之去掉
  了说明行的插槽。
- 上传限制的整段说明一分为二：可填的 MB 区间移到两个输入框各自下方，供填写时随读；单条消息
  的固定附件数量与内嵌图片的独立上限移到页面标题旁的问号。
