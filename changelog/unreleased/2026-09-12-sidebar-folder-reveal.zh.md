# 侧边栏折叠夹一次显示十个对话，并可折回

- **Date:** 2026-09-12
- **Type:** fix
- **Scope:** `web`
- **PR:** [#712](https://github.com/Prism-Shadow/penguin-harness/pull/712)

[English](2026-09-12-sidebar-folder-reveal.md)

会话列表的折叠夹——子智能体、定时任务、已归档——把取回的行全部显示出来，且无法回退：在还剩 28 个对话的「已归档」上点一次「更多」，一次露出 13 条；份额加载齐后又没有任何入口把它们收回去。现在折叠夹遵守与上方活跃列表相同的显示规则：一次显示十行，「展开其余 N 个对话」再显示十行，份额全部显示后出现「收起」。

## 细节

- 每个折叠夹各有自己的显示上限，由它自己的展开行按页抬升，并与活跃列表同口径地在切换分组方式与切换 Project 时复位。
- 展开行先显示内存里已加载的行，不够时才向服务端再取一页。按时间分组时折叠夹是 Project 范围内共享的一组，取数会扇出到每个有份额的 Agent，因此一次请求可能取回好几页；多出来的行留在内存里、不越过显示上限，不会一次全部落到屏幕上。
- 该行报出它仍然藏着的数量——上限之外的已加载行加上本夹未取回的余量——藏无可藏时消失，另由「收起」一行把折叠夹折回最前十条。搜索时折叠夹仍强制展开显示命中结果，两行都不出现。
