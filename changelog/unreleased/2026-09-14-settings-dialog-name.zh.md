# 「系统设置」弹窗更名为「设置」

- **Date:** 2026-09-14
- **Type:** improvement
- **Scope:** `web`, `docs`
- **PR:** [#674](https://github.com/Prism-Shadow/penguin-harness/pull/674)

[English](2026-09-14-settings-dialog-name.md)

侧边栏用户菜单里的「**系统设置**」一行及其打开的弹窗，现统一称为「**设置**」（英文界面为 Settings）。弹窗本身不变：「个人」与「服务器」两个分组下的页面照旧，服务器分组在本版本新增「沙盒」与「插件」两页。
