# The System settings dialog is called Settings

- **Date:** 2026-09-14
- **Type:** improvement
- **Scope:** `web`, `docs`
- **PR:** [#674](https://github.com/Prism-Shadow/penguin-harness/pull/674)

[中文版](2026-09-14-settings-dialog-name.zh.md)

The sidebar user menu's **System settings** row, and the dialog it opens, are now called
**Settings** (设置 in the Chinese UI). The dialog is unchanged: its Personal and Server groups hold the
same pages, and the Server group gains the Sandbox and Plugins pages in this release.
