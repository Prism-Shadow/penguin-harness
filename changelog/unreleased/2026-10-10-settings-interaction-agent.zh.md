# Agent 设置页与其他设置页统一提交方式

- **Date:** 2026-10-10
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1031](https://github.com/Prism-Shadow/penguin-harness/pull/1031)

[English](2026-10-10-settings-interaction-agent.md)

Agent 设置页、各标签页及从中打开的弹窗接入设置项提交口径（[2026-10-10-settings-interaction.zh.md](2026-10-10-settings-interaction.zh.md)）：开关一拨即生效，文字与表格点「保存」后生效，带未保存修改离开时先问「放弃未保存的修改？」。

## 离开

- 标签页有未保存修改时，经任何途径离开都先问：切换标签、返回 Agent 列表、点侧栏链接、浏览器前进后退、刷新。页面自带的放弃确认框（只管标签栏与返回）已移除。
- 技能、密钥保险柜、定时任务三处的 Prompt，以及新建 API 密钥时输入的名称，现在都计入未保存修改；此前离开会悄悄丢弃。拨动这几个标签页的开关、插入占位符，也不再清掉正在编辑的 Prompt。

## 保存与重置

- 概览、系统提示词、运行参数、内置工具表、记忆的两段 Prompt，以及技能、密钥保险柜、定时任务的 Prompt：只有内容有改动且合法时「保存」才可点，旁边新增「重置」，恢复为已存值。这些标签页不再弹「当前没有需要保存的修改」。
- 普通保存前的「保存修改」确认框已移除，点「保存」立即写入。会覆盖或删除内容的确认保留：导入快照、内核更新、恢复默认配置、覆盖已有密钥、各类删除。
- 运行参数的五个数字在输入时即校验：须为大于 0 的整数或 -1。输入非数字也算改动，不再绕过离开确认。清空已保存的值会被标出并禁用「保存」，因为页面上还不能清除已保存的覆盖值；点「重置」可还原。

## 内置工具表

- 每行的 `call_description` 开关一拨即单独写入。同表中输入的超时与输出上限仍等「保存」，「保存」也不会撤销之前拨动的开关。数字格留空即去掉该项覆盖值。

## 弹窗

- 新增 / 编辑 MCP Server、添加密钥、定时任务表单（聊天页定时任务面板也用它）与新建 Agent：记录填写完整且有改动时底部按钮才可点；有输入时，Esc、×、点击弹窗外与「取消」都先问；保存被拒时弹窗保持打开并显示原因，修改仍保留；保存请求返回前弹窗关不掉。弹窗内的开关（如定时任务的「启用」）随弹窗一并保存。
- 这些弹窗每次打开都从对应记录（或空表单）开始。
