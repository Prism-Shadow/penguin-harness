# Web App：会话行操作拆成悬停两键与右键菜单

- **Date:** 2026-08-19
- **Type:** feature
- **Scope:** `web`, `docs`

[English](2026-08-19-session-row-actions.md)

聊天侧边栏里悬停一条会话行时，浮现出来的一度只是一枚省略号按钮，行上的每一项操作——归档与删除也在内——都还要再点一下才够得到。悬停处的操作现在改回 v0.2.2 及更早版本一直提供的样子：归档与删除作为两枚图标按钮直接落在行尾。其余操作并没有消失，包含置顶与重命名在内的完整菜单改由右键打开。

## 悬停两键

- 悬停一行（或用键盘把焦点移到它上面）时，行尾的最近活跃时间让位给归档／取消归档与删除，各自一次点击即可。删除在悬停时仍保留红色处理。
- 该槽位预留了这两枚按钮自身的宽度，因此没有最近活跃时间的行不会再让图标压到标题上，整列图标也依旧对齐成一条竖线。
- 这两枚按钮只在真正显形时才接收指针事件，因此触屏上行尾不会留下一个看不见的点击目标——在那里，悬停显形的按钮根本不会显形。

## 右键菜单

- 右键点击一行，会在指针处打开置顶／取消置顶、重命名、归档／取消归档与删除。置顶只出现在活跃列表的行上——那里它才真的能改变顺序；已归档、子智能体与定时任务的折叠夹提供另外三项。
- 触屏用长按打开同一个菜单（500ms，手指移动超过 10px 即作废，之后被屏幕补发的那次点击也不再打开会话），键盘则用 Shift+F10 对焦点所在行打开，并锚定到该行自身的盒子而不是视口角落。触屏既没有悬停也没有右键，因此这个手势并不是唯一入口。
- 菜单面板复用共享的 `Dropdown`，走的是新增的虚拟锚点模式，于是直接继承了该基础组件的关闭方式（经共享 esc 层栈的 Esc、点击外部、滚动）、焦点处理（打开时聚焦首项，Esc 把焦点交回该行），以及靠近视口边缘时的夹取与翻转。锚在指针上的面板遇到滚动时选择关闭，而不是去追一个它本就没有的触发元素。
- 浏览器自带的右键菜单只在该行的处理函数内部被接管：没有任何东西注册到 document 或 window 上，所以在应用的其他位置右键，行为一如既往。

## 列表选项图标

- 列表选项菜单的四行都加上了前导图标：按 Workspace 分组用文件夹、按 Agent 分组用 Agent 图形——与分区标题栏里那个分组切换按钮所用的正是同两枚，现在统一从一张共享映射表里读取——最近更新用时钟，拖拽得来的手动排序用上下箭头。
- 这些图形只是标签旁的装饰，标签本身没有被替换掉，因此每一行的可访问名称都未发生变化。
