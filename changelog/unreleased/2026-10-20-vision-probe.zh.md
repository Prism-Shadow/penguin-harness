# 模型配置的「检测视觉」恢复可用，并如实转述服务商的说法

- **Date:** 2026-10-20
- **Type:** fix
- **Scope:** `server`, `web`

[English](2026-10-20-vision-probe.md)

「检测视觉」此前对使用严格图片解码器的端点恒定失败，并提示「无法检测接口协议，请检查 API Key 与 base URL」。两个原因：探测用的 1×1 PNG 比文件头声明的少两个字节，以及网关自己的错误原文从未到达调用方。

## 细节

- **探测图。** 常量换成 IDAT 解压后正好五个字节（一个 filter 字节加四个通道）的 1×1 RGBA PNG，严格解码器可以接受。回归测试逐 chunk 校验 CRC、解压 IDAT，并与颜色类型要求的字节数比对。
- **文案。** 视觉检测失败有自己的文案，不再借用协议探测的「请检查 API Key 与 base URL」。
- **错误原文。** 启动时给全局 fetch 加一层包装：当错误响应是 JSON、是普通对象、且没有顶层 `error` 时，补上 OpenAI SDK 读取的 `error` 字段，同时保留网关原有字段。非 OpenAI 形状的错误因此能到达判定逻辑，"模型明确拒绝图片"会关闭开关，而不是被记成"什么都没学到"。
- **验证。** 真实网关下，坏图从 `failed` 变为 `unsupported`，修正后的探测图判为 `supported`，两种 OpenAI 兼容客户端结果一致。
