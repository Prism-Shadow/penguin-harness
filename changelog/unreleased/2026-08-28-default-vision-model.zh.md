# 新建 Project 的默认模型能看图了

- **Date:** 2026-08-28
- **Type:** feature
- **Scope:** `core`

[English](2026-08-28-default-vision-model.md)

新建 Project 的默认模型此前是 `deepseek/deepseek-v4-flash`，它只支持文本，于是在全新安装里粘贴的第一张截图会被拒绝，而界面上没有任何东西解释原因。默认模型现在改为 `deepseek/deepseek-v4-flash-vision-exp`——上下文窗口相同、公开价格相同，额外支持图片输入。

## 细节

- 两行在其他方面完全一致：100 万上下文、CNY 0.05 / 1.5 / 4.5、同一厂商、同一协议。视觉版本是严格超集，因此这项能力不以任何东西为代价换来。
- **仅影响新建 Project。** Project 的默认模型在创建时被复制进去，此后归它自己所有；不会有任何东西改写既有配置，而「同步预置」也明确从不触碰已存的默认模型。既有 Project 像以往一样，自己选一下即可切换。
- core 的测试现在断言的是**性质**而不是那个 id——无论默认模型指向谁，它在目录中的条目必须 `supportsVision`——这样以后再改默认模型，就不会悄悄退回到一个会拒绝它收到的第一张图片的模型上。
