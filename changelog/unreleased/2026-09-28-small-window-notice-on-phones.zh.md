# 手机上的小窗口提示不再挤扁对话区

- **Date:** 2026-09-28
- **Type:** fix
- **Scope:** `web`
- **PR:** PR_URL

[English](2026-09-28-small-window-notice-on-phones.md)

模型的上下文窗口小于 Agent 的压缩阈值时，输入框上方会出现一条带「忽略」与「打开 Agent 设置」按钮的提示。手机上
这两个按钮一直与正文并排，把正文挤成窄窄一列：390 px 宽时提示长到约 490 px，对话区只剩 48 px，粘住的工作组
头部随之盖住待审批行的「允许」与「拒绝」按钮。现在正文与按钮并排放不下时，按钮换到下一行，正文占满整行。
