# 文件面板：目录树与预览并排、就地纯文本编辑、拖放上传

- **Date:** 2026-09-02
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#589](https://github.com/Prism-Shadow/penguin-harness/pull/589)

[English](2026-09-02-workspace-tree-editor.md)

Workspace 文件面板改为两栏浏览器——左侧目录树、右侧所选文件的预览——并支持文本文件的纯文本编辑与从桌面拖放上传。

## 细节

- 目录树：目录在首次展开时才列出内容；展开 / 折叠箭头、文件夹与文件图标、选中文件高亮、方向键导航（上下移动、右展开或进入、左折叠或回到上级）。两栏上方的面包屑标出当前目录。工具栏按钮可隐藏或显示目录树——默认显示，记在一条浏览器本地键（`penguin.files.treeVisible`，宽容解析）下。面板宽度低于 480px 时退化为单栏：先显示目录树，选中文件后换成带「返回列表」按钮的预览。消息文件卡片的点击仍会落到对应文件，现在是把目录树一路展开到它。
- 预览：渲染方式与之前一致（Markdown / HTML 渲染视图并可切换源码、文本高亮、PDF 内嵌）；图片现在可点击放大，扩展名看不出类型的文件在首块字节看起来是文本时按文本读取。文本读取在 256KB 上限处停止，不再整文件下载。
- 编辑：文本文件的**编辑**把预览换成等宽文本框；**保存**（Ctrl+S / Cmd+S）先确认，再经既有的 `PUT /api/sessions/:id/files/content` 接口写回并刷新该行的大小与时间。截断的预览保持只读，超过 14MB 写入上限的保存在发送前即被拒绝。未保存的修改在切换文件、关闭面板标签页或停靠面板（停靠面板在标签页 ×、隐藏 × 与工具栏开关处征询的关闭守卫注册表）、离开页面前都会先询问；切换 Session 时草稿保留，再次打开该文件即恢复。
- 上传：把系统文件拖到面板任意位置即上传到当前目录，或上传到指针下的文件夹行（悬停时高亮），复用聊天区的拖放判定；外壳守卫继续取消其他位置的拖放。选择与拖放走同一条路：读取前先做单文件 14MB 检查、按目标目录的真实列表确认覆盖、工具栏逐文件显示进度、完成后打开第一个上传的文件。
- 文档：Web App 指南的文件面板一节描述了新面板；设计文档中文件面板的相关句子同步更新。
