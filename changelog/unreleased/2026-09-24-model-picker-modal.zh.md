# 模型选择器改为弹窗

- **Date:** 2026-09-24
- **Type:** feature
- **Scope:** `web`

[English](2026-09-24-model-picker-modal.md)

模型选择器改为弹窗：打开时定位到当前模型，任意分组里的模型都能用几次按键找到并切换。

## 布局

- 顶部是搜索框；下方左侧的分组栏按模型页保存的分组顺序列出各厂商分组（logo、名称、模型数），右侧列出当前分组的模型。
- 在搜索框输入后，右侧改为跨全部分组的搜索结果，按厂商分组、最佳匹配在前；清空搜索即回到分组视图。
- 每行显示展示名、与展示名不同时的上游 id，以及原有的标记：「免费」徽标、未配置 key 标记、Project 默认模型与当前模型的勾选。
- 手机宽度下弹窗全屏，分组栏变为列表上方可横向滚动的一排分组标签。

## 焦点与键盘

- 打开时当前模型所在分组处于选中状态，当前模型高亮并滚动到可见处；尚未选择模型时，定位到第一个已配置 key 的分组。
- ↑/↓ 在列表或分组栏内移动，←/→ 或 Tab 在两者之间切换，⌥1–9（macOS 以外为 Alt+1–9）跳到对应分组（不用 ⌘/Ctrl，浏览器用它们切换标签页），Enter 确认，Esc 关闭；任何时候打字都输入到搜索框。

## 未配置 key 的模型

- 与此前一致：未配置 key 的模型默认隐藏，当前选中的模型与 Project 默认模型除外。底栏的「显示未配置 key 的模型（N 个）」开关会连同其分组一并列出，并可再次关闭；没有任何模型配置 key 时列出全部模型。

## 入口

- 对话输入区的模型按钮，以及 Project 设置、定时任务表单、公司弹窗与评估弹窗中的模型字段都改为打开该弹窗；各处触发按钮外观不变，选中后得到的结果也与此前相同。
- 会话中的 `/model` 命令打开同一个弹窗；选中后仍先暂存为 chip，发送消息时才切换。
