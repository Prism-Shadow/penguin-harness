# Cards for interactive replies

- **Date:** 2026-11-23
- **Type:** change
- **Scope:** `ui`, `web`

[中文版](2026-11-23-a2ui-reply-cards.zh.md)

Choices, forms and procedures in a reply use the current theme’s card surface. A form can still fill the composer from the keyboard. Hosts can render the same blocks directly through `@prismshadow/penguin-ui/a2ui`.
