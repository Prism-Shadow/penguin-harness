# Restore a workbench version in the online demo

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** UI Gallery

[中文版](2026-11-24-demo-workbench-history.zh.md)

Open Support in the demo’s App Center and choose **More → Version history** to try an earlier version of the workbench. Restoring a version changes the page and keeps the example conversation. Reloading the demo resets it.
