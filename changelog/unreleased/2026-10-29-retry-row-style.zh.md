# 模型请求失败时按「[已中断]」的样式写成一行，失败详情可复制或提交到 GitHub

- **Date:** 2026-10-29
- **Type:** fix
- **Scope:** `ui`, `web`, `ui-gallery`, `tooling`
- **PR:** [#1386](https://github.com/Prism-Shadow/penguin-harness/pull/1386)

[English](2026-10-29-retry-row-style.md)

模型请求重试的每个状态现在都是对话里的一行淡色文字，与「[已中断]：重试等待中被中断」同一样式：中括号标签、当前进展、括号里的简短原因，其后是中括号形式的文字操作。等待时为「[重试中]：2 秒后发起第 2/10 次请求（网络或服务暂时不可用，HTTP 503） [立即重试] [放弃重试] [详情]」，请求发出后为「[已重试]：已发起第 2/10 次请求（…）」，运行就此结束时为「[请求失败]：6 次请求均失败（…） [重试] [详情]」。不再有任何内容收在问号里。「详情」打开一个对话框，其中的失败报告可以复制，也可以提交为 GitHub issue。

## 细节

- 行内写原因的文字说明，服务方报错里带 HTTP 状态码时一并写出；服务方原话放在详情里，不写在行内。无法重试的错误行写法相同（「[错误]：模型请求错误（凭据被拒绝，HTTP 401） [重试] [详情]」）。倒计时的秒数按本次等待最宽的位数预留宽度，从 10 秒变成 9 秒时这一行不移位。
- 详情对话框（`ReportDialog`，`packages/ui` 新增）按发送时的样子显示报告，报告为英文：发生了什么（已尝试几次、上限几次）、错误码与请求状态、服务方报错里写明的 HTTP 状态码与请求 id、服务方与模型、UTC 时间、PenguinHarness 版本、安装方式（桌面端、服务端或源码）、Session 所在机器的操作系统，以及服务方原话。原话里的密钥类内容（`sk-…` 密钥、Bearer 令牌、`api_key=…` 等命名的密钥、URL 里的账号密码、UUID、较长的随机串）会被去掉，Workspace 路径会被替换。报告里不含 API key、base URL、提示词与对话内容。
- 「复制」把报告以 Markdown 放进剪贴板。「到 GitHub 提交 issue」打开项目的 bug 报告表单，预先填好标题、问题描述（失败情况）、系统信息（版本、安装方式、操作系统）与报错信息（服务方原话），打开即可直接提交；服务方原话过长时会截短以控制链接长度，截短处会注明。桌面端在系统浏览器中打开表单。
- bug 报告表单改为中英双语并精简：只有「问题描述」与「系统信息」必填，「复现步骤」「报错信息」「其他」为选填，去掉了下拉选项。
- 这些行上的操作都是中括号形式的文字操作（「[重试]」）：真正的按钮，以其文字命名，现在是 `TextAction` 唯一的样式。机器重试行、加载失败提示与「展开」的操作也用这一样式。
- 机器卡片的重试行把上次失败的原因接在句子后面、用淡色写出，不再收在带圈问号里。`RetryStatus` 现在只用于机器；它的 `reasonTitle`、`reasonPlacement`、`frame` 属性与 `retried` 阶段已移除。
- 对话顶部更早的消息加载失败时，显示一行提示「[加载失败]：未能加载更早的对话（…） [重试]」，不再是一整句可点击的红字。折叠的工具输出或思考内容没能取回完整内容时，也写成同样的一行：「[加载失败]：完整内容没能加载（…） [重试]」。
- 新增共用的加载失败提示 `LoadFailed`，占据加载不出来的内容的位置。对话历史读取失败时显示危险色的叉、「历史消息加载失败」、其下淡色一行报错原话与「重试」；对话所在机器连不上时用同一个提示，配机器图形。
- 组件库的「重试」板块展示对话里这些行的每个状态、详情对话框、机器的重试行与卡片，以及加载失败提示的两种形态。
