# 系统设置弹窗

- **Date:** 2026-08-20
- **Type:** feature
- **Scope:** `web`, `docs`
- **PR:** [#369](https://github.com/Prism-Shadow/penguin-harness/pull/369)

[English](2026-08-20-system-settings-page.md)

把散落在侧边栏用户菜单里的各项设置合并进一个**系统设置弹窗**，入口是菜单仅存的「系统设置」行：左侧一列页面导航（按「个人 / 服务器」分组），每页是一列「标题 + 说明」式设置行。导航、页面与行布局与项目设置同款的分页弹窗一致；外壳抽成了可复用的 `PagedDialog` 组件。原 `/settings/:section` 与 `/admin/users` 路由随独立设置页一并移除。

## 页面

- **个人 → 通用**——界面语言、显示币种，以及按用户存储的**显示 CLI 会话**开关；与菜单中一样，改动即刻生效。
- **个人 → 外观**——应用主题、终端主题、字号与主题色，从用户菜单原样迁入。
- **个人 → 账户**——修改密码操作；该页只在存在可修改密码时出现（桌面 shell 自己的窗口从未见过密码）。
- **服务器 → 代理选项 / 上传限制**——仅管理员；两页保留原设置页的单次 PUT 保存、行内拒绝与后续行为。
- **服务器 → 更新**——手动检查更新操作，旁附当前版本号与发布日期提示；得知新版本后由此进入更新弹窗。桌面模式下隐藏（更新由 shell 负责）。用户菜单保留提醒：圆点与「有新版本可用」行，点击直达本页。
- **服务器 → 用户管理**——用户管理（列出 / 创建 / 重置密码 / 删除）从独立路由迁入弹窗；仅管理员，桌面模式下不出现。

## 终端主题默认跟随应用

终端主题的默认值由固定深色改为**跟随应用主题**：未显式选择时，应用切换明暗会带动终端。已显式保存的浅色/深色选择不受影响——存储值缺失即视为「跟随」，显式选定任一模式仍可与应用解耦。

## 细节

- 页面可见性收敛为一个注册表，导航与落地页请求共用同一规则：非管理员请求管理员页面会落到自己的第一页——与未知请求得到同一答案——不会得知该页存在；接口侧一律 403。
- 桌面 shell 自己的窗口没有账户、更新、用户管理三页（token 会话、shell 负责更新、单用户服务端）；用密码登录同一桌面模式服务器的会话保留账户页。
- 服务端零改动：迁移的是界面，背后的接口未动。
- Web App 参考的系统设置章节改述弹窗及其页面，「版本与更新」章节指向更新页。
