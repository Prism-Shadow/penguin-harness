# 手绘加载圈、脉冲与近似字形改用共享组件

- **Date:** 2026-09-30
- **Type:** refactor
- **Scope:** `web`

[English](2026-09-30-ui-migration-w1b.md)

UI 包迁移的去冗余批次把 Web App 里手绘的加载圈、自制的脉冲动画、`transition-all` 以及注册表字形的近似副本，换成了共享包的 `Spinner`、`Dot` 与 `ICONS`。

## 细节

- **加载圈**：十三处手绘圆环改用包内的 `Spinner`：更新对话框与账户菜单的更新行、加载更早的历史、子 Agent 行、文件面板的上传与保存、模型页的登录等待、协议选择器与三个检测按钮、id 生成按钮，以及内置浏览器标签栏里加载中的标签。检测按钮与 id 生成按钮通过 `Button` 的 `loading` 显示它。
- **脉冲**：聊天面板里运行中进程的圆点、组织架构图的运行状态，以及对话大纲「正在回答」的预览，改用带 `pulse` 的 `Dot`。派生按钮在派生进行时显示 `Spinner`，不再让图标闪烁。
- **过渡**：会话行的悬停按钮、侧边栏的草稿删除与分组置顶按钮，以及大纲刻度，改为写明所动画的属性，不再用 `transition-all`。
- **字形**：收窄的垃圾桶（记忆、Skill、Hook、评估、模型与 Agent 页）改画 `ICONS.trash`；记忆页的编辑笔改画 `ICONS.penLine`，财务页预算格的铅笔改画 `ICONS.pencil`。
- Web 端的去冗余检查清单与字形路径检查清单删去了本批清掉的全部条目。

## 默认主题（通用）的可见变化

- 各处加载圈外观一致：浅色底环上的一段弧线，10、12 或 14 px，取代 1–2 px 边框的圆环。更新对话框与更新行的加载圈不再有 70% 不透明度。
- 脉冲统一为 `Dot`：运行中进程的圆点与组织架构图的圆点改用色调的实底色（成功色 emerald-500 → emerald-700），架构图向外扩散的光晕取消。大纲「正在回答」的预览在文字前显示一个脉冲圆点，文字本身不再闪烁。
- 垃圾桶与铅笔字形统一：收窄的垃圾桶改为注册表的直边垃圾桶，记忆页的笔与财务页的铅笔改为注册表的笔与铅笔。
- 大纲当前刻度的长度变化不再有缓动，颜色变化仍有缓动。
