# 通过活动 Session 构建 WAF 模块

- **Date:** 2026-09-19
- **Type:** feature
- **Scope:** `server`, `web`

[English](2026-09-19-waf-module-assembly.md)

活动增加了从已保存的有效规格构建模块的功能。每次尝试都获得独立的 Harness Session 工作区，其中包含 WAF TypeScript 运行时模板、模块定义、构建配置，以及产品代码与引用编号配置。

## 构建与预览

构建使用配置的 Agent 和普通工具审批流程，执行依赖安装、行为实现、构建及预览准备。WAF 工作区查找会检查上级目录或指定目录中的 framework、modules 和 media。共享工作区路径作为只读上下文提供。

运行收集器要求文件大小受限且为常规文件的产物，包括编译后的模块 JavaScript、构建日志和预览 HTML／运行时文件，并在候选记录中保留产物哈希。取消、重启恢复和 Project 删除使用了活动生命周期。草稿变化时产生冲突，不会替换其规格。

完成的模块运行链接至现有的隔离 Session 工作区预览。历史记录区分了规格与模块尝试，标记了较早的输入修订，并禁止将模块候选内容放入规格编辑器。预览显示 Session 工作区中的文件。

## 兼容性

现有草稿和规格尝试保持不变。迁移与降级说明记录于[向后兼容性](2026-09-19-backward-compatibility.zh.md)。
