# 全部侧边元素的 Tab 式停靠侧边栏

- **Date:** 2026-08-21
- **Type:** feature
- **Scope:** `web`
- **PR:** [#394](https://github.com/Prism-Shadow/penguin-harness/pull/394)
- **Breaking:** yes — 此前保存的终端停靠布局（浏览器 localStorage）不再沿用；停靠区一次性回到关闭状态，运行中的 Shell 仍可从任一停靠区的「+」菜单找回。

[English](2026-08-21-dock-tab-sidebars.md)

将聊天页抽屉式侧边面板与旧的终端 pane 体系，替换为聊天页右侧与下方两个统一的停靠区（Codex 风格）。所有侧边元素——智能体面板、工作区文件面板、记忆面板、新增的轨迹面板，以及任意数量的终端——都成为停靠区里可关闭的 Tab：两个停靠区可同时打开，Tab 点击切换、在栏内拖拽排序、拖拽或通过停靠区的移动按钮移到另一边；每个 Tab 的关闭 × 常驻并占用独立位置，从不与标题重叠。原先面板之间（以及面板与终端 pane 之间）的互斥关系随抽屉一并移除。

## 细节

- 聊天工具栏的面板切换器改为恰好两个拉开按钮——下侧栏、右侧栏——取代逐元素图标、置顶体系与创建菜单。拉开一个还没有 Tab 的停靠区会显示居中的选择列表（智能体面板 / 终端 / 工作区 / 记忆 / 轨迹），选中即在该处打开；每个停靠区自己的「+」菜单可继续添加面板、新建 Shell，或接入任何无会话持有的在运行 Shell。
- 布局按会话独立，如同每个浏览器窗口管理自己的标签页：Tab、当前 Tab 与停靠区开合随 Session 切换，任何会话的 Tab 都不依赖其他会话，且刷新后保持（最久未使用的会话布局自动老化出存储）。草稿页上的布局会交给首次发送创建出的 Session。停靠区尺寸（右宽、下高）仍是全局偏好。
- 从对话内打开的面板——消息文件卡、子智能体行、记忆变更行、派生自动打开——默认落在右侧栏。
- 轨迹面板展示当前会话的 Trace 文件（文件分页块、原始文件导出，以及复用自轨迹页的性能时间线与事件列表）。左侧导航的轨迹入口移除；/traces 浏览页仍可经其深链接（智能体页、会话详情弹层、评估运行）到达。
- 智能体面板的身份条新增跳转按钮，可在对话区打开所选子智能体自己的 Session。
- Ctrl+` 按本会话的终端状态流转：面板遮住时唤到前台、可见时收起、再按恢复——没有终端 Tab 时接入或新建 Shell。Shell 创建失败以错误 toast 呈现。
- 窗口窄于 1024px 时两个停靠区合并为一个下方表面，列出两边的 Tab；窗口拉宽后按存储布局重新拆分。面板的移动端底部 Sheet 形态随抽屉一并移除。
- 修复轨迹面板在 dev 模式下的首次加载：React StrictMode 双调 effect 时列表请求被取消且不再重试，骨架屏会一直停留到手动切换 Tab。

## 兼容性

停靠布局存储于新的 localStorage 键（`penguin.dock.layout`）。旧键（`penguin.terminal.dock`、`penguin.terminal.dockRatios`、`penguin.terminal.tabOrder`）不再读写、原样留存；没有迁移。一次性影响是更新后停靠区回到关闭状态——Shell 在服务端继续运行，所有无会话持有的在运行 Shell 都可从停靠区「+」菜单或选择列表的终端行接回。共享的侧面板宽度（`penguin.panelWidth`）原样沿用。
