# 全部侧边元素的 Tab 式停靠侧边栏

- **Date:** 2026-08-21
- **Type:** feature
- **Scope:** `web`
- **Breaking:** yes — 此前按会话保存的终端停靠布局（浏览器 localStorage）不再沿用；停靠区一次性回到关闭状态，运行中的 Shell 仍可从工具栏的终端菜单找回。

[English](2026-08-21-dock-tab-sidebars.md)

将聊天页抽屉式侧边面板与按会话隔离的终端 pane 体系，替换为聊天页右侧与下方两个统一的停靠区（Codex 风格）。所有侧边元素——智能体面板、工作区文件面板、记忆面板、新增的轨迹面板，以及任意数量的终端——都成为停靠区里可关闭的 Tab：两个停靠区可同时打开，Tab 点击切换、在栏内拖拽排序、拖拽或通过停靠区的移动按钮移到另一边，停靠区的 × 收起整个表面而保留其 Tab。原先面板之间（以及面板与终端 pane 之间）的互斥关系随抽屉一并移除。

## 细节

- 布局——Tab、当前 Tab、隐藏状态、右侧宽度与下方高度——全局持久化：切换会话与刷新后保持，草稿页同样渲染（依赖会话的面板在首次发送创建 Session 前显示占位提示）。终端不再按打开它的会话隔离。
- 聊天工具栏的面板切换器新增轨迹入口，其创建菜单在原有置顶开关旁增加逐元素的放置操作（「在右侧打开」/「在下方打开」）。每个停靠区自己的「+」菜单可添加面板、新建 Shell，或接入任何尚无 Tab 的在运行 Shell。
- 轨迹面板展示当前会话的 Trace 文件（文件分页块、原始文件导出，以及复用自轨迹页的性能时间线与事件列表）。左侧导航的轨迹入口移除；/traces 浏览页仍可经其深链接（智能体页、会话详情弹层、评估运行）到达。
- 智能体面板的身份条新增跳转按钮，可在对话区打开所选子智能体自己的 Session。
- Ctrl+` 现按终端状态流转：面板遮住终端 Tab 时先唤到前台，终端可见时收起持有终端的停靠区，再按恢复——没有任何终端 Tab 时接入或新建 Shell。Shell 创建失败以错误 toast 呈现。
- 窗口窄于 1024px 时两个停靠区合并为一个下方表面，列出两边的 Tab；窗口拉宽后按存储布局重新拆分。面板的移动端底部 Sheet 形态随抽屉一并移除。

## 兼容性

停靠布局存储于新的 localStorage 键（`penguin.dock.layout`）。旧键（`penguin.terminal.dock`、`penguin.terminal.dockRatios`、`penguin.terminal.tabOrder`）不再读写、原样留存；没有迁移。一次性影响是更新后停靠区回到关闭状态——Shell 在服务端继续运行，所有在运行 Shell 都可从工具栏的终端菜单找回。共享的侧面板宽度（`penguin.panelWidth`）原样沿用。
