# 新增六条快捷键：搜索、新建对话、侧栏、面板、新建终端

- **Date:** 2026-09-18
- **Type:** feature
- **Scope:** `web`
- **PR:** [#790](https://github.com/Prism-Shadow/penguin-harness/pull/790)

[English](2026-09-18-shortcut-commands.md)

快捷键注册表新增六条命令，都可在设置的「快捷键」页改绑（`Mod` 在 macOS 为 ⌘，其余平台为 Ctrl）：搜索会话（Mod+K）、新建对话（Mod+Shift+O）、显示或隐藏侧栏（Mod+B）、显示或隐藏右侧栏（Mod+Alt+B）、显示或隐藏下侧栏（Mod+J），以及新建终端（所有平台均为 `` Ctrl+Shift+` ``，与显示 / 隐藏终端的 `` Ctrl+` `` 相邻）。执行同一动作的按钮——对话工具行的面板开关、侧栏的搜索与新建对话按钮、侧栏的折叠与展开控件——在悬停提示里写明组合。

## 细节

- 终端有焦点时，xterm 会送给 shell 的按键仍归 shell：Windows 与 Linux 上 Ctrl+B、Ctrl+K、Ctrl+J 照旧是 tmux 前缀、删除到行尾与换行。终端里仍能触发的应用命令只有 xterm 自身不发送的组合——`` Ctrl+` ``、`` Ctrl+Shift+` `` 以及 Mac 上的全部 ⌘ 组合。
- 用 AltGr 输入的字符（Windows 把它报成 Ctrl+Alt）视为输入而非组合：捷克与匈牙利键盘布局上的 `{` 虽然按键读作 Mod+Alt+B，仍可照常输入。
- 搜索会话打开侧栏的搜索框，已打开时把光标放回其中；在收起的图标栏上按一次即展开侧栏并打开、聚焦搜索框。新建对话与其他各处的新建对话一致，先把已输入未发送的文字停放为草稿，侧栏收起时同样可用。两者都是开发模式的命令：公司模式下把按键留给浏览器。
- 目标不在屏幕上的命令同样把按键留给浏览器：`md` 断点以下（固定侧栏不显示）的侧栏命令，以及没有停靠栏的页面——组织页、登录页、独立终端页——上的面板与终端命令，因而不会向隐藏的停靠栏里新建终端。对话框或菜单打开期间，全局命令也不触发。
- 设置页此前为空的「面板」分组现在放置侧栏与面板的开关。
