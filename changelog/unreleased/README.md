# Unreleased

- [2026-08-18] Compaction: a mid-task compaction now closes the pending tool exchange first and the loop always resumes afterwards (a failed one continues on a synthesized note instead of silently ending the run); traces left dangling by a crash mid-compaction heal on resume, so the conversation after a compaction no longer vanishes on reload and interrupted runs stop producing "unknown tool" cards; the summary streams live into the Web App's compaction banner via a new `compaction_delta` event (#288, #290). ([details](2026-08-18-compaction-continuity-and-streaming.md))
- [2026-08-18] Web App: the admin proxy address accepts `socks5://` / `socks://` URLs (undici's experimental SOCKS5 tunnel) alongside `http(s)://`, credentials allowed; validation becomes "whatever undici's dispatcher constructs", so schemes it refuses (`socks4://`, …) stay `400 invalid_proxy_url` instead of bricking the next server start. ([details](2026-08-18-proxy-socks.md))
- [2026-08-18] CLI: `penguin server reset-admin-password` — offline rescue for a forgotten Web admin password: with the server stopped, resets `admin` to a fresh initial password (framed notice, re-printed on every start until changed; the login-page footer and top-level `penguin --help` now point at the command) and clears its sign-in sessions. ([details](2026-08-18-admin-password-reset.md))
- [2026-08-18] Core & Web App: an official `MiniMax-M3` preset (1M context, vision) pins AgentHub's `minimax-m3` Responses client and direct endpoint, uses `MINIMAX_*` credential fallback, prices at the standard pay-as-you-go tier (≤512K input), and adds the MiniMax provider glyph plus bilingual docs (requires AgentHub >= 0.4.2). ([details](2026-08-18-minimax-m3-preset.md))
- [2026-08-18] The running harness — desktop app included — can be updated over HTTP without a restart: one atomic push replaces the backend platform, the CLI's commands (`penguin-hmr`), and the Web App together; pushed code can add or replace API endpoints; live terminals survive the swap. Admin session required, loopback-only without HTTPS. ([details](2026-08-18-hot-update.md))
- [2026-08-18] Web App: code highlighting is assembled from `shiki/core` with an explicit language list and the pure-JavaScript regex engine instead of Shiki's full bundle — the first code block of a conversation costs ~69 KB gzip instead of ~308 KB (the oniguruma WASM engine and the 332-grammar registry are gone; every bundled grammar was verified to translate to JavaScript regexes with byte-identical tokens), at the cost of languages outside the carried list rendering unhighlighted (#300). ([details](2026-08-18-web-code-highlight-bundle.md))

([details](2026-08-11-cli-model-remove.md))
