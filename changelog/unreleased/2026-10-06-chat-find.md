# Ctrl+F finds inside the area you are in, Ctrl+Shift+F finds across the window

- **Date:** 2026-10-06
- **Type:** feature
- **Scope:** `web`, `ui`, `docs`
- **Issue:** [#991](https://github.com/Prism-Shadow/penguin-harness/issues/991)

[中文版](2026-10-06-chat-find.zh.md)

A find bar for the app: `Ctrl+F` searches the area the focus is in, `Ctrl+Shift+F` searches every
area on screen at once and lists what it found, and `Escape` closes it. Nothing is sent to the
server — every match is found in the DOM that is already rendered.

## Details

- **An area is whatever opts in.** A surface becomes searchable with `data-find-region="<kind>"` on
  its scroll container, and nothing else: the conversation, a subagent panel's conversation, the
  sidebar's Session list and the Files panel carry it. Ctrl+F resolves the focused element to the
  nearest such ancestor, and falls back to the conversation when the focus is nowhere in particular
  — a composer or a toolbar — rather than to whatever is first in document order.
- **Matches are painted through the CSS Custom Highlight API**
  (`::highlight(penguin-find)` / `::highlight(penguin-find-current)`), so highlighting never wraps
  or splits the text nodes it marks and a re-render under it cannot inherit a half-wrapped tree.
- **Typing never scrolls the page.** The count updates on every keystroke, but in a transcript that
  streams while you read it a scroll that follows each character typed is a scroll that fights the
  reader. Enter, the two stepper buttons and a click on a result row are the ways to travel, and the
  first Enter press only shows the match already selected — the second moves to the next one.
- **`Aa` matches case**, the counter reads `3/12` (or 无结果 / No results) and is announced through
  `aria-live`, and `Enter` / `Shift+Enter` / `Shift+F3` step forward and back.
- **Searching shows what was collapsed.** Turn groups mount their rows only while open
  (`features/chat/work-group.tsx`), so a live query mounts every collapsible body
  (`lib/find-expand.ts`) and a hit inside a closed group is a match rather than invisible text.
  The groups' own open/closed state is untouched, so closing the bar restores the page exactly.
- **The aggregated list** draws one row per hit — its area's label plus 40 characters either side,
  truncated with ellipses — capped at 50 rows with the rest counted instead of rendered. A scope
  button at the bottom widens the search to every area and narrows it back to the one Ctrl+F
  started in.
- **Content that was never loaded is the one thing this cannot fix, and the bar says so.** A region
  that knows it holds more history carries `data-find-more`, which becomes the "Earlier content is
  not loaded — Load and keep searching" row: clicking it starts the same backfill that region's own
  scroll affordance does, and when the window lands the search continues *upward* from where the
  reader was rather than jumping to the top of the conversation.
- **Re-indexing is mutation-driven and debounced**, because the transcript changes under the search
  while it streams and a stale index is the normal case rather than an error: the bar re-walks 300ms
  after the document's mutations quiet down, and at least once every 1.5s during a burst that never
  pauses. Its own panel is excluded from that watcher, and a hit that has left the document gets one
  re-index to settle before the bar gives up on it.
- **Ctrl+F inside a dialog is left to the browser.** A form in a dialog is the one place where
  Ctrl+F means the browser's own find, and stealing it there would be unwelcome; the bar's own
  window-level handler stands down whenever a `[role="dialog"][aria-modal="true"]` is open. The bar
  is itself an Escape layer (`components/ui/modal.tsx`), so Escape closes it before anything
  underneath it — and a dialog opened on top takes that Escape first.
- **Supporting changes**: `FileTree` and `SidebarFrame` in `@prismshadow/penguin-ui` gained an
  optional `findRegion` prop so the Files panel and Session list can opt in without other hosts
  doing so, and `packages/docs/content/chat.en.md` / `chat.zh.md` document the two shortcuts.
