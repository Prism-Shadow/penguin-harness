# 单美元符号的行内公式可以渲染，Shell 变量与价格仍是文字

- **Date:** 2026-10-29
- **Type:** feature
- **Scope:** `ui`

[English](2026-10-29-inline-dollar-math.md)

聊天回复、Trace 事件、Benchmark 用例与 Markdown 文件预览中以 `$…$` 写的公式，现在会像 `\(…\)` 一样排版为行内公式。此前只有 `$$…$$`、`\(…\)` 与 `\[…\]` 能渲染，`分母 $n-1=2$，均值标准误 $s/\sqrt{3}$` 这样的回复会直接显示 TeX 源码。文档站与博客不变。

## 规则

- `$` 之后紧跟非空白字符、且之前不是 ASCII 字母、数字、`\` 或 `$` 时，它开启一个公式。
- 其后第一个未被反斜杠转义的 `$` 在前一个字符不是空白、后一个字符不是 ASCII 字母或数字时闭合公式；这个 `$` 不能闭合时，开启处不构成公式。
- 公式不跨行；代码片段、代码块与 `\$` 中的美元符号保持原样。

`Set $PATH and $HOME`、`$5-$10`、`echo $PATH; echo $HOME`、`$1,200 and $3,400`、`export PATH=$HOME/bin:$PATH`、`"$A$B"` 与 `价格是$5，折扣后$3` 都保持为文字，美元符号一个不少；闭合的 `$` 之后是中文字符或标点则不受影响（`$n$）`）。紧贴单词书写的公式（如 `$i$th`）保持为文字，写作 `$i$-th` 即可渲染。

## 细节

- 回复流式输出时，若一个 `$…$` 的闭合 `$` 恰是目前收到的最后一个字符，它先按原样显示，等下一个字符到达再定，Shell 文本因此不会有一帧丢掉美元符号。公式仍在回复结束后排版，与此前一致。
- `$$…$$` 仍渲染为独立公式，与之并列的 `$…$` 仍为行内公式。
