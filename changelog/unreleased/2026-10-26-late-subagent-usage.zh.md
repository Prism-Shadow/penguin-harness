# 保留会话移除期间已完成的子代理用量

- **Date:** 2026-10-26
- **Type:** fix
- **Scope:** `core`, `server`
- **PR:** [#1363](https://github.com/Prism-Shadow/penguin-harness/pull/1363)

[English](2026-10-26-late-subagent-usage.md)

后台子代理收到模型服务商的完整响应时，最后一条 Trace 记录可能仍在写入。在这个时刻删除父会话，
过去会丢弃随后产生的 token 用量，导致项目汇总少于服务商已报告的用量。

环境释放后现在仍会转交会话元数据和请求记账记录。即使运行时已移除，服务器也会将这些记录计入
原父会话，并保留子代理的模型归属，同时停止向已移除会话的消息流推送子代理输出。
删除整个项目仍会清空其用量历史；先删除会话、再删除项目时，晚到记录也不会重新写入。

更新模型配置或凭据后，父会话可能在子代理仍运行时重建运行时。子代理后续的输出仍会推送到该会话。

此修复保留已报告的用量，不估算未报告的 token，也不代表核实了服务商的实际扣款。

删除测试也覆盖与子任务清理等待组合时的有界清理期限。

替换运行实例后，晚到用量仍保留原实例所属的项目生命周期，因此以同一 ID 重建项目不会继承旧子任务的用量。
