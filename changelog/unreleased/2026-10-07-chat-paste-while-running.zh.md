# `penguin chat` 在 Task 运行时的粘贴会被保留，不再丢失

- **Date:** 2026-10-07
- **Type:** fix
- **Scope:** `cli`, `docs`

[English](2026-10-07-chat-paste-while-running.md)

在终端里，`penguin chat` 会丢掉 Task 运行期间到达的括号粘贴（bracketed paste）：文本没有送到模型，屏幕上也没有任何提示，而同一时刻键入的一行却会成为插话。Task 刚结束、REPL 还没回到提示符时的粘贴同样会丢失。现在，在所有接受消息的状态下，粘贴都与键入的文本行为一致。

## 细节

- Task 运行时，粘贴的文本经渲染器回显并等待 Enter，按下后作为一条插话消息整段发出，所有行一起。等待期间流式输出暂停，与输入了一半的行相同。
- 如果 Task 在按 Enter 之前结束，粘贴的文本保留在续行提示符下，下一次 Enter 把它作为下一条 Prompt 发送；此前回到提示符时会把它清掉。
- 运行中键入以 `\` 结尾的行会继续当前消息，与在提示符下一致。
- 审批询问或退出确认期间的粘贴仍被忽略：这两处只接受键入的 y/N 回答。
- CLI 页面的 REPL 表格中英两版都补充了通过粘贴插话的说明。
