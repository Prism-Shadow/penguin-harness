# The Code of Conduct moves to Contributor Covenant 3.0

- **Date:** 2026-09-12
- **Type:** process
- **Scope:** `docs`
- **PR:** [#704](https://github.com/Prism-Shadow/penguin-harness/pull/704)

[中文版](2026-09-12-code-of-conduct-3-0.zh.md)

## Details

- `.github/CODE_OF_CONDUCT.md` and its Chinese counterpart carry Contributor Covenant 3.0 in
  place of 2.1, each taken from the project's own published text — the English from
  [version/3/0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/), the Chinese
  from [its official zh-cn translation](https://www.contributor-covenant.org/zh-cn/version/3/0/code_of_conduct/)
  rather than a rendering of our own. Both files were moved together: a Code of Conduct is a
  governance document, and leaving the two languages on different versions would have meant the
  rules a reader is held to depended on which file they opened.
- 3.0 reorganises the document. "Our Standards" becomes **Encouraged Behaviors** and
  **Restricted Behaviors** (plus **Other Restrictions**, which 2.1 had no equivalent of);
  "Enforcement" and "Enforcement Guidelines" become **Reporting an Issue** and **Addressing and
  Repairing Harm**; "Enforcement Responsibilities" is gone. The four-rung ladder survives with
  new names — Warning, Temporarily Limited Activities, Temporary Suspension, Permanent Ban —
  and each rung now names the **repair** expected of the person, not only the consequence.
- The reporting route is unchanged: a direct message to a maintainer on Discord. 3.0 leaves that
  as an adopter placeholder, and it is filled with what 2.1 already said.
- 3.0's second adopter placeholder — a note telling the adopter to replace the ladder if the
  project has its own process — is dropped rather than reproduced. This project has no separate
  process, so the ladder is the policy, and a bracketed note to ourselves does not belong in a
  document the community is held to.
- Attribution changes with the version: 3.0 is stewarded by the Organization for Ethical Source
  under CC BY-SA 4.0, so 2.1's Creative Commons attribution replaces the old one. The link to the
  licence text is kept, because CC BY-SA 4.0 asks an adaptation that cites it to carry it. The FAQ
  and resources links and the Mozilla enforcement-ladder credit are dropped: 3.0 still carries all
  three, and they are pointers to the Covenant's own material rather than terms a reader here is
  held to.
