# 文档写明远程机器须运行与服务端相同的版本

- **Date:** 2026-10-26
- **Type:** process
- **Scope:** `docs`, `landing`
- **PR:** [#1340](https://github.com/Prism-Shadow/penguin-harness/pull/1340)

[English](2026-10-26-docs-machine-version.md)

更新文档页新增「更新远程机器」一节：远程机器必须运行与所连服务端相同的版本。更新服务端之后，在「机器管理」页面把每台机器更新到同一版本（单台用「更新」，或用「全部更新」）；机器已显示服务端的版本却仍连不上时，重启它的服务端，重启无效再重装该版本。0.2.17 发布博客的升级须知也补上了同样的一条。
