# RFC 可以带一节 Invariants

- **Date:** 2026-10-26
- **Type:** process
- **Scope:** `rfcs`
- **PR:** [#1310](https://github.com/Prism-Shadow/penguin-harness/pull/1310)

[English](2026-10-26-rfc-invariants.md)

新增草案 PRFC-0022（RFC Invariants）。RFC 正文可以带一节可选的 `## Invariants`，写下设计必须一直保持的性质：每条是一个 `### <名称>` 标题、一句引用块中的陈述和一段简短正文，只能在声明它的那篇 RFC 的修订中按名称撤销。`rfcs/TEMPLATE.md` 加入了这一节，RFC 索引列出了 PRFC-0022。
