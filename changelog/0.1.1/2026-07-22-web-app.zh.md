## 侧边栏按 Workspace 分组

聊天侧边栏现在默认按 Workspace 对会话分组，并提供一个持久化的开关切回按 Agent 分组。Workspace 分组以目录的 basename 作标签（完整路径在 tooltip 中），按其最新会话排序；自动创建的临时工作区（`workspaces/tmp-<8hex>`）会收拢为单个「临时工作区」分组，而不是每个会话一个分组。每个 Workspace 头部的「+」会新建一个预填该工作区的会话；Workspace 模式下的行会带一个小的 Agent 头像，使 Agent 上下文保持可见。分组的折叠状态按 Project 跨刷新持久化。Agent 模式未变。

此后分组又获得了打磨与结构上的改进：头部统一为一致的悬停高度；Workspace 文件夹图标随分组展开与收起而开合；两种分组模式都支持把分组置顶（按 Project 持久化）。由子 Agent 与定时任务创建的会话，会归入两个默认折叠的文件夹——Subagents 与 Scheduled——与每个分组内的 Archived 平级；每个分组至多列出一页会话，并带一个「更多」行按需加载后续页（会话列表 API 新增 `limit`/`offset`，因此侧边栏永远不会拉取无界列表）。

## 模型拾取器优先列出已配置的模型

聊天模型下拉框只显示已配置 API key 的模型（必须是已存储的、脱敏显示的 key——仅有一个环境变量名不算），并由一个弱化的底部行按需展开其余模型，每个都标有带斜线的钥匙图标（本地化标签保留给辅助技术）。当前选中的模型与 Project 默认模型始终可见；而当尚无任何模型配置了 key 时，下拉框会退回显示全部，而不是渲染成空的。

## 自定义模型分组与 Agent 的字母头像

用户自定义的模型 Provider 分组此前共用同一个通用图标，使得模型拾取器中跨分组的同名模型难以区分。自定义分组现在渲染为首字母方块——取名称的第一个字素，置于由该名称派生的柔和底色之上，配以主题感知的彩色字色，在浅色与深色模式下均保持 WCAG AA 对比度——因而每个分组都有稳定且彼此可辨的外观。Agent 头像也采用同样处理，其颜色以 Agent id 为键，因此重命名后颜色不变。

## 收起态的导航栏

收起后的侧边栏现在是一条完整的导航栏，含八个固定顺序的入口——上一次会话（该 Project 最新的未归档会话；仅在确实没有时禁用，加载过程中不禁用）、新建会话、Agents、Skills、Models、Costs、Traces，以及 Benchmark（此前缺失）——每个都有中英悬停提示，并对任何已打开的会话给出导航栏级别的激活高亮。

## 成本中心的提示气泡

每日 Token 图表的悬停气泡以右下偏移跟随指针，在靠近边缘时翻转方向，因此既不会盖住被悬停的图元，也不会被裁切；指针移动通过命令式定位（不会每次 mousemove 都重渲染）。Cache Read 分段的气泡另外显示缓存命中率——缓存读取除以读取加写入——其计算方式与标注文案都与 Trace 页面已有的命中率完全一致。

## 设置表单

在模型详情对话框中，上下文窗口与最大输出 Token 并排排列，Token 单位置于各自输入框内，说明文字作为 placeholder 并配悬停提示；模型主页移到对话框头部并做成按钮；三个价格字段各自带独立标签，不再有标题行；视觉支持改为 iPhone 风格的开关且不带说明文字。Agent 设置中的运行时下拉框不再提供「默认」这一行——改由一个重置链接恢复继承状态——且所有下拉框的文字尺寸与输入框一致。

## 复制的任务统计已本地化

复制消息操作产出的逐任务统计行此前是硬编码中文；现在它像其他每一条 UI 文案一样走词条，因此英文会话复制出的是英文统计。

## 聊天消息渲染

聊天消息中的链接一律在新标签页打开（`target="_blank" rel="noreferrer"`），显式链接与 GFM 自动识别的裸 URL 同样适用。展开的子 Agent 对话现在渲染在该工具调用自身的参数与输出**之下**而非之上；所有聊天下拉框在移动端都保持在视口内（此前有三个面板最多溢出 143px，其中一个还会让整页横向滚动）。长 URL 与行内代码 token 以 `overflow-wrap: anywhere` 换行——它们在容器边缘断开，同时绝不会在中文行文中把普通拉丁词从中切断——宽表格在消息内部滚动而不是撑宽页面，与文档站的规则一致。流式渲染管线中稳定的组件映射得以保留，因此回复流式输出期间，代码块仍保持其文本选区与复制状态。
