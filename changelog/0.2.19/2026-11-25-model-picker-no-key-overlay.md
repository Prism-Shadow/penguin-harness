# Prompt to connect a model provider when no keyed models exist in the picker

- **Date:** 2026-11-25
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1844](https://github.com/Prism-Shadow/penguin-harness/pull/1844)

[中文版](2026-11-25-model-picker-no-key-overlay.zh.md)

When no model in the model picker has an active provider connection or API key, an overlay now prompts the user to connect a provider or configure an API key and offers a direct button to open the Models page.
