# Open a Session's terminals and browser pages on demand

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`, `browser-automation`
- **PR:** [#1740](https://github.com/Prism-Shadow/penguin-harness/pull/1740)

[中文版](2026-11-23-open-scoped-terminal-browser.zh.md)

Opening the terminal or built-in browser shows the selected Session’s running resources. Use the new terminal or new tab button to start one. Closing the last item leaves the empty group open. From another machine, the browser workbench lists the Session’s managed desktop pages and lets you open and close them there.
