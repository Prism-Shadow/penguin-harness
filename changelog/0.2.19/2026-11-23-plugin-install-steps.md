# Move between server and Agent steps in the plugin marketplace

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1729](https://github.com/Prism-Shadow/penguin-harness/pull/1729)

[中文版](2026-11-23-plugin-install-steps.zh.md)

Open the same installation flow from a marketplace card or its details. Return to the server step to inspect the installed package, then continue to individual Agents. Project owners can explicitly uninstall an Agent’s copy, and server administrators can review affected installations before removing a server package.
