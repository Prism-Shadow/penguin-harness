# Administrator settings for terminal and browser limits

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`, `server`
- **PR:** [#1738](https://github.com/Prism-Shadow/penguin-harness/pull/1738)

[中文版](2026-11-23-admin-resource-limits.zh.md)

Administrators can change each user’s active terminal limit and each built-in browser backend’s page limit independently in Settings. Restore defaults puts both default values in the form for review before saving.
