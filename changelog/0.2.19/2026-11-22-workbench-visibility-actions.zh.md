# 在 Agent 设置中打开或隐藏工作台

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1705](https://github.com/Prism-Shadow/penguin-harness/pull/1705)

[English](2026-11-22-workbench-visibility-actions.md)

Agent 设置中的工作台行会根据当前状态提供「从应用中心隐藏」或「在应用中心取消隐藏」。这个操作更改 Project 成员看到的入口。隐藏后仍可在该行点「打开」使用工作台，侧边栏显示仍在「更多」中单独设置。
