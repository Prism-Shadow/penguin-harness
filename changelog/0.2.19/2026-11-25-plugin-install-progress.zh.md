# 插件安装改用一条分段进度条

- **Date:** 2026-11-25
- **Type:** feature
- **Scope:** `web`, `ui`, `ui-gallery`
- **PR:** [#1867](https://github.com/Prism-Shadow/penguin-harness/pull/1867)

[English](2026-11-25-plugin-install-progress.md)

从插件市场安装插件，现在和在手机上装应用差不多：插件的图标和名称，一条按安装阶段分段的进度条，一句话说明正在做什么，装好之后有明确的完成状态。

## 安装面板

- 进度条按这次安装实际会经过的阶段分段：查找插件、下载安装、启动、选择智能体。启用服务器自带的插件，或者装到另一台机器，只有启动一段；没有智能体内容的插件没有选择智能体这一段。
- 已完成的阶段填满。服务端报告了下载量时，当前阶段按实际下载量填充，句末显示百分比；没有报告时只显示一小段脉动标记。一次安装里进度条不会后退，全部完成后才会填满。
- 安装进行中，图标变淡并套上转动的圆环，和应用中心里正在安装的应用一样。面板会说明安装无法中途取消、关掉窗口后在后台继续，此时只有一个按钮**在后台继续**。
- 服务端装好后，面板接着让你选择智能体，说明添加之前没有智能体会用到它，也可以**以后再选**。添加第一个智能体后，面板显示插件可以用了、已添加给谁，并提供打开应用或快速调用。
- 安装失败时，进度条停在失败的那一段，面板写明没能装上和服务端给出的原因，并提供**重试**、插件源设置和从文件导入。属于故障的失败可以报告问题。
- 不能安装的成员看到的是一段简短说明和**请管理员安装**，不再是一个安装步骤。
- 各阶段的说明改成了日常用语，中英文同步。

## 市场卡片与包更新

- 安装进行中，市场卡片的安装操作在单行文字下显示同一条进度条。
- 更新包的确认弹窗显示同一条进度条和说明。

## 共享 UI 与组件库

- UI 包新增 `StagedProgress`，封面卡片的通栏操作新增可选的进度位。
- 组件库的「加载」板块展示分段进度条的各个状态。演示市场里有两个包会走完整个安装流，其中一个在下载中途失败；演示页可以用 `as=member` 以成员身份登录。
