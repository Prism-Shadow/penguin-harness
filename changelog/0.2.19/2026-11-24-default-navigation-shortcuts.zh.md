# 使用常用快捷键导航和切换面板

- **Date:** 2026-11-24
- **Type:** fix
- **Scope:** `web`, `desktop`
- **PR:** [#1806](https://github.com/Prism-Shadow/penguin-harness/pull/1806)

[English](2026-11-24-default-navigation-shortcuts.md)

在 macOS 上按 Cmd+B，在 Windows 和 Linux 上按 Ctrl+B，即可展开或收起侧栏；在聊天输入框中也可使用。桌面应用还支持 Cmd/Ctrl+K 搜索会话、Cmd/Ctrl+N 新建对话、Cmd/Ctrl+Alt+B 切换右侧停靠栏、Cmd/Ctrl+J 切换底部停靠栏。网页继续沿用适合浏览器的对应组合。快捷键设置和按钮提示会显示当前宿主的绑定。
