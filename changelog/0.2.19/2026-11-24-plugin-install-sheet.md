# Guide plugin setup from the server to each agent

- **Date:** 2026-11-24
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1822](https://github.com/Prism-Shadow/penguin-harness/pull/1822)

[中文版](2026-11-24-plugin-install-sheet.zh.md)

The plugin market card and detail open the same setup sheet. It identifies the plugin, explains when it needs a shared server copy or a service enabled for the current project, and shows progress during an actual install. A prepared plugin opens at the agent chooser. Each agent’s status is visible, and adding, updating or removing a copy applies to the selected agent.

Members can request a published plugin from its card or detail before its contents have been downloaded. The server step explains that all projects on the server share one copy, and its impact disclosure opens from the keyboard. Agents with the same name show their IDs. The selected agent’s Add button fits on a narrow screen.
