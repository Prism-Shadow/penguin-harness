# 在侧栏查看已打开的应用

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1713](https://github.com/Prism-Shadow/penguin-harness/pull/1713)

[English](2026-11-23-sidebar-running-system-apps.md)

侧栏「应用」只列出当前窗口、当前 Project 已打开的应用，包括系统应用和远程工作台。可从应用中心或对话旁的「浏览工作台」打开应用。最小化保留标签，关闭即从侧栏移除。在组内可搜索、滚动，或按页面顺序、名称、最近使用排序。应用中心的显隐仍可在 Agent 设置中调整。
