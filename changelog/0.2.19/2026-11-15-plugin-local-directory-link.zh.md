# 插件可以从本机目录链接

- **Date:** 2026-11-15
- **Type:** feature
- **Scope:** `server`, `cli`, `web`
- **PR:** [#1562](https://github.com/Prism-Shadow/penguin-harness/pull/1562)

[English](2026-11-15-plugin-local-directory-link.md)

`penguin plugin link <directory>` 把本机的插件包目录链接进服务端的插件前缀，而不是上传一份拷贝：目录留在原地，服务端就地装载这个插件。链接交给 npm 自己——目录作为 `file:` 依赖记进前缀并落成符号链接，后续安装时 npm 自己保持链接与记录同步；`penguin plugin remove` 摘除链接与往常移除任何包一样，作者目录原样不动。

## 细节

- 送出之前先过校验：CLI 用插件库自己的读取器读目录（与目录安装同一道门），服务端拒绝不是插件包或没有插件贡献面的目录。名字已在前缀安装时先拒绝，加 `--overwrite` 才替换成链接。
- 装载器沿符号链接把链接包的名字解析到作者目录——与安装的包走同一条查找路径——声明、贡献面与版本都从目录的文件读取。改动目录后下一次装载即生效；刷新插件页就读到新版本与新描述。目录被删或被改名时，页面按那次读取把该行的故障如实显示，而不是当作装好的插件通过。
- 链接的插件与安装的插件并排出现在插件页上，同一张卡片，带 **链接** 标记，指向即可看到目录路径。链接的包没有钉住的内容哈希：同一份目录在不同时刻是不同内容，需要钉版本的场合仍走安装。
