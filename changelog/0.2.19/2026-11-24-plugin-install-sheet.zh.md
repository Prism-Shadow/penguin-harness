# 在服务端准备插件后，选择使用它的智能体

- **Date:** 2026-11-24
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1822](https://github.com/Prism-Shadow/penguin-harness/pull/1822)

[English](2026-11-24-plugin-install-sheet.md)

从插件市场卡片或详情打开同一个安装面板。面板显示插件图标和名称，并说明何时需要在服务端安装一份共享插件，或为当前项目启用服务。安装开始后才显示实际进度。已准备的插件直接进入智能体列表。列表显示各智能体的安装状态，可以添加、更新或移除所选智能体的副本。

插件尚未下载时，成员可以从卡片或详情申请安装。安装前会说明这台服务器上的所有项目共用一份插件，可以用键盘展开对服务端的影响。同名智能体在名称下显示各自的 ID，手机窄屏也能完整显示「添加」按钮。
