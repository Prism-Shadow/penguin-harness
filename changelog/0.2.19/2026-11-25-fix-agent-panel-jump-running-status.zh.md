# 从 Agent 面板进入正在运行的子会话时保持运行状态与实时流

- **Type:** fix
- **Scope:** `web`
- **PR:** [#1852](https://github.com/Prism-Shadow/penguin-harness/pull/1852)

修复了从 Agent 面板点击「跳转到该对话」进入正在运行的子会话时错误显示为「运行完毕」的问题，并支持在托管运行的子会话页面直接接收实时流、处理工具审批、插入引导（steer）与停止运行。
