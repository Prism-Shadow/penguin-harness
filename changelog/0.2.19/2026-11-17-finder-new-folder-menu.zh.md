# 工作区选择器：「新建文件夹」移入右键菜单

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1589](https://github.com/Prism-Shadow/penguin-harness/pull/1589)

[English](2026-11-17-finder-new-folder-menu.md)

所有工作区选择入口打开的工作区选择器不再在工具条上设「新建文件夹」按钮。它像 macOS 的 Finder 一样，成为在列表空白处右键所弹出菜单的首项；该菜单针对当前显示的目录。

## 细节

- 该项展开的名称输入行与原先相同，校验和服务端拒绝时的说明也不变。
- 未选中任何行时，在列表上按菜单键或 Shift+F10 弹出同一菜单，焦点落在「新建文件夹」上；Mac 上按 ⇧⌘N（其他平台 Ctrl+Shift+N）直接展开名称输入行。浏览器把这组键留给新建隐私窗口，因此只在桌面端于菜单项旁标出。
- 目录行自己的菜单不提供「新建文件夹」，与 Finder 和资源管理器一致。
- 当前目录读取失败时，菜单照常列出「新建文件夹」，置灰并在其下写明原因，另有复制路径与刷新。
- 目录读取中，「新建文件夹」置灰。
