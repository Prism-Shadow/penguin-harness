# 首页应用中心生成流程、自进化循环与模型标识

- **Date:** 2026-11-26
- **Type:** feature
- **Scope:** `landing`
- **PR:** [#1872](https://github.com/Prism-Shadow/penguin-harness/pull/1872)

[English](2026-11-26-landing-narrative-polish.md)

首页应用中心的演示改为一轮生成九个应用，同一时间只有一两个在构建，主屏填满后停留片刻再从头开始；无论新生成还是已安装，每个应用都换成了图标，不再用文字作封面。自进化工作台里，每个被测 Agent 的循环改成一支绕整圈转动的箭头；Optimizer 与 Evaluator 向下的连线合成一条圆角总线，每条分支末端都有箭头，说明文字移到线旁；一轮循环缩短为两秒。首屏的支持模型标识新增 TokenDance 与 OpenCode。从应用中心一节到页尾，各节的标题、副标题与卡片文字都做了删减。
