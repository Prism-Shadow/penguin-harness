# Keep the new chat composer and shortcuts together

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `web`, `landing`
- **PR:** [#1709](https://github.com/Prism-Shadow/penguin-harness/pull/1709)

[中文版](2026-11-22-home-composer-layout.zh.md)

The new chat shows the product name and tagline above the composer. Suggested examples, saved shortcuts, shuffle and management controls share one horizontally scrollable row. The input grows with long drafts and supports keyboard resizing. The version and update date appear at the foot of the page. The website preview uses the same layout.
