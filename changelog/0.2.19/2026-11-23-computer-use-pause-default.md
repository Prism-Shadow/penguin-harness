# Computer Use leaves pausing during user input off by default

- **Date:** 2026-11-23
- **Type:** fix
- **Scope:** `plugins`, `docs`
- **PR:** [#1724](https://github.com/Prism-Shadow/penguin-harness/pull/1724)

[中文版](2026-11-23-computer-use-pause-default.zh.md)

An administrator can enable **Pause while the user is active** in Computer Use settings. The setting is off until configured. Previously saved choices still apply.
