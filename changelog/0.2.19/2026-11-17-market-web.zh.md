# 插件市场支持卡片与列表视图

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `core`, `server`, `web`, `ui-gallery`
- **PR:** [#1584](https://github.com/Prism-Shadow/penguin-harness/pull/1584)

[English](2026-11-17-market-web.md)

打开应用内的插件市场即可搜索插件、按类别或安装状态筛选，也可以用控件行末的两个图标（网格与列表，悬停显示名称）切换卡片和列表。浏览器会记住上次的视图和排序。若搜索只命中其他分类，可以直接查看全部匹配项。

卡片和列表都可查看详情、管理安装和打开已安装的工作台。详情可用链接直接分享，浏览器后退会回到市场。手机上详情占满屏幕。

市场中只由远端提供的插件也会出现在对应的分类下，例如“实用工具”和“娱乐”。

卡片右上角显示版本，底部是两个单行的文字操作。安装操作只写一种状态：还没有 Agent 装它时为「安装」；任一 Agent 装了之后为「N 个 Agent 已装」，点开「管理安装」，其余 Agent 在那里安装；当前 Agent 的副本落后时为「更新」；服务端插件运行中为「服务端已装」。包有更新时写明可更新到的版本。点「快速调用」可用当前 Agent 打开示例。列表里每个插件一个紧凑行（图标、名称与其下单行的描述，同一行末是安装操作与「快速调用」），常见的桌面宽度下并排两行，窗口窄时一行一个。卡片连同版本标签与两个操作都是 UI 包的封面卡片，与公开站点的目录同一张卡。
