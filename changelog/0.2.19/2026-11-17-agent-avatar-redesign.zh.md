# Agent 的缺省头像换成日系治愈风的小企鹅，并各有配饰

- **Date:** 2026-11-17
- **Type:** feature
- **Scope:** `ui`, `ui-gallery`
- **PR:** [#1577](https://github.com/Prism-Shadow/penguin-harness/pull/1577)

[English](2026-11-17-agent-avatar-redesign.md)

Agent 没有自己的图片时画的那只企鹅，按文具店周边角色的画风重画了：一整只蛋形的小企鹅，鳍贴在身侧，一双橙色小脚，奶油色的脸，眼睛很小、靠下、分得很开，一只橙色小喙，头顶一卷绒毛，通身一条细细的棕色线。它取代原先「深色圆环里套一张小脸」的圆球。每个 Agent 的企鹅另有八选一的配饰，与颜色一样由 Agent 的 id 决定。Agent 自己的图片、底色块的形状与落盘数据均不变。

## 细节

- 颜色更亮：深色模式下身体是该色相的粉彩色，衬在深色底上；浅色模式下是该色相里仍能对浅色底与各主题页面保持 3:1 的最浅一档。脸、眼睛与腮红两种明暗相同。
- 各尺寸是同一张脸，尺寸越小五官画得越大：40px 起为原本大小，24px 起大一号，24px 以下再大一号，线条也更粗、改用眼睛的深棕色，14px 下仍认得出脸。20px 起显示腮红。
- 喙与脚同为一种橙色，线条同为一种棕色，所有颜色、两种明暗一致。
- 配饰为无、围巾、毛线帽、鸭舌帽、耳机、小芽、蝴蝶结、眼镜之一：取 id 哈希值除以 360 的商对 8 取余（颜色取的是余数），因此十二种颜色与八种配饰两两都会出现。配饰用色相环对面那一格的身体色，同样以棕线勾边。
- 内置的通用 Agent（`default_agent`）仍为绿色，不戴配饰。
- 三种画法的名字与所属主题不变：`flat` 圆角方块底（朴素）、`soft` 圆形底（白领、卡通）、`pixel` 方块底（极客，企鹅、轮廓与配饰都在 16 × 16 的格子上逐格画出；16px 以下整幅缩放，眼睛加宽一格）。
- UI 包新增导出 `AGENT_ACCESSORIES`、`agentAccessory(id)`、`AGENT_BEAK`、`AGENT_LINE` 与 `avatarHash(key)`；`AgentColors` 新增 `beak`、`line` 与 `accent`。
- 画廊的头像看板改画 14、18、24、48、96px，十二个示例 Agent 依次轮换配饰，并另起一行逐个标出配饰名称。
