# More space for long drafts on the start page

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `web`, `ui`
- **PR:** [#1696](https://github.com/Prism-Shadow/penguin-harness/pull/1696)

[中文版](2026-11-22-draft-input-height.zh.md)

The start-page message field grew with longer drafts. A handle below the field let writers adjust its height by dragging or using the up and down arrow keys. Shortening a long draft to one line restored the compact field.
