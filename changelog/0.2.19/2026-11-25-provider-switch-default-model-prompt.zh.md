# 保存分组密钥后支持切换带供应商标识的默认模型并自动置顶余额

- **Date:** 2026-11-25
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1850](https://github.com/Prism-Shadow/penguin-harness/pull/1850)

[English](2026-11-25-provider-switch-default-model-prompt.md)

连接或为任意模型分组手动保存密钥后，若当前默认模型不在该分组，弹窗询问切换时新旧模型均附带供应商括号标识，且用户确认后自动将该分组余额置顶到左下角。
