# 服务端：插件索引读取可配置的来源列表

- **Date:** 2026-11-15
- **Type:** feature
- **Scope:** `server`, `web`
- **PR:** [#1573](https://github.com/Prism-Shadow/penguin-harness/pull/1573)

[English](2026-11-15-plugin-index-sources.md)

插件页今天只读一份已发布索引，要同时看内部目录或镜像源的部署只能二选一。插件索引的来源现在是一个设置组（`plugin-index`，在管理员的设置对话框里）：一列按书写顺序尝试的 `index.json` 地址，随本版本发布的索引默认就在列表上——列表本身就是全部配置，没有旁边的开关。删掉发布索引地址或清空列表，则只列出随服务器内置的插件，且不发出任何出网请求。保存即生效，无需重启。

## 细节

- 多个来源合并成一张列表，先登记的先得：第一个登记某个包的地址提供它的整个条目——描述、版本与安装 channel——后面地址再列同一个包也不追加。读不到的地址按 URL 记入 `failures`，其余来源照常列出。
- 安装面用同一份列表、同一条规则解析包的 release channel：一个包的第一个登记者拥有它全部的行，安装取到的就是列表所显示的。
- 地址可以是 `http` 也可以是 `https`——内网镜像或自建目录。安装校验用的完整性哈希来自条目本身，加地址不产生绕过校验的路径。
