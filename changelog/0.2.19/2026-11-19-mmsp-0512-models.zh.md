# Gemini 4 Neon、Gemini Nano Banana 2.1 与 MMSP 0.5.12

- **Date:** 2026-11-19
- **Type:** feature
- **Scope:** `model-catalog`, `core`, `server`, `cli`, `docs`
- **PR:** [#1613](https://github.com/Prism-Shadow/penguin-harness/pull/1613)

[English](2026-11-19-mmsp-0512-models.md)

模型库加入了 Google 和 OpenRouter 的 Gemini 4 Neon 与 Gemini Nano Banana 2.1，PenguinHarness 升级到 [MMSP 0.5.12](https://github.com/Prism-Shadow/model-message-stream-protocol/releases/tag/v0.5.12)。已有项目可在模型库点击**同步新增模型**添加这些预设。当前选用的模型会保留。

## Gemini 4 Neon

- Google 的 `gemini-4-neon` 和 OpenRouter 的 `google/gemini-4-neon` 支持图像输入，上下文窗口为 1,048,576 个 token。
- 两者的牌价均为每百万 token 输入 3 美元、输出 15 美元、缓存命中 0.15 美元，没有促销。
- 在 Google 官方客户端上，`none` 按 `low` 运行，`max` 按 `xhigh` 运行。`low`、`medium`、`high` 和 `xhigh` 按所选档位发送。

## Gemini Nano Banana 2.1

- Google 的 `gemini-nano-banana-2.1` 通过 Interactions API 接收文本、图片和视频，最多可输入 131,072 个 token。
- OpenRouter 的 `google/gemini-nano-banana-2.1` 通过 Images API 接收文本提示词，可生成 1K 或 2K 图片。
- 两者只生成图片，因此目录将它们标为工具模型，对话的模型选择器不会列出它们。
- 公开价格按每百万 token 计算，输入为 1.50 美元，文本或思考输出为 7.50 美元，图像输出为 30 美元。模型库使用图像单价估算整段响应，单独上报的思考按 7.50 美元计算。响应中含普通文本时，估算可能高于账单。

## MMSP 0.5.12

- MMSP 不认识的模型，会得到其厂商最新一代所有模型都接受的思考档位。此前对旧默认值返回 400 的 Gemini 2.5 和 GPT-5 Mini，手动添加后即可使用。
- MiniMax M2.x 的 `none` 按 `low` 运行。
