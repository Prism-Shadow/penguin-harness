# 用 /plan 选择计划模式

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `cli`, `web`, `plugins`
- **PR:** [#1775](https://github.com/Prism-Shadow/penguin-harness/pull/1775)

[English](2026-11-23-plan-command.md)

普通对话的 Agent 启用 Plan 插件后，可选择 `/plan` 开启计划模式并继续输入。网页输入框和 CLI 均支持在 `/plan` 后接正文。后续消息沿用已选模式，直到手动关闭。
