# Open the first terminal in a Session

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `server`, `web`
- **PR:** [#1781](https://github.com/Prism-Shadow/penguin-harness/pull/1781)

[中文版](2026-11-23-session-side-terminal.zh.md)

Opening Terminal beside a Session focuses its current shell or starts one in its Workspace. Concurrent opens share that first shell. Closing the last shell leaves the tab strip available. Browsing the App Center terminal directory uses no terminal slots.
