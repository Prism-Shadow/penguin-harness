# Ship the Default Agent’s plugins with the product

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `server`, `cli`, `desktop`
- **PR:** [#1783](https://github.com/Prism-Shadow/penguin-harness/pull/1783)

[中文版](2026-11-23-default-agent-plugin-baseline.zh.md)

New Projects include Agent Company, the Computer Use skill, Continual Learning and Penguin Support on the Default Agent. Computer Use still requires an administrator to enable its desktop service. New Projects enable the native Git module for workbench history. Existing Projects keep their module settings, and newly created Agents in them can record workbench edits in their own Git history.

Ordinary Agents start without optional plugins. Goal and Plan can be selected at creation or installed later.
