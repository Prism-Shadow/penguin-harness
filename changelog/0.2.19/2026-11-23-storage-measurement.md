# See storage figures as soon as measurement finishes

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `storage`, `web`
- **PR:** [#1727](https://github.com/Prism-Shadow/penguin-harness/pull/1727)

[中文版](2026-11-23-storage-measurement.zh.md)

Settings shows a progress panel while storage is measured for the first time. The totals and categories appear as soon as the server finishes. Refresh keeps the last complete figures on screen while the new measurement runs.
