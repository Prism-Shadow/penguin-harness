# 应用示例要求走查游戏操作与研究来源

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1749](https://github.com/Prism-Shadow/penguin-harness/pull/1749)

[English](2026-11-23-playable-example-prompts.md)

企鹅滑雪、迷你游戏厅、英雄联盟音乐和节奏跑酷示例会要求智能体验证操作并说明结果。文档问答、投资分析、合同审阅工作台则要能追到来源段落、数据时间或原始条款，输入缺失或服务失败后可以继续操作。
