# Agent cards give names more room and show installed plugin counts

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1742](https://github.com/Prism-Shadow/penguin-harness/pull/1742)

[中文版](2026-11-23-agent-cards-inventory.zh.md)

Agent names have their own line. Machine names, IDs and status labels appear below them. Each card shows its installed plugin count immediately before Skills. The system Agent uses the same settings and inventory views, with read-only access to its installed plugins, skills and system apps.
