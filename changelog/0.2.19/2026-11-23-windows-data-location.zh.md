# Windows 桌面安装器支持选择数据目录

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `desktop`, `core`, `cli`, `server`
- **PR:** [#1759](https://github.com/Prism-Shadow/penguin-harness/pull/1759)

[English](2026-11-23-windows-data-location.md)

Windows 安装器可将服务数据与桌面配置保存在其他磁盘。升级时沿用当前位置，也可改选其他目录。校验与原件保留方式见[迁移已有数据](2026-11-23-backward-compatibility.zh.md)。
