# 从对话和应用中心打开会话工具

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1736](https://github.com/Prism-Shadow/penguin-harness/pull/1736)

[English](2026-11-23-session-shortcut-workbenches.md)

从应用中心打开文件、终端或浏览器时，可以选择当前项目中的会话，包括已归档会话和子智能体。终端与浏览器显示活动资源数量，可以关闭选定会话中的资源。对话快捷方式直接在来源会话旁打开工作台。
