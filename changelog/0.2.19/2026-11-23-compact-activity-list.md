# Compact thinking shows the current step

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`, `ui`
- **PR:** [#1730](https://github.com/Prism-Shadow/penguin-harness/pull/1730)

[中文版](2026-11-23-compact-activity-list.zh.md)

The compact row shows the current tool and its description or the thinking label, followed by the step count and elapsed time. Select the row to review every step in the group, including after reopening a conversation.
