# 并排打开对话与应用

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `web`, `ui`
- **PR:** [#1706](https://github.com/Prism-Shadow/penguin-harness/pull/1706)

[English](2026-11-22-session-app-pages.md)

侧栏列出当前窗口中已打开的对话与应用。可把页面放到左侧或右侧、交换两侧，或让一页占满主区。手机上可从同一列表选择要看的页面。

从对话中可以在正文旁浏览该 Agent 的工作台，每个工作台独立打开。「应用」与「工作区」可以分别整体折叠，应用列表支持搜索和排序。
