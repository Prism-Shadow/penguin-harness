# Change the model and thinking level in AI Slides

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `use-bento-slides`, `server`, `web`
- **PR:** [#1722](https://github.com/Prism-Shadow/penguin-harness/pull/1722)

[中文版](2026-11-23-slides-conversation-settings.zh.md)

Choose a model and thinking level before creating a presentation or while working on an existing one. A running request keeps its model. The conversation shows the active model and any queued switch, and the next model request uses the selected thinking level. Reopening a presentation restores its conversation settings.
