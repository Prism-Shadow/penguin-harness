# Give built-in apps their own icons

- **Date:** 2026-11-22
- **Type:** feature
- **Scope:** `ui`, `web`
- **PR:** [#1708](https://github.com/Prism-Shadow/penguin-harness/pull/1708)

[中文版](2026-11-22-system-app-icons.zh.md)

The built-in apps use distinct colors and the active theme’s glyphs. The App Center, folder previews, window titles and the System Agent app list use the same icon at each size.
