# Agent content plugins ship from PenguinHarness Apps

- **Date:** 2026-11-23
- **Type:** refactor

- **PR:** [#1751](https://github.com/Prism-Shadow/penguin-harness/pull/1751)

A2UI, External Plugin Porting and Firecrawl ship with the product from pinned release packages and remain available on a fresh default Agent offline. Action Minutes, Continual Learning, Daily Draw, Fridge Keeper, Humanizer, Party Charades, Reading Desk, Tabletop Desk and Claude Code are available separately through the plugin marketplace. Existing Agent files and preferences keep their original identifiers.
