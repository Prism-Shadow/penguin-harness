# Use skill shortcuts in an interjection

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1773](https://github.com/Prism-Shadow/penguin-harness/pull/1773)

[中文版](2026-11-23-steering-slash-menu.zh.md)

Type `/` in a running conversation to choose one of the Agent’s installed skills. Selecting a skill keeps the interjection open for editing. Sending it includes the chosen skill in the running Task.
