# 插件市场可往返查看服务端与 Agent 安装步骤

- **Date:** 2026-11-23
- **Type:** feature
- **Scope:** `web`
- **PR:** [#1729](https://github.com/Prism-Shadow/penguin-harness/pull/1729)

[English](2026-11-23-plugin-install-steps.md)

市场卡片和详情打开同一安装流程。从 Agent 步骤可返回查看服务端上的插件包，再继续选择 Agent。Project 所有者可单独卸载某个 Agent 的副本，服务端管理员可在移除插件包前核对受影响的安装。
