# 手机宽度下的界面不再越出自己的盒子

- **Date:** 2026-08-23
- **Type:** fix
- **Scope:** `web`
- **PR:** [#430](https://github.com/Prism-Shadow/penguin-harness/pull/430)

[English](2026-08-23-phone-width-overflow.md)

Web App 有四处在手机宽度下把自己排得比所在的盒子更宽，各自都让读者够不到本该看到的东西——被挤出屏幕、
越过卡片边缘，或压在旁边的控件上。现在四处都留在各自的盒子之内。

## 技能库

- 技能卡片的操作按钮——快捷调用、管理安装、更新安装——被带到屏幕右缘之外，又被分组区块裁掉，因此
  一个都点不到。卡片网格现在在 `sm` 断点以下显式声明单列轨道，不再任其隐式生成，卡片也就不会再被
  撑到足以完整容纳其中最长的那条描述。

## 成本中心

- 最近异常表格把消息列压缩到零宽度，并把其余三列推出右缘，连带整个页面横向滚动。表格现在写明四列
  所需的最小宽度，并在自己的盒子内横向滚动，页面本身不再滚动。

## Agent 列表

- Agent 卡片的统计行——会话、工具、技能、记忆、保险柜密钥、定时任务、最近修改——在手机宽度下越过卡片
  内边距，把最后一项带到卡片边缘上。该行现在改为换到第二行；本来就排得下的宽度下位置不变。

## Agent 记忆设置

- 记忆分组的标题栏把自己的标题与条数挤出折叠按钮，压在旁边的导出、导入操作之上。标题现在在按钮内截断
  而不再逸出，且在宽度小于 28rem 的行上，三个分组操作保留图标、去掉文字标签——这正是该标题栏在其他方面
  一直沿用的模型页分组标题栏惯例。任何宽度下都不会隐藏操作本身，每个操作都以 tooltip 和无障碍名称说明
  自己是什么。

## 同一形态的其他位置

- 另有两处网格只声明了带断点的列数而没有基础轨道：模型页的模型卡片，以及 Benchmark 用例浏览器的
  侧栏／详情分栏。两者现在都在断点以下明确声明单列轨道，因此都不会再像技能卡片那样被子元素无法
  截断的内容撑开。对 Web App 中所有 `grid-cols-` 位置的排查未发现其他同类。
