# Changelog

[中文版](CHANGELOG.zh.md)

One brief line per release. Per-release detail lives in [`changelog/<version>/`](changelog/).

- **0.2.3** — 2026-08-19. Conversations you can branch, take back and watch: forking a Session from a completed reply, recalling queued steering and follow-up messages into the composer, live per-row Session status in the sidebar, a compaction rework (tool results kept, interrupted compactions discarded, a summary that streams into a collapsed row, and compaction working on a Session resumed after a restart), thinking levels selectable wherever the work happens with a mid-chat switch that states its cost and a new `max` tier from AgentHub 0.4.4, custom-model protocol and vision detection alongside a per-model fast mode, the session row's hover pair back beside a right-click menu, drag-and-drop composer attachments, and in-place hot updates of a running harness. ([details](changelog/0.2.3/))
- **0.2.2** — 2026-08-11. Long-term Memory across sessions (per-agent user and Workspace scopes, index-only injection, a Memory tab), MCP Server support over stdio / Streamable HTTP / SSE with in-app management, Skills/Vault/Schedules behind Memory-style editable prompts and enable switches, dated config kernel versions with a smart no-loss Update beside restore, a hardened core runtime (unlimited default turns, context-window-derived caps, atomic Trace appends), desktop and proxy polish, a web UX batch, and a clean dependency audit. ([details](changelog/0.2.2/))
- **0.2.1** — 2026-08-04. The desktop app: an Electron shell over the unchanged server and Web App (signed-in on open, shared data root, per-root single-instance lock, three-platform installers mirrored to OSS), a landing download page with mirror-aware static links, download source selection for standalone installers and `penguin update`, compaction that survives malformed summaries with retries and costs finally visible, a random seeded admin password with login throttling, skills manageable from agent settings, per-Project new-chat defaults, a Traces page scaled onto a SQLite trace index, and the server's last IO hotspots closed. ([details](changelog/0.2.1/))
- **0.2.0** — 2026-08-03. One sealed installer bundle per target serving online and offline installs alike — now mirrored to Alibaba Cloud OSS with automatic fallback — truncated tool output recovered from the Session scratchpad, chat navigation for long conversations (shell-style ↑ input recall, stacked sticky run headers, a minimap tick rail with hover previews), steering that survives reloads and carries file attachments, a DB-served session list with paged sidebar groups, and the refreshed qianwenai / OpenRouter model catalog defaulting to deepseek-v4-flash. ([details](changelog/0.2.0/))
- **0.1.5** — 2026-07-30. Self-contained offline installer bundles for all five platforms (with MinGit bundled on Windows), composer attachments of any file type with images reaching steering and goal objectives, in-run recovery for every LLM failure short of a rejected credential, a tenth-shorter default system prompt, the paper-editorial web-design theme with thinking/image guidance in the SDK skill, and a refreshed README/landing install story. ([details](changelog/0.1.5/))
- **0.1.4** — 2026-07-27. Carries the whole 0.1.3 feature set to npm, which 0.1.3 itself never reached: its publish job failed on a version-endpoint test asserting a hard-coded build date, and only the release jobs stamp one. Plus blog images hosted in the sibling community repo rather than in this clone. ([details](changelog/0.1.4/))
- **0.1.3** — 2026-07-27. Windows support (shell selection, `install.ps1`, a win-x64 package), goal mode looping Tasks until an objective completes, a docked subagents panel with a live call graph, LLM-error reconnects with a visible countdown, and in-app version display with update checks and admin self-update. ([details](changelog/0.1.3/))
- **0.1.2** — 2026-07-26. Builtin file tools with git-style edit diffs, mid-run steering and queued follow-ups, handoff-style model switching with a per-request thinking level, free OpenRouter models, and isolated-origin Workspace HTML previews. ([details](changelog/0.1.2/))
- **0.1.1** — 2026-07-22. Gemini 3.6 Flash and 3.5 Flash-Lite in the model catalog, a Workspace-grouped chat sidebar, in-place upgrades via `penguin update`, and the vLLM / Ollama / LlamaFactory and bento-slides skills. ([details](changelog/0.1.1/))
- **0.1.0** — 2026-07-21. First feature release: the Web App, landing site and docs, the model catalog, and the self-improvement skills. ([details](changelog/0.1.0/))
- **0.0.1** — 2026-07-19. First tagged release; changelog history starts after this tag.
