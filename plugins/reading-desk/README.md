# Reading Desk

Install Reading Desk on an Agent from Utilities in the plugin market. Open **Reading Desk** from the App Center or from that Agent's tabs.

Import an EPUB, Word document (.docx), Markdown file or UTF-8/GB18030 text file up to 32 MB. Find a title or author on the bookshelf. Each book shows its progress, and Continue reading opens the last passage. EPUBs with embedded covers display their own artwork. Use the contents to change chapters and the type controls to adjust the text size. EPUBs follow the book's spine. Text and Word imports recognize chapter headings.

Select text in a paragraph and choose **Highlight**. The **Notebook** lets you annotate the passage, return to it and download the current book's notes as Markdown.

The shelf, notes and reading position belong to this browser and the selected workbench. Reopening restores the shelf or the passage you were reading. Clearing this site's browser storage clears the shelf. The starter story can be read before importing a book.
