# 阅读工作台

从插件市场的「实用工具」给 Agent 安装阅读工作台，然后在应用中心或该 Agent 的标签页里打开它。

可导入 32 MB 以内的 EPUB、Word 文稿（.docx）、Markdown，以及 UTF-8 或 GB18030 编码的纯文本。在书架按书名或作者查找，查看每本书的进度，点「继续阅读」回到上次的段落。带内嵌封面的 EPUB 会显示原书封面。用目录切换章节，通过字号按钮调整文字大小。EPUB 按照书中顺序排列，文本和 Word 文稿会识别章节标题。

在同一段中选中文字后点「划线」。打开「笔记本」，可以写下想法、跳回原文，也可以把当前书籍的笔记下载为 Markdown。

书架、笔记和阅读位置保存在当前浏览器中，按工作台分别存放。重新打开会回到离开时的书架或正在读的段落。清理本站的浏览器数据也会清空书架。尚未导入书籍时，可以先翻阅随附的短篇故事。
