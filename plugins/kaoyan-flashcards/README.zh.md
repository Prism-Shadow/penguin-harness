# 考研记忆卡

考研题库、间隔复习与背诵资料，就在 Agent 旁边的一个标签页里。

## 它能做什么

- 用 295 道示例题刷题，覆盖六个科目（数学一、英语一、思想政治、计算机 408、机械设计、经济学），可按整科或单章来刷，并按题型、关键词和范围筛选。
- 每张卡评级后自动排下一次复习：「不会」约 10 小时后、「模糊」1 天后、「会了」依次在 1、2、4、7、15、30 天后，之后每 60 天。答错的题进错题本，也可以收藏。
- 内置 9 篇短篇背诵资料：点段落即可标记，打开「遮重点」会把标记段落里的关键词遮住，点一下段落再核对。
- 可导入自己的资料：.docx、.pdf、.txt、.md 文件或直接粘贴的文字。带题号、选项和答案行的题目变成刷题卡片，其余文字进入背诵。
- 首页显示每日目标、连续打卡天数和正确率；公式由内置渲染器显示，不依赖外部库。
- 界面有中文和英文两种：默认跟随设备语言，顶栏的按钮可以切换并记住你的选择。题目和背诵资料本身是中文。

## 开始使用

1. 在「插件」页把「考研记忆卡」安装到一个 Agent 上。它不会预装到任何 Agent。
2. 打开该 Agent 对话旁的「考研记忆卡」标签页，或应用中心里的对应图标。
3. 接着：
   - 在首页点「开始今日计划」，从第一个科目开始刷题。
   - 选一个选项，或点「显示答案」，再给这张卡评「不会」「模糊」或「会了」。键盘上：空格看答案，1 / 2 / 3 评级，左右方向键切题。
   - 打开「背诵」，点两三段做标记，再打开「遮重点」。

## 你的数据

- 学习进度（评级、复习日期、错题、收藏、标记、你选的界面语言，以及你导入的卡片和资料）保存在服务器上这个工作台自己的状态里，跟随这个 Agent；浏览器里只留一份缓存，所以换一个浏览器也能看到同样的进度。单条超过 512 KB 的数据（例如一份很大的导入 PDF）只留在导入它的那个浏览器里。
- 不会向任何其他主机发送数据。页面不加载任何远程脚本、样式或字体，导入的文件在浏览器内解析。页面只请求本应用自己的服务器：页面本身、两个数据文件和你的存档。
- 「筛选与设置」抽屉里的「导出学习数据」会把这些数据下载为一个 JSON 文件，「导入学习数据」可以把它恢复回来。
- 从 Agent 上移除这个工作台时，它的存档会一并删除。

## 按你的需要改

这个工作台的源码就在 Agent 自己的文件里（`workbenches/kaoyan-flashcards/`），你提出要求，Agent 就能修改它。题库是 `ui/data/decks.json`（一行一道题），背诵资料是 `ui/data/docs.json`，中英文界面文字在 `ui/i18n.js`。例如：

- 「加一个『管理学』题库，20 道组织行为学的单选题，每题附一句解析。」
- 「把『会了』之后的复习间隔改成 1、3、7、14 天，之后每 30 天。」

插件更新会替换源码，包括 Agent 对源码做过的修改；学习进度会保留。
