# 拼豆创作工作台

把一张图片换算成能照着摆的拼豆图纸：网格、色号图例、每色颗数、所需拼板与成品尺寸。

## 功能

- 把图片（PNG、JPG、WebP、GIF 或 BMP，不超过 24 MB；可拖入、点选或粘贴）换算成每边 29、40、52、76 或 104 格的拼豆网格，也可自定义 4–200 格。
- 先分析画面，再推荐图纸尺寸、颜色数量、色卡、取色方式、杂色合并与背景处理，并逐项给出理由；「专业设计」模式可逐项调整，任何改动都会自动重算图纸。
- 按感知色差（CIEDE2000）把每一格匹配到拼豆色卡，列出每种颜色的色号、色名与颗数，并给出 29 × 29 或 50 × 50 拼板的块数和以厘米计的成品尺寸。
- 按手上的实物校准色卡：修改色值、标记缺货、导入自己的色卡，或把缺货色替换成最接近的颜色。
- 导出带网格与图例的 PNG 图纸、逐颗列出的 CSV、完整图纸数据的 JSON，以及按 A4 排版的打印页。
- 界面有中文和英文两种：默认跟随设备语言，顶栏的按钮可以切换并记住你的选择。

## 快速上手

1. 在「插件」页把「拼豆创作工作台」安装到某个 Agent 上（它不会预装到任何 Agent），然后打开该 Agent 聊天旁的「拼豆创作工作台」标签页，或应用中心里的图标。
2. 第一次打开时，示例爱心已经生成好图纸。把自己的图片拖到「素材」区、点击该区选择文件，或用 Ctrl+V 直接粘贴。
3. 看「快速生成」给出的推荐后点「直接生成图纸」，或切到「专业设计」逐项调整。
4. 点「图例与用量」里的一行或图上的一颗豆，只显示该颜色；行尾的「⋯」会列出最接近的替代色。然后用「PNG 图纸」「CSV 数据」「JSON」或「打印页」（在新标签页打开）导出。

### 参数说明

| 参数 | 选项 | 说明 |
| --- | --- | --- |
| 图纸尺寸 | 29 / 40 / 52 / 76 / 104 / 自定义 4–200 | 格数不是厘米；格子越少越省豆，29 格约 841 颗，52 格约 2,704 颗 |
| 颜色数量 | 自动 / 12 / 18 / 29 / 40 / 64 / 96 | 自动按尺寸给足色数（52 格最多 36 色，76 格 48 色）；96 即不压缩，以色卡容量为上限 |
| 色卡体系 | 基础 29 色 / 通用 96 色 / 马卡龙 40 色 / 自定义 | 在「色卡」面板里可改色值、标记缺货或导入色卡 |
| 取色方式 | 面积平均 / 中心点 / 众数 / 中位数 | 照片用面积平均，插画与像素图用中心点 |
| 杂色合并 | 无 / 轻 / 中 / 强 | 先清小色块，再抹孤立单颗 |
| 轮廓增强 | 自动 / 关闭 | 缩小时边缘会被抹平，自动增强把轮廓与五官重新拉开 |
| 拼豆规格 | 2.6 / 5 / 10 mm | 成品尺寸 = 格数 × 规格 |
| 背景处理 | 自动去背 / 保留 / 纯色替换 / 透明留空 | 自动去背从四周边框色向内连通填充 |
| 构图 | 裁切铺满 / 完整留白 | 完整留白时，留白区不摆豆 |

快捷键：`+` / `−` 缩放，`0` 适应窗口，`G` 网格，`C` 坐标，`Esc` 取消隔离或关闭弹窗。

### 关于色号

内置色号取自常用色卡编号，屏幕色值为近似值，与实物有差异。采购前请对照手上的实物：顶部「色卡」按钮可以逐色微调，或整份导入自己的色卡，每行一色，格式为 `色号,色名,hex`：

```
H05,红,#E2231A
H01,白,#FFFFFF
```

导入至少需要 4 行有效颜色，导入后作为「自定义色卡」出现在色卡列表里。缺色替换只从当前色卡里给出候选色及其色差，不会编造色卡之外的颜色。

## 你的数据

- 你的参数设置、界面语言、校准过的色值和导入的色卡保存在这个工作台自己的状态里（在你的 PenguinHarness 服务器上），浏览器存储只作缓存，因此换一个浏览器打开同一个 Agent 也能看到。
- 载入的图片和由它生成的图纸不会保存，只在页面打开期间存在；关闭或刷新前请导出需要保留的内容。
- 图片只在浏览器内读取和计算，不会发送到任何地方。页面只与你自己的 PenguinHarness 服务器上的这个工作台通信：保存你的设置；导出时把导出文件在内存里暂存至多 15 分钟（最多 16 个文件、合计 48 MB），供浏览器下载。不会联系任何其他主机。
- 移除这个工作台会删除它在服务器上保存的数据；若某个浏览器里仍有缓存，同一个 Agent 再次安装该工作台时，这份缓存会被重新上传。

## 按需修改

工作台是 Agent 自己文件里的源代码，你可以直接让 Agent 修改它。例如：

- 「在『基础 29 色』旁边加一个我常用品牌的内置色卡，色号、色名和色值如下：……」
- 「把打印页拆成每块 29 × 29 拼板一页 A4，每页标题写明这块板对应的行列范围。」

代码位置都在 `workbenches/perler-studio/ui/assets/js/` 下：`palettes.js` 是内置色卡，`color.js` 是色彩数学，`engine.js` 是图纸流程（逐格取色、匹配色卡、限制色数、合并杂色、统计），`render.js` 负责绘制网格，`exporters.js` 负责四种导出，`app.js` 是界面交互，`i18n.js` 是中英文界面文字。`workbenches/perler-studio/index.ts` 中的 handler 负责保存设置和暂存导出文件。

更新插件会用新版本替换这份源代码，Agent 做过的修改也会被替换。
