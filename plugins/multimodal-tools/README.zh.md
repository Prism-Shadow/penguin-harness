# 多模态工具

用项目的模型生成文字、理解图片、搜索网页、读取网页、生成图片、视频或语音，以及转写录音。Agent 经插件自带的 `multimodal-tools` 技能以 `penguin tools …` 使用这些工具；Web App 的语音输入和朗读回复也用同一套工具。

每个工具使用项目模型设置中为它绑定的模型（图片理解使用项目的视觉模型）。运行 `penguin tools list` 可查看哪些工具已有模型。每次请求都记入项目用量，与对话请求同样计价，并归属发起它的会话。

工具生成的文件属于其会话：保存在项目目录中，会话不在后随之删除。本地文件只经 `--image` 与 `--audio` 交给工具，生成的文件保存到 `--out` 指定的目录。技能里的[命令示例](skills/multimodal-tools/SKILL.md)说明如何跟进、保存和取消耗时较长的任务。

把插件安装到 Agent 时会一并带上它的服务端模块，由它提供这些命令和 Web App 用到的路由。

插件还带有**图像工作室**，可从应用中心或 Agent 的标签页打开。描述图像、选择画幅，然后点击**生成图像**：每次创作都会为该 Agent 新建一个会话，由它在会话中运行 `penguin tools t2i`，工作室展示并提供下载该会话生成的图像。从历史记录重新打开创作即可再次查看；已取消或失败的创作连同状态保留在历史记录中。项目关闭插件后，已有图像仍可查看，新的创作要等重新启用后才能开始。
