# 多模态工具

用项目选择的模型搜索或读取网页、生成图片和视频、将录音转为文字，或把文字读出来。新项目默认启用「多模态工具」，可在项目插件页管理。到项目的模型设置为所需操作选择供应方和模型。运行 `penguin tools list --json` 可查看当前可用操作和绑定。

插件同时提供图像工作室和 `multimodal-tools` 技能。新建项目的默认 Agent 会自动获得；其他 Agent 可从自己的插件库添加。技能里的[命令示例](skills/multimodal-tools/SKILL.md)说明如何把生成的文件保存在工作区、跟进或取消任务，以及怎样取回本次会话的产物。

为某个项目关闭服务器插件后，该项目不再提供这些操作。项目会保留已选模型、会话、以前的产物与用量记录，再次启用时可继续使用。

在应用中心或智能体标签页打开**图像工作室**。描述图像、选择画幅，然后点击**生成图像**。每次创作都会新建一个会话，由智能体调用项目绑定的模型。工作室从该会话的产物中读取真实图像。可以从历史记录打开作品，查看或下载图片，也可以查看已取消或失败的创作。
