# Bento 幻灯片

用 [Bento Slides](https://bento.page) 制作幻灯片。Bento 是一款以 JSON 为文稿格式的幻灯片编辑器。本插件包含两部分：

- **幻灯片工作台（AI PPT）**：Agent 对话旁的一个标签页，里面是完整的幻灯片编辑器。你在这里修改文稿的同时，Agent 修改同一份文稿，任何一方保存后，另一方立即看到。
- **`bento-slides` Skill**：Agent 编写和修改文稿的方法，既适用于工作台里的文稿，也适用于工作区里自成一体的 `.bento.html` 文件。

新建 Project 时，`default_agent` 会预装本插件；其他 Agent 可从插件库安装。

## 幻灯片工作台

- **从模板新建。** 在首页逐页预览项目简报或团队复盘，命名后创建可编辑的演示文稿。导出的 PowerPoint 保留文字、形状和演讲备注。
- **打开已有文稿**。首页按最近编辑时间排列保存的演示文稿，可打开、重命名或删除。点「文件 → 保存演示文稿」或按 Ctrl+S、Cmd+S，会把正在输入的文字一起写入当前文稿。
- **标签页里的完整编辑器**：Bento 自己的编辑器，含幻灯片列表、画布、文本、形状、图片、表格、图表、morph 过渡与演讲者模式。
- **用一句话提出修改**：编辑器旁的侧栏把你的请求连同当前所在的幻灯片和选中的元素一起发给 Agent，「把这一页的数字做成柱状图」指的就是这一页。
- **双方编辑同一份文稿**：一份文稿就是一个文件。编辑器把你的修改保存进去，Agent 用自己的工具修改它；哪一方最后保存，另一方在一秒内载入。在普通对话里提出请求也一样：Agent 写的是同一个文件。
- **双方的修改都会保留**：你还有未保存的修改时 Agent 保存了文稿，你的修改会按元素重放到它的版本之上。双方改了同一个属性时保留你的值，工作台会提示，Agent 的版本存入文稿的**文件 → 历史版本**，任何一个版本都可以恢复。
- **文稿可以带走**：**导出为 PowerPoint 文件（.pptx）** 可下载 .pptx，在 PowerPoint 里继续编辑文字、形状、表格和支持的图表。想保留原有动画、媒体和编辑器，可用**下载 Bento HTML 文件（.html）** 得到一个自成一体的 `.bento.html`，任何浏览器都能打开，编辑器就在文件里；**导入 Bento HTML 或 JSON…**可以把它或文稿的 `.json` 再导回来。

开始使用：打开 Agent 对话旁的**幻灯片**标签页，或应用中心里的 **AI PPT**。描述一份文稿后选择**让 AI 生成**，或打开示例文稿。然后点开一页，在右侧侧栏写下要改什么，Agent 工作时你可以继续编辑。

## 你的数据

- 文稿随 Agent 存放在服务端：`app/data/<Agent ID>.slides/decks/<名称>.bento.json`，一份文稿一个 JSON 文件；`history/` 下保留最近二十个被另一方替换的版本。
- 编辑器运行在沙盒框架里，没有自己的源，安全策略不允许任何网络连接：它访问不到互联网、应用的 API 和你的登录状态。因此 Bento 的更新检查、实时共享和远程媒体在工作台里不可用；图片嵌入在文稿里。
- 工作台不向任何其他主机发送数据。Agent 自己的工作和任何对话一样，发给你配置的模型。
- 更新或重新安装工作台时，文稿保留在 Agent 的应用数据中。在文件列表中删除文稿时，它的历史版本会一并删除。

## 已知限制

- 工作台和编辑器使用应用语言，演示文稿保留自身的幻灯片配色。
- 在应用的框架里无法打印、导出 PDF 或真正全屏。请导出文稿，在浏览器标签页里演示或打印；Bento 自带的「铺满标签页」演示在工作台里可用。
