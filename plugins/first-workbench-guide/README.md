# Your first workbench

Open **Your first workbench** from the App Center for the default Agent. **Open Models settings** takes you to the native provider setup. Return to the guide and choose a chat model.

Describe a task and send it to the Agent. After its reply, add any changes and choose **Generate checklist**. The same Session produces the checklist title, task groups and completion criteria. Review the preview, then choose **Install on this Agent**. **Test installed checklist** adds a temporary task, checks it off, reads it back and removes it. **Open checklist** opens the installed app.

**Download plugin ZIP** saves the complete content plugin. An administrator can import the ZIP on the Plugins page and a Project member can add its workbench to an Agent. The package includes the generated content and the checklist implementation. Installing it does not require the guide or access to the original conversation.

The guide uses the model selected for this conversation. Both turns run with tools denied. The generated content is data for the packaged checklist editor.
