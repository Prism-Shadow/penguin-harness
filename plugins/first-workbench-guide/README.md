# Your first workbench

The guide starts in the conversation when you first enter a project you own, on an agent with the plugin installed. Connect a model provider when needed, then send your own task in the real composer. You can dismiss the guide at any point and resume it from **Settings → General**.

After reading the reply, select **Use this conversation**. Review the text and any changes, then choose **Generate checklist**. The guide uses the selected conversation’s model to generate the checklist with tool use denied. Review the title, groups and completion criteria before installing it on the agent.

**Open checklist** opens the installed app. **Test checklist** adds a temporary task, marks it complete, reads it back and removes it. **Download plugin** saves the complete plugin ZIP, including the generated content and the checklist editor. An administrator can import it on the Plugins page for other agents to install.
