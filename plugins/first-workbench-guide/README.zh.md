# 我的第一个工作台

首次进入已安装此插件的 Agent 对话时，会在对话旁显示引导。项目所有者可按需连接模型服务商。已有可用模型时，项目成员也能用自己的对话制作清单。可以随时收起引导，也可以从「设置 → 通用」继续。

读完回复后，点击「使用这段对话」。核对内容、填写修改意见后，再点击「生成清单」。引导使用这段对话的模型生成清单，生成期间禁止调用工具。预览清单标题、分组和完成条件后，将其安装到当前智能体。

「打开清单」进入已安装的工作台。「测试清单」添加临时条目、标记完成、回读并清理。「下载插件」可导出包含清单内容和编辑器的完整 ZIP 包，管理员可以在插件市场导入，供其他智能体安装。
