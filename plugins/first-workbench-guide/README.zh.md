# 我的第一个工作台

在默认 Agent 的应用中心打开「我的第一个工作台」。点击「打开模型设置」进入提供商配置页面，然后返回引导，选择对话模型。

描述一件手头要做的事并发送给 Agent。收到回复后，可以补充要求，再点击「生成清单」。Agent 在同一次对话中生成清单标题、任务分组和完成条件。预览后，点击「安装到当前 Agent」。「测试已安装的清单」会添加临时任务，将其勾选、回读并移除。点击「打开清单」即可使用安装好的工作台。

「下载插件 ZIP」会保存完整的内容插件。管理员可以在插件页导入这个 ZIP，项目成员可以从插件库将工作台添加到 Agent。插件包包含生成的内容和清单编辑器，安装时不需要引导插件，也不需要访问原来的对话。

引导使用你为本次对话选择的模型，两轮对话均禁用工具。模型生成的内容作为数据交给插件自带的清单编辑器。
