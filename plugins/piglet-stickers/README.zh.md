# 猪猪的摸鱼小世界

一款粉嫩的贴纸小游戏，主角是一只 emoji 风格的小猪：用小猪、家具和小零食布置小房间和小花园，再把它们存成图片。

## 它能做什么

- 208 张贴纸分在七个栏目（小猪、家具、植物、美食、装饰、自然、生活），放到画布上之后可以拖动、缩放、旋转、翻转、调整层级、复制和锁定。
- 小猪是为这个游戏原创绘制的一个角色：宽宽的豆子形脸蛋、尖端向前折下的小立耳、胶囊形的鼻子和亮晶晶的眼睛，共 36 套装扮。在画布上双击小猪可以换表情。
- 13 个场景，从粉色卧室、草莓花园到星空露营地，另有一张空白画布。
- 10 个主题关卡、每天 3 个今日目标和随机盲盒；攒下的星星可以解锁 4 只限定小猪。
- 作品存在「我的作品」里，每一张都能导出为 1600 × 1600 的 PNG。
- 支持中文和英文：默认跟随设备语言，首页和每个顶栏里的「EN／中文」按钮可以切换，并会记住你的选择。

## 开始使用

1. 在「插件」页把猪猪的摸鱼小世界安装到一个 Agent 上（它不会预装到任何 Agent）。
2. 打开这个 Agent 对话旁的**猪猪的摸鱼小世界**标签页，或在**应用中心**点开它的图标。
3. 先点这三处：
   - **开始造景**，再选一个场景。
   - 底部栏里的任意一张贴纸：它会落到画布上。拖动可以移动，拖四角可以缩放，双击小猪可以换表情。
   - 顶栏的保存图标，把场景存进**我的作品**；旁边的下载图标可以导出 PNG。

想要有目标地玩，就从首页进入**主题关卡**。

## 你的数据

- **进度存在哪里。** 星星、今日目标、已通过的关卡、收集和收藏的贴纸、音效开关、你选择的语言、当前草稿和已保存的作品，都由工作台存在 PenguinHarness 服务端它自己的状态里，每个 Agent 各有一份；浏览器的本地存储只是它的缓存。换一个浏览器打开这个标签页，页面自动刷新一次后进度就接上了。
- **网络上传什么。** 页面只与你所登录的 PenguinHarness 服务端上它自己的工作台通信，用来读取和保存这些存档，不会访问任何其他地址：贴纸和场景由页面绘制，音效在浏览器里合成，PNG 也在浏览器里生成。
- **移除时。** 从 Agent 上移除这个工作台，或从该 Agent 卸载这个插件，都会删除服务端上的存档；插件更新会保留存档。最后玩过的浏览器里仍留有一份缓存，清除该站点数据即可删掉；如果之后在同一个 Agent 上重新安装，这个浏览器会把缓存里的进度传回去。

## 按你的想法改

这个工作台是 Agent 自己文件里的源代码，你提出要求，Agent 就可以改它。例如：

- “加一个图书馆场景，有高高的书架和一盏阅读灯，再在那里加第 11 关，要求两只小猪和三本书。”
- “在「自然」栏里加一组秋天贴纸：栗子、橡果、松果和一片红枫叶，画成同样的粉彩风格。”

文件位置都在 `workbenches/piglet-stickers/ui/` 下：`art.js` 是绘图工具、小猪（`pig()`）以及它的帽子、服装和道具；`stickers.js` 是贴纸登记表；`scenes.js` 是场景；`game.js` 是游戏本身；`i18n.js` 是两种语言的全部文字，贴纸名称也在其中。贴纸编号按位置排列，新贴纸要加在所在列表的末尾，并在两份词典里都补上名称。

插件更新会用新版本替换这些源代码，Agent 做过的修改也会被覆盖；你的存档不受影响。
