# 英语学习工作台

放在 Agent 旁边的每日英语练习台：名著逐词点读，遇到的词随手收藏，按时复习。

## 它能做什么

- 逐句精读三部公版名著（《傲慢与偏见》《波希米亚丑闻》《弗兰肯斯坦》）：点句子朗读，点单词看注释，可以慢速，也可以录音跟读。
- 粘贴任何一篇英文文章（新闻、公众号文章都行），同样点读。内置的新闻和 TED 精选带标注词、摘要或简介和观点问题，全文留在原站阅读。
- 词句库收藏单词和句子，配间隔复习（1、2、4、7、15 天后再来）和最近 30 天的学习热力图。
- 每天 15、30 或 45 分钟的学习计划，分四个档位；雅思、托福、四六级、考研的小题配示范答案。
- 可选的每日外刊：从固定的几个公开新闻订阅源列出今天的标题，默认关闭，打开后才联网。
- 中英文界面：按设备语言显示，顶栏的按钮（或「设置」→「界面语言」）可以切换并记住你的选择。学习材料保持原样：英文原文，以及随附的中文释义、译文和注释。

## 开始使用

1. 在插件页把「英语学习工作台」安装到一个 Agent 上。它是内置插件，但不会预装到任何 Agent。
2. 打开这个 Agent，聊天旁边会出现「英语学习工作台」标签页；也可以从应用中心点它的图标打开。
3. 接着：
   - 在「今日工作台」选今天有多少时间（15、30 或 45 分钟）；
   - 打开「名著轻阅读」→ Pride and Prejudice，点一个句子听朗读，点一个单词看注释；
   - 在一两个词上点「加入词句库」，再到「我的词句库」→「复习」试试复习题。

## 你的数据

学习进度（设置、收藏的单词和句子、笔记、答题和粘贴的文章）作为一份文档，保存在你的 PenguinHarness 服务端这个工作台自己的状态里。页面不在浏览器里留副本，所以换一个浏览器打开同一个工作台，记录还在。「设置」→「数据」可以导出为 JSON 文件。唯一由浏览器记住的是你选的界面语言，单独存一个键，内容只有「zh」或「en」。

默认情况下，工作台不向互联网发送任何内容。会联网的情形都由你决定：

- **每日外刊（打开开关之后）。** 打开外刊页且列表超过 20 分钟、或者点刷新时，服务端读取 feeds.npr.org、feeds.a.dj.com、www.latimes.com、www.wired.com、www.smithsonianmag.com、www.sciencedaily.com、www.nature.com 的 RSS，并以 `PenguinHarness-EnglishWorkbench/1.0` 的名义访问。随后你的浏览器会按订阅源给出的地址直接加载封面图，不发送来源页（Referer）。关掉开关后，页面保留上一次的列表，不显示封面，也不再抓取。
- **你点开的链接**会在新标签页打开原站。
- **朗读**使用浏览器自带的语音。页面优先选择在本机运行的语音；如果浏览器只有云端英文语音，浏览器会把正在朗读的文字发给对应的语音服务。
- **跟读录音**只在你点击后才使用麦克风，录音只留在当前页面里，刷新即消失。

移除这个工作台会一并删除它保存的记录。

## 按你的需要改

工作台是这个 Agent 自己文件里的源代码，你提要求，Agent 就能改。比如：

- 「在名著轻阅读里加第四本书：《简·爱》公版原文里的两段，配标注词和中文译文，格式和其他书一样。」
- 「在考试专项里加五道关于中国传统节日的六级翻译题，每题配示范答案和三个值得复用的表达。」

文件位置，都在 `workbenches/english/ui/` 下：`content.js` 是学习材料（名著、新闻与 TED 精选、考试题、视频、公众号和资源清单、每日计划），`app.js` 是页面逻辑，`i18n.js` 是两种语言的界面文字，`styles.css` 是样式。`workbenches/english/index.ts` 里的处理程序保存学习记录，并在打开开关后读取外刊订阅源。

更新插件会用新版本替换这些源代码，Agent 做过的修改也会被覆盖。
